= 在 Active IQ Unified Manager 中建立報告，以根據傳輸大小檢視 Volume 傳輸
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以建立報告，按傳輸大小檢視 Volume 傳輸情況。

.開始之前
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。


請依照下列步驟建立基於傳輸大小的 Volume 傳輸自訂檢視，然後排程為該檢視產生報告。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備* > *Volume*。
. 在「檢視」功能表中，選擇 *關係* > *最近 1 個月的傳輸速率*。
. 按一下 "`總傳輸大小`" 欄的頂部，依大小對 Volume 傳輸進行排序。
. 將檢視儲存為能夠反映檢視內容的特定名稱，例如 "`依傳輸大小區分的 Volume`"。
. 在庫存頁面上點選 *排程報告* 按鈕。
. 輸入報告排程的名稱並完成其他報告欄位，然後按一下列末尾的勾號（image:../media/blue_check.gif[""]）。
+
報告會立即作為測試傳送。之後，報告會產生並依指定的頻率透過電子郵件傳送給列出的收件者。



根據報告中顯示的結果，您可以依傳輸大小來調查 Volume 關係。
