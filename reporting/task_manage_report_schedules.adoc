= 在 Active IQ Unified Manager 中管理報告排程
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在「報告排程」頁面管理您的報告排程。您可以檢視、修改或刪除現有的排程。

[NOTE]
.開始之前
====
您無法從「報告排程」頁面排程新的報告。您只能從物件清單頁面新增排程的報告。

====
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。


.步驟
. 在左側導覽窗格中，按一下 *儲存管理* > *報告排程*。
. 在「報告排程」頁面上：
+
[cols="2*"]
|===
| 如果您想要…… | 然後 ...... 


 a| 
檢視現有排程
 a| 
使用捲軸和頁面控制項瀏覽現有報告清單。



 a| 
編輯現有排程
 a| 
.. 按一下您要使用的排程的更多圖示 image:../media/more_icon.gif[""]。
.. 點選 *編輯*。
.. 進行必要的變更。
.. 點選勾號儲存變更。




 a| 
刪除現有排程
 a| 
.. 按一下您要使用的排程的更多圖示 image:../media/more_icon.gif[""]。
.. 按一下 *Delete* 。
.. 確認您的決定。


|===
