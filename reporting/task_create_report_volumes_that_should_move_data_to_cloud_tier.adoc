= 在 Active IQ Unified Manager 中識別應將資料移至雲端分層的 Volume
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以建立一份報告，其中包含目前位於 FabricPool 集合體、雲端建議為 Tier 且包含大量冷資料的 Volume 清單。此報告可協助您決定是否應將某些 Volume 的分層原則變更為 "`auto`" 或 "`all`"，以便將更多冷（非活動）資料卸載至雲端分層。

.開始之前
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。
* 您必須設定 FabricPool 集合體，並且在這些集合體上必須有 Volume。


請依照下列步驟建立自訂檢視，以正確的順序顯示所需的欄，然後排程為該檢視產生報告。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備* > *Volume*。
. 在「檢視」功能表中，選擇 *效能* > *所有 Volume*。
. 在欄位選擇器中，請確保「`磁碟類型`」欄顯示在檢視中。
+
新增或移除其他欄，以建立對您的報告至關重要的檢視。

. 將 "`磁碟類型`" 欄拖曳至 "`雲端推薦`" 欄附近。
. 點選篩選圖示，新增以下三個篩選條件，然後點選 *套用篩選條件*：
+
** 磁碟類型包含 FabricPool
** Cloud Recommendation 包含分層
** 冷資料大於 10 GB image:../media/filter_cold_data.gif["一張 UI 快照，顯示如何新增和套用篩選器。"]


. 按一下「冷資料」欄的頂部，使包含最多冷資料的 Volume 顯示在檢視的頂部。
. 將檢視儲存為能夠反映檢視顯示內容的名稱，例如 "`Vols 變更分層原則`"。image:../media/report_vol_cold_data.gif["一張 UI 快照，顯示 Vols 變更分層原則頁面，其中包含按正確順序排列的必要欄。"]
. 在庫存頁面上點選 *排程報告* 按鈕。
. 點擊 *新增排程* 在「報告排程」頁面中新增一列，以便您可以定義新報告的排程特性。
. 輸入報告排程的名稱並完成其他報告欄位，然後按一下列末尾的勾號（image:../media/blue_check.gif[""]）。
+
報告會立即作為測試傳送。之後，報告會產生並依指定的頻率透過電子郵件傳送給列出的收件者。



根據報告中顯示的結果，您可能需要使用 System Manager 或 ONTAP CLI 將某些 Volume 的分層原則變更為 "`auto`" 或 "`all`"，以便將更多冷資料卸載到雲端分層。
