= 在 Active IQ Unified Manager 中建立報告以依叢集模型檢視容量
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以根據儲存系統模型建立報告，以分析叢集的儲存容量和使用率。

.開始之前
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。


請依照下列步驟建立按叢集模型顯示容量的自訂檢視，然後排定為該檢視產生報告。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備* > *叢集*。
. 在「檢視」功能表中，選擇 *容量* > *所有叢集*。
. 選取 *顯示/隱藏* 以移除報告中不需要的任何欄，例如 "`Cluster FQDN`" 和 "`OS Version`"。
. 將 "`Total Raw Capacity`"、"`Model/Family`" 和三個彙總欄拖曳到 "`Cluster`" 欄附近。
. 按一下「`Model/Family`」欄頂部，依叢集類型對結果進行排序。
. 以能反映檢視內容的特定名稱來儲存檢視，例如 "`Capacity by Cluster Model`"。
. 在庫存頁面上點選 *排程報告* 按鈕。
. 按一下 *新增排程* 以在 *報告排程* 頁面新增一列，以便您可以定義新報告的排程特性。
. 輸入報告排程的名稱並完成其他報告欄位，然後按一下列末尾的勾號（image:../media/blue_check.gif[""]）。
+
報告會立即作為測試傳送。之後，報告會產生並依指定的頻率透過電子郵件傳送給列出的收件者。



根據報告中顯示的結果，您可能需要為某些叢集增加更多容量，或升級較舊的叢集型號。
