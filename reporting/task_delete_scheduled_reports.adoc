= 在 Active IQ Unified Manager 中刪除排程報告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
報告排程後，您可以從「報告排程」頁面將其刪除。

.開始之前
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。


.步驟
. 在左側導覽窗格中，按一下 *儲存管理* > *報告排程*。
+
image::../media/scheduled_reports_2.gif[顯示排程報告的 UI 快照。]

+
[NOTE]
====
如果您擁有相應的權限，則可以移除系統中的任何報告及其排程。

====
. 按一下您要移除之排程的更多圖示 image:../media/more_icon.gif[""]。
. 按一下 *Delete* 。
. 確認您的決定。
+
排定的報告已從清單中移除，將不再依設定的排程產生與分發。

+
[NOTE]
====
如果從庫存頁面刪除自訂檢視，則使用該檢視的任何自訂 Excel 檔案或排程報告也會被刪除。

====
