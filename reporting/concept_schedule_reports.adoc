= 在 Active IQ Unified Manager 中排程報告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在您擁有想要重複使用並作為報告共享的檢視之後，您可以使用 Active IQ Unified Manager 進行排程。您可以管理已排程的報告，變更每個報告排程的收件者和經銷頻率。

在 Unified Manager 中，您可以排程大多數的檢視或清單頁面。例外情況是事件，這些是可以下載為 CSV 檔案的報告，但您無法排程事件以進行重新產生與共享。您也無法下載或排程儀表板、我的最愛或組態頁面。

從 Active IQ Unified Manager 9.8 開始，您可以下載 Microsoft® Excel 格式的檢視並進行自訂。您可以使用 Excel 的進階功能，例如複雜排序、分層篩選、樞紐分析表和圖表。如果您對產生的 Excel 報告滿意，可以上傳該 Excel 檔案，以便在每次排程和共享報告時使用。

您可以排程內建檢視或您自訂的檢視。您可以選擇要傳送的檔案類型，可以是 CSV、PDF 或 XSLX。首次排程報告時，您可以下載該報告並將自己指派為唯一的收件人，以便像您的收件人一樣查看報告。
