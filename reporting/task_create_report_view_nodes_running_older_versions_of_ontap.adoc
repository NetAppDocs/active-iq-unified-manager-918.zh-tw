= 建立報告以檢視 Active IQ Unified Manager 中執行舊版 ONTAP 的節點
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以建立報告來顯示所有叢集節點上安裝的 ONTAP 軟體版本，以便查看應該升級哪些節點。

.開始之前
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。


請依照下列步驟建立顯示執行舊版 ONTAP 的節點的自訂檢視，然後排定為該檢視產生報告。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備* > *節點*。
. 選取 *顯示/隱藏* 以移除報告中不需要的任何欄。
. 將 "`OS Version`" 欄拖曳至 "`Node`" 欄附近。
. 按一下「`OS 版本`」欄的頂部，依最舊的 ONTAP 版本對結果進行排序。
. 將檢視儲存為能反映檢視所顯示內容的特定名稱，例如 "`依 ONTAP 版本分類的節點`"。
. 在庫存頁面上點選 *排程報告* 按鈕。
. 點擊 *新增排程* 在「報告排程」頁面中新增一列，以便您可以定義新報告的排程特性。
. 輸入報告排程的名稱並完成其他報告欄位，然後按一下列末尾的勾號（image:../media/blue_check.gif[""]）。
+
報告會立即作為測試傳送。之後，報告會產生並依指定的頻率透過電子郵件傳送給列出的收件者。



根據報告中顯示的結果，您可能需要升級執行舊版 ONTAP 的節點。
