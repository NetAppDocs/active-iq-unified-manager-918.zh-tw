= 請使用支援的升級途徑升級 Active IQ Unified Manager 版本
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 為每個版本支援特定的升級途徑。

並非所有版本的 Unified Manager 都能執行就地升級至較新版本。Unified Manager 的升級僅限於 N-2 模式。這表示在所有平台上，您只能執行升級至接下來的兩個版本。例如，您只能從 Unified Manager 9.14 和 9.16 升級至 Unified Manager 9.18。

如果您目前執行的版本低於支援的版本，則需要先將 Unified Manager 執行個體升級至支援的版本之一，然後再升級至目前版本。

例如，如果您的已安裝版本是 Unified Manager 9.9，並且您想要升級到 Unified Manager 9.14，則需要按照升級順序進行操作。

.升級途徑範例：
. 升級 9.11 -> 9.13
. 升級 9.13 -> 9.14
. 升級 9.13 -> 9.16
. 升級 9.14 或 9.16 -> 9.18


有關升級途徑對照表的更多資訊，請參閱此處 https://kb.netapp.com/Advice_and_Troubleshooting/Data_Infrastructure_Management/Active_IQ_Unified_Manager/What_is_the_upgrade_path_for_Active_IQ_Unified_Manager_versions["知識庫（KB）文章"]。
