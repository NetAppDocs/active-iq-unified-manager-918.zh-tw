= 在 Active IQ Unified Manager 中變更 Windows 上的 JBoss 密碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以重設安裝期間設定的特定執行個體 JBoss 密碼。如果您的站台需要此安全性功能來置換 Unified Manager 的安裝設定，您可以選擇性地重設密碼。此作業也會變更 JBoss 用於存取 MySQL 的密碼。

.開始之前
* 您應具備安裝 Unified Manager 之系統的 Windows 系統管理員權限。
* 您應該擁有 MySQL root 使用者的密碼。
* 您應該能夠存取目錄中由 NetApp 提供 `password.bat`的指令碼
+
`C:\Program Files\NetApp\essentials\bin`。



.步驟
. 以 admin 使用者身分登入 Unified Manager 主機。
. 使用 Windows 服務主控台停止下列 Unified Manager 服務：
+
** NetApp Active IQ Acquisition Service （Ocie-au）
** NetApp Active IQ 管理伺服器服務（Oncommandsvc）


. 執行  `password.bat` 指令碼以開始密碼變更程序：
+
`C:\Program Files\NetApp\essentials\bin> password.bat resetJBossPassword`

. 出現提示時，輸入 MySQL root 使用者密碼。
. 出現提示時，輸入新的 JBoss 使用者密碼，然後再次輸入以進行確認。
+
請注意，密碼長度應為 8 到 16 個字元，並且必須至少包含一個數字、一個大寫字母和一個小寫字母，以及以下特殊字元中的至少一個：

+
`+!@%^*-_+=[]:<>.?/~+`

. 指令碼完成後，使用 Windows 服務主控台啟動 Unified Manager 服務：
+
** NetApp Active IQ 管理伺服器服務（Oncommandsvc）
** NetApp Active IQ Acquisition Service （Ocie-au）


. 所有服務啟動完畢後，即可登入 Unified Manager 使用者介面。
