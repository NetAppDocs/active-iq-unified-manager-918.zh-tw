= 在 Active IQ Unified Manager 中刪除群組規則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當不再需要某個群組規則時，您可以從 Active IQ Unified Manager 中刪除該群組規則。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

刪除群組規則時，關聯的儲存設備物件將從群組中移除。

.步驟
. 在左側導覽窗格中，按一下 *儲存管理* > *群組*。
. 在 *群組規則* 標籤中，選擇要刪除的群組規則，然後按一下 *刪除*。
. 在「警告」對話方塊中，按一下「是」確認刪除。
