= 在 Active IQ Unified Manager 中檢視叢集 / 健全狀況詳細資料頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「叢集 / 健全狀況詳細資料」頁面提供有關所選叢集的詳細資訊，例如健全狀況、容量和組態詳細資料。您也可以檢視有關叢集的網路介面（LIF）、節點、磁碟、相關裝置以及相關警報的資訊。

叢集名稱旁邊的狀態（例如「良好」）表示通訊狀態；即 Unified Manager 是否可以與叢集通訊。它並不表示容錯移轉狀態或叢集的整體狀態。



[[command-buttons]]
== 命令按鈕

透過命令按鈕，您可以對選取的叢集執行下列操作：

* *切換至效能檢視*
+
可讓您導覽至叢集 / 效能詳細資料頁面。

* *Actions*
+
** 新增警示：開啟「新增警示」對話方塊，讓您能夠將警示新增至選取的叢集。
** 重新發現：啟動叢集的手冊重新整理，使 Unified Manager 能夠發現叢集的最新變更。
+
如果 Unified Manager 與 OnCommand Workflow Automation 配對使用，重新探索作業也會從 WFA 重新取得快取的資料（如果有）。

+
重新探索作業啟動後，將顯示相關工作詳細資訊的連結，以便追蹤工作狀態。

** 註解：可讓您為選取的叢集加上註解。


* *檢視叢集*
+
可讓您導覽至健全狀況：所有叢集檢視。





[[health-tab]]
== 健全狀況索引標籤

顯示各種叢集物件（例如節點、SVM 和彙總）的資料可用度和資料容量問題的詳細資訊。可用度問題與叢集物件的資料服務功能有關。容量問題與叢集物件的資料儲存功能有關。

您可以點選物件的圖表來檢視物件的篩選清單。例如，您可以點選顯示警告的 SVM 容量圖表來檢視 SVM 的篩選清單。此清單包含的 SVM 具有磁碟區或 qtree，且其容量問題的嚴重層級為「警告」。您也可以點選顯示警告的 SVM 可用度圖表，以檢視具有可用度問題且嚴重層級為「警告」的 SVM 清單。



[[availability-issues]]
=== 可用度問題

以圖形方式顯示物件總數，包括發生可用度問題的物件，以及沒有任何可用度相關問題的物件。圖表中的顏色代表問題的不同嚴重層級。圖表下方的資訊提供有關可能影響或已經影響叢集中資料可用度之可用度問題的詳細資料。例如，會顯示有關停機的磁碟櫃與離線的彙總等資訊。

[NOTE]
====
SFO 長條圖顯示的資料是根據節點的 HA 狀態。所有其他長條圖顯示的資料是根據產生的事件計算得出。

====


[[capacity-issues]]
=== 容量問題

以圖形方式顯示物件總數，包括發生容量問題的物件，以及未發生任何容量相關問題的物件。圖表中的顏色代表問題的不同嚴重層級。圖表下方的資訊提供可能影響或已經影響叢集中資料容量的容量問題詳細資料。例如，會顯示可能超出設定臨界值的彙總相關資訊。



[[capacity-tab]]
== 容量標籤

顯示所選叢集的詳細容量資訊。



[[capacity]]
=== 容量

顯示所有已配置彙總的已使用容量與可用容量的資料容量圖：

* 已使用的邏輯空間
+
未套用 ONTAP 儲存效率技術所節省的空間時，儲存在此叢集所有彙總中的資料實際大小。這不包含 Snapshot 快照技術複本。

* 資料縮減
+
顯示不包含 Snapshot 快照技術複本的比率，並保留兩位有效數字，例如 1.8 比 1。此比率是根據已設定的 ONTAP 儲存效率設定。

* 已使用
+
所有彙總上的資料所使用的實體容量。這不包括用於同位元檢查、設定適當規模和預留的容量。

* 可用
+
顯示可用於資料的容量。

* 備援裝置
+
顯示所有備援裝置磁碟的可用儲存設備容量。

* 已配置
+
顯示為所有底層磁碟區配置的容量。

* 已使用

[[physical-capacity-breakout-by-disk-type]]
=== 依磁碟類型劃分的實體容量細分

「按磁碟類型劃分的實體容量」區域會顯示叢集中各種磁碟類型的磁碟容量詳細資訊。按一下磁碟類型，即可從「磁碟」標籤檢視有關該磁碟類型的更多資訊。

* 總可用容量
+
顯示資料磁碟的可用容量和備援裝置容量。

* HDD
+
以圖形方式顯示叢集中所有 HDD 資料磁碟的已使用容量和可用容量。虛線表示 HDD 中資料磁碟的備援裝置容量。

* Flash
+
** SSD Data
+
以圖形方式顯示叢集中 SSD 資料磁碟的已使用容量和可用容量。

** SSD 快取
+
以圖形方式顯示叢集中 SSD 快取磁碟的可儲存容量。

** SSD 備援裝置
+
以圖形方式顯示叢集中 SSD、資料磁碟和快取磁碟的備援裝置容量。



* 未分配磁碟
+
顯示叢集中未指派磁碟的數量。





[[aggregates-with-capacity-issues-list]]
=== 發生容量問題的彙總清單

以表格形式顯示有容量風險問題之彙總的已用容量和可用容量的詳細資訊。

* 狀態
+
顯示該彙總存在一定嚴重程度的容量相關問題。

+
您可以將指標移至狀態上，以檢視有關為彙總產生之事件的更多資訊。

+
如果彙總狀態由單一事件決定，您可以檢視事件名稱、事件觸發時間和日期、事件指派的系統管理員姓名以及事件原因等資訊。您可以按一下 *檢視詳細資料* 按鈕來檢視有關該事件的更多資訊。

+
如果彙總的狀態是由多個相同嚴重性的事件所決定，則會顯示前三個事件的相關資訊，例如事件名稱、事件觸發的時間與日期，以及指派該事件的系統管理員名稱。您可以按一下事件名稱，檢視每個事件的詳細資訊。您也可以按一下 *View All Events* 連結，檢視已產生事件的清單。

+
[NOTE]
====
一個彙總可以包含多個相同嚴重程度或不同嚴重程度的容量相關事件。但是，只會顯示最高嚴重程度。例如，如果一個彙總包含兩個嚴重程度分別為「錯誤」和「嚴重」的事件，則只會顯示「嚴重」的嚴重程度。

====
* 彙總
+
顯示彙總的名稱。

* 已使用資料容量
+
以圖形方式顯示彙總容量使用率（以百分比表示）的相關資訊。

* 達到滿載所需天數
+
顯示彙總達到完整容量前剩餘的預估天數。

[[metrocluster-overview]]
=== MetroCluster 概觀

提供 FC 上的 MetroCluster 或 IP 上的 MetroCluster 組態中本機叢集的詳細資料。此資訊僅針對 FC 或 IP 上的 MetroCluster 組態顯示。

* 類型
+
顯示 MetroCluster 類型為雙節點或四節點。對於 IP 上的 MetroCluster，僅支援四節點。

* 組態
+
顯示透過 FC 和 IP 的 MetroCluster 組態，其可具有下列值：



*適用於 FC*

* 使用 SAS 纜線的延伸組態
* 採用 FC-SAS 橋接的延伸組態
* 使用 FC 交換器的 Fabric 組態
+
[NOTE]
====
對於四節點 MetroCluster，僅支援使用 FC 交換器的 Fabric 組態。

====


*適用於 IP*

* 使用乙太網路交換器進行 IP 組態（L2 或 L3，取決於叢集的設定方式）
+
** 自動非排程切換（AUSO）
+
顯示本機叢集是否啟用自動非計畫性切換。依預設，Unified Manager 中雙節點 MetroCluster 組態的所有叢集都會啟用 AUSO。您可以使用命令列介面變更 AUSO 設定。此功能僅支援透過 FC 的 MetroCluster。

** 切換模式
+
顯示 MetroCluster 基於 IP 組態的切換模式。可用值為： `Active`、 `Negotiated Switchover` 和  `Automatic Unplanned Switchover`。

[[metrocluster-connectivity-tab]]
== MetroCluster 連線索引標籤

顯示 MetroCluster over FC 組態中叢集元件的問題和連線狀態。當叢集的災難恢復合作夥伴出現問題時，此叢集會以紅色方塊顯示。

[NOTE]
====
只有處於 MetroCluster over FC 組態的叢集，才會顯示 MetroCluster 連線能力索引標籤。

====
您可以透過點選遠端叢集的名稱來導覽至遠端叢集的詳細資料頁面。您也可以透過點選元件的計數連結來檢視元件的詳細資料。例如，點選叢集中節點的計數連結，即可在叢集的詳細資料頁面中顯示節點標籤。點選遠端叢集中磁碟的計數連結，即可在遠端叢集的詳細資料頁面中顯示磁碟標籤。

[NOTE]
====
管理八節點 MetroCluster 組態時，按一下磁碟櫃元件的計數連結，只會顯示預設 HA 配對的本機磁碟櫃。此外，無法顯示另一個 HA 配對上的本機磁碟櫃。

====
您可以將指標移到元件上，以檢視叢集的詳細資訊和連接狀態（如果出現任何問題），並檢視有關該問題產生的事件的更多資訊。

如果元件之間連線問題的狀態是由單一事件決定，您可以檢視事件名稱、事件觸發的時間和日期、指派該事件的系統管理員姓名，以及事件原因等資訊。「檢視詳細資料」按鈕提供有關該事件的更多資訊。

如果元件間連線問題的狀態是由多個相同嚴重程度的事件決定，則會顯示前三個事件，並包含事件名稱、觸發時間和日期，以及指派給該事件的系統管理員姓名等資訊。您可以點擊事件名稱來檢視每個事件的更多詳細資訊。您也可以點擊 *檢視所有事件* 連結來檢視已產生的事件清單。



[[metrocluster-replication-tab]]
== MetroCluster 複寫索引標籤

顯示在 FC 上的 MetroCluster 組態中正在複寫的資料狀態。您可以使用 MetroCluster 複寫索引標籤，透過將資料與已建立對等關係的叢集同步鏡射來確保資料保護。當叢集的災難恢復合作夥伴發生問題時，叢集會顯示在紅色方塊中。

[NOTE]
====
只有在叢集處於 MetroCluster over FC 組態時，才會顯示「MetroCluster 複寫」索引標籤。

====
在 MetroCluster 環境中，您可以使用此索引標籤來驗證本機叢集與遠端叢集的邏輯連線和對等關係。您可以檢視叢集元件及其邏輯連線的客觀表示。這有助於識別在鏡射中繼資料和資料期間可能發生的問題。

在 MetroCluster 複寫標籤中，本機叢集提供所選叢集的詳細圖形表示，而 MetroCluster 合作夥伴則是指遠端叢集。

[[nodes-tab]]
== 節點索引標籤

顯示所選叢集中節點的相關資訊。您可以檢視有關 HA 配對、磁碟櫃和連接埠的詳細資訊：



[[ha-details]]
=== HA 詳細資料

以圖形方式呈現 HA 狀態以及 HA 配對中各節點的健全狀況。節點的健全狀況以下列顏色表示：

* *綠色*
+
該節點處於正常工作狀態。

* *黃色*
+
該節點已接管合作夥伴節點，或該節點面臨一些環境問題。

* *紅色*
+
節點已關閉。



您可以檢視有關 HA 配對可用度的資訊，並採取必要的行動來預防任何風險。例如，在可能發生接管作業的情況下，會顯示下列訊息：儲存設備容錯移轉可能。

您可以檢視與 HA 配對及其環境相關的事件清單，例如風扇、電源供應器、NVRAM 電池、快閃記憶卡、服務處理器，以及磁碟櫃的連線。您也可以檢視事件觸發的時間。

您可以檢視其他與節點相關的資訊，例如型號。

如果有單節點叢集，您也可以檢視有關節點的詳細資訊。



[[disk-shelves]]
=== 磁碟櫃

顯示有關 HA 配對中磁碟櫃的資訊。

您也可以檢視磁碟櫃和環境元件產生的事件，以及事件觸發的時間。

* *機櫃 ID*
+
顯示磁碟所在機櫃的 ID。

* *元件狀態*
+
顯示磁碟櫃的環境詳細資訊，例如電源供應器、風扇、溫度感測器、電流感測器、磁碟連線和電壓感測器。環境詳細資訊會以下列顏色的圖示顯示：

+
** *綠色*
+
環境組件運作正常。

** *灰色*
+
環境元件沒有可用資料。

** *紅色*
+
部分環境元件已停機。



* *狀態*
+
顯示磁碟櫃的狀態。可能的狀態有：離線、線上、無狀態、需要初始化、遺失與未知。

* *型號*
+
顯示磁碟櫃的型號。

* *本機磁碟櫃*
+
指示磁碟櫃位於本機叢集還是遠端叢集。此欄僅針對 MetroCluster 組態中的叢集顯示。

* *唯一識別碼*
+
顯示磁碟櫃的唯一識別碼。

* *韌體版本*
+
顯示磁碟櫃的韌體版本。





[[ports]]
=== 連接埠

顯示相關 FC、FCoE 和乙太網路連接埠的資訊。點擊連接埠圖示即可檢視連接埠及其相關 LIF 的詳細資訊。

您也可以檢視連接埠產生的事件。

您可以檢視以下連接埠詳細資訊：

* 連接埠 ID
+
顯示連接埠名稱。例如，連接埠名稱可以是 e0M、e0a 和 e0b。

* 角色
+
顯示連接埠的角色。可能的角色包括：叢集、資料、叢集間、節點管理以及未定義。

* 類型
+
顯示連接埠使用的實體階層協定。可能的類型包括乙太網路、Fibre Channel 和 FCoE。

* WWPN
+
顯示連接埠的全球連接埠名稱（WWPN）。

* 韌體版本
+
顯示 FC/FCoE 連接埠的韌體版本。

* 狀態
+
顯示連接埠的目前狀態。可能的狀態有：已啟用、已停用、連結未連線或未知（image:../media/hastate_unknown.gif["HA 狀態圖示 – 未知"]）。

+
您可以從「事件」清單中檢視與連接埠相關的事件。您也可以檢視相關的 LIF 詳細資料，例如 LIF 名稱、運作狀態、IP 位址或 WWPN、協定、與 LIF 相關聯的 SVM 名稱、目前連接埠、容錯移轉原則和容錯移轉群組。





[[disks-tab]]
== 磁碟索引標籤

顯示所選叢集中磁碟的詳細資訊。您可以檢視磁碟相關資訊，例如已使用磁碟、備援裝置、故障磁碟和未指派磁碟的數量。您也可以檢視其他詳細資訊，例如磁碟名稱、磁碟類型和磁碟的擁有者節點。



[[disk-pool-summary]]
=== 磁碟池摘要

顯示磁碟數量，這些磁碟依有效類型 （FCAL、SAS、SATA、MSATA、SSD、NVMe SSD、SSD CAP、Array LUN 和 VMDISK） 分類，並顯示磁碟狀態。您也可以檢視其他詳細資料，例如彙總數量、共享的磁碟、備援裝置磁碟、損壞磁碟、未指派磁碟及不支援磁碟的數量。如果按一下有效磁碟類型計數連結，將會顯示所選狀態和有效類型的磁碟。例如，如果按一下磁碟狀態為「Broken」且有效類型為 SAS 的計數連結，將會顯示所有磁碟狀態為「Broken」且有效類型為 SAS 的磁碟。



[[disk]]
=== 磁碟

顯示磁碟名稱。



[[raid-groups]]
=== RAID 群組

顯示 RAID 群組的名稱。



[[owner-node]]
=== 所有者節點

顯示磁碟所屬節點的名稱。如果磁碟未指派，則此欄不顯示任何值。



[[state]]
=== 狀態

顯示磁碟的狀態：彙總、共享的、備援裝置、損壞、未指派、不支援或未知。預設情況下，此欄會依下列順序排序顯示狀態：損壞、未指派、不支援、備援裝置、彙總及共享的。



[[local-disk]]
=== 本機磁碟

顯示「是」或「否」，以指出磁碟是位於本機叢集或遠端叢集。此欄僅針對 MetroCluster 組態中的叢集顯示。



[[position]]
=== 位置

根據 Container 類型顯示磁碟位置：例如，複製、資料或同位元。預設情況下，此欄為隱藏狀態。



[[impacted-aggregates]]
=== 受影響的彙總

顯示因故障磁碟而受影響的彙總數量。您可以將指標懸停在計數連結上以檢視受影響的彙總，然後按一下彙總名稱以檢視彙總的詳細資訊。您也可以按一下彙總計數，在「健全狀況：所有彙總」檢視中檢視受影響的彙總清單。

在下列情況下，此欄不顯示任何值：

* 針對損壞的磁碟，當包含此類磁碟的叢集新增至 Unified Manager 時
* 當沒有故障磁碟時




[[storage-pool]]
=== 儲存資源池

顯示 SSD 所屬的儲存資源池名稱。您可以將指標移至儲存資源池名稱上方，以檢視儲存資源池的詳細資訊。



[[storable-capacity]]
=== 可儲存容量

顯示可供使用的磁碟容量。



[[raw-capacity]]
=== 原始容量

顯示設定適當規模與 RAID 組態之前的原始未格式化磁碟容量。預設情況下，此欄為隱藏狀態。



[[type]]
=== 類型

顯示磁碟類型：例如，ATA、SATA、FCAL 或 VMDISK。



[[effective-type]]
=== 有效類型

顯示 ONTAP 分配的磁碟類型。

就建立和新增至彙總以及備援裝置管理而言，某些 ONTAP 磁碟類型被視為等效。ONTAP 會為每種磁碟類型指派一個有效的磁碟類型。



[[spare-blocks-consumed]]
=== 備援裝置區塊已消耗 %

以百分比形式顯示 SSD 磁碟中已使用的備援裝置區塊。對於非 SSD 磁碟，此欄為空白。



[[rated-life-used]]
=== 額定壽命已使用百分比

以百分比形式顯示 SSD 已用壽命的估算值，該估算值基於 SSD 的實際使用情況和製造商對 SSD 壽命的預測。大於 99 的值表示已達到預估壽命，但這並不一定表示 SSD 故障。如果該值未知，則忽略該磁碟。



[[firmware]]
=== 韌體

顯示磁碟的韌體版本。



[[rpm]]
=== RPM

顯示磁碟的每分鐘轉速（RPM）。預設情況下，此欄為隱藏狀態。



[[model]]
=== 模型

顯示磁碟型號。預設情況下，此欄為隱藏狀態。



[[vendor]]
=== 廠商

顯示磁碟廠商名稱。預設情況下，此列處於隱藏狀態。



[[shelf-id]]
=== 機櫃 ID

[[bay]]
=== 機槽

顯示磁碟所在磁碟位的 ID。



[[related-annotations-pane]]
== 相關註釋窗格

此功能可讓您檢視與所選叢集關聯的註釋詳細資訊。詳細資訊包括註釋名稱和套用於叢集的註釋值。您也可以從「相關註釋」窗格中移除手冊註釋。



[[related-devices-pane]]
== 相關設備窗格

可讓您檢視與所選叢集相關聯的裝置詳細資料。

詳細資訊包括連接到叢集的裝置屬性，例如裝置類型、大小、數量和健全狀況。您可以按一下數量連結，對該特定裝置進行進一步的分析。

您可以使用 MetroCluster 合作夥伴窗格來取得遠端 MetroCluster 合作夥伴的數量和詳細資料，以及與其關聯的叢集元件，例如節點、彙總和 SVM。MetroCluster 合作夥伴窗格僅對 MetroCluster 組態中的叢集顯示。

「相關設備」窗格可讓您檢視和導覽至與叢集相關的節點、SVM 和彙總：



[[metrocluster-partner]]
=== MetroCluster 合作夥伴

顯示 MetroCluster 合作夥伴的健全狀況。使用計數連結，您可以進一步導覽並取得有關叢集元件健全狀況與容量的資訊。



[[nodes]]
=== 節點

顯示屬於所選叢集的節點數量、容量和健全狀況。容量表示總可用容量與可用容量的比例。



[[storage-virtual-machines]]
=== 儲存虛擬機器

顯示屬於所選叢集的 SVM 數量。



[[aggregates]]
=== Aggregate

顯示屬於所選叢集的彙總數量、容量與健全狀況。



[[related-groups-pane]]
== 相關群組窗格

可讓您檢視包含所選叢集的群組清單。



[[related-alerts-pane]]
== 相關警報窗格

「相關警報」窗格可讓您檢視所選叢集的警報清單。您也可以按一下「新增警報」連結來新增警報，或按一下警報名稱來編輯現有警報。
