= 在 Active IQ Unified Manager 中查看彙總清單和詳細資訊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
從「健全狀況：所有彙總」檢視中，您可以監控彙總的庫存。「容量：所有彙總」檢視可讓您檢視所有叢集中彙總的容量與使用率資訊。

.開始之前
您必須擁有操作員、應用程式管理員或儲存管理員角色。

您可以在「彙總 / 健全狀況」詳細資訊頁面檢視彙總容量與組態，以及磁碟資訊等詳細資訊。如有需要，您可以在設定臨界值設定之前使用這些詳細資訊。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備* > *彙總*。
. 請選擇以下方式之一檢視彙總詳情：
+
** 若要檢視所有叢集中所有彙總的健全狀況資訊，請在「檢視」功能表中選擇「健全狀況：所有彙總」檢視。
** 若要檢視所有叢集中所有彙總的容量與使用率資訊，請在「檢視」功能表中，選取「容量：所有彙總」檢視。
** 若要檢視完整的詳細資料，請按一下彙總名稱。
+
您也可以在精簡詳細資料對話方塊中按一下 *檢視詳細資料* 來檢視完整的詳細資料。



. 從最小詳細資料對話方塊中按一下 *檢視相關*，即可檢視與彙總相關的物件。
