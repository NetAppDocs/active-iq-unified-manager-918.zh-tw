= 在 Active IQ Unified Manager 中檢視有關 SMB/CIFS 共用的詳細資料
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以檢視所有 SMB/CIFS 共享的詳細資料，例如共享名稱、交會路徑、包含物件、安全性設定，以及為共享定義的匯出原則。使用「健全狀況：所有 SMB 共享」檢視可查看所有受監控叢集上的所有 SMB 共享，而使用「Storage VM / 健全狀況」詳細資料頁面可檢視特定儲存設備虛擬機器 (SVM) 上的所有 SMB 共享。

.開始之前
* 叢集上必須啟用 CIFS 授權。
* 必須設定用於 SMB/CIFS 共用區的網路介面。
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。


[NOTE]
====
不會顯示資料夾中的共享。

====
.步驟
. 在左側導覽窗格中，根據您要檢視所有 SMB/CIFS 共用區還是僅檢視特定 SVM 的共用區，請依照下列步驟操作。
+
[cols="2*"]
|===
| 若要…… | 請依照以下步驟操作...... 


 a| 
檢視所有 SMB/CIFS 共用區
 a| 
點選 *儲存設備* > *SMB 共享*



 a| 
檢視單一 SVM 的 SMB/CIFS 共享
 a| 
.. 點選 *儲存設備* > *儲存虛擬機器*
.. 按一下要檢視 SMB/CIFS 共用區詳細資訊的 SVM。
.. 在 Storage VM / 健全狀況詳細資料頁面中，按一下 *SMB 共享* 標籤。


|===


如需詳細資訊，請參閱 link:../api-automation/concept_provision_file_share.html["使用 API 配置 CIFS 和 NFS 檔案共享"]。
