= 從 Active IQ Unified Manager 產生並上傳支援套裝組合
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以產生包含診斷資訊的支援套裝組合，以便將其傳送給技術支援尋求疑難排解協助。

從 Unified Manager 9.8 開始，如果您的 Unified Manager 伺服器已連線至網際網路，您也可以從維護主控台將支援套裝組合上傳至 NetApp。

.開始之前
您必須以維護使用者的身分存取維護控制台。

由於某些類型的支援資料會佔用大量叢集資源或耗時較長，因此在選擇完整支援套裝組合時，您可以指定要包含或排除的資料類型，以減少支援套裝組合的大小。您也可以選擇建立輕量級支援套裝組合，其中僅包含 30 天的日誌和組態資料庫記錄—它不包含效能資料、擷取記錄檔和伺服器 heap dump。

Unified Manager 僅儲存最近產生的兩個支援套裝組合。較舊的支援套裝組合會從系統中刪除。

.步驟
. 在維護控制台 *主選單* 中，選擇 *支援/診斷*。
. 根據您希望在支援套裝組合中包含的詳細資訊層級，選擇 *產生輕量級支援套裝組合* 或 *產生支援套裝組合*。
. 如果您選擇完整支援套裝組合，請選擇或取消選取以下資料類型，以包含在支援套裝組合中或從中排除：
+
** *資料庫轉儲*
+
MySQL 伺服器資料庫的轉儲檔案。

** *堆積傾印*
+
主 Unified Manager 伺服器程序狀態的快照。此選項預設為停用，僅應在客戶支援要求時選取。

** *採集記錄*
+
記錄 Unified Manager 與受監控叢集之間的所有通訊。



+
[NOTE]
====
如果您取消選取所有資料類型，支援套裝組合仍會使用其他 Unified Manager 資料產生。

====
. 輸入 `g`，然後按 Enter 鍵產生支援套裝組合。
+
由於產生支援套裝組合是一項記憶體容量密集型操作，因此系統會提示您確認是否確定要立即產生支援套裝組合。

. 輸入 `y`，然後按 Enter 鍵產生支援套裝組合。
+
如果您此時不想產生支援套裝組合，請鍵入 `n`，然後按 Enter 鍵。

. 如果您在完整支援套裝組合中包含了資料庫傾印檔案，系統會提示您指定要包含效能統計資料的期間。包含效能統計資料可能會佔用大量時間和空間，因此您也可以在不包含效能統計資料的情況下傾印資料庫：
+
.. 請以 YYYYMMDD 格式輸入起始日期。
+
例如，輸入 `20210101` 代表 2021 年 1 月 1 日。如果您不想包含效能統計資料，請輸入 `n`。

.. 請輸入要包含的統計資料天數，從指定起始日期的凌晨 12 點開始。
+
您可以輸入 1 到 10 之間的數字。



+
如果您要包含效能統計資料，系統會顯示收集效能統計資料的期間。

. 支援套裝組合建立完成後，系統會提示您是否要將其上傳至 NetApp。輸入  `y`，然後按 Enter 鍵。
+
系統會提示您輸入支援案例編號。

. 如果您已有案例編號，請輸入該編號並按下 Enter 鍵。否則，只需按下 Enter 鍵即可。
+
支援套裝組合已上傳至 NetApp。



如果您的 Unified Manager 伺服器未連線至網際網路，或因任何其他原因無法上傳支援套裝組合，您可以手動擷取並傳送。您可以使用 SFTP 用戶端或使用 UNIX 或 Linux CLI 命令來擷取它。在 Windows 安裝中，您可以使用遠端桌面（RDP）來擷取支援套裝組合。

產生的支援套裝組合位於 VMware 系統的 /support 目錄中，Linux 系統的 /opt/netapp/data/support/ 中，以及 Windows 系統的 ProgramData\NetApp\OnCommandAppData\ocum\support 中。
