= 了解 Active IQ Unified Manager 中群組規則的運作方式
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
群組規則是您定義的用於將儲存設備物件（ Volume 、叢集或 SVM ）包含在特定群組中的條件。您可以使用條件群組或條件來定義群組的群組規則。

* 您必須將群組規則關聯到群組。
* 您必須為群組規則關聯一個物件類型；一個群組規則只能關聯一個物件類型。
* 每次監控週期結束後，或建立、編輯或刪除規則時，都會在群組中新增或刪除儲存物件。
* 一個群組規則可以有一或多個條件群組，每個條件群組可以有一或多個條件。
* 根據您建立的群組規則，儲存物件可以屬於多個群組。




[[conditions]]
== 狀況

您可以建立多個條件群組，每個條件群組可以包含一個或多個條件。您可以將所有已定義的條件群組套用到群組規則中，以指定哪些儲存設備物件包含在群組中。

條件群組中的條件會使用邏輯 AND 執行。必須符合條件群組中的所有條件。建立或修改群組規則時，系統會建立一個條件，該條件僅套用、選取並分組符合條件群組中所有條件的儲存設備物件。當您想要縮小要包含在群組中的儲存設備物件範圍時，可以在條件群組中使用多個條件。

您可以使用下列運算元和營運者並指定所需的值來建立儲存設備物件的條件。

[cols="2*"]
|===
| 儲存物件類型 | 適用運算元 


 a| 
磁碟區
 a| 
* 物件名稱
* 所屬叢集名稱
* 擁有 SVM 名稱
* 註解




 a| 
SVM
 a| 
* 物件名稱
* 所屬叢集名稱
* 註解




 a| 
叢集
 a| 
* 物件名稱
* 註解


|===
當您選擇註解作為任何儲存設備物件的運算數時，「`Is`」營運者可用。對於所有其他運算數，您可以選擇「`Is`」或「`Contains`」作為營運者。

* 運算元
+
Unified Manager 中的操作數清單會根據所選物件類型而變更。此清單包括物件名稱、所屬叢集名稱、所屬 SVM 名稱以及您在 Unified Manager 中定義的註解。

* 操作員
+
運算子清單會根據條件所選的運算元而改變。Unified Manager 支援的運算子為 "`Is`" 和 "`Contains`"。

+
當您選擇 "`Is`" 營運者時，將評估條件，以確定運算元值與為所選運算元提供的值是否完全相符。

+
當您選擇 "`Contains`" 營運者時，將評估該條件是否符合下列準則之一：

+
** 運算元值與為所選運算元提供的值完全相符
** 運算元值包含為所選運算元提供的值


* 價值
+
值欄位會根據所選的運算元而改變。





[[example-of-a-group-rule-with-conditions]]
== 帶有條件的群組規則範例

考慮一個具有下列兩個條件的 Volume 條件群組：

* 名稱包含 "`vol`"
* SVM 名稱為 "`data_svm`"


此條件群組選擇名稱中包含 "`vol`" 且託管在名為 "`data_svm`" 的 SVM 上的所有 Volume。



[[condition-groups]]
== 條件群組

條件群組使用邏輯「或」運算執行，然後套用於儲存設備物件。儲存設備物件必須滿足其中一個條件群組才能包含在群組中。所有條件群組的儲存設備物件將合併。您可以使用條件群組來擴大包含在群組中的儲存設備物件範圍。



[[example-of-a-group-rule-with-condition-groups]]
== 包含條件群組的群組規則範例

考慮 Volume 的兩個條件組，每組包含以下兩個條件：

* 條件組 1
+
** 名稱包含 "`vol`"
** SVM 名稱是 "`data_svm`" 條件群組 1 選擇名稱中包含 "`vol`" 且託管在名稱為 "`data_svm`" 的 SVM 上的所有 Volume。


* 條件組 2
+
** 名稱包含 "`vol`"
** data-priority 的註釋值為 "`關鍵`"。條件群組 2 會選取名稱中包含 "`vol`" 且 data-priority 註釋值為 "`關鍵`" 的所有 Volume。




當包含這兩個條件群組的群組規則套用至儲存設備物件時，下列儲存設備物件會新增至選取的群組：

* 名稱中包含 "`vol`" 且託管在名為 "`data_svm`" 的 SVM 上的所有 Volume。
* 所有名稱中包含 "`vol`" 且標註資料優先順序註解值 "`關鍵`" 的 Volume。
