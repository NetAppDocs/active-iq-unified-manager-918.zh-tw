= 在 Active IQ Unified Manager 中重新排序群組動作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以變更要套用至群組中儲存設備物件的群組行動順序。群組行動會根據其順位依序套用至儲存設備物件。最低的順位會指派給您最後設定的群組行動。您可以根據需求變更群組行動的順位。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

您可以選擇單一或多行，然後執行多次拖放操作以變更群組行動的優先權。但是，您必須儲存變更，重新排序後的優先順序才會反映在群組行動網格中。

.步驟
. 在左側導覽窗格中，按一下 *儲存管理* > *群組*。
. 在 *群組行動* 標籤中，按一下 *重新排序*。
. 在 *重新排序群組行動* 對話方塊中，拖放列以視需要重新排列群組行動的順序。
. 按一下 *Save* 。
