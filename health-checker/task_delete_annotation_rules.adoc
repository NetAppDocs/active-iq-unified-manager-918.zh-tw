= 在 Active IQ Unified Manager 中刪除註解規則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當不再需要註解規則時，您可以從 Active IQ Unified Manager 中刪除這些規則。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

刪除註解規則時，此註解將會解除關聯並從儲存設備物件中移除。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *註解*。
. 在 *註解規則* 標籤中，選擇要刪除的註解規則，然後按一下 *刪除*。
. 在 *警告* 對話方塊中，按一下 *是* 以確認刪除。
