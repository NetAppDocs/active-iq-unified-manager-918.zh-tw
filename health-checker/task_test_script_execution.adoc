= 在 Active IQ Unified Manager 中執行測試指令碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當儲存設備物件產生警報時，您可以驗證指令碼是否正確執行。

* 您必須擁有應用程式系統管理員或儲存系統管理員角色。
* 您必須將指令碼以支援的檔案格式上傳至 Unified Manager。


.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *指令碼*。
. 在「指令碼」頁面中，新增您的測試指令碼。
. 在左側導覽窗格中，按一下 *儲存設備管理* > *警示設定*。
. 在「警報設定」頁面中，執行下列行動之一：
+
[cols="2*"]
|===
| 若要…… | 這樣做…… 


 a| 
新增提醒
 a| 
.. 點擊 *Add* 。
.. 在「行動」部分，將警報與您的測試指令碼建立關聯。




 a| 
編輯提醒
 a| 
.. 選取警報，然後點選 *編輯*。
.. 在「行動」部分，將警報與您的測試指令碼建立關聯。


|===
. 按一下 *Save* 。
. 在 *警報設定* 頁面中，選擇您新增或修改的警報，然後按一下 *測試*。
+
指令碼會以 "`-test`" 參數執行，並將通知警示傳送至建立警示時所指定的電子郵件地址。
