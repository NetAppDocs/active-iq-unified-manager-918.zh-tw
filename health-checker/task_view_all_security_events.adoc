= 在 Active IQ Unified Manager 中查看所有作用中安全性事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以檢視所有作用中的安全性事件，然後將每個事件指派給能夠解決問題的使用者。此外，如果您不想接收某些安全性事件，此清單可以幫助您識別要停用的事件。

.開始之前
您必須擁有操作員、應用程式管理員或儲存管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *事件管理*。
+
預設情況下，新事件和已確認事件會顯示在事件管理清單頁面上。

. 從「檢視」功能表中，選擇 *作用中安全性事件*。
+
此頁面顯示過去 7 天內產生的所有新安全性事件與已確認的安全性事件。
