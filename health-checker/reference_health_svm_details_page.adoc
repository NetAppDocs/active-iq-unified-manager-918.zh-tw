= 在 Active IQ Unified Manager 中查看儲存虛擬機器 / 健全狀況詳細資訊頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用「Storage VM / 健全狀況詳細資料」頁面來檢視所選 Storage VM 的詳細資訊，例如其健全狀況、容量、組態、資料原則、邏輯介面（LIF）、LUN、qtree、使用者、使用者群組配額和保護詳細資料。您也可以檢視有關 Storage VM 的相關物件和相關警示的資訊。

[NOTE]
====
您只能監控資料儲存設備 VM。

====


[[command-buttons]]
== 命令按鈕

透過命令按鈕，您可以對選取的儲存設備 VM 執行下列工作：

* *切換至效能檢視*
+
可讓您導覽至 Storage VM / 效能詳細資料頁面。

* *Actions*
+
** 新增警示
+
可讓您新增警報至選定的儲存設備 VM。

** 註解
+
允許您對選定的儲存設備 VM 進行註釋。



* *檢視儲存虛擬機器*
+
可讓您導覽至「健全狀況：所有 Storage VM」檢視。





[[health-tab]]
== 健全狀況索引標籤

「健全狀況」標籤顯示有關各種物件（例如 Volume、彙總、NAS LIF、SAN LIF、LUN、協定、服務、NFS 共用和 CIFS 共用）的資料可用度、資料容量和保護問題的詳細資訊。

您可以點擊物件的圖表來檢視篩選後的物件清單。例如，您可以點擊顯示警告的 Volume 容量圖表，檢視存在容量問題且嚴重程度為警告的 Volume 清單。

* *可用度問題*
+
以圖表形式顯示物件總數，包括有可用度問題的物件和沒有任何可用度相關問題的物件。圖表中的顏色代表問題的不同嚴重程度。圖表下方的資訊提供有關可能影響或已經影響儲存設備 VM 中資料可用度的可用度問題詳細資訊。例如，會顯示已關閉的 NAS LIF 和 SAN LIF 以及已離線的 Volume 的資訊。

+
您也可以檢視目前正在執行的相關協定和服務的資訊，以及 NFS 和 CIFS 共用的數量和狀態。

* *容量問題*
+
以圖表形式顯示物件總數，包括有容量問題的物件和沒有任何容量相關問題的物件。圖表中的顏色代表問題的不同嚴重程度。圖表下方的資訊提供有關可能影響或已經影響 storage VM 中資料容量之容量問題的詳細資料。例如，會顯示可能超出設定臨界值的彙總相關資訊。

* *保護問題*
+
透過以欄位對話方塊的形式顯示關係總數（包括發生保護問題的關係和沒有任何保護相關問題的關係），提供儲存 VM 保護相關健全狀況的快速總覽。您也可以檢視所選儲存 VM 的儲存 VM DR 關係狀態。此處會顯示儲存 VM DR 關係事件，按一下事件即可進入事件詳細資料頁面。當存在未受保護的 Volume 時，按一下連結會將您帶往「健全狀況：所有 Volume」檢視，您可以在其中檢視儲存 VM 上未受保護 Volume 的篩選清單。圖表中的顏色代表問題的不同嚴重程度。按一下圖表會將您帶往「關係：所有關係」檢視，您可以在其中檢視保護關係詳細資料的篩選清單。圖表下方的資訊提供有關可能影響或已經影響儲存 VM 中資料保護的保護問題詳細資料。例如，會顯示有關 Snapshot 複本保留幾乎已滿的 Volume，或有關 SnapMirror 關係延遲問題的資訊。





[[capacity-tab]]
== 容量標籤

「容量」標籤顯示所選 SVM 資料容量的詳細資訊。

針對具有 FlexVol Volume 或 FlexGroup Volume 的 Storage VM，會顯示下列資訊：

* *容量*
+
容量區域顯示從所有 Volume 分配的已使用和可用容量的詳細資訊：

+
** 總容量
+
顯示 Storage VM 的總容量。

** 已使用
+
顯示屬於 Storage VM 的 Volume 中資料所使用的空間。

** 保證可用
+
顯示 Storage VM 中 Volume 可用資料的保證可用空間。

** 不保證
+
顯示 Storage VM 中為精簡配置 Volume 所配置之資料的剩餘可用空間。



* *發生容量問題的 Volume*
+
「發生容量問題的 Volume」清單以表格形式顯示發生容量問題的 Volume 詳細資訊：

+
** 狀態
+
表示該 Volume 有指定嚴重程度的容量相關問題。

+
您可以將指標移到狀態上，以檢視有關為 Volume 產生的容量相關事件的更多資訊。

+
如果 Volume 的狀態由單一事件決定，您可以檢視事件名稱、事件觸發的時間和日期、事件的指定系統管理員姓名以及事件原因等資訊。您可以使用 *檢視詳細資料* 按鈕檢視有關該事件的更多資訊。

+
如果 Volume 的狀態由多個相同嚴重程度的事件決定，則會顯示前三個事件，並包含事件名稱、事件觸發時間和日期以及分配給該事件的系統管理員姓名等資訊。您可以點擊事件名稱檢視每個事件的更多詳細資訊。您也可以點擊 *檢視所有事件* 連結檢視已產生的事件清單。

+
[NOTE]
====
一個 Volume 可以包含多個相同嚴重程度或不同嚴重程度的事件。但是，只會顯示最高嚴重程度。例如，如果一個 Volume 包含兩個嚴重程度分別為「錯誤」和「警告」的事件，則只會顯示「錯誤」嚴重程度。

====
** 磁碟區
+
顯示 Volume 的名稱。

** 已使用資料容量
+
以圖表形式顯示 Volume 容量使用量資訊（百分比）。

** 達到滿載所需天數
+
顯示 Volume 達到滿載前預計剩餘的天數。

** 精簡配置
+
顯示所選 Volume 是否設定了空間保證。有效值為「是」和「否」。

** Aggregate
+
對於 FlexVol Volume，顯示包含該 Volume 的彙總名稱。對於 FlexGroup Volume，顯示 FlexGroup 中使用的彙總數量。







[[configuration-tab]]
== 組態索引標籤

「組態」索引標籤會顯示所選儲存設備 VM 的組態詳細資料，例如其叢集、根 Volume、其包含的 Volume 類型（FlexVol Volume）、原則，以及在儲存設備 VM 上建立的保護：

* *概述*
+
** 叢集
+
顯示儲存設備虛擬機器所屬叢集的名稱。

** 允許的 Volume 類型
+
顯示可在儲存設備 VM 中建立的 Volume 類型。類型可以是 FlexVol 或 FlexVol/FlexGroup。

** 根 Volume
+
顯示儲存設備虛擬機器的根 Volume 名稱。

** 允許的協定
+
顯示可在儲存設備虛擬機器上設定的協定類型。此外，也指示協定是已啟用（image:../media/availability_up_um60.gif["LIF 可用度圖示 – 啟動"]）、已停用（image:../media/availability_down_um60.gif["LIF 可用度圖示 – 關閉"]）或未設定（image:../media/disabled_um60.gif["LIF 可用度圖示 – 未知"]）。



* *資料網路介面*
+
** NAS
+
顯示與儲存設備虛擬機器關聯的 NAS 介面數量。同時，指示介面是處於啟用狀態（image:../media/availability_up_um60.gif["LIF 可用度圖示 – 啟動"]）還是停用狀態（image:../media/availability_down_um60.gif["LIF 可用度圖示 – 關閉"]）。

** SAN
+
顯示與儲存設備 VM 關聯的 SAN 介面數量。同時，指示介面是處於啟用狀態（image:../media/availability_up_um60.gif["LIF 可用度圖示 – 啟動"]）還是停用狀態（image:../media/availability_down_um60.gif["LIF 可用度圖示 – 關閉"]）。

** FC-NVMe
+
顯示與 Storage VM 關聯的 FC-NVMe 介面數量。同時，指出介面是處於啟用狀態（image:../media/availability_up_um60.gif["LIF 可用度圖示 – 啟動"]）還是停用狀態（image:../media/availability_down_um60.gif["LIF 可用度圖示 – 關閉"]）。



* *管理網路介面*
+
** 可用性
+
顯示與 Storage VM 關聯的管理介面數量。同時，指示管理介面是處於啟用狀態（image:../media/availability_up_um60.gif["LIF 可用度圖示 – 啟動"]）還是停用狀態（image:../media/availability_down_um60.gif["LIF 可用度圖示 – 關閉"]）。



* *原則*
+
** 快照
+
顯示在 Storage VM 上建立的 Snapshot 原則的名稱。

** 匯出原則
+
如果建立單一原則，則顯示匯出原則的名稱；如果建立多個原則，則顯示匯出原則的數量。



* *保護*
+
** Storage VM 災難復原
+
顯示所選儲存設備 VM 是否受保護、為目的地或未受保護，以及該儲存設備 VM 受保護的目的地名稱。如果所選儲存設備 VM 為目的地，則會顯示來源儲存設備 VM 的詳細資訊。在連出的情況下，此欄位會顯示該儲存設備 VM 受保護的目的地儲存設備 VM 總數。計數連結會將您帶往依來源儲存設備 VM 篩選的儲存設備 VM 關係網格。

** 受保護的 Volume
+
顯示所選儲存設備 VM 上受保護的 Volume 數量佔總 Volume 數的比例。如果您正在檢視目的地儲存設備 VM，則數字連結是指向所選儲存設備 VM 的目的地 Volume。

** 未受保護的 Volume
+
顯示所選儲存設備 VM 上未受保護的 Volume 數量。



* *服務*
+
** 類型
+
顯示在儲存設備虛擬機器上設定的服務類型。此類型可以是網域名稱系統（DNS）或網路資訊服務（NIS）。

** 狀態
+
顯示服務的狀態，可以是「啟動」（image:../media/availability_up_um60.gif["LIF 可用度圖示 – 啟動"]）、「關閉」（image:../media/availability_down_um60.gif["LIF 可用度圖示 – 關閉"]）或「未組態」（image:../media/disabled_um60.gif["LIF 可用度圖示 – 未知"]）。

** 網域名稱
+
顯示 DNS 服務的 DNS 伺服器或 NIS 服務的 NIS 伺服器的完整網域名稱（FQDN）。啟用 NIS 伺服器時，會顯示 NIS 伺服器作用中的 FQDN。停用 NIS 伺服器時，會顯示所有 FQDN 的清單。

** IP 位址
+
顯示 DNS 或 NIS 伺服器的 IP 位址。啟用 NIS 伺服器時，會顯示作用中的 NIS 伺服器 IP 位址。停用 NIS 伺服器時，會顯示所有 IP 位址清單。







[[network-interfaces-tab]]
== 網路介面索引標籤

「網路介面」標籤顯示在所選儲存設備 VM 上建立的資料網路介面（LIF）的詳細資訊：

* *網路介面*
+
顯示在選定儲存設備 VM 上建立的介面名稱。

* *運作狀態*
+
顯示介面的運作狀態，可以是 Up（image:../media/lif_status_up.gif["LIF 狀態圖示 – 啟動"]）、Down（image:../media/lif_status_down.gif["LIF 狀態圖示 – 停機"]）或 Unknown（image:../media/hastate_unknown.gif["HA 狀態圖示 – 未知"]）。介面的運作狀態取決於其實體連接埠的狀態。

* *管理狀態*
+
顯示介面的管理狀態，可以是「已啟用」（Up image:../media/lif_status_up.gif["LIF 狀態圖示 – 啟動"]）、「已停用」（Down image:../media/lif_status_down.gif["LIF 狀態圖示 – 停機"]）或「未知」（Unknown image:../media/hastate_unknown.gif["HA 狀態圖示 – 未知"]）。儲存管理員可以控制介面的管理狀態，以便變更組態或進行維護。管理狀態可能與運作狀態不同。但是，如果介面的管理狀態為「已停用」，則其運作狀態預設為「已停用」。

* *IP 位址 / WWPN*
+
顯示乙太網路介面的 IP 位址和 FC LIF 的全球連接埠名稱（WWPN）。

* *協定*
+
顯示為介面指定的資料協定清單，例如 CIFS、NFS、iSCSI、FC/FCoE、FC-NVMe 和 FlexCache。

* *角色*
+
顯示介面角色。角色可以是資料角色或管理角色。

* *主連接埠*
+
顯示介面最初關聯的實體連接埠。

* *目前連接埠*
+
顯示介面目前關聯的實體連接埠。如果介面已遷移，則目前連接埠可能與主連接埠不同。

* *連接埠集*
+
顯示介面所對應的連接埠集。

* *容錯移轉原則*
+
顯示為介面設定的容錯移轉原則。對於 NFS、CIFS 和 FlexCache 介面，預設容錯移轉原則為 Next Available。容錯移轉原則不適用於 FC 和 iSCSI 介面。

* *路由群組*
+
顯示路由群組的名稱。按一下路由群組名稱，即可檢視更多有關路由和目的地閘道的資訊。

+
ONTAP 8.3 或更新版本不支援路由群組，因此這些叢集會顯示空白欄。

* *容錯移轉群組*
+
顯示容錯移轉群組的名稱。





[[qtrees-tab]]
== Qtrees 索引標籤

「Qtrees」標籤顯示有關 qtree 及其配額的詳細資訊。如果您想要編輯一個或多個 qtree 的 qtree 容量健全狀況臨界值設定，可以按一下 *編輯臨界值* 按鈕。

使用 *匯出* 按鈕建立包含所有受監控 qtree 詳細資料的逗號分隔值 (.csv) 檔案。匯出至 CSV 檔案時，您可以選擇為目前的儲存設備 VM、目前叢集中的所有儲存設備 VM，或是資料中心內所有叢集的所有儲存設備 VM 建立 qtree 報告。匯出的 CSV 檔案中會顯示一些額外的 qtree 欄位。

* *狀態*
+
顯示 qtree 的目前狀態。狀態可以是關鍵（image:../media/sev_critical_um60.png["事件嚴重程度圖示 – 關鍵"]）、錯誤（image:../media/sev_error_um60.png["事件嚴重程度圖示 – 錯誤"]）、警告（image:../media/sev_warning_um60.png["事件嚴重性圖示 – 警告"]）或正常（image:../media/sev_normal_um60.png["事件嚴重程度圖示 – 正常"]）。

+
您可以將指標移到狀態圖示上，以檢視有關為 qtree 產生之事件的更多資訊。

+
如果 qtree 的狀態由單一事件決定，您可以檢視事件名稱、事件觸發的時間和日期、事件指派的系統管理員姓名以及事件原因等資訊。您可以使用 *檢視詳細資訊* 來檢視有關該事件的更多資訊。

+
如果 qtree 的狀態由多個相同嚴重程度的事件決定，則會顯示前三個事件，並包含事件名稱、觸發時間和日期以及分配給該事件的系統管理員姓名等資訊。您可以點擊事件名稱檢視每個事件的更多詳細資訊。您也可以使用 *檢視所有事件* 來檢視已產生的事件清單。

+
[NOTE]
====
一個 qtree 可以包含多個相同嚴重程度或不同嚴重程度的事件。但是，只會顯示最高嚴重程度的事件。例如，如果一個 qtree 包含兩個嚴重程度分別為「錯誤」和「警告」的事件，則只會顯示「錯誤」嚴重程度。

====
* *Qtree*
+
顯示 qtree 的名稱。

* *叢集*
+
顯示包含 qtree 的叢集名稱。僅顯示在匯出的 CSV 檔案中。

* *儲存虛擬機器*
+
顯示包含 qtree 的儲存虛擬機器（SVM）名稱。僅出現在匯出的 CSV 檔案中。

* *磁碟區*
+
顯示包含 qtree 的 Volume 的名稱。

+
您可以將指標移到 Volume 名稱上，以檢視有關該 Volume 的更多資訊。

* *配額設定*
+
指示 qtree 上是否啟用或停用配額。

* *配額類型*
+
指定配額是針對使用者、使用者群組還是 qtree。僅顯示在匯出的 CSV 檔案中。

* *使用者或群組*
+
顯示使用者或使用者群組的名稱。每個使用者和使用者群組對應多行資料。當配額類型為 qtree 或未設定配額時，此列為空。僅顯示在匯出的 CSV 檔案中。

* *磁碟使用率 %*
+
顯示已使用磁碟空間百分比。如果設定了磁碟硬限制，則此值基於該磁碟硬限制。如果未設定磁碟硬限制而設定了配額，則此值會基於 Volume 資料空間。如果未設定配額，或 qtree 所屬 Volume 的配額已關閉，則網格頁面中將顯示 "`不適用`"，且 CSV 匯出資料中的該欄位為空。

* *磁碟硬限制*
+
顯示分配給 qtree 的最大磁碟空間。當達到此限制且不再允許任何磁碟寫入操作時，Unified Manager 會產生一個關鍵事件。在下列情況下，該值顯示為「`Unlimited`」：如果配額設定時未設定磁碟硬限制，或未設定配額，或 qtree 所屬 Volume 的配額已關閉。

* *磁碟軟限制*
+
顯示產生警告事件之前分配給 qtree 的磁碟空間量。在下列情況下，該值顯示為「`Unlimited`」：若設定配額時未設定磁碟軟限制、如果未設定配額，或 qtree 所屬 Volume 的配額已關閉。預設情況下，此欄為隱藏狀態。

* *磁碟臨界值*
+
顯示磁碟空間上設定的臨界值。在下列情況下，該值會顯示為「`Unlimited`」：若配額設定時沒有磁碟臨界值限制、若未設定配額，或是若 qtree 所屬 Volume 上的配額已關閉。預設情況下，此欄位為隱藏。

* *已使用檔案 %*
+
顯示 qtree 中已使用的檔案百分比。如果設定了檔案硬限制，則此值基於檔案硬限制。如果設定了配額但未設定檔案硬限制，則不顯示任何值。如果未設定配額，或 qtree 所屬 Volume 的配額已關閉，則網格頁面中會顯示 "`不適用`"，且 CSV 匯出資料中的該欄位為空。

* *檔案硬限制*
+
顯示 qtree 上允許的檔案數量硬限制。在下列情況下，此值會顯示為 "`Unlimited`"：若配額設定時未設定檔案硬限制、若未設定配額，或若 qtree 所屬 Volume 的配額已關閉。

* *檔案軟限制*
+
顯示 qtree 上允許的檔案數的軟限制。在下列情況下，數值顯示為 "`Unlimited`"：若配額設定時未設定檔案軟限制，或未設定配額，或 qtree 所屬 Volume 的配額已關閉。預設情況下，此欄為隱藏狀態。





[[user-and-group-quotas-tab]]
== 使用者和群組配額索引標籤

顯示所選儲存設備 VM 的使用者與使用者群組配額詳細資料。您可以檢視配額狀態、使用者或使用者群組名稱、在磁碟和檔案上設定的軟限制和硬限制、已使用的磁碟空間量和檔案數量，以及磁碟臨界值等資訊。您也可以變更與使用者或使用者群組關聯的電子郵件地址。

* *編輯電子郵件地址命令按鈕*
+
開啟「編輯電子郵件地址」對話方塊，其中顯示所選使用者或使用者群組的目前電子郵件地址。您可以修改電子郵件地址。如果 **編輯電子郵件地址** 欄位為空白，則會使用預設規則為所選使用者或使用者群組產生電子郵件地址。

+
如果多個使用者擁有相同的配額，則使用者名稱將以逗號分隔值顯示。此外，系統不會使用預設規則產生電子郵件地址；因此，您必須提供所需的電子郵件地址才能接收通知。

* *設定郵件規則命令按鈕*
+
允許您建立或修改規則，為儲存設備 VM 上設定的使用者或使用者群組配額產生電子郵件地址。當違反配額時，系統會傳送通知至指定的電子郵件地址。

* *狀態*
+
顯示配額的目前狀態。狀態可以是關鍵（image:../media/sev_critical_um60.png["事件嚴重程度圖示 – 關鍵"]）、警告（image:../media/sev_warning_um60.png["事件嚴重性圖示 – 警告"]）或正常（image:../media/sev_normal_um60.png["事件嚴重程度圖示 – 正常"]）。

+
您可以將指標移到狀態圖示上，以檢視有關配額產生的事件的更多資訊。

+
如果配額狀態由單一事件決定，您可以檢視事件名稱、事件觸發時間和日期、事件分配的系統管理員姓名以及事件原因等資訊。您可以使用 *檢視詳細資料* 檢視有關該事件的更多資訊。

+
如果配額狀態由多個相同嚴重程度的事件決定，則會顯示前三個事件，並包含事件名稱、觸發時間和日期以及分配給該事件的系統管理員姓名等資訊。您可以點擊事件名稱檢視每個事件的更多詳細資訊。您也可以使用 *檢視所有事件* 來檢視已產生的事件清單。

+
[NOTE]
====
一個配額可以包含多個相同嚴重程度或不同嚴重程度的事件。但是，只會顯示最高嚴重程度。例如，如果一個配額包含兩個嚴重程度分別為「錯誤」和「警告」的事件，則只會顯示「錯誤」嚴重程度。

====
* *使用者或群組*
+
顯示使用者或使用者群組的名稱。如果多個使用者擁有相同的配額，則以逗號分隔值顯示使用者名稱。

+
當 ONTAP 因 SecD 錯誤而無法提供有效的使用者名稱時，該值將顯示為 "`Unknown`"。

* *類型*
+
指定配額是針對使用者還是使用者群組。

* *Volume 或 Qtree*
+
顯示指定使用者或使用者群組配額的 Volume 或 qtree 的名稱。

+
您可以將指標移到 Volume 或 qtree 的名稱上，以檢視有關該 Volume 或 qtree 的更多資訊。

* *磁碟使用率 %*
+
顯示已使用的磁碟空間百分比。如果設定配額時沒有磁碟硬限制，則該值將顯示為「`不適用`」。

* *磁碟硬限制*
+
顯示配額分配的最大磁碟空間量。當達到此限制且不再允許任何磁碟寫入操作時，Unified Manager 會產生關鍵事件。如果配額設定時未指定磁碟硬限制，則該值顯示為 "`Unlimited`"。

* *磁碟軟限制*
+
顯示產生警告事件之前分配給配額的磁碟空間量。如果配額設定時未設定磁碟軟限制，則該值顯示為 "`Unlimited`"。預設情況下，此欄為隱藏狀態。

* *磁碟臨界值*
+
顯示在磁碟空間上設定的臨界值。如果設定的配額沒有磁碟臨界值限制，則該值會顯示為 "`Unlimited`"。預設情況下，此欄為隱藏狀態。

* *已使用檔案 %*
+
顯示 qtree 中已使用檔案的百分比。如果設定配額時沒有檔案硬限制，則該值會顯示為 "`不適用`"。

* *檔案硬限制*
+
顯示配額允許的檔案數量的硬限制。如果配額未設定檔案硬限制，則該值顯示為 "`Unlimited`"。

* *檔案軟限制*
+
顯示配額允許的檔案數量的軟限制。如果配額未設定檔案軟限制，則該值顯示為 "`Unlimited`"。預設情況下，此欄位為隱藏狀態。

* *電子郵件地址*
+
顯示配額超限時，接收通知的使用者或使用者群組的電子郵件地址。





[[nfs-shares-tab]]
== NFS 共享索引標籤

「NFS 共享」標籤顯示有關 NFS 共享的資訊，例如其狀態、與 Volume 關聯的路徑（FlexGroup Volume 或 FlexVol Volume）、用戶端對 NFS 共享的存取等級，以及為匯出的 Volume 定義的匯出原則。在下列情況下，將不會顯示 NFS 共享：如果 Volume 未掛載，或與 Volume 的匯出原則關聯的協定不包含 NFS 共享。

* *狀態*
+
顯示 NFS 共享的目前狀態。狀態可以是錯誤（image:../media/sev_error_um60.png["事件嚴重程度圖示 – 錯誤"]）或正常（image:../media/sev_normal_um60.png["事件嚴重程度圖示 – 正常"]）。

* *交會路徑*
+
顯示 Volume 的掛載路徑。如果對 qtree 套用明確的 NFS 匯出原則，則此欄會顯示可透過其存取 qtree 的 Volume 路徑。

* *交會路徑作用中*
+
顯示存取掛載 Volume 的路徑是作用中還是非作用中。

* *Volume 或 Qtree*
+
顯示套用 NFS 匯出原則的 Volume 或 qtree 的名稱。如果 NFS 匯出原則套用於 Volume 中的 qtree，則該欄會同時顯示 Volume 的名稱和 qtree 的名稱。

+
您可以點擊連結在對應的詳情頁面檢視物件的詳細資訊。如果物件是 qtree，則會同時顯示 qtree 和 Volume 的連結。

* *Volume 狀態*
+
顯示正在匯出的 Volume 的狀態。狀態可以是離線、線上、受限或混合。

+
** 離線
+
不允許對該 Volume 進行讀取或寫入存取。

** 線上
+
允許對該 Volume 進行讀取與寫入存取。

** 受限
+
允許進行有限的操作，例如同位元檢查重構，但不允許資料存取。

** 混合
+
一個 FlexGroup Volume 的各個組成部分並不都處於相同的狀態。



* *安全樣式*
+
顯示已匯出 Volume 的存取權限。安全樣式可以是 UNIX、統一、NTFS 或混合。

+
** UNIX（NFS 用戶端）
+
Volume 中的檔案和目錄具有 UNIX 權限。

** 統一化
+
Volume 中的檔案和目錄具有統一化的安全風格。

** NTFS（CIFS 用戶端）
+
Volume 中的檔案和目錄具有 Windows NTFS 權限。

** 混合
+
Volume 中的檔案和目錄可以具有 UNIX 權限或 Windows NTFS 權限。



* *UNIX 權限*
+
以八進位字串格式顯示為匯出 Volume 設定的 UNIX 權限位元。它類似於 UNIX 樣式的權限位元。

* *匯出原則*
+
顯示定義匯出 Volume 存取權限的規則。您可以點擊連結檢視與匯出原則關聯的規則詳情，例如驗證協定和存取權限。
