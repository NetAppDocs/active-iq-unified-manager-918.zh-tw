= 了解 Active IQ Unified Manager 中的註解規則如何運作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
註解規則是您為註解儲存設備物件（Volume、叢集或儲存設備虛擬機器（SVM））所定義的準則。您可以使用條件群組或條件來定義註解規則。

* 您必須將註釋規則與註釋建立關聯。
* 您必須為註解規則關聯一個物件類型；一個註解規則只能關聯一個物件類型。
* Unified Manager 會在每個監控週期之後，或是建立、編輯、刪除或重新排序規則時，為儲存設備物件新增或移除註解。
* 一項註釋規則可以有一個或多個條件群組，每個條件群組可以有一個或多個條件。
* 儲存設備物件可以擁有多個註解。針對特定註解的註解規則也可以在其規則條件中使用不同的註解，以將另一個註解新增至已加上註解的物件。




[[conditions]]
== 狀況

您可以建立多個條件群組，每個條件群組可以包含一個或多個條件。您可以將所有定義的條件群組套用至註解的註解規則中，以便對儲存設備物件進行註解。

條件群組中的條件是使用邏輯 AND 執行。必須符合條件群組中的所有條件。建立或修改註解規則時，系統會建立一個條件，該條件僅套用、選取並註解符合條件群組中所有條件的儲存設備物件。當您想要縮小要註解的儲存設備物件範圍時，可以在條件群組中使用多個條件。

您可以使用下列運算元和營運者並指定所需的值來建立儲存設備物件的條件。

[cols="2*"]
|===
| 儲存物件類型 | 適用運算元 


 a| 
磁碟區
 a| 
* 物件名稱
* 所屬叢集名稱
* 擁有 SVM 名稱
* 註解




 a| 
SVM
 a| 
* 物件名稱
* 所屬叢集名稱
* 註解




 a| 
叢集
 a| 
* 物件名稱
* 註解


|===
當您選擇註解作為任何儲存設備物件的運算數時， "`Is`" 營運者可用。對於所有其他運算數，您可以選擇 "`Is`" 或 "`Contains`" 作為營運者。當您選擇 "`Is`" 營運者時，系統會評估條件，以確認運算數的值是否與為所選運算數提供的值完全相符。當您選擇 "`Contains`" 營運者時，系統會評估條件是否符合下列準則之一：

* 運算元值與所選運算元的值完全相符。
* 運算元值包含為所選運算元提供的值。




[[example-of-an-annotation-rule-with-conditions]]
== 帶有條件的註解規則範例

考慮一個註釋規則，該規則包含一個條件群組，用於滿足下列兩個條件的 Volume：

* 名稱包含 "`vol`"
* SVM 名稱為 "`data_svm`"


此註釋規則會以選定的註釋和註釋類型，對所有名稱中包含 "`vol`" 且託管在名稱為 "`data_svm`" 的 SVM 上的 Volume 進行註釋。



[[condition-groups]]
== 條件群組

條件群組使用邏輯「或」運算執行，然後套用於儲存設備物件。儲存設備物件必須滿足其中一個條件群組的要求才能被標註。滿足所有條件群組要求的儲存設備物件將被標註。您可以使用條件群組來擴大需要標註的儲存設備物件的範圍。



[[example-of-an-annotation-rule-with-condition-groups]]
== 包含條件群組的註釋規則範例

考慮一個包含兩個條件群組的 Volume 註解規則；每個群組包含下列兩個條件：

* 條件組 1
+
** 名稱包含 "`vol`"
** SVM 名稱是「`data_svm`」。此條件群組會註解名稱中包含「`vol`」且託管在名為「`data_svm`」的 SVM 上的所有 Volume。


* 條件組 2
+
** 名稱包含 "`vol`"
** data-priority 的註解值為 "`關鍵`"。此條件群組會註解所有名稱中包含 "`vol`" 且 data-priority 註解值為 "`關鍵`" 的 Volume。




當包含這兩個條件組的註解規則應用於儲存設備物件時，以下儲存設備物件將被註解：

* 名稱中包含「`vol`」且託管在名稱為「`data_svm`」的 SVM 上的所有 Volume。
* 所有名稱中包含 "`vol`" 且 data-priority 註解值標註為 "`關鍵`" 的 Volume。
