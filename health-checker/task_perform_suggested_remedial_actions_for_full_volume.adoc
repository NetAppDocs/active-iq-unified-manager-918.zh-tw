= 在 Active IQ Unified Manager 中對容量已滿的 Volume 執行建議的補救措施
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
收到 "`Volume 空間已滿`" 錯誤事件後，您在事件詳細資料頁面上審查建議的補救行動，並決定執行其中一項建議的行動。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

任何角色的使用者都可以執行此工作流程中所有使用 Unified Manager 的任務。

在本例中，您在 Unified ManagerEvent Management 庫存頁面上看到了 Volume 空間已滿錯誤事件，並點選了該事件的名稱。

針對已滿的 Volume，您可以執行下列可能的補救行動：

* 在 Volume 上啟用自動擴充、重複資料刪除或壓縮
* 調整 Volume 大小或移動 Volume
* 從 Volume 中刪除或移動資料


雖然所有這些行動都必須透過 ONTAP System Manager 或 ONTAP CLI 執行，但您可以使用 Unified Manager 來尋找您可能需要用來決定要採取哪些行動的資訊。

.步驟
. 在「事件」詳細資料頁面中，按一下「來源」欄位中的 Volume 名稱，即可檢視受影響 Volume 的詳細資訊。
. 在 *Volume / 健全狀況* 詳細資料頁面上，按一下 *組態*，可以看到該 Volume 已啟用重複資料刪除和壓縮。
+
您決定調整 Volume 的大小。

. 在 *相關設備* 窗格中，按一下託管彙總的名稱，查看該彙總是否可以容納更大的 Volume。
. 在 *彙總 / 運作狀況* 詳細資料頁面上，您可以看到託管已滿 Volume 的彙總確實有足夠的未分配容量，因此您可以使用 ONTAP System Manager 調整 Volume 大小，為其提供更多容量。
