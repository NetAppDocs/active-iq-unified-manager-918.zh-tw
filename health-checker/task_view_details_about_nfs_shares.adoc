= 在 Active IQ Unified Manager 中檢視 NFS 共用的詳細資料
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以檢視所有 NFS 共享的詳細資料，例如其狀態、與 Volume 關聯的路徑（FlexGroup Volume 或 FlexVol Volume）、用戶端對 NFS 共享的存取層級，以及為匯出的 Volume 定義的匯出原則。使用「健全狀況：所有 NFS 共享」檢視可查看所有受監控叢集上的所有 NFS 共享，並使用「儲存設備虛擬機器 / 健全狀況」詳細資料頁面來檢視特定儲存設備虛擬機器（SVM）上的所有 NFS 共享。

.開始之前
* 叢集上必須啟用 NFS 授權。
* 必須設定用於 NFS 共享的網路介面。
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。


.步驟
. 在左側導覽窗格中，根據您要檢視所有 NFS 共享還是僅檢視特定 SVM 的 NFS 共享，請按照下列步驟操作。
+
[cols="2*"]
|===
| 若要…… | 請依照以下步驟操作...... 


 a| 
檢視所有 NFS 共享
 a| 
按一下 *儲存設備* > *NFS 共享*



 a| 
檢視單一 SVM 的 NFS 共享
 a| 
.. 點選 *儲存設備* > *儲存虛擬機器*
.. 按一下要檢視 NFS 共享詳細資訊的 SVM。
.. 在 Storage VM / 健全狀況詳細資料頁面中，按一下「*NFS 共享*」標籤。


|===


如需更多資訊,請參閱 link:../storage-mgmt/task_provision_fileshares.html["配置檔案共享 Volume"] 和 link:../api-automation/concept_provision_file_share.html["使用 API 配置 CIFS 和 NFS 檔案共享"]。
