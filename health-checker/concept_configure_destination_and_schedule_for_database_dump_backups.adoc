= 在 Active IQ Unified Manager 中設定資料庫傾印備份設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以設定 Unified Manager 資料庫傾印備份設定，以設定資料庫備份路徑、保留計數和備份排程。您可以啟用每日或每週的排程備份。預設情況下，排程備份為停用狀態，但您應該設定備份排程。

.開始之前
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。
* 您指定的備份路徑位置必須至少有 150 GB 的可用空間。
+
建議您使用位於 Unified Manager 主機系統外部的遠端位置。

* 當 Unified Manager 安裝在 Linux 系統上，並使用 MySQL 備份時，請確保在備份目錄上設定下列權限和所有權。
+
權限：0750，擁有權：jboss:maintenance

* 當 Unified Manager 安裝在 Windows 系統上，並使用 MySQL 備份時，請確保只有系統管理員才能存取備份目錄。


首次備份所需時間比後續備份更長，因為首次備份是完整備份。完整備份可能超過 1 GB，耗時三到四小時。後續備份是遞增，所需時間更短。

[NOTE]
====
* 如果遞增備份檔案數量過多，超過了您分配的備份空間，您可以定期進行完整備份，以取代舊的備份及其遞增檔案。此外，您也可以使用 Snapshot 複本進行備份。
* 在新叢集加入後的前 15 天內所做的備份可能不夠準確，無法取得歷史效能資料。


====
.步驟
. 在左側導覽窗格中，按一下 *一般* > *資料庫備份*。
. 在 *資料庫備份* 頁面中，按一下 *備份設定*。
. 設定備份路徑、保留計數和排程的適當值。
+
保留計數的預設值為 10；您可以將其設為 0 以建立無限備份。

. 選擇 *排程每日* 或 *排程每週* 按鈕，然後指定排程詳細資料。
. 點選 *套用*。


資料庫傾印備份檔案會根據排程建立。您可以在「資料庫備份」頁面查看可用的備份檔案。
