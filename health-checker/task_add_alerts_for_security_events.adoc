= 在 Active IQ Unified Manager 中新增安全性事件警報
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以像設定 Unified Manager 接收的任何其他事件一樣，為個別安全性事件設定警報。此外，如果您希望將所有安全性事件一視同仁，並將電子郵件傳送給同一個人，您可以建立單一警報，以便在觸發任何安全性事件時通知您。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

以下範例展示如何為 "`Telnet Protocol Enabled`" 安全性事件建立警報。如果已設定 Telnet 存取以進行叢集的遠端管理存取，這將會傳送警報。您可以使用相同的方法為所有安全性事件建立警報。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *警示設定*。
. 在 *警報設定* 頁面中，按一下 *新增*。
. 在 *新增警報* 對話方塊中，按一下 *名稱*，然後輸入警報的名稱和執行摘要。
. 按一下 *資源*，然後選擇要啟用此警報的叢集或叢集。
. 按一下 *事件* 並執行下列動作：
+
.. 在事件嚴重性清單中，選擇 *警告*。
.. 在符合事件清單中，選擇 *已啟用 Telnet 協定*。


. 按一下 *動作* ，然後在 *警示這些使用者* 欄位中選取將收到警示電子郵件的使用者名稱。
. 在此頁面上設定通知頻率、發出 SNMP taps 及執行指令碼的任何其他選項。
. 按一下 *Save* 。
