= 從 Active IQ Unified Manager 中刪除註解值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當某個值不再適用於註釋時，您可以刪除與自訂註釋相關聯的值。

.開始之前
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。
* 註解值不得與任何註解規則或群組規則關聯。


您無法從預先定義的註釋中刪除值。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *註解*。
. 在 *註釋* 標籤的註釋清單中，選擇要從中刪除值的註釋。
. 在 *註釋* 標籤的 *值* 區域中，選擇您要刪除的值，然後按一下 *刪除*。
. 在「警告」對話方塊中，按一下「是」。
+
該值已被刪除，不再顯示在所選註釋的值清單中。
