= 了解常見的 Active IQ Unified Manager 健全狀況工作流程與任務
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
與 Unified Manager 相關的一些常見管理工作流程和任務包括：選擇要監控的儲存設備叢集；診斷對資料可用度、容量和保護產生不利影響的情況；還原遺失的資料；設定和管理 Volume；以及將診斷資料打包並傳送給技術支援（如有必要）。

Unified Manager 使儲存設備管理員能夠檢視儀表板，評估代管儲存設備叢集的整體容量、可用度和保護健全狀況，然後快速識別、定位、診斷及指派解決任何可能出現的特定問題。

與叢集、儲存虛擬機器 (SVM) 、 Volume 或 FlexGroup Volume 相關，且會影響代管儲存物件之儲存容量或資料可用度的最重要問題，會顯示在「儀表板」頁面的系統健全狀況圖表與事件中。當發現關鍵問題時，此頁面會提供連結，以支援適當的疑難排解工作流程。

Unified Manager 也可以包含在具備相關管理工具（例如 OnCommand Workflow Automation（WFA））的工作流程中，以支援儲存資源的直接組態。

本文件說明與下列管理任務相關的常見工作流程：

* 診斷與管理可用度問題
+
如果硬體故障或儲存資源組態問題導致儀表板頁面顯示資料可用度事件，儲存設備管理員可以按照嵌入的連結檢視受影響儲存資源的連線資訊、檢視疑難排解建議，並將問題解決指派給其他管理員。

* 設定與監控效能事件
+
管理員可以監控和管理正在監控的儲存系統資源的效能。如需詳細資訊，請參閱 link:../performance-checker/concept_introduction_to_unified_manager_performance_monitoring.html["Active IQ Unified Manager 效能監控簡介"]。

* 診斷與管理 Volume 容量問題
+
如果儀表板頁面顯示 Volume 儲存容量問題，儲存設備管理員可以點擊嵌入的連結檢視與受影響 Volume 的儲存容量相關的目前和歷史趨勢，檢視疑難排解建議，並將問題解決指派給其他管理員。

* 設定、監控與診斷保護關係問題
+
建立和設定保護關係後，儲存設備管理員可以檢視與保護關係相關的潛力問題、保護關係的目前狀態、受影響關係的目前和歷史保護作業成功資訊，以及疑難排解建議。如需詳細資訊，請參閱 link:../data-protection/concept_manage_and_monitor_protection_relationships.html["了解如何管理與監控保護關係"]。

* 建立備份檔案並從備份檔案中還原資料。
* 將儲存設備物件與註解建立關聯
+
透過將儲存設備物件與註解建立關聯，儲存設備管理員可以篩選及檢視與儲存設備物件相關的事件，進而讓儲存設備管理員能夠排定與事件相關之問題的優先順序並加以解決。

* 使用 REST API 檢視 Unified Manager 所擷取的健全狀況、容量與效能資訊，以協助管理您的叢集。如需詳細資訊，請參閱 link:../api-automation/concept_get_started_with_um_apis.html["Active IQ Unified Manager REST API 入門指南"]。
* 傳送支援套裝組合給技術支援
+
儲存管理員可以使用維護主控台擷取支援套裝組合，並將其傳送給技術支援。當問題需要比 AutoSupport 訊息所提供的更詳細的診斷與疑難排解時，必須將支援套裝組合傳送給技術支援。
