= 在 Active IQ Unified Manager 中重新排序註解規則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以變更 Unified Manager 將註解規則套用至儲存設備物件的順序。註解規則會根據其優先順序依序套用至儲存設備物件。設定註解規則時，其優先順序最低。但您可以根據需求變更註解規則的優先順序。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

您可以選擇單一列或多列，並執行多項拖放操作來變更註解規則的順序。但是，您必須儲存變更，重新排定優先順序的結果才會顯示在「註解規則」標籤中。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *註解*。
. 在 *註解規則* 標籤中，按一下 *重新排序*。
. 在 *重新排序註解規則* 對話方塊中，拖放單一或多個資料列以重新排列註解規則的順序。
. 按一下 *Save* 。
+
必須儲存變更才能顯示重新排序的結果。
