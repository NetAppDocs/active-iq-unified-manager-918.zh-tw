= 在 Active IQ Unified Manager 中編輯群組
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以編輯在 Unified Manager 中建立的群組的名稱和執行摘要。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

編輯群組以更新名稱時，必須指定一個唯一的名稱；不能使用現有的群組名稱。

.步驟
. 在左側導覽窗格中，按一下 *儲存管理* > *群組*。
. 在「群組」標籤中，選擇您要編輯的群組，然後按一下「編輯」。
. 在 *編輯群組* 對話方塊中，變更群組的名稱、執行摘要或兩者。
. 按一下 *Save* 。
