= 在 Active IQ Unified Manager 中檢視 Storage VM 清單與詳細資料
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在「健全狀況：所有儲存設備虛擬機器」檢視中，您可以監控儲存設備虛擬機器（SVM）的清單。您可以使用「儲存設備虛擬機器 / 健全狀況詳細資料」頁面檢視有關受監控 SVM 的詳細資訊。

.開始之前
您必須擁有操作員、應用程式管理員或儲存管理員角色。

您可以檢視 SVM 的詳細資訊，例如 SVM 的容量、效率和組態。您也可以檢視有關該 SVM 的相關裝置和相關警報的資訊。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備* > *儲存虛擬機器*。
. 請選擇以下方式之一檢視 SVM 詳細資料：
+
** 若要檢視所有叢集中所有 SVM 的健全狀況資訊，請在「檢視」功能表中，選取「健全狀況：所有 Storage VM 檢視」。
** 若要檢視完整的詳細資料，請按一下 Storage VM 名稱。
+
您也可以在精簡詳細資料對話方塊中按一下 *檢視詳細資料* 來檢視完整的詳細資料。



. 在最小詳細資料對話方塊中，按一下 *檢視相關* 以檢視與 SVM 相關的物件。
