= 了解 Active IQ Unified Manager 的健全狀況監控功能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 建構於伺服器基礎架構之上，可提供擴充性、支援性，以及增強的監控與通知功能。Unified Manager 支援對執行 ONTAP 軟體之系統的監控。

Unified Manager 包含以下功能：

* 針對安裝 ONTAP 軟體的系統進行探索、監控與通知：
+
** 實體物件：節點、磁碟、磁碟櫃、SFO 對、連接埠和 Flash Cache
** 邏輯物件：叢集、儲存設備虛擬機器 (SVM)、Aggregate、Volume、LUN、命名空間、qtree、LIF、Snapshot 複本、交會路徑、NFS 共享、SMB 共享、使用者和群組配額、QoS 原則群組和啟動器群組
** 協定：CIFS、NFS、FC、iSCSI、NVMe 和 FCoE
** 儲存效率：SSD Aggregate、Flash Pool Aggregate、FabricPool Aggregate、重複資料刪除與壓縮
** 保護：SnapMirror 關係（同步與非同步）與 SnapVault 關係


* 檢視叢集探索與監控狀態
* MetroCluster 透過 FC 與 IP 的組態：檢視與監控叢集元件的組態、問題與連線狀態。MetroCluster 交換器與橋接器（適用於透過 FC 組態的 MetroCluster）
* 增強型警報、事件與臨界值基礎架構
* LDAP、LDAPS、SAML 驗證和本機使用者支援
* RBAC（針對預先定義的角色集）
* AutoSupport 和支援套裝組合
* 增強型儀表板，用於顯示環境的容量、可用度、保護和效能健全狀況
* Volume 移動互通性、Volume 移動歷史記錄與交會路徑變更歷史記錄
* 影響範圍區域以圖形方式顯示受「部分磁碟故障」、MetroCluster「Aggregate 鏡射降級」及 MetroCluster「備用磁碟遺留」等事件影響的資源
* 可能影響區域，顯示 MetroCluster 事件的影響
* 「建議的修正措施」區域會顯示可用於解決諸如「部分磁碟故障」、MetroCluster「Aggregate 鏡射降級」和 MetroCluster「遺留的備用磁碟」等事件的動作
* 「可能受影響的資源」區域會顯示可能受 Volume 離線事件、 Volume 受限事件和精簡資源配置 Volume 空間風險事件等事件影響的資源
* 支援採用 FlexVol 或 FlexGroup Volume 的 SVM
* 支援監控節點根 Volume
* 增強 Snapshot 複本監控，包括運算可回收空間和刪除 Snapshot 複本
* 儲存設備物件的註解
* 建立和管理儲存設備物件資訊的報告，例如實體和邏輯容量、使用率、空間節約效益、效能和相關事件
* 與 OnCommand Workflow Automation 整合以執行工作流程
