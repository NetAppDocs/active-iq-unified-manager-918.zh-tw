= 在 Active IQ Unified Manager 中檢視叢集和儲存虛擬機器的安全性狀態
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 可讓您從介面的不同位置檢視環境中儲存設備物件的安全性狀態。您可以根據定義的參數收集和分析資訊及報告，並偵測受監控叢集和儲存設備虛擬機器上的可疑行為或未經授權的系統變更。

有關安全性建議，請參閱 https://www.netapp.com/pdf.html?item=/media/10674-tr4569pdf.pdf["NetApp ONTAP 9 安全性強化指南"^]



[[view-object-level-security-status-on-security-page]]
== 在「安全性」頁面上檢視物件層級的安全性狀態

身為系統管理員，您可以使用 *Security* 頁面來取得資料中心和站台層級的 ONTAP 叢集和儲存設備虛擬機器安全性強度的可見度。支援的物件包括叢集、儲存設備虛擬機器和 Volume。請依照下列步驟操作：

.步驟
. 在左側導覽窗格中，按一下 *儀表板*。
. 視您要檢視所有受監控叢集或單一叢集的安全性狀態而定，請選擇 *所有叢集* 或從下拉式選單中選擇單一叢集。
. 點選 *安全性* 面板中的右箭頭。隨即顯示「安全性」頁面。


按一下長條圖、計數和 `View Reports`連結，即可進入 Volume 、叢集或儲存 VM 頁面，以便視需要檢視對應的詳細資料或產生報告。

「安全性」頁面顯示下列面板：

* *叢集法規遵循*：資料中心內所有叢集的安全性狀態（符合法規或不符合法規的叢集數量）
* *Storage VM 法規遵循*：資料中心內所有 Storage VM 的安全性狀態（符合法規或不符合法規的 Storage VM 數量）
* *Volume Encryption*：您環境中所有 Volume 的 Volume 加密狀態（已加密或未加密的 Volume 數量）
* *Volume 反勒索軟體狀態*：環境中所有 Volume 的安全性狀態（已啟用或已停用反勒索軟體的 Volume 數量）
* *叢集身分驗證和憑證*：使用每種身分驗證方法（例如 SAML、Active Directory 或透過憑證和本機驗證）的叢集數量。此面板還會顯示憑證已過期或將在 60 天內過期的叢集數量。




[[view-security-details-of-all-clusters-on-the-clusters-page]]
== 在「叢集」頁面上檢視所有叢集的安全性詳細資料

*叢集 / 安全性* 詳細資訊頁面可讓您檢視叢集層級的安全性法規遵循狀態。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備 > 叢集*。
. 選擇 *檢視 > 安全性 > 所有叢集*。


顯示預設安全性參數，例如全域 FIPS、Telnet、不安全的 SSH 設定、登入橫幅、網路時間協定、AutoSupport HTTPS 傳輸以及叢集憑證過期狀態。

您可以點選 image:icon_kabob.gif["烤肉串圖示"] 「更多選項」按鈕，選擇在 Unified Manager 的 *安全性* 頁面或 System Manager 中檢視安全性詳情。您需要擁有有效的憑證才能在 System Manager 中檢視詳情。


NOTE: 如果叢集的憑證已過期，您可以按一下 *Cluster Certificate Validity* 下方的 `expired`，然後從 System Manager（9.10.1 及更新版本）將其續約。如果 System Manager 執行個體的版本早於 9.10.1，則無法按一下 `expired`。



[[view-security-details-of-all-clusters-from-the-storage-vms-page]]
== 從儲存設備虛擬機器頁面檢視所有叢集的安全性詳細資料

*儲存虛擬機器 / 安全性* 詳細資訊頁面可讓您檢視儲存虛擬機器層級的安全性法規遵循狀態。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備 > 儲存 VM*。
. 選擇 *檢視 > 安全性 > 所有儲存虛擬機器*。此時將顯示包含安全性參數的叢集清單。


您可以透過檢查安全性參數（例如儲存設備虛擬機器、叢集、登入橫幅、稽核日誌和不安全的 SSH 設定）來取得儲存設備虛擬機器安全性法規遵循的預設檢視。

您可以點選 image:icon_kabob.gif["烤肉串圖示"] 「更多選項」按鈕，選擇在 Unified Manager 的 *安全性* 頁面或 System Manager 中檢視安全性詳情。您需要擁有有效的憑證才能在 System Manager 中檢視詳情。

如需 Volume 和儲存設備虛擬機器的反勒索軟體安全性詳細資訊，請參閱 link:../health-checker/task_view_antiransomware_status_of_all_volumes_storage_vms.html["檢視所有 Volume 和 Storage VM 的反勒索軟體狀態"]。
