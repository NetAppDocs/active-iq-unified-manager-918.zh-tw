= 了解 Active IQ Unified Manager 中的預設註解值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
*資料優先權* 是一個預先定義的註解，其值包括「關鍵任務型」、「高」和「低」。這些值可讓您根據儲存設備物件中所含資料的優先順序來為其加上註解。您無法編輯或刪除預先定義的註解值。

* *資料優先：關鍵任務型*
+
此註解應用於包含任務關鍵型資料的儲存設備物件。例如，包含生產應用程式的物件可以被視為關鍵任務型。

* *資料優先：高*
+
此註解會套用於包含高優先權資料的儲存設備物件。例如，代管企業應用程式的物件可視為高優先權。

* *資料優先：低*
+
此註解套用於包含低優先順序資料的儲存設備物件。例如，位於次要儲存設備上的物件（例如備份和鏡射目的地）可能優先順序較低。
