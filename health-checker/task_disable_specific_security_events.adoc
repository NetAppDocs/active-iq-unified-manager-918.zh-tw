= 在 Active IQ Unified Manager 中停用特定安全性事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
所有事件預設啟用。您可以停用特定事件，以防止產生與您的環境無關的事件通知。如果您希望恢復接收已停用事件的通知，可以重新啟用這些事件。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

停用事件後，系統中先前產生的事件將被標記為過時，並且不會觸發針對這些事件設定的警報。啟用已停用的事件後，這些事件的通知將從下一個監控週期開始產生。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *事件設定*。
. 在 *事件* 設定頁面中，選擇下列選項之一來停用或啟用事件：
+
[cols="2*"]
|===
| 如果您想要…… | 然後這樣做…… 


 a| 
停用事件
 a| 
.. 按一下 *Disable* 。
.. 在「停用事件」對話方塊中，選擇 *警告* 嚴重程度。這是所有安全性事件的類別。
.. 在「符合事件」欄中，選擇要停用的安全性事件，然後按一下右箭頭將這些事件移至「停用事件」欄。
.. 點選 *儲存並關閉*。
.. 確認您已停用的事件是否顯示在「事件設定」頁面的清單檢視中。




 a| 
啟用事件
 a| 
.. 從已停用事件清單中，選取要重新啟用之事件的核取方塊。
.. 按一下 *Enable* 。


|===
