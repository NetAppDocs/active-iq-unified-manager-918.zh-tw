= 在 Active IQ Unified Manager 中編輯群組動作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以編輯在 Unified Manager 中設定的群組行動參數，例如群組行動名稱、執行摘要、關聯群組名稱和行動類型的參數。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *儲存管理* > *群組*。
. 在 *群組行動* 標籤中，選取您要編輯的群組行動，然後按一下 *編輯*。
. 在 *編輯群組行動* 對話方塊中，根據需要變更群組行動名稱、執行摘要、關聯群組名稱和行動類型的參數。
. 按一下 *Save* 。
