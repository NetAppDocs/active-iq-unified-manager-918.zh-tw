= 了解 Active IQ Unified Manager 中的資源池頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
資源池頁面顯示現有資源池及其成員，並允許您建立、監控和管理用於配置目的的資源池。



[[command-buttons]]
== 命令按鈕

命令按鈕可讓您執行下列任務：

* *建立*
+
啟動「建立資源池」對話方塊，您可以使用該對話方塊建立資源池。

* *編輯*
+
允許您編輯所建立的資源池的名稱和執行摘要。

* *刪除*
+
允許您刪除一個或多個資源池。





[[resource-pools-list]]
== 資源池清單

資源池清單（以表格形式）顯示現有資源池的屬性。

* *資源池*
+
顯示資源池的名稱。

* *說明*
+
描述資源池。

* *SnapLock 類型*
+
顯示資源池中 Aggregate 所使用的 SnapLock 類型。SnapLock 類型的有效值為 Compliance、Enterprise 和 Non-SnapLock。資源池只能包含一種 SnapLock 類型的 Aggregate。

* *總容量*
+
顯示資源池的總容量（以 MB、GB 等為單位）。

* *已使用容量*
+
顯示資源池使用的空間量（以 MB、GB 等為單位）。

* *可用容量*
+
顯示資源池可用的空間量（以 MB、GB 等為單位）。

* *已使用 %*
+
顯示資源池已使用的空間百分比。





[[members-list-command-buttons]]
== 成員清單命令按鈕

成員清單命令按鈕可讓您執行以下操作：

* *新增*
+
可讓您將成員新增至資源池。

* *刪除*
+
允許您從資源池刪除一個或多個成員。





[[members-list]]
== 成員名單

選擇資源池時，成員清單會以表格形式顯示資源池成員及其屬性。

* *狀態*
+
顯示成員彙總的目前狀態。狀態可以是嚴重（image:../media/sev_critical_um60.png[""]）、錯誤（image:../media/sev_error_um60.png[""]）、警告（image:../media/sev_warning_um60.png[""]）或正常（image:../media/sev_normal_um60.png[""]）。

* *彙總名稱*
+
顯示成員彙總的名稱。

* *狀態*
+
顯示 Aggregate 的目前狀態，可能為下列其中一種：

+
** 離線
+
不允許讀取或寫入存取。

** 線上
+
允許對託管在此 Aggregate 上的 Volume 進行讀寫存取。

** 受限
+
允許進行有限的操作（例如同位元檢查重構），但不允許資料存取。

** 建立
+
彙總正在建立。

** 摧毀
+
彙總正在銷毀中。

** 失敗
+
該彙總無法設為線上。

** 凍結
+
此彙總（暫時）不處理請求。

** 不一致
+
此彙總已被標記為損壞；您應該聯絡技術支援。

** Iron 受限
+
無法在此彙總上執行診斷工具。

** 掛載
+
該彙總正在掛載中。

** 部分
+
至少找到了一個磁碟用於彙總，但缺少兩個或更多磁碟。

** 靜默
+
彙總正在靜止。

** 已靜止
+
彙總處於靜止狀態。

** 已回復
+
彙總的回復已完成。

** 未掛載
+
彙總已卸載。

** 卸載
+
正在將彙總設為離線。

** 未知
+
已發現彙總，但 Unified Manager 伺服器尚未擷取彙總資訊。



+
預設情況下，此欄處於隱藏狀態。

* *叢集*
+
顯示彙總所屬叢集的名稱。

* *節點*
+
顯示彙總所在的節點名稱。

* *總容量*
+
顯示彙總的總容量（以 MB、GB 等為單位）。

* *已使用容量*
+
顯示彙總中使用的空間量（以 MB、GB 等為單位）。

* *可用容量*
+
顯示彙總中可用的空間量（以 MB 、 GB 等為單位）。

* *已使用 %*
+
顯示彙總中已使用的空間百分比。

* *磁碟類型*
+
顯示 RAID 組態類型，可以是下列幾種類型之一：

+
** RAID0：所有 RAID 群組均為 RAID0 類型。
** RAID4：所有 RAID 群組均為 RAID4 類型。
** RAID-DP：所有 RAID 群組均為 RAID-DP 類型。
** RAID-TEC：所有 RAID 群組均為 RAID-TEC 類型。
** 混合 RAID：彙總包含不同 RAID 類型（RAID0、RAID4、RAID-DP 和 RAID-TEC）的 RAID 群組。預設情況下，此欄為隱藏狀態。
