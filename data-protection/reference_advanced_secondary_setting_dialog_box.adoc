= 在 Active IQ Unified Manager 中使用「進階次要設定」對話方塊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用「進階次要設定」對話方塊在次要 Volume 上啟用版本彈性複寫、多複本備份和空間相關設定。當您想要變更、啟用或停用目前設定時，可以使用「進階次要設定」對話方塊。

與空間相關的設定可最大化儲存的資料量，包括下列各項：重複資料刪除、資料壓縮、自動增長和空間保證。

對話方塊包含以下欄位：

* *啟用版本靈活複寫*
+
啟用 SnapMirror 版本靈活複寫。版本靈活複寫可讓 SnapMirror 保護來源 Volume，即使目的地 Volume 執行的 ONTAP 版本早於來源 Volume。

+
** 啟用備份
+
如果啟用版本靈活複寫，也允許將 SnapMirror 來源資料的多個 Snapshot 快照技術複本傳輸並保留在 SnapMirror 目的地。



* *啟用重複資料刪除功能*
+
在 SnapVault 關係中的次要 Volume 上啟用重複資料刪除，以便消除複製的資料區塊來達成空間節約效益。當空間節約效益至少達 10% 且資料覆寫率不快時，您可以使用重複資料刪除。重複資料刪除常用於虛擬化環境、檔案共用和備份資料。此設定預設為停用。啟用時，此作業會在每次傳輸後啟動。

+
** 啟用壓縮
+
啟用透明的資料壓縮。當空間節約效益至少 10%、潛力例行成本可接受，且有充足的系統資源可在非尖峰時段完成壓縮時，您可以使用壓縮。在 SnapVault 關係中，此設定預設為停用。只有在選取重複資料刪除時，才能使用壓縮。

** 即時壓縮
+
透過在將資料寫入磁碟之前壓縮資料，可實現立即的空間節約效益。當您的系統在尖峰時段的使用率不超過 50%，且系統可以在尖峰時段容納新的寫入和額外的 CPU 時，您可以使用即時壓縮。此設定僅在選取 "`啟用壓縮`" 時可用。



* *啟用自動增長*
+
當可用空間百分比低於指定臨界值時，只要關聯的彙總上有可用空間，即可自動擴展目的地 Volume。

* *最大大小*
+
設定 Volume 可以增長的最大百分比。預設值為大於來源 Volume 大小 20%。如果目前大小大於或等於最大自動增長百分比，Volume 不會自動增長。僅當啟用自動增長設定時，此欄位才可用。

* *增量大小*
+
指定 Volume 在達到來源 Volume 的最大百分比之前自動增長的百分比增量。

* *空間保證*
+
確保在次要 Volume 上分配足夠的空間，以確保資料傳輸始終成功。空間保證設定可以是下列之一：

+
** 檔案
** 磁碟區
** 無 + 例如，您可能有一個 200 GB 的 Volume，其中包含總計 50 GB 的檔案；但是，這些檔案只包含 10 GB 的資料。Volume 保證會分配 200 GB 給目的地 Volume，無論來源上的內容為何。檔案保證會分配 50 GB，以確保為來源上的檔案保留足夠的空間；在此情況下選擇「無」，表示在目的地上僅分配 10 GB，用於來源上檔案資料實際使用的空間。


+
空間保證預設為 Volume。





[[command-buttons]]
== 命令按鈕

命令按鈕可讓您執行下列任務：

* *套用*
+
儲存選定的效率設定，並在「設定保護」對話方塊中按一下 *套用* 時套用這些設定。

* *取消*
+
放棄您的選擇並關閉「進階目的地設定」對話方塊。
