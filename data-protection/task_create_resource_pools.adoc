= 在 Active IQ Unified Manager 中建立資源池
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用「建立資源池」對話方塊對彙總進行分組，以便進行資源配置。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

.步驟
資源池可包含來自不同叢集的彙總，但相同的彙總不能屬於不同的資源池。

. 在左側導覽窗格中，按一下 *保護* > *資源池*。
. 在 *資源池頁面* 中，按一下 *建立*。
. 依照 *Create Resource Pool* 對話方塊中的指示，提供名稱和執行摘要，並將彙總新增為成員至您要建立的資源池。
