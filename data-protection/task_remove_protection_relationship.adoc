= 從 Active IQ Unified Manager 的「磁碟區關係」頁面中移除保護關係
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在「Volume 關係」頁面，您可以移除保護關係，從而永久刪除所選來源和目的地之間的現有關係：例如，當您想要使用不同的目的地建立關係時。此操作會移除所有中繼資料，且無法撤銷。

.開始之前
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。
* 您必須已設定 Workflow Automation。


.步驟
. 在 *Volume 關係* 頁面中，選取一個或多個具有您要移除之保護關係的 Volume，然後在工具列上，按一下 *移除*。
+
將顯示「移除關係」對話方塊。

. 按一下 *繼續* 以移除關係。
+
該關係已從「Volume 關係」頁面中移除。
