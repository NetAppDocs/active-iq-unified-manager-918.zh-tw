= 在 Active IQ Unified Manager 中新增資源池成員
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
資源池由多個成員彙總組成。您可以將彙總新增至現有資源池，以增加可用於次要 Volume 配置的空間量。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

一次最多只能在資源池新增 200 個彙總。顯示在「彙總」對話方塊中的彙總不屬於任何其他資源池。

.步驟
. 在左側導覽窗格中，按一下 *保護* > *資源池*。
. 從 *資源池* 清單中選取資源池。
+
資源池成員顯示在資源池清單下方的區域。

. 在資源池成員區域中，按一下 *新增*。
+
顯示「彙總」對話方塊。

. 選擇一個或多個彙總。
. 點擊 *Add* 。
+
對話方塊已關閉，且彙總顯示在所選資源池的成員清單中。
