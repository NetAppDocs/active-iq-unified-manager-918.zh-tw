= 在 Active IQ Unified Manager 中使用「初始化/更新」對話方塊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「初始化/更新」對話方塊可讓您對新的保護關係執行首次基礎傳輸，或在關係已初始化且您想要執行手冊、非計劃的遞增更新時更新關係。



[[transfer-options-tab]]
== 傳輸選項索引標籤

「傳輸選項」標籤可讓您變更傳輸的初始化優先權，並變更傳輸期間使用的頻寬。

* *傳輸優先權*
+
傳輸執行的優先順序。您可以選擇「正常」或「低」。指定正常傳輸優先順序之原則的關係，會先於指定低傳輸優先順序的關係執行。預設會選取「正常」。

* *最高傳輸率*
+
指定叢集間透過網路傳輸資料的最大速率。如果選擇不使用最大傳輸率，則關係間的基礎傳輸不受限制。如果選擇多個具有不同最大傳輸率的關係，則可以指定下列最大傳輸率設定之一：

+
** 使用在個別關係設定或編輯期間指定的值
+
選取此項目後，初始化和更新操作將使用在建立或編輯每個關係時指定的最大傳輸率。僅當初始化或更新多個具有不同傳輸率的關係時，此欄位才可用。

** 無限
+
表示關係之間的傳輸沒有頻寬限制。此欄位僅在初始化或更新多個具有不同傳輸率的關係時可用。

** 限制頻寬至
+
選取後，網路頻寬將限制為您指定的值。您可以輸入數值，然後選擇每秒千位元組（KBps）、每秒百萬位元組（MBps）、每秒十億位元組（GB/s）或每秒兆位元組（TBps）。您指定的最大傳輸率必須大於 1 KBps 且小於 4 TBps。







[[source-snapshot-copies-tab]]
== 來源 Snapshot 複本索引標籤

「來源 Snapshot 複本」索引標籤會顯示用於基礎傳輸之來源 Snapshot 複本的下列資訊：

* *來源 Volume*
+
顯示對應來源 Volume 的名稱。

* *目的地 Volume*
+
顯示所選目的地 Volume 的名稱。

* *來源類型*
+
顯示 Volume 類型。類型可以是讀取/寫入或資料保護。

* *Snapshot 複本*
+
顯示用於資料傳輸的 Snapshot 複本。按一下 Snapshot 複本值將顯示「選擇來源 Snapshot 複本」對話方塊，您可以在其中根據保護關係類型和要執行的作業，選擇用於傳輸的特定 Snapshot 複本。對於資料保護類型的來源，無法指定其他 Snapshot 複本。





[[command-buttons]]
== 命令按鈕

命令按鈕可讓您執行下列任務：

* *取消*
+
放棄您的選擇並關閉「初始化/更新」對話方塊。

* *提交*
+
儲存您的選擇並開始初始化或更新作業。
