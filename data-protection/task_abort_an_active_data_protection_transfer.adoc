= 在 Active IQ Unified Manager 的「磁碟區關係」頁面中止傳輸
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當您想要停止正在進行的 SnapMirror 複寫時，您可以中止作用中的資料保護傳輸。您也可以清除基礎傳輸之後傳輸的重新啟動檢查點。當傳輸與其他操作（例如 Volume 移動）衝突時，您可以中止傳輸。


NOTE: 您無法中止受一致性群組保護的 Volume 關係。

.開始之前
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。
* 您必須已設定 Workflow Automation。


在以下情況下，不會顯示中止行動：

* 如果 RBAC 設定不允許此行動：例如，如果您只有營運者權限
* 當 Volume ID 未知時：例如，當您有叢集間關係且目的地叢集尚未被發現時


您無法清除基礎傳輸的重新啟動檢查點。

.步驟
. 若要中止一個或多個保護關係的傳輸，請從 *Volume 關係* 頁面選取一個或多個 Volume，然後在工具列上按一下 *中止*。
+
顯示「中止傳輸」對話方塊。

. 如果您要清除非基礎傳輸的重新啟動檢查點，請選取 *清除檢查點*。
. 按一下 *繼續*。
+
「中止傳輸」對話方塊已關閉，中止作業的狀態會顯示在「Volume 關係」頁面頂端，並附有作業詳細資料的連結。

. *選用：*按一下 *View details* 連結，前往 *Job* 詳細資料頁面，以取得其他詳細資料並檢視工作進度。
