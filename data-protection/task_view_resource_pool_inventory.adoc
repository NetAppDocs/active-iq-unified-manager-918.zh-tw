= 在 Active IQ Unified Manager 中查看資源池清單
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用資源池頁面檢視資源池清單，並監控每個資源池的剩餘容量。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *保護* > *資源池*。
+
顯示資源池清單。
