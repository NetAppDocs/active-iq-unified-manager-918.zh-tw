= 在 Active IQ Unified Manager 中管理儲存設備 VM 關聯
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
儲存虛擬機器（儲存設備 VM）關聯是從來源儲存設備 VM 到目的地儲存設備 VM 的對應，合作夥伴應用程式會使用這些對應來進行資源選擇與次要 Volume 配置。

無論目的地儲存虛擬機器是次要目的地還是第三目的地，都會在來源儲存虛擬機器和目的地儲存虛擬機器之間建立關聯。您無法使用次要目的地儲存虛擬機器作為來源，來建立與第三目的地儲存虛擬機器的關聯。

身為應用程式管理員或儲存管理員，您可以在 *保護* > *儲存 VM 關聯* 頁面上檢視環境中的儲存 VM 關聯。

您可以透過三種方式關聯 SVM：

* *關聯任何儲存 VM*：您可以將任何主要來源儲存 VM 與一個或多個目的地 SVM 建立關聯。這表示目前需要保護的所有現有 SVM，以及未來建立的任何 SVM，都會與指定的目的地 SVM 建立關聯。例如，您可能想要將位於不同位置之數個不同來源的應用程式，備份到同一個位置的一個或多個目的地 SVM。
* *關聯特定儲存 VM*：您可以將特定的來源儲存 VM 與一個或多個特定的目的地 SVM 關聯。例如，如果您為多個用戶端提供儲存設備服務，且這些用戶端的資料必須彼此分隔，則可以選擇此選項將特定的來源儲存 VM 與僅指派給該用戶端的特定目的地儲存 VM 關聯起來。
* *與外部儲存設備 VM 關聯*：您可以建立來源儲存設備 VM 與目的地儲存設備 VM 的外部彈性 Volume 之間的關聯。




[[create-storage-vm-associations]]
== 建立儲存 VM 關聯

「建立儲存虛擬機器關聯」精靈可讓合作夥伴保護應用程式將來源儲存 VM 與目的地儲存 VM 建立關聯，以便用於 SnapMirror 與 SnapVault 關係。合作夥伴應用程式在初始資源配置目的地 Volume 時，會使用這些關聯來決定要選擇哪些資源。dd

.開始之前
* 您要關聯的儲存 VM 必須已存在。
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。


對於任何來源儲存設備 VM 和關係類型，每個目的地叢集上只能選擇一個目的地儲存設備 VM。

使用刪除和建立功能變更關聯只會影響未來的配置作業。它不會移動現有的目的地 Volume。

.步驟
. 在左側導覽窗格中，按一下 *保護* > *儲存 VM 關聯*。
. 在「儲存虛擬機器關聯」頁面上，按一下「建立」。
+
啟動 *建立儲存虛擬機器關聯* 精靈。

. 請選擇以下來源之一：
+
** *任何*
+
當您想要在任何主儲存設備 VM 來源與一個或多個目的地儲存設備 VM 之間建立關聯時，請選擇此選項。這表示所有目前需要保護的現有儲存設備 VM，以及未來建立的任何儲存設備 VM，都會與指定的目的地儲存設備 VM 建立關聯。例如，您可能希望將來自不同位置的多個不同來源的應用程式，備份到同一個位置的一個或多個目的地儲存設備 VM。

** *單一*
+
當您想要選擇與一個或多個目的地儲存設備 VM 關聯的特定來源儲存設備 VM 時，請選擇此選項。例如，如果您為多個用戶端提供儲存設備服務，且其資料必須彼此分隔，請選擇此選項，將特定的儲存設備 VM 來源與僅指派給該用戶端的特定儲存設備 VM 目的地建立關聯。

** *無（外部）*
+
如果要建立來源儲存設備 VM 和目的地儲存設備 VM 的外部彈性 Volume 之間的關聯，請選擇此選項。



. 選擇您要建立的一種或兩種保護關係類型：
+
** *SnapMirror*
** *SnapVault*


. 按一下 *Next* 。
. 選擇一個或多個儲存設備 VM 保護目的地。
. 點選 *Finish* 。




[[delete-storage-vm-associations]]
== 刪除儲存設備 VM 關聯

您可以刪除合作夥伴應用程式的儲存設備 VM 關聯，以移除來源與目的地儲存設備 VM 之間的次要配置關係；例如，當目的地儲存設備 VM 已滿，且您想要建立新的儲存設備 VM 保護關聯時，您可能會執行此操作。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

在至少選取一個儲存 VM 關聯之前，*刪除*按鈕將處於停用狀態。使用刪除和建立功能變更關聯只會影響未來的配置作業；它不會移動現有的目的地 Volume。

.步驟
. 在左側導覽窗格中，按一下 *保護* > *儲存 VM 關聯*。
. 請至少選取一個儲存設備 VM 關聯。
+
*刪除*按鈕已啟用。

. 按一下 *刪除*。
+
會顯示警告對話方塊。

. 按一下 *Yes* 繼續。
+
選定的儲存設備 VM 關聯已從清單中移除。
