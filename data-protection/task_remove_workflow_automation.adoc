= 從 Active IQ Unified Manager 移除 OnCommand Workflow Automation 設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當您不再想要使用 Workflow Automation 時，您可以從 Unified Manager 移除 OnCommand Workflow Automation 設定。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

.步驟
. 在左側導覽窗格中，按一下左側設定功能表中的 *一般* > *工作流程自動化*。
. 在 *Workflow Automation* 頁面中，按一下 *Remove Setup*。
