= 了解 Active IQ Unified Manager 中的工作詳細資料頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
作業詳細資料頁面可讓您檢視正在執行、已排隊或已完成的特定保護作業工作的狀態和其他資訊。您可以使用這些資訊來監控保護作業進度並疑難排解作業故障。



[[job-summary]]
== 工作總結

工作總結顯示以下資訊：

* 工作 ID
* 類型
* 狀態
* 提交時間
* 完成時間
* 期間




[[command-buttons]]
== 命令按鈕

命令按鈕可讓您執行下列任務：

* *重新整理*
+
重新整理工作清單以及與每個工作關聯的屬性。

* *檢視工作*
+
返回「工作」頁面。





[[job-tasks-list]]
== 工作的工作列表

作業工作清單以表格形式顯示與特定作業相關的所有工作以及與每個工作相關的屬性。

* *開始時間*
+
顯示工作開始的日期和時間。預設情況下，最新的工作會顯示在欄的頂端，較舊的工作則顯示在底部。

* *類型*
+
顯示工作類型。

* *狀態*
+
特定工作的狀態：

+
** *已完成*
+
工作已完成。

** *已排隊*
+
工作即將執行。

** *執行中*
+
工作正在執行。

** *等待*
+
作業已提交，且一些相關工作正在等待排隊與執行。



* *狀態*
+
顯示工作狀態：

+
** *錯誤 （image:../media/sev_error.gif[""]）*
+
工作失敗。

** *正常（image:../media/sev_normal.gif[""]）*
+
工作成功。

** *已跳過（image:../media/icon_skipped.gif[""]）*
+
一項工作失敗，導致後續工作遭到略過。



* *期間*
+
顯示工作開始以來經過的時間。

* *完成時間*
+
顯示工作完成時間。預設情況下，此列處於隱藏狀態。

* *工作 ID*
+
顯示用於識別作業中各個工作的 GUID。此欄可排序和篩選。預設情況下，此欄處於隱藏狀態。

* *相依性順序*
+
顯示代表圖表中工作順序的整數，第一個工作指派為 0。預設情況下，此欄處於隱藏狀態。

* *工作詳細資料窗格*
+
顯示有關每個作業工作的額外資訊，包括工作名稱、工作執行摘要，以及（如果工作失敗）故障原因。

* *工作訊息窗格*
+
顯示與所選工作相關的特定訊息。訊息可能包含錯誤原因和解決方法建議。並非所有工作都會顯示工作訊息。
