= 從 Active IQ Unified Manager 的「磁碟區/運作狀況」詳細資料頁面中移除保護關係
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以移除保護關係，以永久刪除所選來源與目的地之間的現有關係：例如，當您想要使用不同的目的地建立關係時。此操作會移除所有中繼資料，且無法復原。

.開始之前
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。
* 您必須已設定 Workflow Automation。


.步驟
. 在 *Volume / Health* 詳細資料頁面的 *Protection* 索引標籤中，從拓撲中選取您要移除的 SnapMirror 關係。
. 以滑鼠右鍵按一下目的地名稱，然後從選單中選取 *移除*。
+
將顯示「移除關係」對話方塊。

. 按一下 *繼續* 以移除關係。
+
該關係已從「Volume / 健康狀況」詳細資料頁面移除。
