= 在 Active IQ Unified Manager 中使用集合體對話方塊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用「彙總」對話方塊選擇要新增至資源池的彙總。



[[command-buttons]]
== 命令按鈕

命令按鈕可讓您執行下列任務：

* *新增*
+
將選定的彙總新增至資源池。「新增」按鈕只有在至少選擇一個彙總後才會啟用。

* *取消*
+
放棄變更，並關閉彙總對話方塊。





[[aggregates-list]]
== 彙總清單

彙總清單以表格形式顯示受監控彙總的名稱和屬性。

* *狀態*
+
顯示 Volume 的目前狀態。狀態可以是嚴重（image:../media/sev_critical_um60.png[""]）、錯誤（image:../media/sev_error_um60.png[""]）、警告（image:../media/sev_warning_um60.png[""]）或正常（image:../media/sev_normal_um60.png[""]）。

+
您可以將指標移到狀態上，以檢視有關該 Volume 產生之事件的更多資訊。

* *彙總名稱*
+
顯示彙總的名稱。

* *狀態*
+
顯示 Aggregate 的目前狀態，可能為下列其中一種：

+
** 離線
+
不允許讀取或寫入存取。

** 受限
+
允許進行有限的操作（例如同位元檢查重構），但不允許資料存取。

** 線上
+
允許對託管在此 Aggregate 上的 Volume 進行讀寫存取。

** 建立
+
彙總正在建立。

** 摧毀
+
彙總正在銷毀中。

** 失敗
+
該彙總無法設為線上。

** 凍結
+
此彙總（暫時）不處理請求。

** 不一致
+
此彙總已被標記為損壞；您應該聯絡技術支援。

** Iron 受限
+
無法在此彙總上執行診斷工具。

** 掛載
+
該彙總正在掛載中。

** 部分
+
至少找到了一個磁碟用於彙總，但缺少兩個或更多磁碟。

** 靜默
+
彙總正在靜止。

** 已靜止
+
彙總處於靜止狀態。

** 已回復
+
彙總的回復已完成。

** 未掛載
+
彙總已離線。

** 卸載
+
正在將彙總設為離線。

** 未知
+
已發現彙總，但 Unified Manager 伺服器尚未擷取彙總資訊。



* *叢集*
+
顯示彙總所在的叢集名稱。

* *節點*
+
顯示包含彙總的儲存控制器的名稱。

* *總容量*
+
顯示彙總的總資料大小（以 MB、GB 等為單位）。預設情況下，此欄為隱藏狀態。

* *已承諾容量*
+
顯示彙總中所有 Volume 已提交的總空間（以 MB、GB 等為單位）。預設情況下，此欄為隱藏狀態。

* *已使用容量*
+
顯示彙總中使用的空間量（以 MB、GB 等為單位）。

* *可用容量*
+
顯示彙總中可用於資料的空間量（以 MB、GB 等為單位）。預設情況下，此欄為隱藏。

* *可用 %*
+
顯示彙總中可用於資料的空間百分比。預設情況下，此欄為隱藏狀態。

* *已使用 %*
+
顯示彙總中資料所使用的空間百分比。

* *RAID 類型*
+
顯示所選 Volume 的 RAID 類型。RAID 類型可以是 RAID0、RAID4、RAID-DP、RAID-TEC 或混合 RAID。
