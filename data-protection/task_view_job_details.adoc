= 在 Active IQ Unified Manager 中檢視工作詳細資料
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
開始工作後，您可以從「工作詳細資料」頁面追蹤其進度，並監控相關的工作是否有錯誤。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *保護* > *作業*。
. 在「工作」頁面中，按一下 *名稱* 欄位中的工作名稱，即可顯示與該工作關聯的工作清單。
. 按一下工作，即可在工作清單右側的 *工作詳細資料* 窗格和 *工作訊息* 窗格中顯示其他資訊。
