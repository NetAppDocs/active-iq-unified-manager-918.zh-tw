= 了解 Active IQ Unified Manager 中的工作頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「作業」頁面可讓您檢視所有正在執行和已完成的合作夥伴應用程式保護作業的目前狀態和其他資訊。您可以利用這些資訊來查看哪些作業仍在執行，以及作業是成功還是失敗。



[[command-buttons]]
== 命令按鈕

命令按鈕可讓您執行下列任務：

* *中止*
+
中止所選作業。僅當所選作業正在執行時，此選項才可用。

* *重試*
+
重新啟動失敗的「保護組態」或「保護關係操作」類型的作業。一次只能重試一個失敗的作業。如果選擇了多個失敗的作業，*重試*按鈕將處於停用狀態。您無法重試失敗的儲存設備服務作業。

* *重新整理*
+
重新整理工作清單及其相關資訊。





[[jobs-list]]
== 工作清單

「工作」清單以表格形式顯示正在進行中的工作。預設情況下，清單僅顯示過去一週內產生的工作。您可以使用欄排序和篩選功能來自訂顯示的工作。

* *狀態*
+
顯示作業的目前狀態。狀態可以是錯誤（image:../media/sev_error.gif[""]）或正常（image:../media/sev_normal.gif[""]）。

* *工作 ID*
+
顯示作業的識別編號。預設情況下，此欄為隱藏狀態。

+
作業識別號碼是唯一的，由伺服器在啟動作業時指派。您可以透過在欄篩選器提供的文字方塊中輸入作業識別號碼來搜尋特定作業。

* *名稱*
+
顯示工作名稱。

* *類型*
+
顯示工作類型。工作類型如下：

+
** *叢集擷取*
+
Workflow Automation 作業正在重新探索叢集。

** *保護組態*
+
保護作業會啟動 Workflow Automation 工作流程，例如 cron 排程、SnapMirror 原則建立等等。

** *保護關係作業*
+
保護工作正在執行 SnapMirror 作業。

** *保護工作流程鏈*
+
一個 Workflow Automation 作業正在執行多個工作流程。

** *還原*
+
還原工作正在執行。

** *清理*
+
這項工作是清理不再需要用於還原目的的儲存設備服務成員工件。

** *符合*
+
這項工作是檢查儲存設備服務成員的組態，以確保它們符合規格。

** *銷毀*
+
這項工作正在銷毀儲存設備服務。

** *匯入*
+
這項工作是將非託管儲存設備物件匯入到現有儲存設備服務。

** *修改*
+
這項工作是修改現有儲存設備服務的屬性。

** *訂閱*
+
這項工作是將成員訂閱至儲存設備服務。

** *取消訂閱*
+
這項工作是取消會員對儲存設備服務的訂閱。

** *更新*
+
正在執行保護更新作業。

** *WFA 組態*
+
工作流程自動化作業正在推送叢集憑證並同步資料庫快取。



* *狀態*
+
顯示作業的運作狀態。狀態選項如下：

+
** *已中止*
+
作業已中止。

** *中止*
+
該作業正在中止過程中。

** *已完成*
+
工作已完成。

** *執行中*
+
工作正在執行。



* *提交時間*
+
顯示作業提交時間。

* *期間*
+
顯示完成工作所花費的時間。此欄預設會顯示。

* *完成時間*
+
顯示工作完成的時間。預設情況下，此欄為隱藏狀態。
