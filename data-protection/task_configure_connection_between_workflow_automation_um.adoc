= 設定 Workflow Automation 和 Active IQ Unified Manager 之間的連線
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以設定 OnCommand Workflow Automation (WFA) 與 Unified Manager 之間的安全的連線。連線至 Workflow Automation 可讓您使用保護功能，例如 SnapMirror 與 SnapVault 組態工作流程，以及用於管理 SnapMirror 關係的命令。

.開始之前
* 安裝的 Workflow Automation 版本必須為 5.1.1P6 或更高版本。
+
[NOTE]
====
WFA 5.1.1P6 中包含了「`用於管理 Clustered Data ONTAP 的 WFA 套件`」，因此無需像過去那樣從 NetAppStorage Automation Store 下載此套件並將其單獨安裝到 WFA 伺服器上。 https://mysupport.netapp.com/site/products/all/details/ocwfa/downloads-tab["WFA 下載"^]

====
* 您必須擁有在 Unified Manager 中建立的資料庫使用者名稱，以支援 WFA 和 Unified Manager 連線。
+
此資料庫使用者必須已被指派整合模式使用者角色。

* 您必須被指派 Workflow Automation 中的管理員角色或架構師角色。
* 您必須擁有 Workflow Automation 設定的主機位址、連接埠號碼 443、使用者名稱和密碼。
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。


.步驟
. 在左側導覽窗格中，按一下 *一般* > *工作流程自動化*。
. 在 *Workflow Automation* 頁面的 *資料庫使用者* 區域中，選擇名稱，並輸入您為支援 Unified Manager 和 Workflow Automation 連線所建立之資料庫使用者的密碼。
. 在頁面的「*Workflow Automation Credentials*」區域中，輸入 Workflow Automation 設定的主機名稱或 IP 位址（IPv4 或 IPv6），以及使用者名稱和密碼。
+
您必須使用 Unified Manager 伺服器連接埠（連接埠 443）。

. 按一下 *Save* 。
. 如果您使用自簽憑證，請按一下 *Yes* 以授權安全性憑證。
+
顯示 Workflow Automation 頁面。

. 點擊 *Yes* 重新載入 Web 使用者介面，並新增 Workflow Automation 功能。
