= 在 Active IQ Unified Manager 中使用「還原」對話方塊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用「還原」對話方塊將資料從特定的 Snapshot 複本還原到 Volume。



[[restore-from]]
== 還原自

「還原自」區域可讓您指定要從何處還原資料。

* *磁碟區*
+
指定要從中還原資料的 Volume。預設情況下，會選取您發起還原行動的 Volume。您可以從下拉清單中選取不同的 Volume，該清單包含與您發起還原行動的 Volume 具有保護關係的所有 Volume。

* *Snapshot 複本*
+
指定您要用來還原資料的 Snapshot 複本。預設會選取最新的 Snapshot 複本。您也可以從下拉式清單中選取不同的 Snapshot 複本。Snapshot 複本清單會根據所選取的 Volume 而變更。

* *最多可列出 995 個檔案和目錄*
+
預設情況下，清單中最多顯示 995 個物件。如果您想要檢視所選 Volume 內的所有物件，可以取消選取此核取方塊。如果項目數量非常大，此作業可能需要一些時間。





[[select-items-to-restore]]
== 選擇要還原的項目

在「選擇要還原的項目」區域，您可以選擇整個 Volume 或要還原的特定檔案和資料夾。您最多可以選擇 10 個檔案、資料夾或兩者的組合。選擇的項目數量達到上限後，項目選擇核取方塊會停用。

* *路徑欄位*
+
顯示要還原的資料路徑。您可以導覽至要還原的資料夾和檔案，也可以輸入路徑。在您選擇或輸入路徑之前，此欄位為空白。選擇路徑後，按一下 image:../media/icon_upfolder.gif["上一層資料夾圖示"] 即可在目錄結構中向上移動一個層級。

* *資料夾和檔案列表*
+
顯示您輸入的路徑中的內容。預設情況下，首先顯示根目錄資料夾。按一下資料夾名稱將顯示該資料夾的內容。



您可以選擇要還原的項目，具體操作如下：

* 當您在路徑欄位中輸入指定檔案名稱的路徑時，指定的檔案將顯示在「資料夾和檔案」中。
* 當您輸入路徑而未指定特定檔案時，資料夾的內容將顯示在「資料夾和檔案」清單中，您可以選擇最多 10 個檔案、資料夾或兩者的組合進行還原。
+
如果資料夾包含超過 995 個項目，則會顯示一則訊息，提示項目過多無法顯示。如果繼續操作，則指定資料夾中的所有項目都將還原。如果要檢視所選 Volume 中的所有物件，可以取消選取「最多列出 995 個檔案和目錄」核取方塊。



[NOTE]
====
您無法還原 NTFS 檔案流。

====


[[restore-to]]
== 還原至

「還原至」區域可讓您指定要將資料還原的位置。

* *Volume_Name 中的原始位置*
+
將選定的資料還原到來源上最初備份資料的目錄中。

* *替代位置*
+
將選定的資料還原到新位置：

+
** 還原路徑
+
指定恢復所選資料的替代路徑。該路徑必須已存在。您可以使用 *Browse* 按鈕導覽至要恢復資料的位置，也可以使用格式 `cluster://svm/volume/path`手動輸入路徑。

** 保留目錄層級結構
+
選取此項目後，將保留原始檔案或目錄的結構。例如，如果來源為 /A/B/C/myFile.txt 且目的地為 /X/Y/Z，則 Unified Manager 將使用下列目錄結構在目的地還原資料：/X/Y/Z/A/B/C/myFile.txt。







[[command-buttons]]
== 命令按鈕

命令按鈕可讓您執行下列任務：

* *取消*
+
放棄您的選擇並關閉「還原」對話方塊。

* *還原*
+
套用您的選擇並開始還原程序。
