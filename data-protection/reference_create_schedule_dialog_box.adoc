= 在 Active IQ Unified Manager 中使用「建立排程」對話方塊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「建立排程」對話方塊可讓您建立基本或進階保護排程，用於 SnapMirror 和 SnapVault 關係傳輸。您可以建立新排程來提高資料傳輸頻率，以因應頻繁的資料更新；或者，當資料變更不頻繁時，您可以建立頻率較低的排程。

無法為 SnapMirror 同步關係設定排程。

* *目的地叢集*
+
您在「設定保護」對話方塊的 SnapVault 索引標籤或 SnapMirror 索引標籤中所選取的叢集名稱。

* *排程名稱*
+
您為排程提供的名稱。排程名稱可以包含 A 到 Z、a 到 z、0 到 9 的字元，以及下列任何特殊字元：! @ # $ % {caret} & * ( ) _ -.排程名稱不能包含下列字元：< >。

* *基礎或進階*
+
您想要使用的排程模式。

+
基本模式包含以下元素：

+
** 重複
+
排程傳輸發生的頻率。選項包括每小時、每天和每週。

** 天
+
選擇每週重複時，將指定一週中的哪一天進行傳輸。

** 時間
+
選擇「每日」或「每週」時，傳輸發生的時間。



+
進階模式包含以下要素：

+
** 月
+
以逗號分隔的數字清單，代表一年中的月份。有效值為 0 到 11，其中 0 代表一月，依此類推。此元素為選用。將此欄位留白表示每個月都會進行傳輸。

** 天
+
以逗號分隔的數字清單，表示當月的日期。有效值為 1 到 31。此元素為選用。將此欄位留空表示每個月的每一天都會進行傳輸。

** 工作日
+
以逗號分隔的數字清單，表示一週中的日期。有效值為 0 到 6，其中 0 代表星期日，依此類推。此元素為選用。如果此欄位留空，則表示一週中的每一天都會進行傳輸。如果指定了星期幾但未指定月份中的日期，則僅在指定的星期幾進行傳輸，而不是每天都進行傳輸。

** 小時
+
以逗號分隔的數字清單，代表一天中的小時數。有效值為 0 到 23，其中 0 代表午夜。此元素為選用。

** 分鐘
+
以逗號分隔的數字列表，表示一小時的分鐘數。有效值為 0 到 59。此元素為必填項。
