= 使用 Active IQ Unified Manager 中的「關係」頁面監控儲存設備 VM
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在「清單」的「保護」區段的「關係」頁面中監控儲存設備 VM 災難恢復關係。預設情況下，「關係」頁面僅列出頂層關係，因為套用了組成關係篩選器。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

您可以使用篩選器檢視儲存設備虛擬機器災難恢復關係。

.步驟
. 在左側導覽窗格中，按一下 *保護* > *關係*。
+
此頁面顯示所有類型的關係：Volume、一致性群組和儲存設備 VM 關係。

. 按一下 *篩選* ，然後選取 *關係物件類型* 和 *儲存 VM* ，以僅檢視儲存設備 VM 災難恢復關係。
. 按一下 *套用篩選器*。
+
[NOTE]
====
您應該清除成員關係篩選器以檢視所有保護關係。

====
+
此頁面僅顯示儲存設備 VM 災難恢復關係。
