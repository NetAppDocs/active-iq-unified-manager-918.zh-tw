= 在 Active IQ Unified Manager 中變更 Windows 上的維護使用者密碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
必要時，您可以變更 Unified Manager 維護使用者的密碼。

.步驟
. 在 Unified Manager Web UI 登入頁面上，按一下 *忘記密碼*。
+
系統會顯示一個頁面，提示您輸入要重設密碼的使用者名稱。

. 輸入使用者名稱並按一下 *提交*。
+
系統會將包含重設密碼連結的電子郵件傳送至為該使用者名稱定義的電子郵件位址。

. 按一下電子郵件中的 *重設密碼連結*，並設定新密碼。
. 返回 Web 使用者介面，並使用新密碼登入 Unified Manager。
