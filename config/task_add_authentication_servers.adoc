= 將驗證伺服器新增至 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以新增驗證伺服器並在管理伺服器上啟用遠端驗證，以便驗證伺服器內的遠端使用者可以存取 Unified Manager。

.開始之前
* 必須提供以下資訊：
+
** 驗證伺服器的主機名稱或 IP 位址
** 驗證伺服器的連接埠號碼


* 您必須已啟用遠端驗證並設定驗證服務，以便管理伺服器可以對驗證伺服器中的遠端使用者或群組進行驗證。
* 您必須擁有應用程式管理員角色。


如果您新增的驗證伺服器是高可用性 (HA) 配對的一部分（使用相同的資料庫），您也可以新增合作夥伴驗證伺服器。這可讓管理伺服器在其中一部驗證伺服器無法連線時，與合作夥伴通訊。

.步驟
. 在左側導覽窗格中，按一下 *一般* > *遠端驗證*。
. 啟用或停用 *使用安全的連線* 選項：
+
[cols="2*"]
|===
| 如果您想要…… | 然後這樣做…… 


 a| 
啟用
 a| 
.. 選取 *使用安全連線* 選項。
.. 在「驗證伺服器」區域中，按一下 *新增*。
.. 在「新增驗證伺服器」對話方塊中，輸入伺服器的驗證名稱或 IP 位址（IPv4 或 IPv6）。
.. 在「授權主機」對話方塊中，按一下「檢視憑證」。
.. 在「檢視憑證」對話方塊中，驗證憑證資訊，然後按一下 *關閉*。
.. 在「授權主機」對話方塊中，按一下 *是*。
+
[NOTE]
====
啟用 *Use Secure Connection authentication* 選項後， Unified Manager 將與驗證伺服器通訊並顯示憑證。Unified Manager 預設使用 636 連接埠進行安全的通訊，並使用 389 連接埠進行非安全通訊。

====




 a| 
停用它
 a| 
.. 取消勾選 *使用安全連線* 選項。
.. 在「驗證伺服器」區域中，按一下 *新增*。
.. 在「新增驗證伺服器」對話方塊中，指定伺服器的主機名稱或 IP 位址（IPv4 或 IPv6）以及連接埠詳細資料。
.. 點擊 *Add* 。


|===
+
您新增的驗證伺服器將顯示在「伺服器」區域中。

. 執行測試驗證，以確認您可以在新增的驗證伺服器中驗證使用者。
