= 在 Active IQ Unified Manager 中新增使用者
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用「使用者」頁面新增本機使用者或資料庫使用者。您也可以新增屬於驗證伺服器的遠端使用者或使用者群組。您可以為這些使用者指派角色，並且根據角色的權限，使用者可以使用 Unified Manager 管理儲存設備物件和資料，或檢視資料庫中的資料。

.開始之前
* 您必須擁有應用程式管理員角色。
* 若要新增遠端使用者或群組，您必須啟用遠端驗證並設定驗證伺服器。
* 如果您打算設定 SAML 驗證，以便身分供應商（IdP）對存取圖形介面的使用者進行驗證，請確保將這些使用者定義為 "`remote`" 使用者。
+
啟用 SAML 驗證時，類型為 "`local`" 或 "`maintenance`" 的使用者無權存取 UI。



如果從 Windows Active Directory 新增群組，則所有直接成員和巢狀子群組都可以向 Unified Manager 驗證，除非巢狀子群組已停用。如果從 OpenLDAP 或其他驗證服務新增群組，則只有該群組的直接成員才能向 Unified Manager 驗證。

.步驟
. 在左側導覽窗格中，按一下 *一般* > *使用者*。
. 在「使用者」頁面上，按一下 *新增*。
. 在「新增使用者」對話方塊中，選擇要新增的使用者類型，並輸入所需資訊。
+
輸入所需的使用者資訊時，您必須指定該使用者獨有的電子郵件地址。您必須避免指定多個使用者共享的電子郵件地址。

. 點擊 *Add* 。
