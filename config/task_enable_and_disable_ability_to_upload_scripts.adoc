= 在 Active IQ Unified Manager 中啟用和停用指令碼上傳
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
預設情況下，上傳指令碼到 Unified Manager 並執行指令碼的功能已啟用。如果出於安全性原因，您的組織不希望允許此活動，您可以停用此功能。

.開始之前
您必須擁有應用程式管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *一般* > *功能設定*。
. 在 *功能設定* 頁面中，選擇下列選項之一來停用或啟用指令碼：
+
[cols="2*"]
|===
| 如果您想要…… | 然後這樣做…… 


 a| 
停用指令碼
 a| 
在 *指令碼上傳* 面板中，將滑桿按鈕向左移動。



 a| 
啟用指令碼
 a| 
在 *腳本上傳* 面板中，將滑桿按鈕向右移動。

|===
