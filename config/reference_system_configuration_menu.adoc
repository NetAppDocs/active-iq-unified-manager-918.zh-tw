= 使用 Active IQ Unified Manager 中的系統組態選單
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
系統組態選單可讓您透過提供各種選項來管理您的虛擬應用裝置，例如檢視伺服器狀態，以及重新啟動和關閉虛擬機器。

[NOTE]
====
當 Unified Manager 安裝在 Linux 或 Microsoft Windows 系統上時，此功能表中僅提供 "`從 Unified Manager 備份還原`" 選項。

====
以下是可供選擇的選單選項：

* *顯示伺服器狀態*
+
顯示目前伺服器狀態。狀態選項包括「執行中」和「未執行」。

+
如果伺服器未執行，您可能需要聯絡技術支援。

* *重新啟動虛擬機器*
+
重新啟動虛擬機器，停止所有服務。重新啟動後，虛擬機器和服務會重新啟動。

* *關閉虛擬機器*
+
關閉虛擬機器，停止所有服務。

+
您只能從虛擬機器控制台選擇此選項。

* *更改<logged in user>使用者密碼*
+
更改目前登入使用者的密碼，該使用者只能是維護使用者。

* *增加資料磁碟容量*
+
增加虛擬機器中資料磁碟（磁碟 3）的大小。

* *增加交換磁碟容量*
+
增加虛擬機器中交換磁碟（磁碟 2）的大小。

* *更改時區*
+
將時區變更為您所在的位置。

* *更改 NTP 伺服器*
+
變更 NTP 伺服器設定，例如 IP 位址或完整網域名稱（FQDN）。

* *更改 NTP 服務*
+
在 `ntp`與 `systemd-timesyncd`服務之間切換。

* *從 Unified Manager 備份還原*
+
從先前備份的版本還原 Unified Manager 資料庫和組態設定。

* *重設伺服器憑證*
+
重設伺服器安全性憑證。

* *更改主機名稱*
+
變更安裝虛擬應用裝置的主機名稱。

* *返回*
+
退出系統組態選單並返回主選單。

* *離開*
+
退出維護主控台選單。
