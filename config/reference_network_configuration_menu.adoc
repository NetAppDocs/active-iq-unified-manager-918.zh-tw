= Active IQ Unified Manager 中的網路組態選單
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
網路組態功能表可讓您管理網路設定。當 Unified Manager 使用者介面無法使用時，您應該使用此功能表。

[NOTE]
====
如果 Unified Manager 安裝在 Red Hat Enterprise Linux 或 Microsoft Windows 上，則此功能表無法使用。

====
以下是可供選擇的選單選項。

* *顯示 IP 位址設定*
+
顯示虛擬應用裝置的目前網路設定，包括 IP 位址、網路、廣播位址、子網路遮罩、閘道和 DNS 伺服器。

* *更改 IP 位址設定*
+
可讓您變更虛擬應用裝置的任何網路設定，包括 IP 位址、網路遮罩、閘道或 DNS 伺服器。如果您使用維護主控台將網路設定從 DHCP 切換為靜態連網，則無法編輯主機名稱。您必須選取 *提交變更* 才能使變更生效。

* *顯示網域名稱搜尋設定*
+
顯示用於解析主機名稱的網域名稱搜尋清單。

* *變更網域名稱搜尋設定*
+
可讓您變更解析主機名稱時要搜尋的網域名稱。您必須選取 *提交變更* 才能使變更生效。

* *顯示靜態路由*
+
顯示目前靜態網路路由。

* *更改靜態路由*
+
允許您新增或刪除靜態網路路由。您必須選取 *提交變更* 才能使變更生效。

+
** *新增路由*
+
允許您新增靜態路由。

** *刪除路由*
+
允許您刪除靜態路由。

** *返回*
+
返回*主選單*。

** *離開*
+
退出維護主控台。



* *停用網路介面*
+
停用任何可用的網路介面。如果只有一個網路介面可用，則無法將其停用。您必須選取 *提交變更* 才能使變更生效。

* *啟用網路介面*
+
啟用可用的網路介面。您必須選取 *提交變更* 才能使變更生效。

* *提交變更*
+
套用對虛擬應用裝置網路設定所做的任何變更。您必須選取此選項才能使所做的任何變更生效，否則變更將不會生效。

* *Ping 主機*
+
Ping 目標主機以確認 IP 位址變更或 DNS 組態。

* *恢復預設值*
+
將所有設定重設為出廠預設值。您必須選擇 *提交變更* 才能使變更生效。

* *返回*
+
返回*主選單*。

* *離開*
+
退出維護主控台。
