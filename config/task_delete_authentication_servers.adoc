= 在 Active IQ Unified Manager 中刪除驗證伺服器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您想要阻止 Unified Manager 伺服器與某個驗證伺服器通訊，可以刪除該驗證伺服器。例如，如果您想要變更管理伺服器正在通訊的驗證伺服器，可以刪除該驗證伺服器並新增新的驗證伺服器。

.開始之前
您必須擁有應用程式管理員角色。

刪除驗證伺服器後，該驗證伺服器的遠端使用者或群組將無法再存取 Unified Manager。

.步驟
. 在左側導覽窗格中，按一下 *一般* > *遠端驗證*。
. 選擇一個或多個要刪除的驗證伺服器，然後按一下 *刪除*。
. 點擊 *是* 確認刪除請求。
+
如果啟用 *使用安全連線* 選項，則與驗證伺服器關聯的憑證將隨驗證伺服器一起刪除。
