= 在 Active IQ Unified Manager 中變更本機使用者密碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以變更本機使用者登入密碼以防止潛力的安全性風險。

.開始之前
您必須以本機使用者登入。

使用這些步驟無法變更維護使用者和遠端使用者的密碼。若要變更遠端使用者密碼，請聯絡您的密碼系統管理員。若要變更維護使用者密碼，請參閱 link:task_use_maintenance_console.html["使用維護主控台"]。

.步驟
. 登入 Unified Manager。
. 從頂部功能表列中，按一下使用者圖示，然後按一下 *更改密碼*。
+
如果您是遠端使用者，則不會顯示 *變更密碼* 選項。

. 在「更改密碼」對話方塊中，輸入目前密碼和新密碼。
. 按一下 *Save* 。


如果 Unified Manager 設定為高可用性組態，則必須變更設定中第二個節點的密碼。兩個執行個體必須具有相同的密碼。
