= Active IQ Unified Manager 中的診斷使用者功能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
診斷存取的目的是為了方便技術支援協助您進行疑難排解，您只能在技術支援的指導下使用它。

診斷使用者可以在技術支援的指導下執行作業系統層級的命令，以進行疑難排解。
