= 使用 Active IQ Unified Manager 中的遠端身分驗證頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用遠端驗證頁面設定 Unified Manager 與您的驗證伺服器通訊，以驗證嘗試登入 Unified Manager Web UI 的遠端使用者。

您必須擁有應用程式系統管理員或儲存系統管理員角色。

選取「啟用遠端驗證」核取方塊後，即可使用驗證伺服器啟用遠端驗證。

* *驗證服務*
+
允許您設定管理伺服器，使其能夠透過目錄服務供應商（例如 Active Directory 、 OpenLDAP ）驗證使用者，或指定您自己的驗證機制。只有在啟用遠端驗證後，才能指定驗證服務。

+
** *Active Directory*
+
*** 系統管理員姓名
+
指定驗證伺服器的系統管理員名稱。

*** 密碼
+
指定存取驗證伺服器的密碼。

*** 基本辨識名稱
+
指定遠端使用者在驗證伺服器中的位置。例如，如果驗證伺服器的網域名稱為 +ou@domain.com+，則基本可分辨名稱為 *cn=ou,dc=domain,dc=com*。

*** 停用巢狀群組查詢
+
指定是否啟用或停用巢狀群組查閱選項。預設情況下，此選項處於停用狀態。如果您使用 Active Directory，則可以透過停用對巢狀群組的支援來加快驗證速度。

*** 使用安全的連線
+
指定用於與驗證伺服器通訊的驗證服務。



** *OpenLDAP*
+
*** 連結辨別名稱
+
指定與基本可分辨名稱一起使用的連結可分辨名稱，以便在驗證伺服器中尋找遠端使用者。

*** 連結密碼
+
指定存取驗證伺服器的密碼。

*** 基本辨識名稱
+
指定遠端使用者在驗證伺服器中的位置。例如，如果驗證伺服器的網域名稱為 +ou@domain.com+，則基本可分辨名稱為 *cn=ou,dc=domain,dc=com*。

*** 使用安全的連線
+
指定使用安全 LDAP 與 LDAP 驗證伺服器通訊。



** *其他*
+
*** 連結辨別名稱
+
指定與基本可分辨名稱一起使用的連結可分辨名稱，以便在您設定的驗證伺服器中尋找遠端使用者。

*** 連結密碼
+
指定存取驗證伺服器的密碼。

*** 基本辨識名稱
+
指定遠端使用者在驗證伺服器中的位置。例如，如果驗證伺服器的網域名稱為 +ou@domain.com+，則基本可分辨名稱為 *cn=ou,dc=domain,dc=com*。

*** 傳輸協定版本
+
指定驗證伺服器支援的輕量級目錄存取協定 (LDAP) 版本。您可以指定是否必須自動偵測傳輸協定版本，也可以將版本設定為 2 或 3。

*** 使用者名稱屬性
+
指定驗證伺服器中包含要由管理伺服器進行驗證的使用者登入名稱的屬性名稱。

*** 群組成員屬性
+
指定一個值，該值根據使用者驗證伺服器中指定的屬性和值，將管理伺服器群組成員身分指派給遠端使用者。

*** UGID
+
如果遠端使用者在驗證伺服器中被包含為 GroupOfUniqueNames 物件的成員，則此選項可讓您根據該 GroupOfUniqueNames 物件中的指定屬性，將管理伺服器群組成員身分指派給遠端使用者。

*** 停用巢狀群組查詢
+
指定是否啟用或停用巢狀群組查閱選項。預設情況下，此選項處於停用狀態。如果您使用 Active Directory，則可以透過停用對巢狀群組的支援來加快驗證速度。

*** 成員
+
指定驗證伺服器用於儲存有關群組內各個成員資訊的屬性名稱。

*** 使用者物件類別
+
指定遠端驗證伺服器中使用者的物件類別。

*** 群組物件類別
+
指定遠端驗證伺服器中所有群組的物件類別。

+

NOTE: 您為 _Member_、_User Object Class_ 和 _Group Object Class_ 屬性輸入的值應與您的 Active Directory、OpenLDAP 和 LDAP 組態中新增的值相同。否則，驗證可能會失敗。

*** 使用安全的連線
+
指定用於與驗證伺服器通訊的驗證服務。





+
[NOTE]
====
如果您要修改驗證服務，請務必刪除任何現有的驗證伺服器，並新增新的驗證伺服器。

====




[[authentication-servers-area]]
== 驗證伺服器區域

「驗證伺服器」區域顯示管理伺服器用於尋找和驗證遠端使用者的驗證伺服器。遠端使用者或群組的憑證由驗證伺服器維護。

* *命令按鈕*
+
允許您新增、編輯或刪除驗證伺服器。

+
** 新增
+
允許您新增驗證伺服器。

+
如果您新增的驗證伺服器是高可用性配對（使用相同資料庫）的一部分，您也可以新增合作夥伴驗證伺服器。這可讓管理伺服器在其中一個驗證伺服器無法連線時，與合作夥伴進行通訊。

** 編輯
+
允許您編輯所選驗證伺服器的設定。

** 刪除
+
刪除選定的驗證伺服器。



* *名稱或 IP 位址*
+
顯示用於在管理伺服器上驗證使用者身分的驗證伺服器的主機名稱或 IP 位址。

* *連接埠*
+
顯示驗證伺服器的連接埠號碼。

* *測試驗證*
+
此按鈕透過驗證遠端使用者或群組來驗證您的驗證伺服器組態。

+
測試時，如果僅指定使用者名稱，管理伺服器會在驗證伺服器中搜尋遠端使用者，但不會驗證該使用者。如果同時指定使用者名稱和密碼，管理伺服器會搜尋並驗證遠端使用者。

+
如果停用遠端驗證，則無法測試驗證。
