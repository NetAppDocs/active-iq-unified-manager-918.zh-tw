= 了解 Active IQ Unified Manager 中的功能設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「功能設定」頁面可讓您啟用和停用 Active IQ Unified Manager 中的特定功能。這包括根據原則建立和管理儲存設備物件、啟用 API 閘道和登入橫幅、上傳用於管理警報的指令碼、根據閒置時間使 Web UI 工作階段逾時，以及停用接收 Active IQ 平台事件。

[NOTE]
====
只有具有應用程式管理員角色的使用者才能存取「功能設定」頁面。

====
有關腳本上傳的資訊，請參閱 link:task_enable_and_disable_ability_to_upload_scripts.html["啟用與停用指令碼上傳"]。
