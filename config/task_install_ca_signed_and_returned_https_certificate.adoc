= 在 Active IQ Unified Manager 中安裝由 CA 簽署的 HTTPS 憑證
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在憑證授權單位（CA）簽署並傳回憑證後，您可以上傳並安裝安全性憑證。您上傳並安裝的檔案必須是現有自簽憑證的簽署版本。CA 簽署的憑證有助於防止中間人攻擊，並提供比自簽憑證更好的安全性保護。

*什麼。開始之前

您必須完成以下操作：

* 已下載憑證簽署要求檔案，並由憑證授權單位簽署
* 已將憑證鏈儲存為 PEM 格式
* 包含憑證鏈中的所有憑證，從 Unified Manager 伺服器憑證到根目錄簽署憑證，包括任何存在的中繼憑證


您必須擁有應用程式管理員角色。

[NOTE]
====
如果已建立 CSR 的憑證有效期超過 397 天，則 CA 在簽署並傳回憑證之前，會將憑證有效期縮短至 397 天

====
.步驟
. 在左側導覽窗格中，按一下 *一般* > *HTTPS 憑證*。
. 按一下 *安裝 HTTPS 憑證*。
. 在顯示的對話方塊中，按一下 *選擇檔案……* 以找到要上傳的檔案。
. 選擇檔案，然後按一下 *安裝* 來安裝檔案。
+
如需相關資訊，請參閱 link:concept_install_https_certificate_generated_using_external_tools.html["安裝使用外部工具產生的 HTTPS 憑證"]。
