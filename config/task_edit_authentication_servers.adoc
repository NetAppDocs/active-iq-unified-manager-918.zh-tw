= 在 Active IQ Unified Manager 中編輯驗證伺服器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以變更 Unified Manager 伺服器與驗證伺服器通訊時使用的連接埠。

.開始之前
您必須擁有應用程式管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *一般* > *遠端驗證*。
. 勾選 *停用巢狀群組查閱* 核取方塊。
. 在 *驗證伺服器* 區域中，選擇您要編輯的驗證伺服器，然後按一下 *編輯*。
. 在 *編輯驗證伺服器* 對話方塊中，編輯連接埠詳細資訊。
. 按一下 *Save* 。
