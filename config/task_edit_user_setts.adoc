= 在 Active IQ Unified Manager 中編輯使用者設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以編輯為每位使用者指定的使用者設定，例如電子郵件地址和角色。例如，您可能需要變更身為儲存設備營運者的使用者角色，並為該使用者指派儲存管理員權限。

.開始之前
您必須擁有應用程式管理員角色。

當您修改指派給使用者的角色時，下列任一操作發生時，變更才會生效：

* 使用者登出並重新登入 Unified Manager。
* 已達到 24 小時的工作階段逾時。


.步驟
. 在左側導覽窗格中，按一下 *一般* > *使用者*。
. 在「使用者」頁面中，選取您要編輯設定的使用者，然後按一下 *編輯*。
. 在「編輯使用者」對話方塊中，編輯為該使用者指定的相應設定。
. 按一下 *Save* 。
