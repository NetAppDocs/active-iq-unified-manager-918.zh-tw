= 在 Active IQ Unified Manager 中啟用並停用原則型儲存管理
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
從 Unified Manager 9.7 開始，您可以在 ONTAP 叢集上資源配置儲存設備工作負載（磁碟區和 LUN），並根據指派的效能服務層級管理這些工作負載。此功能類似於在 ONTAP System Manager 中建立工作負載並附加 QoS 原則，但使用 Unified Manager 套用時，您可以跨您的 Unified Manager 執行個體監控的所有叢集資源配置和管理工作負載。

您必須擁有應用程式管理員角色。

此選項預設為啟用，但如果您不想使用 Unified Manager 來資源配置和管理工作負載，則可以將其停用。

啟用後，此選項會在使用者介面中提供許多新項目：

[cols="2*"]
|===
| 新內容 | 地點 


 a| 
用於資源配置新工作負載的頁面
 a| 
可從 *常用任務* > *資源配置* 中取得



 a| 
用於建立效能服務層級原則的頁面
 a| 
可從 *設定* > *原則* > *效能服務層級* 取得



 a| 
用於建立效能儲存效率原則的頁面
 a| 
可從 *設定* > *原則* > *儲存效率* 取得



 a| 
顯示目前工作負載效能和工作負載 IOPS 的面板
 a| 
可從儀表板取得

|===
有關這些頁面和此功能的更多資訊，請參閱產品中的線上說明。

.步驟
. 在左側導覽窗格中，按一下 *一般* > *功能設定*。
. 在 *功能設定* 頁面中，選擇下列選項之一來停用或啟用原則型儲存管理：
+
[cols="2*"]
|===
| 如果您想要…… | 然後這樣做…… 


 a| 
停用原則型儲存管理
 a| 
在 *原則型儲存管理* 面板中，將滑桿按鈕向左移動。



 a| 
啟用原則型儲存管理
 a| 
在 *原則型儲存管理* 面板中，將滑桿按鈕向右移動。

|===
