= 設定 Active IQ Unified Manager 以傳送警示通知
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以設定 Unified Manager 以傳送通知，提醒您環境中發生的事件。在傳送通知之前，您必須設定其他幾個 Unified Manager 選項。

.開始之前
您必須擁有應用程式管理員角色。

部署 Unified Manager 並完成初始組態後，您應該考慮設定您的環境，以便在收到事件時觸發警報並產生通知電子郵件或 SNMP 陷阱。

.步驟
. link:task_configure_event_notification_settings.html["設定事件通知設定"]。
+
如果您希望在環境中發生特定事件時收到警報通知，則必須設定 SMTP 伺服器並提供用於傳送警報通知的電子郵件地址。如果您想使用 SNMP 陷阱，可以選擇該選項並提供必要的資訊。

. link:task_enable_remote_authentication.html["啟用遠端驗證"]。
+
如果您希望遠端 LDAP 或 Active Directory 使用者存取 Unified Manager 執行個體並接收警報通知，則必須啟用遠端驗證。

. link:task_add_authentication_servers.html["新增驗證伺服器"]。
+
您可以新增驗證伺服器，以便驗證伺服器內的遠端使用者可以存取 Unified Manager。

. link:task_add_users.html["新增使用者"]。
+
您可以新增多種不同類型的本機或遠端使用者，並指派特定角色。建立警示時，您會指派一位使用者來接收警示通知。

. link:task_add_alerts.html["新增警示"]。
+
新增用於傳送通知的電子郵件地址、新增接收通知的使用者、設定網路設定以及設定環境所需的 SMTP 和 SNMP 選項後，即可指派警報。
