= 在 Active IQ Unified Manager 中啟用遠端驗證
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以啟用遠端驗證，以便 Unified Manager 伺服器可以與您的驗證伺服器通訊。驗證伺服器的使用者可以存取 Unified Manager 圖形介面來管理儲存設備物件和資料。

.開始之前
您必須擁有應用程式管理員角色。

[NOTE]
====
Unified Manager 伺服器必須直接連接至驗證伺服器。您必須停用任何本機 LDAP 用戶端，例如 SSSD（System Security Services Daemon）或 NSLCD（Name Service LDAP Caching Daemon）。

====
您可以使用 Open LDAP 或 Active Directory 啟用遠端驗證。如果停用遠端驗證，遠端使用者將無法存取 Unified Manager。

支援透過 LDAP 和 LDAPS（Secure LDAP）進行遠端驗證。Unified Manager 使用 389 作為非安全通訊的預設連接埠，並使用 636 作為安全通訊的預設連接埠。

[NOTE]
====
用於驗證使用者身分的憑證必須符合 X.509 格式。

====
.步驟
. 在左側導覽窗格中，按一下 *一般* > *遠端驗證*。
. 勾選 *啟用遠端驗證……* 核取方塊。
. 在「驗證服務」欄位中，選擇服務類型並設定驗證服務。
+
[cols="2*"]
|===
| 對於驗證類型…… | 請輸入以下資訊…… 


 a| 
Active Directory
 a| 
** 驗證伺服器系統管理員名稱，採用下列其中一種格式：
+
*** `domainname\username`
*** `username@domainname`
*** `Bind Distinguished Name`（使用適當的 LDAP 表示法）


** 管理員密碼
** 基本辨別名稱（使用適當的 LDAP 表示法）




 a| 
Open LDAP
 a| 
** 綁定辨別名稱（採用適當的 LDAP 表示法）
** 綁定密碼
** 基本辨識名稱


|===
+
如果 Active Directory 使用者驗證耗時過長或逾時，則可能是驗證伺服器回應速度過慢。停用 Unified Manager 中的巢狀群組支援可能會縮短驗證時間。

+
如果為驗證伺服器選擇「使用安全連線」選項，則 Unified Manager 將使用安全通訊端層 (SSL) 協定與驗證伺服器通訊。

. *可選：*新增驗證伺服器，並測試驗證。
. 按一下 *Save* 。
