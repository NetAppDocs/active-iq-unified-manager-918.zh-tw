= 更改 Active IQ Unified Manager 用於 HTTP 和 HTTPS 協定的連接埠
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果基於安全性考量而有需要，可以在安裝後變更 Unified Manager 用於 HTTP 和 HTTPS 協定的預設連接埠。HTTP 的預設連接埠為 80，HTTPS 的預設連接埠為 443。

.開始之前
您必須擁有授權的使用者 ID 和密碼才能登入 Unified Manager 伺服器的維護控制台。

[NOTE]
====
使用 Mozilla Firefox 或 Google Chrome 瀏覽器時，某些連接埠被認為是不安全的。在為 HTTP 和 HTTPS 流量指派新的連接埠號碼之前，請務必檢查您的瀏覽器設定。選擇不安全的連接埠可能會導致系統無法存取，屆時您需要聯絡客戶支援尋求解決方案。

====
更改連接埠後，Unified Manager 執行個體會自動重新啟動，因此請確保此時是讓系統停機一小段時間的好時機。

. 使用 SSH 以維護使用者身分登入 Unified Manager 主機。
+
顯示 Unified Manager 維護主控台提示。

. 輸入標記為 *檢視/變更應用程式連接埠* 的選單選項編號，然後按 Enter 鍵。
. 如果出現提示，請再次輸入維護使用者密碼。
. 輸入 HTTP 和 HTTPS 連接埠的新連接埠號碼，然後按 Enter 鍵。
+
連接埠號碼留空將指定協定的預設連接埠。

+
系統會提示您是否要變更連接埠並立即重新啟動 Unified Manager。

. 輸入 *y* 變更連接埠並重新啟動 Unified Manager。
. 退出維護主控台。


更改後，使用者必須在 URL 中包含新的連接埠號碼才能存取 Unified Manager Web UI，例如 +https://host.company.com:1234+、+https://12.13.14.15:1122+ 或 +https://[2001:db8:0:1]:2123+。
