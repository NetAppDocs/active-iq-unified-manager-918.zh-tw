= 在 Active IQ Unified Manager 中使用身分供應商
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
設定 Unified Manager 使用身分供應商（IdP）為所有遠端使用者執行 SAML 驗證時，您需要感知一些必要的組態設定，以便成功連線到 Unified Manager。

您必須將 Unified Manager URI 和中繼資料輸入到 IdP 伺服器中。您可以從 Unified Manager SAML 驗證頁面複本此資訊。Unified Manager 在安全性聲明標記語言 (SAML) 標準中被視為服務供應商 (SP)。



[[supported-encryption-standards]]
== 支援的加密標準

* 進階加密標準（AES）：AES-128 和 AES-256
* 安全雜湊演算法（SHA）：SHA-1 和 SHA-256




[[validated-identity-providers]]
== 已驗證的身分供應商

* Shibboleth
* Active Directory Federation Services (ADFS)




[[adfs-configuration-requirements]]
== ADFS 組態要求

* 您必須依照下列順序定義三個宣告規則，這些規則是 Unified Manager 解析此信賴憑證者信任項目的 ADFS 安全性聲明標記語言 (SAML) 回應時所需的。
+
[cols="2*"]
|===
| 宣告規則 | 價值 


 a| 
SAM-account-name
 a| 
名稱 ID



 a| 
SAM-account-name
 a| 
urn:oid:0.9.2342.19200300.100.1.1



 a| 
權杖群組 -- 非限定名稱
 a| 
urn:oid:1.3.6.1.4.1.5923.1.5.1.1

|===
* 您必須將身分驗證方法設定為 "`Forms Authentication`"，否則使用者在登出 Unified Manager 時可能會收到錯誤。請依照以下步驟操作：
+
.. 開啟 ADFS 管理控制台。
.. 點選左側樹狀檢視中的「驗證策略」資料夾。
.. 在右側的「動作」下，按一下「編輯全域主要驗證原則」。
.. 將 Intranet 身分驗證方法設定為 "`表單驗證`"，而不是預設的 "`Windows 驗證`"。


* 在某些情況下，當 Unified Manager 安全性憑證由 CA 簽署時，透過身分提供者 (IdP) 登入會被拒絕。有兩種方法可以解決此問題：
+
** 請依照連結中的說明，停用 ADFS 伺服器上與鏈結 CA 憑證關聯之信賴方的撤銷檢查：
+
http://www.torivar.com/2016/03/22/adfs-3-0-disable-revocation-check-windows-2012-r2/["停用依賴方信任的撤銷檢查"]

** 讓 CA 伺服器位於 ADFS 伺服器內，以便對 Unified Manager 伺服器憑證要求進行簽署。






[[other-configuration-requirements]]
== 其他組態要求

* Unified Manager 的時鐘偏差設定為 5 分鐘，因此 IdP 伺服器和 Unified Manager 伺服器之間的時間差不能超過 5 分鐘，否則驗證會失敗。
