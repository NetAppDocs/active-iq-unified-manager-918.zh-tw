= 更改 Linux 系統上的 Active IQ Unified Manager umadmin 密碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
基於安全性考慮，您必須在完成安裝程序後立即變更 Unified Manager umadmin 使用者的預設密碼。如有必要，您可以稍後隨時再次變更密碼。

.開始之前
* Unified Manager 必須安裝在 Red Hat Enterprise Linux 系統上。
* 您必須擁有安裝 Unified Manager 的 Linux 系統的 root 使用者憑證。


.步驟
. 以 root 使用者登入執行 Unified Manager 的 Linux 系統。
. 更改 umadmin 密碼：
+
`passwd umadmin`

+
系統提示您為 umadmin 使用者輸入新密碼。
