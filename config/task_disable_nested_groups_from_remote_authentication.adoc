= 在 Active IQ Unified Manager 中停用巢狀群組的遠端驗證
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您已啟用遠端驗證，您可以停用巢狀群組驗證，這樣只有個別使用者（而非群組成員）才能遠端向 Unified Manager 進行驗證。當您想要改善 Active Directory 驗證回應時間時，可以停用巢狀群組。

.開始之前
* 您必須擁有應用程式管理員角色。
* 停用巢狀群組僅適用於使用 Active Directory 的情況。


停用 Unified Manager 中的巢狀群組支援可能會縮短驗證時間。如果停用巢狀群組支援，並且在 Unified Manager 新增了遠端群組，則個別使用者必須是該遠端群組的成員，才能向 Unified Manager 進行驗證。

.步驟
. 在左側導覽窗格中，按一下 *一般* > *遠端驗證*。
. 勾選 *停用巢狀群組查詢* 的核取方塊。
. 按一下 *Save* 。
