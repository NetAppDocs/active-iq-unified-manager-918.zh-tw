= 在 Active IQ Unified Manager 中重新產生 HTTPS 憑證對話方塊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「重新產生 HTTPS 憑證」對話方塊可讓您自訂安全性資訊，然後使用該資訊產生新的 HTTPS 憑證。

此頁面顯示目前的憑證資訊。

"\`使用目前憑證屬性重新產生\`" 和 "\`更新目前憑證屬性\`" 選項可讓您使用目前資訊重新產生憑證，或使用新資訊產生憑證。

* *通用名稱*
+
必填。您希望安全的完整網域名稱（FQDN）。

+
在 Unified Manager 高可用度組態中，使用虛擬 IP 位址。

* *電子郵件*
+
選用。用於聯絡貴組織的電子郵件地址；通常是憑證系統管理員或 IT 部門的電子郵件地址。

* *公司*
+
選填。通常為貴公司的法定名稱。

* *部門*
+
選用。貴公司的部門名稱。

* *城市*
+
選用。貴公司所在的城市。

* *狀態*
+
選用。貴公司所在的州或省份位置，請勿縮寫。

* *國家*
+
選用。貴公司所在的國家。這通常是該國家的兩個字母 ISO 代碼。

* *別名*
+
必填。除了現有的 localhost 或其他網路位址之外，可用來存取此伺服器的其他非主要網域名稱。請以逗號分隔每個替代名稱。

+
如果您想要從憑證的「備用名稱」欄位移除本機識別資訊，請選取 "`排除本機識別資訊（例如 localhost）`" 核取方塊。選取此核取方塊後，「備用名稱」欄位將僅使用您在此欄位中輸入的內容。如果留空，則產生的憑證將完全不包含「備用名稱」欄位。

* *金鑰長度（金鑰演算法：RSA）*
+
金鑰演算法設定為 RSA。您可以從下列金鑰長度中選擇：2048 位元、3072 位元或 4096 位元。預設金鑰長度設定為 2048 位元。

* *有效期限*
+
預設有效期為 397 天。如果您是從舊版本升級而來，則可能會發現先前的憑證有效期未變更。



如需詳細資訊，請參閱 link:../config/task_generate_an_https_security_certificate_ocf.html["產生 HTTPS 憑證"]。
