= 在 Active IQ Unified Manager 中新增指令碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在 Unified Manager 中新增指令碼，並將這些指令碼與警報關聯。當產生警報時，這些指令碼會自動執行，使您能夠取得有關觸發事件的儲存設備物件的資訊。

.開始之前
* 您必須已經建立並儲存要新增至 Unified Manager 伺服器的指令碼。
* 指令碼支援的檔案格式有 Perl、Shell、PowerShell、Python 和 `.bat` 檔案。
+
|===
| 安裝 Unified Manager 的平台 | 支援的語言 


 a| 
VMware
 a| 
Perl 和 Shell 指令碼



 a| 
Linux
 a| 
Perl、Python 和 Shell 指令碼



 a| 
Windows
 a| 
PowerShell、Perl、Python 和 .bat 指令碼

|===
+
** 對於 Perl 指令碼，必須在 Unified Manager 伺服器上安裝 Perl。對於 VMware 安裝，預設會安裝 Perl 5，且指令碼僅支援 Perl 5 支援的功能。如果 Perl 是在 Unified Manager 之後才安裝，則必須重新啟動 Unified Manager 伺服器。
** 對於 PowerShell 指令碼，必須在 Windows 伺服器上設定適當的 PowerShell 執行原則，以便指令碼能夠執行。


+
[NOTE]
====
如果您的指令碼會建立記錄檔來追蹤警報指令碼的進度，您必須確保記錄檔不會建立在 Unified Manager 安裝資料夾內的任何位置。

====
* 您必須擁有應用程式系統管理員或儲存系統管理員角色。


您可以上傳自訂指令碼並收集有關警報的事件詳細資訊。

[NOTE]
====
如果您在使用者介面中看不到此功能，則是因為您的系統管理員已停用該功能。如有需要，您可以從 *儲存設備管理* > *功能設定* 啟用此功能。

====
.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *指令碼*。
. 在「指令碼」頁面中，按一下「新增」。
. 在 *新增指令碼* 對話方塊中，按一下 *瀏覽* 選擇您的指令碼檔案。
. 請輸入所選指令碼的執行摘要。
. 點擊 *Add* 。
