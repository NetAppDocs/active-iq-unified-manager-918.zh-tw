= 在 Active IQ Unified Manager 中解決 Active IQ 平台事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ 平台事件和風險與其他 Unified Manager 事件類似，因為它們可以指派給其他使用者進行解決，並且具有相同的可用狀態。但是，當您使用 *Fix It* 按鈕解決此類事件時，可以在數小時內驗證解決方案。

下圖顯示您在解決從 Active IQ 平台產生的事件時必須採取的行動（綠色）以及 Unified Manager 採取的行動（黑色）。

image::../media/aiq_and_um_event_resolution.png[UI 快照，顯示了您必須採取的行動以及 Unified Manager 在解決事件時採取的行動。]

執行手冊解決時，您必須登入 System Manager 或 ONTAP 命令列介面來修正問題。只有在叢集於午夜產生新的 AutoSupport 訊息後，您才能驗證問題。

使用 *Fix It* 按鈕執行半自動修復時，您可以在幾個小時內驗證修復是否成功。
