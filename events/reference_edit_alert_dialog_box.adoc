= 在 Active IQ Unified Manager 中編輯警示屬性
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以編輯警報屬性，例如警報關聯的資源、事件、指令碼和通知選項。



[[name]]
== Name

您可以在此處編輯警報的名稱和執行摘要。

* *警報名稱*
+
可讓您編輯警報名稱。

* *警報執行摘要*
+
允許您為警報指定執行摘要。

* *警報狀態*
+
允許您啟用或停用警報。





[[resources]]
== 資源

在此區域，您可以選擇單一資源，或根據動態規則對資源進行分組，以觸發警報。您可以從下拉清單中選擇資源類型來搜尋資源，也可以指定確切的資源名稱來顯示特定資源。

* *包括*
+
可讓您包含要觸發警報的資源。您可以指定字串來將符合該字串的資源分組，並選取此群組以包含在警報中。例如，您可以將名稱包含 "`vol0`" 字串的所有 Volume 分組。

* *排除*
+
允許您排除不想觸發警報的資源。例如，您可以排除名稱包含 "`xyz`" 字串的所有 Volume。

+
[NOTE]
====
只有當您選擇特定資源類型的所有資源時，才會顯示「排除」標籤——例如，+<<All Volumes>>+ 或 +<<All Volumes whose name contains 'xyz'>>+。

====




[[events]]
== 事件

在此區域，您可以選擇要觸發警報的事件。您可以根據特定嚴重程度或一組事件觸發警報。

* *事件嚴重程度*
+
允許您根據嚴重性類別選擇事件，該類別可以是「嚴重」、「錯誤」或「警告」。

* *事件名稱包含*
+
允許您選擇名稱包含指定字元的事件。





[[actions]]
== 動作

您可以在此指定通知方式和通知頻率。

* *通知這些使用者*
+
您可以編輯電子郵件地址或使用者名稱，或指定新的電子郵件地址或使用者名稱來接收通知。

* *通知頻率*
+
您可以編輯管理伺服器發送通知的頻率，直到事件被確認、解決或移至過時狀態。

+
您可以選擇以下通知方式：

+
** 僅通知一次
** 按指定頻率通知
** 在指定的時間範圍內，以指定的頻率發出通知


* *發出 SNMP 陷阱*
+
允許您指定是否應將 SNMP 陷阱傳送至全域設定的 SNMP 主機。

* *執行指令碼*
+
可讓您將指令碼與警報建立關聯。產生警報時，即會執行此指令碼。





[[command-buttons]]
== 命令按鈕

* *儲存*
+
儲存變更並關閉對話方塊。

* *取消*
+
放棄變更並關閉對話方塊。
