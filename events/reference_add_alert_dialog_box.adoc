= 了解 Active IQ Unified Manager 中的「新增警報」對話方塊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以建立警報，以便在發生特定事件時收到通知，從而快速解決問題，最大限度地減少對環境的影響。您可以為單一資源或一組資源建立警報，也可以為特定嚴重性類別的事件建立警報。此外，您也可以指定警報的通知方式和頻率。

您必須擁有應用程式系統管理員或儲存系統管理員角色。



[[name]]
== Name

您可以在此指定警報的名稱和執行摘要：

* *警報名稱*
+
允許您指定警報名稱。

* *警報執行摘要*
+
允許您為警報指定執行摘要。





[[resources]]
== 資源

在此區域，您可以選擇單一資源，或根據動態規則對資源進行分組，以觸發警報。_動態規則_ 是指根據您指定的字串篩選出的資源集合。您可以從下拉清單中選擇資源類型來搜尋資源，也可以指定確切的資源名稱來顯示特定資源。

如果您從任何儲存設備物件詳細資料頁面建立警報，則儲存設備物件會自動包含在警報中。

* *包括*
+
可讓您包含要觸發警報的資源。您可以指定字串來將符合該字串的資源分組，並選取要包含在警報中的此群組。例如，您可以將名稱包含 "abc" 字串的所有磁碟區分組。

* *排除*
+
可讓您排除不想觸發警報的資源。例如，您可以排除名稱包含 "xyz" 字串的所有磁碟區。

+
只有當您選擇特定資源類型的所有資源時，才會顯示「排除」標籤：例如，+<<All Volumes>> 或 <<All Volumes whose name contains 'xyz'>>+。

+
如果資源同時符合您指定的包含規則和排除規則，則排除規則優先於包含規則，並且不會為該事件產生警報。





[[events]]
== 事件

在此區域，您可以選擇要為其建立警報的事件。您可以根據特定嚴重程度或一組事件建立警報。

若要選擇多個事件，您應該在進行選擇時按住 Ctrl 鍵。

* *事件嚴重程度*
+
允許您根據嚴重性類別選擇事件，該類別可以是「嚴重」、「錯誤」或「警告」。

* *事件名稱包含*
+
允許您選擇名稱包含指定字元的事件。





[[actions]]
== 動作

在此區域，您可以指定觸發警報時要通知的使用者。您也可以指定通知方式和通知頻率。

* *通知這些使用者*
+
允許您指定接收通知的使用者的電子郵件地址或使用者名稱。

+
如果您修改為使用者指定的電子郵件地址，並重新開啟警報以進行編輯，則「名稱」欄位會顯示為空白，因為修改後的電子郵件地址不再對應至先前選取的使用者。此外，如果您從「使用者」頁面修改了所選使用者的電子郵件地址，則修改後的電子郵件地址不會為所選使用者更新。

* *通知頻率*
+
可讓您指定管理伺服器傳送通知的頻率，直到事件獲得確認、解決或移至過時狀態為止。

+
您可以選擇以下通知方式：

+
** 僅通知一次
** 按指定頻率通知
** 在指定的時間範圍內，以指定的頻率發出通知


* *發出 SNMP 陷阱*
+
勾選此方塊可指定是否應將 SNMP 陷阱傳送至全域設定的 SNMP 主機。

* *執行指令碼*
+
可讓您將自訂指令碼新增至警報。產生警報時會執行此指令碼。

+
[NOTE]
====
如果您在使用者介面中看不到此功能，則是因為您的系統管理員已停用該功能。如有需要，您可以從 *儲存設備管理* > *功能設定* 啟用此功能。

====




[[command-buttons]]
== 命令按鈕

* *儲存*
+
建立警示並關閉對話方塊。

* *取消*
+
放棄變更並關閉對話方塊。
