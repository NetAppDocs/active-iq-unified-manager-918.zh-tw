= 了解 Active IQ Unified Manager 中的事件管理清單頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
事件管理清單頁面可讓您檢視目前事件及其屬性的清單。您可以執行確認、解決及指派事件等工作。您也可以為特定事件新增警示。

本頁面的資訊每 5 分鐘會自動重新整理一次，以確保顯示最新的事件。



[[filter-components]]
== 篩選器元件

可讓您自訂事件清單中顯示的資訊。您可以使用下列元件來精簡所顯示的事件清單：

* 檢視選單，從預先定義的篩選選項清單中進行選擇。
+
這包括所有作用中（新的和已確認的）事件、作用中效能事件、分配給我（登入使用者）的事件以及所有維護視窗期間產生的所有事件等項目。

* 搜尋窗格，可透過輸入完整或部分詞彙來精簡事件清單。
* 篩選按鈕可啟動篩選器窗格，讓您從每個可用的欄位和欄位屬性中進行選擇，以精簡事件清單。




[[command-buttons]]
== 命令按鈕

命令按鈕可讓您執行下列任務：

* *指派給*
+
您可以選擇事件的指定使用者。當您將事件指派給使用者時，該使用者的姓名和指派時間將會新增至所選事件的事件清單中。

+
** 我
+
將事件指派給目前登入的使用者。

** 另一位使用者
+
顯示「指定擁有者」對話方塊，讓您能夠將事件指派或重新指派給其他使用者。您也可以將所有權欄位留白來取消指派事件。



* *確認*
+
確認所選事件。

+
當您確認事件時，您的使用者名稱和確認事件的時間會新增至所選事件的事件清單中。當您確認事件時，您將負責管理該事件。

+
[NOTE]
====
您無法確認資訊事件。

====
* *標記為已解決*
+
允許您將事件狀態變更為已解決。

+
當您解決事件時，您的使用者名稱和解決事件的時間會加入所選事件的事件清單中。在您對事件採取修正行動後，必須將該事件標記為已解決。

* *新增提醒*
+
顯示「新增警示」對話框，可讓您為所選事件新增警示。

* *報告*
+
可讓您將目前事件檢視的詳細資訊匯出至逗號分隔值（.csv）檔案或 PDF 文件。

* *顯示/隱藏欄選擇器*
+
可讓您選擇要在頁面上顯示的欄，並選擇其顯示順序。





[[events-list]]
== 事件清單

顯示所有事件的詳細資料，並依觸發時間排序。

預設會顯示「所有作用中事件」檢視，以顯示過去七天內影響層級為「事件」或「風險」的新事件和已確認事件。

* *觸發時間*
+
事件產生的時間。

* *嚴重程度*
+
事件嚴重性：嚴重（image:../media/sev_critical_um60.png[""]）、錯誤（image:../media/sev_error_um60.png[""]）、警告（image:../media/sev_warning_um60.png[""]）與資訊（image:../media/sev_information_um60.gif[""]）。

* *狀態*
+
事件狀態：新建、已確認、已解決或已過時。

* *影響層級*
+
事件影響層級：事故、風險、事件或升級。

* *影響區域*
+
事件影響範圍：可用度、容量、效能、保護、組態或安全性。

* *名稱*
+
事件名稱。您可以選擇名稱以顯示該事件的事件詳細資料頁面。

* *來源*
+
發生事件的物件名稱。您可以選擇該名稱以顯示該物件的健全狀況或效能詳細資料頁面。

+
當共享的 QoS 原則發生違規時，此欄位僅顯示消耗 IOPS 或 MB/s 最多的工作負載物件。使用此原則的其他工作負載將顯示在「事件詳細資料」頁面中。

* *來源類型*
+
與事件關聯的物件類型（例如，Storage VM、磁碟區或 Qtree）。

* *指派給*
+
獲派事件的使用者名稱。

* *事件起源*
+
事件是源自「Active IQ Portal」還是直接源自「Active IQ Unified Manager」。

* *註解名稱*
+
指派給儲存設備物件的註解名稱。

* *備註*
+
為某個事件新增的附註數量。

* *未解決天數*
+
自事件最初產生以來的天數。

* *指定時間*
+
自事件指派給使用者以來所經過的時間。如果經過的時間超過一週，則會顯示事件指派給使用者的時間戳記。

* *確認者*
+
確認事件的使用者名稱。如果事件未確認，則此欄位為空白。

* *確認時間*
+
自事件確認以來經過的時間。如果經過的時間超過一週，則顯示事件確認的時間戳記。

* *解決者*
+
解決事件的使用者名稱。如果事件未解決，則此欄位為空白。

* *已解決時間*
+
自事件解決後所經過的時間。如果經過的時間超過一週，則會顯示事件解決時的時間戳記。

* *過時時間*
+
該事件狀態過時的時間點。
