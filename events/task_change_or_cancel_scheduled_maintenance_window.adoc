= 在 Active IQ Unified Manager 中變更或取消排定的維護所需時間
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您已設定 Unified Manager 維護所需時間在未來進行，您可以變更開始時間和結束時間，或取消維護所需時間的進行。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

如果您在排定的維護所需時間結束時間之前完成了叢集維護，並且想要再次開始接收來自叢集的事件和警示，則取消目前正在執行的維護所需時間會很有用。

.步驟
. 在左側導覽窗格中，按一下 *儲存管理* > *叢集設定*。
. 在叢集的 *維護模式* 欄位中：
+
|===
| 如果您想要…… | 執行此步驟…… 


 a| 
變更排定的維護所需時間的時間範圍
 a| 
.. 點選滑桿按鈕旁的「已排程」字樣。
.. 變更開始和/或結束日期和時間，然後按一下 *套用*。




 a| 
延長作用中維護所需時間
 a| 
.. 點選滑桿按鈕旁的「作用中」字樣。
.. 變更結束日期和時間，然後按一下 *套用*。




 a| 
取消排定的維護所需時間
 a| 
選擇滑桿按鈕並將其向左移動。



 a| 
取消作用中的維護所需時間
 a| 
選擇滑桿按鈕並將其向左移動。

|===
