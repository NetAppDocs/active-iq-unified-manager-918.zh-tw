= 在 Active IQ Unified Manager 中檢視未指派的事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以檢視未指派的事件，然後將每個事件指派給能夠解決該事件的使用者。

.開始之前
您必須擁有操作員、應用程式管理員或儲存管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *事件管理*。
+
預設情況下，新事件和已確認事件會顯示在事件管理清單頁面上。

. 在 *篩選器* 窗格中，選取 *指派給* 區域中的 *未指派* 篩選選項。
