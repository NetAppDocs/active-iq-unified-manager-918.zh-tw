= 在 Active IQ Unified Manager 中停用「事件」對話方塊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「停用事件」對話方塊顯示可停用事件的事件類型清單。您可以根據特定嚴重程度或一組事件停用事件類型的事件。

您必須擁有應用程式系統管理員或儲存系統管理員角色。



[[event-properties-area]]
== 事件屬性區域

「事件屬性」區域指定下列事件屬性：

* *事件嚴重程度*
+
允許您根據嚴重性類別選擇事件，嚴重性類別可以是關鍵、錯誤、警告或資訊。

* *事件名稱包含*
+
允許您篩選名稱包含指定字元的事件。

* *相符事件*
+
顯示與事件嚴重性類別和您指定的字串相符的事件清單。

* *停用事件*
+
顯示您已選擇要停用的事件清單。

+
事件的嚴重程度也會與事件名稱一起顯示。





[[command-buttons]]
== 命令按鈕

透過命令按鈕，您可以對選定的事件執行以下操作：

* *儲存並結案*
+
停用該事件類型並關閉對話方塊。

* *取消*
+
放棄變更並關閉對話方塊。
