= 了解 Active IQ Unified Manager 中的事件嚴重性類型
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
每個事件都與一個嚴重性類別相關聯，以幫助您確定需要立即修正行動的事件的優先順序。

* *關鍵*
+
發生問題，如果不立即採取修正行動，可能會導致服務中斷。

+
效能關鍵事件僅由使用者定義的臨界值傳送。

* *錯誤*
+
事件來源仍在運作；但是，需要修正行動以避免服務中斷。

* *警告*
+
事件來源發生了您應該感知的事件，或者叢集物件的效能計數器超出正常範圍，應該加以監控以確保其不會達到關鍵嚴重性。此嚴重程度的事件不會導致服務中斷，可能不需要立即修正行動。

+
效能警告事件是從使用者定義、系統定義或動態臨界值所傳送。

* *資訊*
+
當發現新物件或執行使用者行動時，就會觸發此事件。例如，當刪除任何儲存設備物件或進行任何組態變更時，都會產生嚴重性類別為「資訊」的事件。

+
當 ONTAP 偵測到組態變更時，資訊事件會直接從 ONTAP 傳送。
