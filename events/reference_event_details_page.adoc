= 了解 Active IQ Unified Manager 中的「事件詳細資料」頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在「事件詳細資料」頁面中，您可以檢視所選事件的詳細資訊，例如事件嚴重性、影響層級、影響區域和事件來源。您也可以檢視有關解決該問題之可能補救措施的其他資訊。

* *事件名稱*
+
事件名稱和事件最後一次出現的時間。

+
對於非效能事件，當事件處於「新增」或「已確認」狀態時，最後看見的資訊為未知，因此會隱藏。

* *事件執行摘要*
+
事件的簡短執行摘要。

+
在某些情況下，事件執行摘要中會提供觸發事件的原因。

* *發生競爭的元件*
+
對於動態效能事件，此部分會顯示代表叢集邏輯元件和實體元件的圖示。如果某個元件處於爭用狀態，其圖示會被圈起並以紅色醒目提示。

+
如需此處顯示之元件的執行摘要，請參閱 _叢集元件及其可能發生爭用的原因_。



事件資訊、系統診斷和建議行動部分將在其他主題中說明。

== 命令按鈕

命令按鈕可讓您執行下列任務：

* *附註圖示*
+
您可以新增或更新有關該事件的附註，並審查其他使用者留下的所有附註。



*操作選單*

* *指派給我*
+
將事件指派給您。

* *指派給其他人*
+
開啟「指派擁有者」對話方塊，您可以透過該對話方塊將事件指派或重新指派給其他使用者。

+
當您將事件指派給使用者時，使用者的姓名和事件指派時間將會新增至所選事件的事件清單中。

+
您也可以將所有權欄位留空來取消分配事件。

* *確認*
+
確認所選事件，以便您不再收到重複的警報通知。

+
當您確認事件時，您的使用者名稱和確認事件的時間將會新增至所選事件的事件清單（確認者）中。確認事件後，您將負責管理該事件。

* *標記為已解決*
+
可讓您將事件狀態變更為「已解決」。

+
當您解決事件時，您的使用者名稱以及解決事件的時間將會新增至所選事件的事件清單中 （Resolved By）。針對事件採取修正行動後，您必須將事件標示為已解決。

* *新增提醒*
+
顯示「新增警報」對話方塊，讓您為選取的事件新增警報。
