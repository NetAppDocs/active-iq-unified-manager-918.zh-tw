= 了解 Active IQ Unified Manager 中的「通知」頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以設定 Unified Manager 伺服器，使其在產生事件或將事件指派給使用者時傳送通知。您也可以設定通知機制。例如，通知可以透過電子郵件或 SNMP 陷阱傳送。

您必須擁有應用程式系統管理員或儲存系統管理員角色。



[[email]]
== 電子郵件

此區域可讓您設定下列警示通知的電子郵件設定：

* *寄件者地址*
+
指定傳送警示通知的來源電子郵件地址。共享報告時，此值也會用作寄件者地址。如果「寄件者地址」已預先填入「ActiveIQUnifiedManager@localhost.com」，您應將其變更為實際有效的電子郵件地址，以確保所有電子郵件通知均能成功傳遞。





[[smtp-server]]
== SMTP 伺服器

您可以在此處設定以下 SMTP 伺服器設定：

* *主機名稱或 IP 位址*
+
指定 SMTP 主機伺服器的主機名稱，該主機名稱用於向指定的收件者發送警報通知。

* *使用者名稱*
+
指定 SMTP 使用者名稱。僅當 SMTP 伺服器啟用 SMTPAUTH 時才需要 SMTP 使用者名稱。

* *密碼*
+
指定 SMTP 密碼。僅當 SMTP 伺服器啟用 SMTPAUTH 時才需要 SMTP 使用者名稱。

* *連接埠*
+
指定 SMTP 主機伺服器用於發送警報通知的連接埠。

+
預設值為 25。

* *使用 START/TLS*
+
勾選此方塊可透過使用 TLS/SSL 協定（也稱為 start_tls 和 StartTLS）在 SMTP 伺服器和管理伺服器之間提供安全的通訊。

* *使用 SSL*
+
勾選此方塊可透過使用 SSL 協定在 SMTP 伺服器和管理伺服器之間提供安全的通訊。





[[snmp]]
== SNMP

在此區域，您可以設定以下 SNMP 陷阱設定：

* *版本*
+
根據您所需的安全性類型，指定您要使用的 SNMP 版本。選項包括版本 1、版本 3、具備驗證的版本 3，以及具備驗證與加密的版本 3。預設值為版本 1。

* *Trap 目的地主機*
+
指定接收管理伺服器傳送的 SNMP 陷阱的主機名稱或 IP 位址（IPv4 或 IPv6）。若要指定多個陷阱目標，請用逗號分隔每個主機。

+
[NOTE]
====
所有其他 SNMP 設定（例如「版本」和「出站連接埠」）對於清單中的所有主機都必須相同。

====
* *傳出 Trap 連接埠*
+
指定 SNMP 伺服器用來接收管理伺服器所傳送之陷阱的連接埠。

+
預設值為 162。

* *社群*
+
用於存取主機的社群字串。

* *引擎識別碼*
+
指定 SNMP 代理程式的唯一識別碼，並由管理伺服器自動產生。引擎 ID 可用於 SNMP 版本 3、具有驗證的 SNMP 版本 3，以及具有驗證和加密的 SNMP 版本 3。

* *使用者名稱*
+
指定 SNMP 使用者名稱。SNMP 版本 3、具有驗證的 SNMP 版本 3 以及具有驗證和加密的 SNMP 版本 3 均支援使用者名稱。

* *身份驗證協定*
+
指定用於驗證使用者的協定。協定選項包括 MD5 和 SHA。MD5 為預設值。驗證協定適用於具有驗證的 SNMP 版本 3 和具有驗證與加密的 SNMP 版本 3。

* *驗證密碼*
+
指定驗證使用者時所使用的密碼。SNMP 第 3 版（含驗證）和 SNMP 第 3 版（含驗證與加密）均提供驗證密碼。

* *隱私權通訊協定*
+
指定用於加密 SNMP 訊息的隱私協定。協定選項包括 AES 128 和 DES。預設值為 AES 128。隱私協定在啟用驗證和加密的 SNMP 版本 3 中可用。

* *隱私密碼*
+
指定使用隱私協定時的密碼。隱私權密碼適用於啟用驗證和加密的 SNMP 版本 3。
