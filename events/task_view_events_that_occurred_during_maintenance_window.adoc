= 在 Active IQ Unified Manager 中查看維護所需時間期間產生的事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如有需要，您可以檢視在 Unified Manager 維護所需時間期間為所有儲存設備物件產生的事件。維護所需時間結束且所有系統資源皆已恢復運作後，大多數事件將顯示為「已過時」狀態。

.開始之前
在任何事件可用之前，至少必須完成一個維護所需時間。

預設情況下，維護所需時間期間發生的事件不會顯示在事件管理清單頁面上。

.步驟
. 在左側導覽窗格中，按一下 *事件*。
+
預設情況下，所有作用中（新建和已確認）事件都會顯示在事件管理清單頁面上。

. 從「檢視」窗格中，選取 *維護期間產生的所有事件* 選項。
+
顯示過去 7 天內從所有維護所需時間工作階段與所有叢集觸發的事件清單。

. 如果單一叢集有多個維護所需時間，您可以按一下 *觸發時間* 日曆圖示，然後選取您有興趣檢視的維護所需時間事件的期間。
