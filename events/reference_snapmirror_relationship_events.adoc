= 了解 Active IQ Unified Manager 中的 SnapMirror 關係事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapMirror 關係事件提供有關非同步和同步 SnapMirror 關係狀態的資訊，以便您可以監控潛力問題。非同步 SnapMirror 關係事件會針對儲存設備虛擬機器和 Volume 產生，而同步 SnapMirror 關係事件僅針對 Volume 關係產生。對於構成儲存設備虛擬機器災難恢復關係的 Volume，不會產生任何事件。事件按影響區域分組，並包含事件和陷阱名稱、影響層級、來源類型和嚴重性。
