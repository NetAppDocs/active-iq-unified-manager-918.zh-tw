= 了解 Active IQ Unified Manager 中的事件影響級別
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
每個事件都與一個影響層級（事故、風險、事件或升級）相關聯，以幫助您確定需要立即修正行動的事件的優先順序。

* *事件*
+
事故是指可能導致叢集停止向用戶端提供資料並耗盡資料儲存空間的一組事件。影響層級為「事故」的事件最為嚴重。應立即採取修正行動以避免服務中斷。

* *風險*
+
風險是指可能導致叢集停止向用戶端提供資料並耗盡資料儲存空間的一系列事件。影響層級為「風險」的事件可能導致服務中斷。可能需要採取修正行動。

* *事件*
+
事件是指儲存設備物件及其屬性的狀態或狀態變更。影響層級為「事件」的事件僅供參考，無需採取修正行動。

* *升級*
+
升級事件是 Active IQ 平台報告的特定類型的事件。這些事件顯示存在一些問題，需要升級 ONTAP 軟體、節點韌體或作業系統軟體（針對安全性公告）才能解決。對於某些問題，您可能需要立即採取修正行動，而其他問題則可以等到下次排定的維護再處理。
