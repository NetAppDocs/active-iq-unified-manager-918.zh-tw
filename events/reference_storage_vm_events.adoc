= 了解 Active IQ Unified Manager 中的儲存 VM 事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Storage VM （儲存設備虛擬機器，也稱為 SVM）事件提供有關 Storage VM （SVM）狀態的資訊，以便您可以監控潛力問題。事件按影響區域分組，包括事件和設陷名稱、影響層級、來源類型和嚴重性。

星號（*）表示已轉換為 Unified Manager 事件的 EMS 事件。
