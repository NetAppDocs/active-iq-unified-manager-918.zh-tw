= 了解 Active IQ Unified Manager 中的「警報設定」頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「警報設定」頁面顯示警報列表，並提供有關警報名稱、狀態、通知方式和通知頻率的資訊。您也可以在此頁面新增、編輯、移除、啟用或停用警報。

您必須擁有應用程式系統管理員或儲存系統管理員角色。



[[command-buttons]]
== 命令按鈕

* *新增*
+
顯示「新增警報」對話方塊，可讓您新增警報。

* *編輯*
+
顯示「編輯警報」對話方塊，讓您編輯選定的警報。

* *刪除*
+
刪除選取的警報。

* *啟用*
+
啟用所選警報以發送通知。

* *停用*
+
當您想要暫時停止傳送通知時，停用所選的警示。

* *測試*
+
新增或編輯後，測試選定的警報以驗證其組態。

* *已解決和已過時事件的警示*
+
允許您啟用或停用事件狀態變為「已解決」或「已過時」時發送的提醒。這有助於使用者避免接收不必要的通知。





[[list-view]]
== 清單檢視

清單檢視以表格形式顯示已建立的警報資訊。您可以使用欄篩選器自訂顯示的資料。您也可以選擇某個警報，在詳細資訊區域檢視更多相關資訊。

* *狀態*
+
指定警報是否啟用（image:../media/alert_status_enabled.gif[""]）或停用（image:../media/alert_status_disabled.gif[""]）。

* *警報*
+
顯示警報名稱。

* *說明*
+
顯示警報的執行摘要。

* *通知方式*
+
顯示為警報選擇的通知方式。您可以透過電子郵件或 SNMP 陷阱通知使用者。

* *通知頻率*
+
指定管理伺服器持續發送通知的頻率（以分鐘為單位），直到事件被確認、解決或移至過時狀態。





[[details-area]]
== 詳細資訊區域

詳細資訊區域提供有關所選警報的更多資訊。

* *警報名稱*
+
顯示警報名稱。

* *警報執行摘要*
+
顯示警報的執行摘要。

* *事件*
+
顯示您希望觸發警報的事件。

* *資源*
+
顯示要觸發警報的資源。

* *包含*
+
顯示要觸發警報的資源群組。

* *不包括*
+
顯示您不想觸發警報的資源群組。

* *通知方式*
+
顯示警報的通知方式。

* *通知頻率*
+
顯示管理伺服器持續傳送警報通知的頻率，直到事件被確認、解決或移至過時狀態為止。

* *指令碼名稱*
+
顯示與所選警報關聯的指令碼名稱。該指令碼在產生警報時執行。

* *郵件收件者*
+
顯示收到警報通知的使用者的電子郵件地址。
