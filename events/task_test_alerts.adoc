= 在 Active IQ Unified Manager 中測試警報
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以測試警報以驗證設定是否正確。當事件觸發時，會產生警報，並將警報電子郵件傳送給已設定的收件者。您可以使用測試警報來驗證通知是否已傳送，以及指令碼是否已執行。

.開始之前
* 您必須已設定通知設定，例如收件者的電子郵件地址、SMTP 伺服器和 SNMP 設陷。
+
Unified Manager 伺服器可以使用這些設定，在產生事件時向使用者傳送通知。

* 您必須已指派指令碼並設定該指令碼，以便在產生警報時執行。
* 您必須擁有應用程式管理員角色。


.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *警示設定*。
. 在 *警報設定* 頁面中，選擇您要測試的警報，然後按一下 *測試*。
+
系統會傳送測試警報郵件給您在建立警報時指定的電子郵件地址。
