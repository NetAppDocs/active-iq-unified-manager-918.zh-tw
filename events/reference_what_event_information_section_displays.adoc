= 了解 Active IQ Unified Manager 中的「事件資訊」部分
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用「事件詳細資料」頁面上的「事件資訊」區段來檢視所選事件的詳細資訊，例如事件嚴重性、影響層級、影響區域和事件來源。

不適用於該事件類型的欄位已被隱藏。您可以檢視以下事件詳情：

* *事件觸發時間*
+
事件產生的時間。

* *狀態*
+
事件狀態：新建、已確認、已解決或已過時。

* *已過時的原因*
+
導致事件過時的行動，例如，問題已修復。

* *事件持續時間*
+
對於作用中（新發生且已確認）的事件，此時間是指從偵測到事件至最後一次分析事件之間的時間。對於已過時的事件，此時間是指從偵測到事件至事件解決之間的時間。

+
此欄位會顯示在所有效能事件中，而對於其他事件類型，只有在事件解決或過時後才會顯示。

* *最後出現時間*
+
事件最後一次處於作用中的日期和時間。

+
對於效能事件，此值可能會比事件觸發時間更新，因為只要事件處於作用中，每次收集到新的效能資料後，此欄位都會更新。對於其他類型的事件，當處於「新」或「已確認」狀態時，此內容不會更新，因此該欄位會被隱藏。

* *嚴重程度*
+
事件嚴重性：嚴重（image:../media/sev_critical_um60.png[""]）、錯誤（image:../media/sev_error_um60.png[""]）、警告（image:../media/sev_warning_um60.png[""]）與資訊（image:../media/sev_information_um60.gif[""]）。

* *影響層級*
+
事件影響層級：事故、風險、事件或升級。

* *影響區域*
+
事件影響範圍：可用度、容量、效能、保護、組態或安全性。

* *來源*
+
發生事件的物件名稱。

+
在檢視共享的 QoS 原則事件的詳細資訊時，此欄位中最多會列出消耗最多 IOPS 或 MBps 的三個工作負載物件。

+
您可以點選來源名稱連結來顯示該物件的健全狀況或效能詳細資料頁面。

* *來源註解*
+
顯示與事件關聯的物件的註解名稱和值。

+
此欄位僅針對叢集、SVM 和 Volume 上的健全狀況事件顯示。

* *來源群組*
+
顯示受影響物件所屬的所有群組的名稱。

+
此欄位僅針對叢集、SVM 和 Volume 上的健全狀況事件顯示。

* *來源類型*
+
與事件關聯的物件類型（例如 SVM、Volume 或 Qtree）。

* *叢集上*
+
事件發生的叢集名稱。

+
您可以按一下叢集名稱連結，顯示該叢集的健全狀況或效能詳細資訊頁面。

* *受影響物件數量*
+
受事件影響的物件數量。

+
您可以按一下物件連結來顯示詳細目錄頁面，其中包含目前受此事件影響的物件。

+
此欄位僅針對效能事件顯示。

* *受影響的 Volume*
+
受此事件影響的 Volume 數量。

+
此欄位僅針對節點或 Aggregate 上的效能事件顯示。

* *觸發原則*
+
發布該事件的臨界值原則的名稱。

+
您可以將滑鼠懸停在原則名稱上，查看臨界值原則的詳細資訊。對於具調適能力的 QoS 原則，也會顯示已定義的原則、區塊大小和分配類型（已分配空間或已使用空間）。

+
此欄位僅針對效能事件顯示。

* *規則 ID*
+
對於 Active IQ 平台事件，這是觸發產生該事件的規則編號。

* *確認者*
+
確認事件的人員姓名以及確認事件的時間。

* *解決者*
+
事件解決者的姓名以及事件解決的時間。

* *分配給*
+
負責此次事件的人員姓名。

* *提醒設定*
+
顯示下列有關警報的資訊：

+
** 如果所選事件沒有關聯的警報，則會顯示 *新增警報* 連結。
+
按一下連結即可開啟「新增警報」對話方塊。

** 如果有一個警報與選定的事件相關聯，則會顯示警報名稱。
+
您可以點擊連結開啟「編輯警示」對話方塊。

** 如果與所選事件關聯的警報不只一個，則會顯示警報的數量。
+
您可以點擊連結開啟「警報設定」頁面，檢視有關這些警報的更多詳細資訊。



+
已停用的警報不會顯示。

* *最後傳送的通知*
+
最近一次警報通知的發送日期和時間。

* *發送人*
+
發送警報通知所使用的機制：電子郵件或 SNMP trap。

* *上次指令碼執行*
+
警報產生時執行的指令碼名稱。
