= 在 Active IQ Unified Manager 中刪除警報
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以刪除不再需要的警報。例如，當 Unified Manager 不再監控某個資源時，您可以刪除為該資源建立的警報。

.開始之前
您必須擁有應用程式管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *警示設定*。
. 在 *警報設定* 頁面上，選擇要刪除的警報，然後按一下 *刪除*。
. 點擊 *是* 確認刪除請求。
