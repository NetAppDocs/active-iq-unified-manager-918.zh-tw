= 在 Active IQ Unified Manager 中管理主機系統資源事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 包含一項服務，用於監控安裝 Unified Manager 的主機系統上的資源問題。例如，主機系統可用磁碟空間不足或記憶體容量不足等問題可能會觸發管理站台事件，這些事件會以橫幅訊息的形式顯示在使用者介面頂部。

管理站事件表示安裝了 Unified Manager 的主機系統有問題。管理站問題的範例包括：主機系統磁碟空間不足；Unified Manager 錯失常規資料收集週期；以及由於已啟動下一次收集輪詢而導致統計資料分析未完成或延遲完成。

與所有其他 Unified Manager 事件訊息不同，這些特定的管理站警告和關鍵事件會顯示在橫幅訊息中。

.步驟
. 若要檢視管理站台事件資訊，請執行這些行動：
+
|===
| 如果您想要…… | 這樣做…… 


 a| 
檢視事件詳細資料
 a| 
按一下事件橫幅以顯示事件詳細資料頁面，其中包含針對該問題的建議解決方案。



 a| 
檢視所有管理站台事件
 a| 
.. 在左側導覽窗格中，按一下 *事件管理*。
.. 在事件管理庫存頁面的篩選器窗格中，按一下來源類型清單中「Management Station」的方塊。


|===
