====
最後這兩個效能事件僅適用於 Unified Manager 7.2。如果其中任何一個事件處於「新增」狀態，然後您升級到較新版本的 Unified Manager 軟體，則這些事件不會自動清除。您需要手動將這些事件移至「已解決」狀態。
