= 在 Active IQ Unified Manager 中查看事件詳情
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以檢視由 Unified Manager 觸發之事件的詳細資訊，以便採取修正行動。例如，如果出現「Volume 離線」健全狀況事件，您可以按一下該事件以檢視詳細資訊並執行修正行動。

.開始之前
您必須擁有操作員、應用程式管理員或儲存管理員角色。

事件詳情包括事件來源、事件起因以及與事件相關的任何備註等資訊。

.步驟
. 在左側導覽窗格中，按一下 *事件管理*。
+
預設情況下，「所有作用中事件」檢視會顯示過去 7 天內產生的、影響等級為「事件」或「風險」的新事件和已確認（作用中）事件。

. 如果您想檢視特定類別的事件，例如容量事件或效能事件，請按一下 *檢視*，然後從事件類型選單中進行選擇。
. 按一下您要檢視詳細資料的事件名稱。
+
事件詳細資料會顯示在事件詳細資料頁面中。
