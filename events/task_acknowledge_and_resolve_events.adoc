= 在 Active IQ Unified Manager 中確認並解決事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在著手處理引發該事件的問題之前，您應該先確認該事件，以免繼續收到重複的警報通知。針對特定事件採取修正行動後，您應該將該事件標記為已解決。

.開始之前
您必須擁有操作員、應用程式管理員或儲存管理員角色。

您可以同時確認和解決多個事件。

[NOTE]
====
您無法確認資訊事件。

====
.步驟
. 在左側導覽窗格中，按一下 *事件管理*。
. 從事件清單中，執行以下操作以確認事件：
+
|===
| 如果您想要…… | 這樣做…… 


 a| 
確認並標記單一事件為已解決
 a| 
.. 點選事件名稱。
.. 從事件詳細資料頁面中，判斷事件的原因。
.. 按一下 *確認*。
.. 採取適當的修正行動。
.. 按一下 *標記為已解決*。




 a| 
確認並標記多個事件為已解決
 a| 
.. 從相應的事件詳細資料頁面確定事件的原因。
.. 選擇事件。
.. 按一下 *確認*。
.. 採取適當的修正行動。
.. 按一下 *標記為已解決*。


|===
+
事件被標記為已解決後，事件會移至已解決事件清單。

. *選用*：在 *附註和更新* 區域中，新增關於您如何處理該事件的附註，然後按一下 *發布*。
