= 在 Active IQ Unified Manager 中新增警報的指南
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以根據資源（例如叢集、節點、彙總或 Volume）以及特定嚴重性類別的事件新增警報。最佳實務做法是，在新增物件所屬的叢集之後，再為任何關鍵物件新增警報。

您可以參考以下準則和注意事項來建立警報，從而有效管理系統：

* 警報執行摘要
+
您應該為警報提供執行摘要，以便有效地追蹤警報。

* 資源
+
您需要決定哪些實體或邏輯資源需要發出警報。您可以根據需要包含或排除資源。例如，如果您想要透過設定警報來密切監控您的彙總，則必須從資源清單中選擇所需的彙總。

+
如果您選擇資源類別，例如 *+<<All User or Group Quotas>>+*，那麼您將收到該類別中所有物件的警報。

+
[NOTE]
====
選擇叢集作為資源並不會自動選擇該叢集內的儲存設備物件。例如，如果您為所有叢集的所有關鍵事件建立警報，則只會收到叢集關鍵事件的警報。您不會收到節點、彙總等關鍵事件的警報。

====
* 事件嚴重性
+
您應該決定特定嚴重性類別（關鍵、錯誤、警告）的事件是否應觸發警報，如果是，則應觸發哪種嚴重性類別。

* 選取的事件
+
如果根據產生的事件類型新增警報，則應決定哪些事件需要警報。

+
如果您選擇事件嚴重性，但沒有選擇任何單一事件（如果您將「已選事件」列留空），則您將收到該類別中所有事件的警報。

* 動作
+
您必須提供接收通知的使用者的使用者名稱和電子郵件地址。您也可以指定 SNMP 陷阱作為通知方式。您可以將指令碼與警報關聯，以便在產生警報時執行指令碼。

* 通知頻率
+
您可以設定警報，使其在指定時間內重複向收件人發送通知。您需要確定警報事件通知的作用中時間。如果您希望事件通知持續發送直至事件被確認，則需要確定通知的重複頻率。

* 執行指令碼
+
您可以將指令碼與警報建立關聯。產生警報時，即會執行您的指令碼。
