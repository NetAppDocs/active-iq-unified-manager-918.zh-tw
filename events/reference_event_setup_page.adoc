= 了解 Active IQ Unified Manager 中的「事件設定」頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「事件設定」頁面會顯示已停用事件的清單，並提供相關物件類型和事件嚴重性等資訊。您也可以執行全域停用或啟用事件等工作。

只有擁有應用程式管理員或儲存設備管理員角色的使用者才能存取此頁面。



[[command-buttons]]
== 命令按鈕

命令按鈕可讓您對選定的事件執行以下操作：

* *停用*
+
開啟「停用事件」對話框，您可以使用該對話框停用事件。

* *啟用*
+
啟用您之前選擇停用的所選事件。

* *上傳規則*
+
啟動「上傳規則」對話方塊，讓沒有外部網路存取的網站能夠手動將 Active IQ 規則檔案上傳至 Unified Manager。這些規則會針對叢集 AutoSupport 訊息執行，以產生 Active IQ 平台所定義的系統組態、佈線、最佳實務做法和可用度事件。

* *訂閱 EMS 事件*
+
啟動「訂閱 EMS 事件」對話方塊，讓您能夠訂閱以接收來自您正在監控之叢集的特定事件管理系統（EMS）事件。EMS 會收集有關叢集上發生之事件的資訊。當收到已訂閱之 EMS 事件的通知時，系統會產生具有適當嚴重性的 Unified Manager 事件。





[[list-view]]
== 清單檢視

清單檢視以表格形式顯示已停用事件的相關資訊。您可以使用欄篩選器自訂顯示的資料。

* *事件*
+
顯示已停用事件的名稱。

* *嚴重程度*
+
顯示事件的嚴重程度。嚴重程度分為：嚴重、錯誤、警告或訊息。

* *來源類型*
+
顯示產生事件的來源類型。
