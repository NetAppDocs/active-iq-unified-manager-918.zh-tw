= 了解 Active IQ Unified Manager 中的非同步鏡像和 Vault 關係事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
非同步鏡像和 Vault 關係事件提供有關非同步 SnapMirror 和 Vault 關係狀態的資訊，以便您可以監控潛力問題。非同步鏡像和 Vault 關係事件同時支援 Volume 和 Storage VM 保護關係。但僅 Vault 關係不支援 Storage VM 災難恢復。事件按影響區域分組，並包含事件和陷阱名稱、影響層級、來源類型和嚴重性。



[[impact-area-protection]]
