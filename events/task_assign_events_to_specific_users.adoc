= 在 Active IQ Unified Manager 中將事件指派給特定使用者
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以將未指派的事件指派給自己或其他使用者，包括遠端使用者。如有需要，您可以將已指派的事件重新指派給其他使用者。例如，當儲存設備物件頻繁發生問題時，您可以將這些問題的事件指派給管理該物件的使用者。

.開始之前
* 使用者的姓名和電子郵件 ID 必須設定正確。
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。


.步驟
. 在左側導覽窗格中，按一下 *事件管理*。
. 在「*事件管理*」清單頁面中，選取一或多個您要指派的事件。
. 請選擇以下選項之一來指派事件：
+
|===
| 如果您想將事件分配給…… | 然後這樣做…… 


 a| 
您自己
 a| 
點選 *指派給* > *我*。



 a| 
另一位使用者
 a| 
.. 點選 *指派給* > *其他使用者*。
.. 在「指派擁有者」對話方塊中，輸入使用者名稱，或從下拉式清單中選取使用者。
.. 按一下 *指派*。
+
系統會向使用者發送電子郵件通知。

+
[NOTE]
====
如果您未輸入使用者名稱或從下拉清單中選取使用者，並按一下 *指派*，則該事件將保持未指派狀態。

====
