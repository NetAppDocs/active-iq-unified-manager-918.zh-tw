= 在 Active IQ Unified Manager 中停用不需要的事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
所有事件預設啟用。您可以全域停用事件，以防止產生環境中不重要事件的通知。如果您想要恢復接收某些事件的通知，可以重新啟用這些已停用的事件。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

停用事件後，系統中先前產生的事件將被標記為過時，並且不會觸發針對這些事件設定的警報。啟用已停用的事件後，這些事件的通知將從下一個監控週期開始產生。

當您停用物件的事件（例如 `vol offline`事件），然後稍後再啟用該事件時， Unified Manager 不會為事件處於停用狀態時離線的物件產生新事件。Unified Manager 僅在重新啟用事件後物件狀態發生變更時，才會產生新事件。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *事件設定*。
. 在 *事件設定* 頁面中，選擇下列選項之一以停用或啟用事件：
+
|===
| 如果您想要…… | 然後這樣做…… 


 a| 
停用事件
 a| 
.. 按一下 *Disable* 。
.. 在「停用事件」對話方塊中，選擇事件嚴重性。
.. 在「比對事件」欄中，根據事件嚴重性選擇要停用的事件，然後按一下右箭頭將這些事件移至「停用事件」欄位。
.. 點選 *儲存並關閉*。
.. 確認您已停用的事件是否顯示在「事件設定」頁面的清單檢視中。




 a| 
啟用事件
 a| 
.. 選取您要啟用的一個或多個事件的核取方塊。
.. 按一下 *Enable* 。


|===
