= 了解 Active IQ Unified Manager 中的系統診斷功能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
事件詳細資料頁面的「系統診斷」部分提供有助於診斷可能導致該事件之問題的資訊。

此區域僅針對部分事件顯示。

某些效能事件會提供與觸發的特定事件相關的圖表。通常這包括過去十天的 IOPS 或 MBps 圖表以及延遲圖表。透過這種排列方式，您可以在事件作用中時，查看哪些儲存設備元件對延遲的影響最大，或受延遲的影響最大。

對於動態效能事件，將顯示以下圖表：

* 工作負載延遲 - 顯示發生爭用的元件上，排名最高的受害者、惡霸或鯊魚工作負載的延遲歷史記錄。
* 工作負載活動 - 顯示有關爭用叢集元件的工作負載使用情況的詳細資訊。
* 資源活動 - 顯示發生爭用的叢集元件的歷史效能統計資料。


當某些叢集元件發生爭用時，會顯示其他圖表。

其他事件提供系統正在對儲存設備物件執行的分析類型的簡要執行摘要。在某些情況下，可能會出現一行或多行；對於分析多個效能計數器的系統定義效能原則，每行對應一個已分析的元件。在這種情況下，診斷結果旁邊會顯示綠色或紅色圖示，以指示該特定診斷中是否發現了問題。
