= 在 Active IQ Unified Manager 中檢閱叢集效能事件窗格
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「叢集效能事件」窗格會顯示叢集的效能統計資料和所有作用中事件。這在監控您的叢集以及所有與叢集相關的效能和事件時最有幫助。



[[all-events-on-this-cluster-pane]]
== 「此叢集上的所有事件」窗格

「此叢集上的所有事件」窗格顯示過去 72 小時內所有作用中的叢集效能事件。最左側顯示的是「作用中事件總數」；此數字表示此叢集中所有儲存設備物件的「新增」和「已確認」事件的總數。您可以點擊「作用中事件總數」連結導覽至「事件清單」頁面，該頁面已篩選並顯示這些事件。

叢集的「作用中事件總數」長條圖顯示作用中的關鍵與警告事件總數：

* 延遲（節點、彙總、SVM、Volume、LUN 和命名空間的總計）
* IOPS（叢集、節點、彙總、SVM、Volume、LUN 和命名空間的總和）
* MB/s（叢集、節點、彙總、SVM、Volume、LUN、命名空間、連接埠和 LIF 的總和）
* 已用效能容量（節點和彙總的總和）
* 使用率（節點、彙總和連接埠的總計）
* 其他（Volume 的快取未命中比率）


此清單包含由使用者定義的臨界值原則、系統定義的臨界值原則和動態臨界值所觸發的作用中效能事件。

圖表資料（垂直計數條）以紅色（image:../media/treemapred_png.gif["TreeMap 圖示 – 紅色"]）顯示關鍵事件，以黃色（image:../media/treemapstatus_warning_png.gif["TreeMap 圖示 – 警告狀態"]）顯示警告事件。將游標停留在每個垂直計數條上，即可檢視事件的實際類型和數量。您可以按一下 *Refresh* 來更新計數器面板資料。

您可以按一下圖例中的 *關鍵* 和 *警告* 圖示，在「總作用中事件」效能圖表中顯示或隱藏關鍵和警告事件。如果您隱藏某些事件類型，圖例圖示將顯示為灰色。



[[counter-panels]]
== 計數器面板

計數器面板顯示過去 72 小時內的叢集活動和效能事件，包括以下計數器：

* *IOPS 計數器面板*
+
IOPS 表示叢集的運作速度，單位為每秒輸入 / 輸出作業次數。此計數器面板提供叢集過去 72 小時 IOPS 健全狀況的高階總覽。您可以將游標停留在圖表趨勢線上，檢視特定時間的 IOPS 值。

* *MB/s 計數器面板*
+
MB/s 表示傳輸至叢集與從叢集傳出的資料量（以每秒百萬位元組為單位）。此計數器面板提供叢集過去 72 小時期間 MB/s 健全狀況的高階總覽。您可以將游標停留在圖表趨勢線上，以檢視特定時間的 MB/s 值。



圖表右上角灰色長條中的數字是過去 72 小時的平均值。趨勢線圖底部和頂部顯示的數字是過去 72 小時的最小值和最大值。圖表下方的灰色長條包含過去 72 小時內作用中（新增和已確認）事件和已失效事件的數量。

計數器面板包含兩種類型的事件：

* *作用中*
+
表示效能事件目前處於作用中（新建或已確認）。導致該事件的問題尚未自行修正或解決。儲存設備物件的效能計數器仍高於效能臨界值。

* *已過時*
+
表示該事件已不再作用中。導致該事件的問題已自行修正或已解決。儲存設備物件的效能計數器已不再高於效能臨界值。



對於 *作用中事件*，如果只有一個事件，您可以將游標停留在事件圖示上，然後按一下事件編號，以連結至適當的事件詳細資料頁面。如果有多個事件，您可以按一下 *檢視所有事件* 以顯示事件清單頁面，該頁面會經過篩選，顯示所選物件計數器類型的所有事件。
