= 在 Active IQ Unified Manager 儀表板上檢閱效能面板
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 儀表板提供多個面板，用於顯示環境中所有受監控叢集的高階效能狀態。您可以選擇檢視所有叢集的狀態或單一叢集的狀態。

除了顯示效能資訊外，大多數面板還會顯示該類別中的作用中事件數量，以及過去 24 小時內新增的事件數量。這些資訊有助於您決定可能需要進一步分析哪些叢集，以解決已報告的事件。按一下事件會顯示前幾個事件，並提供連結至事件管理清單頁面，該頁面已篩選為顯示該類別中的事件。

以下面板顯示效能狀態。

* *效能容量面板*
+
檢視所有叢集時，此面板會顯示每個叢集的效能容量值（過去 1 小時的平均值）以及效能容量達到上限所需的天數（根據每日成長率）。按一下長條圖即可進入該叢集的節點清單頁面。請注意，節點清單頁面顯示的是過去 72 小時的平均效能容量，因此此值可能與儀表板值不符。

+
查看單一叢集時，此面板顯示叢集效能容量、總 IOPS 和總處理量值。

* *工作負載 IOPS 面板*
+
啟用工作負載作用中管理後，在檢視單一叢集時，此面板會顯示目前在特定 IOPS 範圍內執行的工作負載總數。

* *工作負載效能面板*
+
啟用工作負載作用中管理後，此面板會顯示指派給每個已定義效能服務等級的符合要求和不符合要求的工作負載總數。按一下長條圖即可在「工作負載」頁面中查看指派給該原則的工作負載。

* *使用總覽面板*
+
檢視所有叢集時，您可以選擇檢視依最高 IOPS 或處理量（MB/s）排序的叢集。

+
在檢視單一叢集時，您可以選擇依最高 IOPS 或處理量（MB/s）排序來檢視該叢集上的工作負載。
