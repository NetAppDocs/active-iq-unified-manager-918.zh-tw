= 使用 Active IQ Unified Manager 分析 MetroCluster 效能事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager 來分析 MetroCluster 組態的效能事件。您可以識別事件中涉及的工作負載，並審查解決該事件的建議動作。

MetroCluster 效能事件可能是由於過度使用叢集之間交換器間連結 (ISL) 的 _bully_ 工作負載所致，或是由於連結健全狀況問題所致。Unified Manager 會獨立監控 MetroCluster 組態中的每個叢集，而不考慮合作夥伴叢集上的效能事件。

MetroCluster 組態中兩個叢集的效能事件也會顯示在 Unified Manager 儀表板頁面上。您也可以檢視 Unified Manager 的健全狀況頁面，以檢查每個叢集的健全狀況並檢視它們之間的關係。
