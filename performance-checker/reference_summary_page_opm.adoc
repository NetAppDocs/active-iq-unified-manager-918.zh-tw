= 檢閱 Active IQ Unified Manager 中的「效能摘要」頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
總結頁面顯示計數器圖表，其中包含過去 72 小時內每個物件的事件和效能詳細資料。此資料不會自動重新整理，而是截至上次頁面載入時的最新資料。總結頁面中的圖表回答了「我是否需要進一步查看？」這個問題。



[[charts-and-counter-statistics]]
== 圖表和計數器統計資料

總結圖表提供了過去 72 小時的快速、高階總覽，並幫助您識別可能需要進一步調查的問題。

總結頁面計數器統計資料以圖表形式顯示。

您可以將游標停留在圖表中的趨勢線上，檢視特定時間點的計數器值。總結圖表也會顯示以下計數器在過去 72 小時內的作用中關鍵和警告事件總數：

* *延遲*
+
所有 I/O 請求的平均回應時間；以每次操作的毫秒數表示。

+
對所有物件類型均顯示。

* *IOPS*
+
平均運轉速度；以每秒輸入 / 輸出作業次數表示。

+
對所有物件類型均顯示。

* *MB/s*
+
平均處理量；以每秒百萬位元組表示。

+
對所有物件類型均顯示。

* *已使用效能容量*
+
節點或彙總所消耗的效能容量百分比。

+
僅針對節點和彙總顯示。

* *使用率*
+
節點和彙總的物件使用率百分比，或連接埠的頻寬利用率百分比。

+
僅針對節點、彙總和連接埠顯示。



將游標停留在作用中事件的事件計數上，即可顯示事件的類型和數量。關鍵事件以紅色（image:../media/treemapred_png.gif["TreeMap 圖示 – 紅色"]）顯示，警告事件以黃色（image:../media/treemapstatus_warning_png.gif["TreeMap 圖示 – 警告狀態"]）顯示。

圖表右上角灰色長條中的數字是過去 72 小時的平均值。趨勢線圖底部和頂部顯示的數字是過去 72 小時的最小值和最大值。圖表下方的灰色長條包含過去 72 小時內作用中（新增和已確認）事件和已失效事件的數量。

image::../media/iops_graph.gif[顯示 IOPS 圖表的 UI 快照。]

* *延遲計數器圖表*
+
延遲計數器圖表提供過去 72 小時期間物件延遲的高階總覽。延遲是指所有 I/O 要求的平均回應時間；以每次作業的毫秒數表示，即所考量的叢集儲存設備元件中，資料封包或區塊所經歷的服務時間、等待時間或兩者。

+
*頂部（計數器值）：* 標題中的數字顯示前 72 小時的平均值。

+
*中段（效能圖）：* 圖表底部的數字顯示過去 72 小時內的最低延遲，圖表頂部的數字顯示最高延遲。將游標停留在圖表趨勢線上，即可檢視特定時間的延遲值。

+
*底部（事件）：* 滑鼠懸停時，彈出視窗會顯示事件的詳細資料。按一下圖表下方的 *作用中事件* 連結，導覽至「事件清單」頁面以檢視完整的事件詳細資料。

* *IOPS 計數器圖表*
+
IOPS 計數器圖表提供過去 72 小時期間物件 IOPS 健全狀況的高階總覽。IOPS 表示儲存系統的速度，即每秒輸入 / 輸出作業次數。

+
*頂部（計數器值）：* 標題中的數字顯示前 72 小時的平均值。

+
*中段（效能圖）：* 圖表底部的數字顯示過去 72 小時內的最低 IOPS 值，圖表頂部的數字顯示最高 IOPS 值。將游標停留在圖表趨勢線上，即可檢視特定時間的 IOPS 值。

+
*底部（事件）：* 滑鼠懸停時，彈出視窗會顯示事件的詳細資料。按一下圖表下方的 *作用中事件* 連結，導覽至「事件清單」頁面以檢視完整的事件詳細資料。

* *MB/s 計數器圖表*
+
MB/s 計數器圖表顯示物件的 MB/s 效能，並指示每秒與物件之間傳輸的資料量（以百萬位元組為單位）。MB/s 計數器圖表提供物件在過去 72 小時內 MB/s 健全狀況的高階總覽。

+
*頂部（計數器值）：* 標題中的數字顯示前 72 小時期間的平均 MB/s 數。

+
*中間（效能圖）：* 圖表底部的數值顯示過去 72 小時內的最低 MB/s 值，圖表頂部的數值顯示最高 MB/s 值。將游標停留在圖表趨勢線上，即可檢視特定時間的 MB/s 值。

+
*底部（事件）：* 滑鼠懸停時，彈出視窗會顯示事件的詳細資料。按一下圖表下方的 *作用中事件* 連結，導覽至「事件清單」頁面以檢視完整的事件詳細資料。

* *已使用的效能容量計數器圖表*
+
效能容量使用量計數器圖表顯示物件正在消耗的效能容量百分比。

+
*頂部（計數器值）：* 標題中的數字顯示前 72 小時期間的平均已使用效能容量。

+
*中間（效能圖）：* 圖表底部的數值顯示最低的已使用效能容量百分比，圖表頂部的數值顯示過去 72 小時期間最高的已使用效能容量百分比。將游標停留在圖表趨勢線上，即可檢視特定時間的已使用效能容量值。

+
*底部（事件）：* 滑鼠懸停時，彈出視窗會顯示事件的詳細資料。按一下圖表下方的 *作用中事件* 連結，導覽至「事件清單」頁面以檢視完整的事件詳細資料。

* *使用率計數器圖表*
+
使用率計數器圖表顯示物件使用率百分比。使用率計數器圖表提供過去 72 小時期間內物件或頻寬利用率百分比的高階總覽。

+
*頂部（計數器值）：* 標題中的數字顯示前 72 小時的平均使用率百分比。

+
*中間（效能圖）：* 圖表底部的數值顯示過去 72 小時內的最低使用率百分比，圖表頂部的數值顯示最高使用率百分比。將游標停留在圖表趨勢線上，即可檢視特定時間的使用率值。

+
*底部（事件）：* 滑鼠懸停時，彈出視窗會顯示事件的詳細資料。按一下圖表下方的 *作用中事件* 連結，導覽至「事件清單」頁面以檢視完整的事件詳細資料。

== 事件

事件歷史記錄表（如適用）會列出該物件上發生的最新事件。按一下事件名稱可在「事件詳細資料」頁面上顯示事件的詳細資訊。
