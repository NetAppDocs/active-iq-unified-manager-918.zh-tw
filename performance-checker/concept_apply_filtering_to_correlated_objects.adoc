= 在 Active IQ Unified Manager 網格中篩選相關物件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
篩選功能可讓您在網格中顯示更小、更明確的物件子集。例如，如果網格中有 25 個 Volume，篩選功能可讓您僅檢視處理量小於 90 MBps 或延遲大於 1 ms/op 的 Volume。
