= 在 Active IQ Unified Manager 事件時間軸中檢視事件詳情
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在 Performance Explorer 的「事件時間軸」窗格中檢視所有事件及其相關詳細資訊。這是一種快速且有效率的方法，可檢視指定時間範圍內根目錄物件上發生的所有健全狀況和效能事件，這有助於疑難排解效能問題。

「事件時間軸」窗格顯示在選定時間範圍內根目錄物件上發生的關鍵、錯誤、警告和資訊事件。每個事件嚴重程度都有其專屬的時間軸。單一事件和多個事件在時間軸上以事件點表示。您可以將游標懸停在事件點上以檢視事件詳細資訊。若要提高多個事件的視覺精細度，您可以縮小時間範圍。這會將多個事件展開為單一事件，使您能夠分別檢視和調查每個事件。

事件時間軸上的每個效能事件點都與事件時間軸下方顯示的計數器圖表趨勢線中的相應峰值垂直對齊。這在事件與整體效能之間提供了直接的視覺關聯。健全狀況事件也會顯示在時間軸上，但這些類型的事件不一定與效能圖表中的峰值對齊。

.步驟
. 在 *事件時間軸* 窗格中，將游標停留在時間軸上的事件點上，即可檢視該事件點的事件總結。
+
彈出對話方塊顯示有關事件類型、事件發生的日期和時間、狀態以及事件持續時間的資訊。

. 檢視一個或多個事件的完整事件詳細資料：
