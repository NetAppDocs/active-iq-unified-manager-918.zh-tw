= 在 Active IQ Unified Manager 中將工作負載移至不同的彙總
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager 來協助識別比目前工作負載位於的彙總較不忙碌的彙總，然後將選定的 Volume 或 LUN 移至該彙總。將高效能工作負載移至較不忙碌的彙總，或是啟用 Flash 儲存設備的彙總，可讓工作負載更有效率地執行。

.開始之前
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。
* 您必須已記錄目前發生效能問題的彙總名稱。
* 您必須記錄彙總接收到事件的日期和時間。
* Unified Manager 必須收集並分析一個月或更長時間的效能資料。


這些步驟可協助您識別以下資源，以便您可以將高效能工作負載遷移到使用率較低的彙總：

* 同一叢集上使用率較低的彙總
* 目前彙總上最高效能的 Volume


.步驟
. 識別叢集中使用率最低的彙總：
+
.. 在「事件」詳細資料頁面中，按一下彙總所在的叢集名稱。
+
叢集詳細資料顯示在「效能/叢集登陸頁面」中。

.. 在 *摘要* 頁面上，從 *託管物件* 窗格中按一下 *彙總*。
+
顯示此叢集上的彙總清單。

.. 點選 *使用率* 欄，依使用率最低對彙總進行排序。
+
您也可以辨識出那些擁有最大*可用容量*的彙總。這將提供一個潛力彙總清單，您可以將工作負載遷移到這些彙總。

.. 寫下要將工作負載遷移到的彙總名稱。


. 從接收到事件的彙總中辨識出效能優異的 Volume：
+
.. 點選出現效能問題的彙總。
+
彙總詳細資料顯示在「效能/彙總分析」頁面中。

.. 從 *時間範圍* 選擇器中，選取 *最近 30 天*，然後按一下 *套用範圍*。
+
這可讓您檢視比預設 72 小時更長的效能歷史記錄。您想要移動一致佔用大量資源的 Volume，而不僅僅是過去 72 小時內。

.. 從 *檢視與比較* 控制中，選擇 *此彙總上的 Volume*。
+
顯示此彙總上的 FlexVol Volume 與 FlexGroup 組成 Volume 清單。

.. 依最高 MB/s 排序 Volume，然後依最高 IOPS 排序，以查看效能最高的 Volume。
.. 寫下要移至不同彙總的 Volume 的名稱。


. 將高效能 Volume 移至您識別為低使用率的彙總。
+
您可以使用 ONTAP System Manager、OnCommand Workflow Automation、ONTAP 命令或這些工具的組合來執行移動作業。



幾天後，檢查是否從該節點或彙總收到相同類型的事件。
