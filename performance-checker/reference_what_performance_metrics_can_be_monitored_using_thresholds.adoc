= 了解 Active IQ Unified Manager 中使用臨界值追蹤的效能計數器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
一些常用的效能計數器，例如 IOPS 和 MB/s，可以為所有儲存設備物件設定臨界值。其他計數器則只能為某些特定的儲存設備物件設定臨界值。



[[available-performance-counters]]
== 可用效能計數器

|===
| 儲存物件 | 效能計數器 | 說明 


 a| 
叢集
 a| 
IOPS
 a| 
叢集每秒處理的平均輸入/輸出作業數。



 a| 
MB/s
 a| 
每秒進出此叢集的平均資料 MB 數。



 a| 
節點
 a| 
IOPS
 a| 
節點每秒處理的平均輸入/輸出作業數。



 a| 
MB/s
 a| 
每秒進出此節點的平均資料傳輸量（MB）。



 a| 
延遲
 a| 
節點回應應用程式要求的平均毫秒數。



 a| 
使用率
 a| 
節點 CPU 和 RAM 的平均使用百分比。



 a| 
已使用的效能容量
 a| 
節點消耗的效能容量的平均百分比。



 a| 
已使用的效能容量 - 接管
 a| 
節點消耗的平均效能容量百分比，加上其合作夥伴節點的效能容量。



 a| 
彙總
 a| 
IOPS
 a| 
彙總每秒處理的平均輸入/輸出作業數。



 a| 
MB/s
 a| 
每秒與此彙總之間傳輸的資料平均 MB 數。



 a| 
延遲
 a| 
彙總回應應用程式要求的平均毫秒數。



 a| 
使用率
 a| 
彙總中正在使用的磁碟平均百分比。



 a| 
已使用的效能容量
 a| 
彙總消耗的效能容量的平均百分比。



 a| 
儲存 VM
 a| 
IOPS
 a| 
SVM 每秒處理的平均輸入/輸出作業數。



 a| 
MB/s
 a| 
每秒與此 SVM 之間傳輸的資料平均 MB 數。



 a| 
延遲
 a| 
SVM 回應應用程式請求的平均毫秒數。



 a| 
磁碟區
 a| 
IOPS
 a| 
Volume 每秒處理的平均輸入/輸出操作次數。



 a| 
MB/s
 a| 
每秒進出該 Volume 的平均資料傳輸量（MB）。



 a| 
延遲
 a| 
Volume 對應用程式請求的平均回應時間（毫秒）。



 a| 
快取未命中比率
 a| 
用戶端應用程式讀取請求從 Volume 返回而不是從快取返回的平均百分比。



 a| 
LUN
 a| 
IOPS
 a| 
LUN 每秒處理的平均輸入/輸出作業數。



 a| 
MB/s
 a| 
每秒傳輸至此 LUN 及從此 LUN 傳出的平均資料 MB 數。



 a| 
延遲
 a| 
LUN 回應應用程式請求的平均毫秒數。



 a| 
命名空間
 a| 
IOPS
 a| 
命名空間每秒處理的平均輸入/輸出作業數。



 a| 
MB/s
 a| 
每秒進出此命名空間的平均資料傳輸量（MB）。



 a| 
延遲
 a| 
命名空間回應應用程式請求的平均毫秒數。



 a| 
連接埠
 a| 
頻寬使用率
 a| 
連接埠可用頻寬的平均使用百分比。



 a| 
MB/s
 a| 
每秒透過此連接埠傳輸和接收的平均資料量（MB）。



 a| 
網路介面（LIF）
 a| 
MB/s
 a| 
每秒與此 LIF 之間傳輸的資料平均 MB 數。

|===
