= 在 Active IQ Unified Manager 中檢視 Volume 或 LUN 的 QoS 原則群組設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以檢視已套用至 Volume 和 LUN 的服務品質原則群組，也可以連結至 Performance/QoS Policy Groups 檢視，以顯示每個服務品質原則的詳細組態設定。

以下列出了檢視應用於 Volume 的 QoS 原則的步驟。檢視 LUN 的此資訊的步驟類似。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備* > *Volume*。
+
預設會顯示「健康狀況：所有 Volume」檢視。

. 在「檢視」功能表中，選擇 *效能：QoS 原則群組中的 Volume*。
. 找到要審查的 Volume，然後向右捲動，直到看到 *QoS 原則群組* 欄。
. 按一下 QoS 原則群組名稱。
+
根據它是傳統的 QoS 原則、具調適能力的 QoS 原則還是使用 Unified Manager 效能服務層級建立的 QoS 原則，將顯示對應的服務品質頁面。

. 檢視 QoS 原則群組的詳細組態設定。
. 按一下 QoS 原則群組名稱旁的擴充按鈕（image:../media/chevron_down.gif[""]），檢視有關該原則群組的更多詳細資訊。
