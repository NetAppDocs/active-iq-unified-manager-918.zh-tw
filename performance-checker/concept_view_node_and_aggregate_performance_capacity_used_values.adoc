= 在 Active IQ Unified Manager 中檢視節點和彙總效能容量使用值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以監控叢集中所有節點或所有彙總的效能容量使用值，也可以檢視單一節點或彙總的詳細資訊。

已使用的效能容量值會顯示在「儀表板」、「效能清單」頁面、「頂尖效能」頁面、「建立臨界值原則」頁面、「效能總管」頁面以及詳細圖表中。例如，「效能：所有彙總」頁面提供「已使用的效能容量」欄，用於檢視所有彙總的已使用效能容量值。

image::../media/node_inventory_used_headroom.gif[「效能：所有彙總」頁面的 UI 快照]

監控已使用的效能容量計數器可讓您識別下列項目：

* 任何叢集上的任何節點或彙總是否具有高效能容量使用值
* 任何叢集上的任何節點或彙總是否具有作用中的效能容量使用事件
* 叢集中已用效能容量值最高與最低的節點與彙總
* 延遲和使用率計數器值與具有高效能容量使用值的節點或彙總結合使用
* 如果其中一個節點發生故障，HA 配對中節點的效能容量使用率值將如何受到影響
* 具有高已用效能容量值的彙總上最繁忙的 Volume 和 LUN
