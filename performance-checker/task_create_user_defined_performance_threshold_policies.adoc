= 在 Active IQ Unified Manager 中建立使用者自訂的效能臨界值原則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以為儲存設備物件建立效能臨界值原則，以便在效能計數器超過特定值時傳送通知。事件通知會指出叢集發生效能問題。

.開始之前
您必須擁有應用程式管理員角色。

您可以透過在「建立效能臨界值原則」頁面上輸入臨界值來建立效能臨界值原則。您可以透過在此頁面中定義所有原則值來建立新原則，也可以製作現有原則的複本並變更複本中的值（稱為 _Clone_）。

有效的臨界值範圍為：數字 0.001 至 10,000,000，百分比 0.001 至 100，以及效能容量使用百分比 0.001 至 200。

[NOTE]
====
目前版本提供的臨界值會在計數器值超過臨界值設定時傳送事件。您無法設定在計數器值低於臨界值設定時傳送事件的臨界值。

====
.步驟
. 在左側導覽窗格中，選擇 *事件臨界值* > *效能*。
+
顯示「效能臨界值」頁面。

. 根據您是想建立新原則還是想 Clone 類似原則並修改複製版本，按一下適當的按鈕。
+
|===
| 若要…… | 按一下…… 


 a| 
建立新原則
 a| 
*建立*



 a| 
Clone 現有原則
 a| 
選擇現有原則，然後點選 *Clone*

|===
+
將顯示「建立效能臨界值原則」頁面或「Clone 效能臨界值原則」頁面。

. 透過指定要為特定儲存設備物件設定的效能計數器臨界值來定義臨界值原則：
+
.. 選擇儲存設備物件類型，並指定原則的名稱和執行摘要。
.. 選擇要追蹤的效能計數器，並指定定義警告和關鍵事件的限制值。
+
您必須至少定義一個警告限制或一個關鍵限制。您無需同時定義這兩種類型的限制。

.. 如果需要，請選擇次要效能計數器，並指定警告和關鍵事件的限制值。
+
包含次要計數器時，必須兩個計數器都超過限制值，才會違反臨界值並報告事件。只有特定的物件和計數器才能使用組合原則進行設定。

.. 選擇必須超過限制值的時間長度，才能傳送事件。


+
Clone 現有原則時，您必須為該原則輸入新名稱。

. 按一下 *儲存* 以儲存原則。
+
您將返回「效能臨界值」頁面。頁面頂部的成功訊息會確認已建立臨界值原則，並提供該物件類型之「清單」頁面的連結，以便您能立即將新原則套用至儲存設備物件。



如果此時要將新的臨界值原則套用至儲存設備物件，可以點選 *立即前往 object_type* 連結進入「庫存」頁面。
