= 分析 Active IQ Unified Manager 中使用者定義的效能閾值事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
由使用者定義的臨界值產生的事件指出，某個儲存設備物件（例如彙總或 Volume）的效能計數器已超過您在原則中定義的臨界值。這表示叢集物件發生效能問題。

您可以使用「事件詳情」頁面來分析效能事件，並在必要時採取修正行動，使效能恢復正常。
