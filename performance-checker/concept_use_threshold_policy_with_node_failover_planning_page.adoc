= 在 Active IQ Unified Manager 中為節點故障轉移規劃建立臨界值原則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以建立節點臨界值原則，以便在潛力的故障轉移將接管節點的效能降級到不可接受的層級時，在「效能/節點故障轉移規劃」頁面中收到通知。

系統定義名為 "`Node HA pair over-utilized`" 的效能臨界值原則會在連續六個收集週期（30 分鐘）內超出臨界值時產生警告事件。當 HA 配對中節點的總效能容量使用率超過 200% 時，即視為超出臨界值。

系統定義的臨界值原則觸發的事件會提醒您，容錯移轉會導致接管節點的延遲增加到無法接受的層級。當您看到由該原則針對特定節點產生的事件時，您可以導覽至該節點的「效能 / 節點容錯移轉規劃」頁面，檢視容錯移轉導致的預測延遲值。

除了使用此系統定義的臨界值原則外，您還可以使用 "`Performance Capacity Used - Takeover`" 計數器來建立臨界值原則，然後將該原則套用至選定的節點。指定低於 200% 的臨界值，可讓您在超過系統定義原則的臨界值之前收到事件。如果您希望在產生系統定義原則事件之前收到通知，也可以將超過臨界值的最短時間指定為少於 30 分鐘。

例如，您可以定義臨界值原則，當 HA 配對中節點的總效能容量使用率超過 175% 且持續超過 10 分鐘時，產生警告事件。您可以將此原則套用於組成 HA 配對的 Node1 和 Node2。收到 Node1 或 Node2 的警告事件通知後，您可以檢視該節點的「效能/節點容錯移轉規劃」頁面，以評估對接管節點的預估效能影響。如果確實發生容錯移轉，您可以採取修正行動，以避免接管節點過載。如果在節點的總效能容量使用率低於 200% 時採取行動，即使在此期間發生容錯移轉，接管節點的延遲也不會達到無法接受的層級。
