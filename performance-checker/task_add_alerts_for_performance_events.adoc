= 在 Active IQ Unified Manager 中新增效能事件警報
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以像設定 Unified Manager 接收的任何其他事件一樣，為個別效能事件設定警報。此外，如果您希望將所有效能事件一視同仁，並將電子郵件傳送給同一個人，您可以建立單一警報，以便在觸發任何關鍵或警告效能事件時通知您。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

以下範例顯示如何為所有關鍵延遲、IOPS 和 MBps 事件建立事件。您可以使用相同的方法從所有效能計數器中選擇事件，以及所有警告事件。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備管理* > *警示設定*。
. 在「警報設定」頁面中，按一下 *新增*。
. 在「新增警報」對話方塊中，按一下 *名稱*，然後輸入警報的名稱和執行摘要。
. 請勿在「資源」頁面上選擇任何資源。
+
由於未選取任何資源，因此警報會套用至收到這些事件的所有叢集、集合體、磁碟區等。

. 按一下 *事件* 並執行下列動作：
+
.. 在事件嚴重性清單中，選擇 *關鍵*。
.. 在「事件名稱包含」欄位中輸入 `*latency*`，然後按一下箭頭以選取所有符合的事件。
.. 在「事件名稱包含」欄位中輸入 `*iops*`，然後按一下箭頭選擇所有符合的事件。
.. 在「事件名稱包含」欄位中輸入 `*mbps*`，然後按一下箭頭以選取所有符合的事件。


. 按一下 *動作* ，然後在 *警示這些使用者* 欄位中選取將收到警示電子郵件的使用者名稱。
. 在此頁面上設定任何其他選項，以發出 SNMP tap 並執行指令碼。
. 按一下 *Save* 。
