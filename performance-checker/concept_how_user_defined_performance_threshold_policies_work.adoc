= 在 Active IQ Unified Manager 中使用使用者定義的效能臨界值原則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以為儲存設備物件（例如彙總和 Volume）設定效能臨界值原則，以便將事件傳送給儲存管理員，通知系統管理員叢集發生效能問題。

您可透過下列方式為儲存設備物件建立效能臨界值原則：

* 選擇儲存設備物件
* 選取與該物件相關聯的效能計數器
* 指定定義被視為警告和關鍵情況的效能計數器上限值
* 指定定義計數器必須超過上限多久的時間週期


例如，您可以在 Volume 上設定效能臨界值原則，以便在該 Volume 的 IOPS 連續 10 分鐘超過每秒 750 次作業時，收到關鍵事件通知。此相同的臨界值原則也可指定，當 IOPS 在 10 分鐘內超過每秒 500 次作業時傳送警告事件。

[NOTE]
====
目前版本提供的臨界值會在計數器值超過臨界值設定時傳送事件。您無法設定在計數器值低於臨界值設定時傳送事件的臨界值。

====
此處顯示計數器圖表範例，指出在 1:00 突破了警告臨界值（黃色圖示），並在 12:10、12:30 和 1:10 突破了關鍵臨界值（紅色圖示）：

image::../media/opm2_threshold_breach.gif[顯示範例計數器圖表的使用者介面快照。]
