= 使用 Active IQ Unified Manager 監控 MetroCluster 效能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 可讓您監控 MetroCluster 組態中叢集之間的寫入處理量，以識別具有大量寫入處理量的工作負載。

如果這些高效能工作負載導致本機叢集上的其他 Volume 出現較高的 I/O 回應時間，Unified Manager 會觸發效能事件來通知您。


NOTE: Unified Manager 將 MetroCluster 組態中的各個叢集視為獨立的叢集。它不會區分互為合作夥伴的叢集，也不會關聯各個叢集的寫入處理量。

當 MetroCluster 組態中的本機叢集將其資料鏡射到其合作夥伴叢集時，資料會寫入 NVRAM，然後透過交換器間連結（ISL）傳送到遠端彙總。Unified Manager 會分析 NVRAM，以識別高寫入處理量過度使用 NVRAM、導致 NVRAM 發生爭用的工作負載。

回應時間偏差超過效能臨界值的工作負載稱為 _受害者_，而寫入 NVRAM 處理量偏差高於正常水準並導致爭用的工作負載稱為 _霸凌者_。由於只有寫入要求會鏡射到合作夥伴叢集，因此 Unified Manager 不會分析讀取處理量。

您可以從下列畫面分析對應 LUN 與 Volume 的工作負載，以檢視 MetroCluster 組態中任何叢集的處理量。您可以依叢集篩選結果。從左側導覽窗格：

* *儲存設備 > 叢集 > 效能：所有叢集*檢視。請參閱
* *儲存設備 > Volume > 效能：所有 Volume* 檢視。
* *儲存設備 > LUN > 效能：所有 LUN* 檢視。
* *工作負載分析 > 所有工作負載*
