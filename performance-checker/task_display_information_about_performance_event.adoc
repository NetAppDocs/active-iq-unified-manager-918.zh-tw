= 在 Active IQ Unified Manager 中顯示有關效能事件的資訊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用「事件管理」清單頁面檢視 Unified Manager 監控的叢集上所有效能事件的清單。透過檢視此資訊，您可以判斷最關鍵的事件，然後深入檢視詳細資訊以判斷事件的原因。

.開始之前
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。


事件清單依偵測時間排序，最新事件顯示在最前面。您可以點選欄標題，根據該欄對事件進行排序。例如，您可以依「狀態」欄排序，依嚴重程度檢視事件。如果您正在尋找特定事件或特定類型的事件，可以使用篩選和搜尋機制來縮小顯示在清單中的事件範圍。

所有來源的事件都顯示在此頁面上：

* 使用者自訂效能臨界值原則
* 系統定義的效能臨界值原則
* 動態效能臨界值


「事件類型」欄會列出事件的來源。您可以選取事件，在「事件詳細資料」頁面中檢視事件的詳細資料。

.步驟
. 在左側導覽窗格中，按一下 *事件管理*。
. 從「檢視」功能表中，選取 *作用中效能事件*。
+
此頁面顯示過去 7 天內產生的所有新的和已確認的效能事件。

. 找到您想要分析的事件，然後按一下事件名稱。
+
隨即顯示事件的詳細資料頁面。

+
[NOTE]
====
您也可以透過點擊 Performance Explorer 頁面和警示電子郵件中的事件名稱連結，來顯示事件的詳細資訊頁面。
