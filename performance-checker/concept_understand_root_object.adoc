= 在 Active IQ Unified Manager 中使用根目錄物件進行效能監控
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
根目錄物件是其他物件進行比較的基準。這可讓您檢視其他物件的資料並與根目錄物件進行比較，提供效能資料分析，協助您進行疑難排解並改善物件效能。

根目錄物件名稱顯示在「比較」窗格頂部。其他物件顯示在根目錄物件下方。雖然您可以為「比較」窗格新增的其他物件數量沒有限制，但只允許新增一個根目錄物件。根目錄物件的資料會自動顯示在「計數器圖表」窗格的圖表中。

您無法變更根目錄物件；它始終設定為您正在檢視的物件頁面。例如，如果您開啟 Volume1 的「Volume 效能總管」頁面，則 Volume1 就是根目錄物件，無法變更。如果您想與其他根目錄物件進行比較，則必須按一下物件的連結並開啟其活動網頁。

[NOTE]
====
事件和臨界值僅針對根目錄物件顯示。
