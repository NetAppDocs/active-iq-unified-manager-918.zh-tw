[NOTE]
====
當 Volume 組合原則套用於 FlexGroup Volume（而非 FlexVol Volume）時，只能選擇 "`Volume IOPS`" 和 "`Volume MB/s`" 屬性作為次要計數器。如果臨界值原則包含節點或彙總屬性，則該原則不會套用於 FlexGroup Volume，而且您會收到描述此情況的錯誤訊息。這是因為 FlexGroup Volume 可以存在於多個節點或彙總上。
