= 透過在 Active IQ Unified Manager 中啟用節點上的 Flash Cache 來提高工作負載效能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以透過在叢集中的每個節點上啟用 Flash Cache™ 至能資料快取來提高工作負載效能。

Flash Cache 模組（或效能加速模組，一種基於 PCIe 的記憶體容量模組）透過充當至能外部讀取快取來最佳化隨機讀取密集型工作負載的效能。此硬體與 ONTAP 的 WAFL 外部快取軟體元件協同運作。

在 Unified Manager 的「事件詳細資料」頁面上，代表爭用彙總的叢集元件圖示會以紅色反白顯示。圖示下方括號內是彙總的名稱，用於識別該彙總。您可以在彙總所在的節點上啟用 Flash Cache。

您可以使用 ONTAP System Manager 或 ONTAP 命令來查看 Flash Cache 是否已安裝或啟用，如果尚未啟用，則可以將其啟用。下列命令會指出特定節點上是否已啟用 Flash Cache： `*cluster::> run local options flexscale.enable*`

如需 Flash Cache 及其使用需求的詳細資訊，請參閱下列技術報告：
