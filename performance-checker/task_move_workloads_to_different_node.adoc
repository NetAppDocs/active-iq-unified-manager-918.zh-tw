= 在 Active IQ Unified Manager 中將工作負載移至不同的節點
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager 來協助識別位於其他節點上、負載低於目前工作負載執行節點的彙總，然後將選定的 Volume 移至該彙總。將高效能工作負載移至負載較低節點上的彙總，可讓兩個節點上的工作負載運作更有效率。

.開始之前
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。
* 您必須已記錄目前發生效能問題的節點名稱。
* 您必須記錄節點接收到效能事件的日期和時間。
* Unified Manager 必須收集並分析一個月或更長時間的效能資料。


此流程可協助您識別下列資源，以便將高效能工作負載遷移到使用率較低的節點：

* 在同一叢集中具有最大可用效能容量的節點
* 新節點上具有最大可用效能容量的彙總
* 目前節點上效能最高的 Volume


.步驟
. 找出叢集中剩餘效能容量最大的節點：
+
.. 在 *事件詳情* 頁面上，按一下節點所位於的叢集名稱。
+
叢集詳細資料顯示在「效能/叢集登陸頁面」中。

.. 在 *摘要* 標籤上，從 *託管物件* 窗格中按一下 *節點*。
+
顯示此叢集上的節點清單。

.. 點選 *效能容量使用情況* 欄，依使用率最低對節點進行排序。
+
這提供了一份潛力節點清單，您可能會想將工作負載移至這些節點。

.. 記下要將工作負載遷移到的節點名稱。


. 識別新節點上使用率最低的彙總：
+
.. 在左側導覽窗格中，按一下 *儲存設備* > *彙總*，然後從「檢視」功能表中選擇 *效能* > *所有彙總*。
+
顯示「效能：所有彙總」檢視。

.. 按一下 *篩選*，從左側下拉選單中選取 *節點*，在文字欄位中輸入節點名稱，然後按一下 *套用篩選*。
+
效能：所有彙總檢視重新顯示，其中列出了此節點上可用的彙總。

.. 點選 *已使用效能容量* 欄，依使用率最低對彙總進行排序。
+
這提供了一份潛力彙總清單，您可能想要將工作負載移至其中。

.. 寫下要將工作負載遷移到的彙總名稱。


. 識別接收到事件的節點上的高效能工作負載：
+
.. 返回該事件的*事件詳細資料*頁面。
.. 在 *受影響的 Volume* 欄位中，按一下 Volume 數量的連結。
+
「效能：所有 Volume」檢視顯示該節點上所有 Volume 的篩選清單。

.. 點選 *總容量* 欄，依最大分配空間對 Volume 進行排序。
+
這提供了您可能想要移動的潛力 Volume 清單。

.. 寫下您要移動的 Volume 名稱，以及它們所位於的目前彙總名稱。


. 將 Volume 移至您在新節點上識別為具有最大可用效能容量的彙總。
+
您可以使用 ONTAP System Manager、OnCommand Workflow Automation、ONTAP 命令或這些工具的組合來執行移動作業。



幾天後，您可以檢查是否從此節點或彙總收到相同類型的事件。
