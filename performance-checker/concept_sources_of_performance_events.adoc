= 辨識 Active IQ Unified Manager 中的效能事件來源
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
效能事件是指與叢集工作負載效能相關的問題。它們可以幫助您識別回應時間緩慢（也稱為高延遲）的儲存設備物件。結合同時發生的其他健全狀況事件，您可以確定可能導致或加劇回應時間緩慢的問題。

Unified Manager 從下列來源接收效能事件：

* *使用者自訂效能臨界值原則事件*
+
基於您設定的自訂臨界值的效能問題。您可以為儲存設備物件（例如彙總和 Volume）設定效能臨界值原則，以便在違反效能計數器的臨界值時產生事件。

+
您必須定義效能臨界值原則並將其指派給儲存設備物件以接收這些事件。

* *系統定義效能臨界值原則事件*
+
基於系統定義的臨界值的效能問題。這些臨界值原則包含在 Unified Manager 的安裝中，用於解決常見的效能問題。

+
這些臨界值原則預設為啟用，新增叢集後不久您可能會看到相關事件。

* *動態效能臨界值事件*
+
效能問題可能是由於 IT 基礎架構故障或錯誤，或是工作負載過度佔用叢集資源所造成的。這些事件的起因可能很簡單，過一段時間後即可自行解決，或者可以透過修理或組態變更來解決。動態臨界值事件表明，由於其他工作負載大量使用共享的叢集元件，導致 ONTAP 系統上的工作負載運作緩慢。

+
這些臨界值預設為啟用，從新叢集收集資料三天後，您可能會看到事件。
