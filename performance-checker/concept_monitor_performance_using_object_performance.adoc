= 使用 Active IQ Unified Manager 中的效能清單頁面監控物件效能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
物件清單效能頁面顯示物件類型類別中所有物件的效能資訊、效能事件和物件健全狀況。這可讓您快速總覽叢集中每個物件的效能狀態，例如所有節點或所有 Volume 的效能狀態。

物件清單效能頁面提供物件狀態的高階總覽，使您能夠評估所有物件的整體效能並比較物件效能資料。您可以透過搜尋、排序和篩選來精簡物件清單頁面的內容。這在監控和管理物件效能時非常有用，因為它使您能夠快速找出有效能問題的物件，並開始疑難排解程序。

image::../media/perf_node_inventory.gif[顯示「效能/所有節點」清單頁面中物件詳細資訊的 UI 快照。]

預設情況下，效能清單頁面上的物件會根據物件效能嚴重程度進行排序。出現新的關鍵效能事件的物件會優先列出，出現警告事件的物件則列在其次。這能立即以視覺方式指出必須解決的問題。所有效能資料均基於 72 小時平均值。

您可以點選物件名稱欄中的物件名稱，輕鬆地從物件清單效能頁面導覽至物件詳細資料頁面。例如，在「效能 / 所有節點」清單頁面上，您可以點擊 *Nodes* 欄中的節點物件。物件詳細資料頁面提供有關所選物件的深入資訊與詳細資料，包括並排比較作用中事件。
