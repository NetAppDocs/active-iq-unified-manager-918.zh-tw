= 檢閱 Active IQ Unified Manager 中的「效能/節點容錯移轉規劃」頁面元件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「效能/節點容錯移轉規劃」頁面的元件會顯示在網格與「比較」窗格中。這些區段可讓您評估節點容錯移轉對接管節點效能的影響。



[[performance-statistics-grid]]
== 效能統計資料網格

效能 / 節點容錯移轉規劃頁面顯示一個網格，其中包含延遲、IOPS、使用率和已使用效能容量的統計資料。

[NOTE]
====
此頁面和效能 / 節點效能瀏覽器頁面中顯示的延遲和 IOPS 值可能不相符，因為用於計算預測節點容錯移轉之值的效能計數器不同。

====
在網格中，每個節點都被指派以下角色之一：

* 主要
+
在 HA 合作夥伴發生故障時接管合作夥伴的節點。根目錄物件始終是主要節點。

* 合作夥伴
+
容錯移轉情境中發生故障的節點。

* 預計接管
+
與主節點相同。此節點顯示的效能統計資料，顯示接管節點在接管故障的合作夥伴後的效能。



[NOTE]
====
雖然在容錯移轉之後，接管節點的工作負載等於兩個節點工作負載的總和，但「預估接管節點」的統計資料並非主要節點和合作夥伴節點統計資料的總和。例如，如果主要節點的延遲為 2 ms/op，而合作夥伴節點的延遲為 3 ms/op，則「預估接管節點」的延遲可能為 4 ms/op。此值是由 Unified Manager 計算得出。

====
如果您希望將合作夥伴節點設為根目錄物件，可以點選該節點的名稱。在顯示「效能 / 節點效能資源管理器」頁面後，您可以按一下 *故障轉移規劃* 標籤，查看在此節點故障情境下效能的變化。例如，如果 Node1 是主節點，Node2 是合作夥伴節點，您可以按一下 Node2 將其設為主節點。這樣，您就可以看到根據哪個節點發生故障，預估效能如何變化。

== 比較窗格

以下清單說明「比較」窗格中預設顯示的元件：

* *事件圖表*
+
它們以與「效能 / 節點效能瀏覽器」頁面中相同的格式顯示。它們僅與主要節點相關。

* *計數器圖表*
+
它們顯示網格中所示效能計數器的歷史統計資料。在每個圖表中，「預估接管」節點的圖表顯示在任何給定時間發生容錯移轉時的預估效能。

+
例如，假設使用率圖表顯示，2 月 8 日上午 11 點，預估接管節點的使用率為 73%。如果當時發生容錯移轉，接管節點的使用率將為 73%。

+
歷史統計資料可協助您找到啟動容錯移轉的最佳時機，將接管節點過載的可能性降至最低。您只能在接管節點的預期效能可接受時，排程容錯移轉。



預設情況下，「比較」窗格中會顯示根目錄物件和合作夥伴節點的統計資料。與「效能 / 節點效能總管」頁面不同，此頁面不顯示 * 新增 * 按鈕供您新增物件以進行統計資料比較。

您可以像在「效能 / 節點效能總管」頁面中一樣，自訂「比較」窗格。下列清單顯示自訂圖表的範例：

* 按一下節點名稱，即可在計數器圖表中顯示或隱藏該節點的統計資料。
* 點選 *縮放檢視* 可在新視窗中顯示特定計數器的詳細圖表。
