= 在 Active IQ Unified Manager 中搜尋儲存設備物件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要快速存取特定物件，您可以使用功能表列頂部的 *搜尋所有儲存設備物件* 欄位。這種跨所有物件的全域搜尋方法可讓您依類型快速尋找特定物件。搜尋結果會依儲存設備物件類型排序，您可以使用下拉式選單進行篩選。有效的搜尋必須至少包含三個字元。

全域搜尋會顯示結果總數，但只有前 25 個搜尋結果可供存取。因此，如果您知道想要快速尋找的項目，可以將全域搜尋功能視為發現特定項目的捷徑工具。若要取得完整的搜尋結果，您可以使用物件清單頁面中的搜尋及其相關的篩選功能。

您可以按一下下拉式方塊並選擇 *全部* ，以同時搜尋所有物件和事件。或者，您可以按一下下拉式方塊來指定物件類型。在 *搜尋所有儲存設備物件* 欄位中輸入物件或事件名稱的至少三個字元，然後按下 *Enter* 以顯示搜尋結果，例如：

* 叢集：叢集名稱
* 節點：節點名稱
* 彙總：彙總名稱
* SVMs：SVM 名稱
* Volume：Volume 名稱
* LUNs：LUN 路徑


image::../media/opm_search_field_jpg.gif[Unified Manager 中的搜尋欄位]

[NOTE]
====
LIF 和連接埠無法在全域搜尋欄中搜尋。

====
在此範例中，下拉方塊已選取 Volume 物件類型。在「搜尋所有儲存設備物件」欄位中輸入「`vol`」，將顯示名稱包含這些字元的所有 Volume 清單。對於物件搜尋，您可以按一下任何搜尋結果，以導覽至該物件的 Performance Explorer 頁面。對於事件搜尋，按一下搜尋結果中的項目將導覽至「事件詳細資料」頁面。
