= 將 Active IQ Unified Manager 效能資料傳送至外部伺服器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 會從它監控的所有叢集中收集各種效能資料。您可以將特定的資料群組傳送到外部伺服器。

根據您想要繪製成圖表的效能資料，您可以選擇傳送下列統計資料群組之一：

|===
| 統計資料群組 | 包含的資料 | 詳細資料 


 a| 
效能監視器
 a| 
以下物件的高階效能統計資料：

* LUN
* 磁碟區

 a| 
此群組提供所有受監控叢集中所有 LUN 和 Volume 的總 IOPS 或延遲。

該組提供的統計資料數量最少。



 a| 
資源使用率
 a| 
以下物件的資源使用率統計資料：

* 節點
* Aggregate

 a| 
此群組提供所有受監控叢集中節點與彙總實體資源的使用率統計資料。

它還提供在效能監視器群組中收集的統計資料。



 a| 
向下鑽取
 a| 
所有追蹤物件的低階讀寫與各協定統計資料：

* 節點
* Aggregate
* LUN
* 磁碟區
* 磁碟
* LIF
* 連接埠/網路卡

 a| 
此群組提供所有受監控叢集中所有七種追蹤物件類型的讀寫與依協定細分。

它還提供在效能監控群組和資源使用率群組中收集的統計資料。

此群組提供的統計資料數量最多。

|===
[NOTE]
====
如果在儲存系統上變更了叢集或叢集物件的名稱，則新舊物件都會在外部伺服器（稱為「`metric_path`」）上包含效能資料。這兩個物件並未關聯為同一個物件。例如，如果您將 Volume 的名稱從「`volume1_acct`」變更為「`acct_vol1`」，您將看到舊 Volume 的舊效能資料和新 Volume 的新效能資料。

====
