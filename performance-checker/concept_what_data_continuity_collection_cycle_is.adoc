= 了解 Active IQ Unified Manager 中的資料連續性收集週期
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
資料連續性收集週期會擷取即時叢集效能收集週期（預設每五分鐘執行一次）以外的效能資料。資料連續性收集可讓 Unified Manager 填補因無法收集即時資料而發生的統計資料缺漏。

當發生下列事件時，Unified Manager 會執行歷史效能資料的資料連續性收集輪詢：

* 首先將叢集新增至 Unified Manager。
+
Unified Manager 會收集過去 15 天的歷史效能資料。這可讓您在新增叢集幾個小時後，檢視該叢集兩週的歷史效能資訊。

+
此外，如果存在系統定義的臨界值事件，則會報告上一期間的此類事件。

* 目前的效能資料收集週期未能準時完成。
+
如果即時效能輪詢超出五分鐘的收集週期，則會啟動資料連續性收集週期來收集遺失的資訊。如果沒有進行資料連續性收集，則會跳過下一個收集週期。

* Unified Manager 有一段時間無法存取，然後又恢復線上，例如以下情況：
+
** 它已重新啟動。
** 它在軟體升級或建立備份檔案時關閉。
** 網路停電已修復。


* 叢集在一段時間內無法存取，然後恢復線上，例如以下情況：
+
** 網路停電已修復。
** 廣域網路連線緩慢，導致效能資料的正常收集延遲。




資料連續性收集週期最多可收集 24 小時的歷史資料。如果 Unified Manager 中斷超過 24 小時，使用者介面頁面中會出現效能資料缺失。

資料連續性收集週期和即時資料收集週期不能同時運作。必須先完成資料連續性收集週期，才能啟動即時效能資料收集。當資料連續性收集需要收集超過一小時的歷史資料時，您會在「通知」窗格頂部看到該叢集的橫幅訊息。
