= 在 Active IQ Unified Manager 中回應使用者定義的效能臨界值事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager 來調查由效能計數器超過使用者定義的警告或關鍵臨界值所導致的效能事件。您也可以使用 Unified Manager 來檢查叢集元件的健全狀況，以查看最近在該元件上偵測到的健全狀況事件是否導致了該效能事件。

.開始之前
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。
* 必須存在新的或已過時的效能事件。


.步驟
. 顯示 *事件詳細資料* 頁面以檢視事件的資訊。
. 請檢閱 *描述* ，其中說明導致事件的臨界值違規。
+
例如，訊息 "`延遲值為 456 ms/op 已根據 400 ms/op 的臨界值設定觸發警告事件`" 表示該物件發生了延遲警告事件。

. 將滑鼠懸停在原則名稱上，即可顯示觸發該事件的臨界值原則的詳細資訊。
+
這包括原則名稱、正在評估的效能計數器、必須突破才能被視為關鍵或警告事件的計數器值，以及計數器必須超過該值的持續時間。

. 請附註*事件觸發時間*，以便調查是否同時發生了其他事件，這些事件可能導致了該事件的發生。
. 請按照以下選項之一進一步調查此事件，以確定是否需要採取任何措施來解決效能問題：
+
|===
| 選項 | 可能的調查行動 


 a| 
按一下來源物件名稱以顯示該物件的 Explorer 頁面。
 a| 
此頁面可讓您檢視物件詳細資料，並將此物件與其他類似的儲存設備物件進行比較，以查看其他儲存設備物件是否在同一時間段內出現效能問題。例如，查看同一彙總上的其他 Volume 是否也存在效能問題。



 a| 
按一下叢集名稱以顯示叢集摘要頁面。
 a| 
此頁面可讓您檢視此物件所在叢集的詳細資料，以查看是否在同一時間發生了其他效能問題。

|===
