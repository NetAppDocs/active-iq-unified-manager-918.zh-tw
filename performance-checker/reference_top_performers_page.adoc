= 在 Active IQ Unified Manager 中檢視「表現最佳者」頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「效能最佳」頁面會根據您選擇的效能計數器，顯示效能最高或最低的儲存設備物件。例如，在「Storage VM」類別中，您可以顯示 IOPS 最高、延遲最高或 MB/s 最低的 SVM。此頁面也會顯示任何效能最佳的項目是否有任何作用中的效能事件（新增或已確認）。

「表現最佳者」頁面最多顯示每種物件的 10 個。請注意， Volume 物件包含 FlexVol Volume 和 FlexGroup Volume。

* *時間範圍*
+
您可以選擇一個時間範圍來檢視表現最佳者；所選時間範圍適用於所有儲存設備物件。可用時間範圍：

+
** 過去一小時
** 最近 24 小時
** 過去 72 小時（預設）
** 過去 7 天


* *指標*
+
點選 *指標* 選單以選擇不同的計數器。計數器選項因物件類型而異。例如，*Volume* 物件可用的計數器為 *延遲*、*IOPS* 和 *MB/s*。變更計數器會根據所選計數器，以最高效能者重新載入面板資料。

+
可用計數器：

+
** 延遲
** IOPS
** MB/s
** 已用效能容量（針對節點和彙總）
** 使用率（針對節點和彙總）


* *排序*
+
點選 *排序* 選單，選擇對所選物件和計數器進行遞增或遞減排序。選項包括 *從高到低* 和 *從低到高* 。這些選項可讓您檢視效能最高或效能最低的物件。

* *計數器列*
+
圖表中的計數器長條會顯示每個物件的效能統計資料，以該項目的長條表示。長條圖採用顏色編碼。如果計數器未違反效能臨界值，則計數器長條會顯示為藍色。如果臨界值違規為作用中（新事件或已確認的事件），則長條會顯示為該事件的顏色：警告事件顯示為黃色（image:../media/treemapstatus_warning_png.gif["TreeMap 圖示 – 警告狀態"]），關鍵事件顯示為紅色（image:../media/treemapred_png.gif["TreeMap 圖示 – 紅色"]）。臨界值違規會進一步由警告和關鍵事件的嚴重性事件指示器圖示來指出。

+
image::../media/top_10_example.gif[一張 UI 快照，顯示圖表中以計數條表示的每個物件的效能統計資料。]

+
對於每個圖表，X 軸顯示所選物件類型的最佳表現者。Y 軸顯示適用於所選計數器的單位。按一下每個垂直長條圖元素下方的物件名稱連結，即可導覽至所選物件的效能登陸頁面。

* *嚴重事件指示器*
+
在表現最佳圖表中，對於作用中的關鍵（image:../media/sev_critical_um60.png["事件嚴重程度圖示 – 關鍵"]）或警告（image:../media/sev_warning_um60.png["事件嚴重性圖示 – 警告"]）事件，物件名稱左側會顯示 *嚴重事件* 指示器圖示。按一下 *嚴重事件* 指示器圖示以檢視：

+
** *一項事件*
+
導覽至該事件的事件詳細資料頁面。

** *兩個或多個事件*
+
導覽至事件清單頁面，該頁面已篩選以顯示所選物件的所有事件。



* *匯出按鈕*
+
建立一個 `.csv`檔案，其中包含計數器列中顯示的資料。您可以選擇為目前檢視的單一叢集建立檔案，也可以為資料中心內的所有叢集建立檔案。
