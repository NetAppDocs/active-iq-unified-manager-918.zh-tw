= 了解 Active IQ Unified Manager 中的計數器圖表
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「計數器圖表」窗格中的圖表可讓您檢視和比較根目錄物件以及您從關聯物件網格中新增的物件的效能資料。這有助於您了解效能趨勢，並隔離和解決效能問題。

預設顯示的計數器圖表為事件、延遲、IOPS 和 MBps。您可以選擇顯示的選用圖表包括使用率、已使用效能容量、可用 IOPS、IOPS/TB 和快取未命中比率。此外，您可以選擇檢視延遲、IOPS、MBps 和已使用效能容量圖表的總值或細分值。

Performance Explorer 預設會顯示某些計數器圖表，無論儲存設備物件是否全部支援。當不支援某個計數器時，計數器圖表會是空白的，並顯示訊息 `Not applicable for <object>`。

圖表顯示根目錄物件以及您在「比較」窗格中選擇的所有物件的效能趨勢。每個圖表中的資料排列方式如下：

* *X 軸*
+
顯示指定的時間期間。如果您尚未指定時間範圍，預設值為前 72 小時期間。

* *Y 軸*
+
顯示所選物件或多個物件特有的計數器單位。



趨勢線顏色與「比較」窗格中顯示的物件名稱顏色一致。您可以將游標移至任何趨勢線上的某個點，以檢視該點的時間和數值詳細資料。

如果要分析圖表中的特定時間段，可以使用下列方法之一：

* 使用 *<* 按鈕將計數器圖表窗格擴充到頁面寬度。
* 使用游標（當其變成放大鏡時）選取圖表中時間範圍的一部分，以聚焦並放大該區域。您可以按一下「重設圖表縮放」，將圖表還原為預設的時間範圍。
* 使用 *縮放檢視* 按鈕顯示包含擴充的詳細資料和臨界值指標的大型單一計數器圖表。


[NOTE]
====
趨勢線偶爾會出現缺口。缺口意味著 Unified Manager 未能從儲存系統收集效能資料，或者 Unified Manager 可能已停止運作。
