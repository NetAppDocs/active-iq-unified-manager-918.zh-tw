= 檢閱 Active IQ Unified Manager 中的「效能資源管理器」頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Performance Explorer 頁面可讓您比較叢集中類似物件的效能，例如叢集中的所有 Volume。這有助於疑難排解效能事件並微調物件效能。您也可以將物件與根目錄物件進行比較，根目錄物件是其他物件進行比較的基準。

您可以點擊 *切換至健全狀況檢視* 按鈕，顯示此物件的健全狀況詳細資料頁面。在某些情況下，您可以了解有關此物件的儲存組態設定的重要資訊，這可能有助於疑難排解問題。

Performance Explorer 頁面會顯示叢集物件及其效能資料的清單。此頁面以表格格式顯示所有相同類型的叢集物件（例如，Volume 及其物件專屬的效能統計資料）。此檢視提供叢集物件效能的高效總覽。

[NOTE]
====
如果表格中的任何儲存格中出現 "`N/A`"，則表示無法取得該計數器的值，因為此時該物件上沒有 I/O。

====
效能資源管理器頁面包含下列元件：

* *時間範圍*
+
允許您選擇物件資料的時間範圍。

+
您可以選擇預先定義的時間範圍，也可以指定您自己的自訂時間範圍。

* *檢視與比較*
+
可讓您選擇要在網格中顯示的關聯物件類型。

+
可用選項取決於根目錄物件類型及其可用資料。您可以點選「檢視和比較」下拉清單選擇物件類型。您選擇的物件類型將顯示在清單中。

* *過濾*
+
您可以依照自己的喜好，縮小接收資料量的範圍。

+
您可以建立套用於物件資料的篩選器，例如 IOPS 大於 4。您最多可以同時新增四個篩選器。

* *比較*
+
顯示您選擇與根目錄物件進行比較的物件清單。

+
比較窗格中物件的資料將顯示在計數器圖表中。

* *檢視統計資料於*
+
對於 Volume 和 LUN，可讓您選擇統計資料是在每個收集週期（預設 5 分鐘）後顯示，還是將統計資料顯示為每小時平均值。此功能可讓您檢視延遲圖表，以支援 NetApp 「效能保證」方案。

* *計數器圖表*
+
顯示每個物件效能類別的圖表資料。

+
通常情況下，預設只顯示三到四個圖表。「選擇圖表」元件可讓您顯示更多圖表或隱藏特定圖表。您也可以選擇顯示或隱藏事件時間軸。

* *事件時間軸*
+
顯示在「時間範圍」元件中選擇的時間範圍內發生的效能和健全狀況事件。
