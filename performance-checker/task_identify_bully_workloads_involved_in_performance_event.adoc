= 在 Active IQ Unified Manager 中識別動態效能事件中的惡霸工作負載
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 Unified Manager 中，您可以辨識出哪些工作負載在爭用叢集元件的使用率上偏差最大。識別這些工作負載有助於您了解叢集上某些 Volume 回應時間（延遲）緩慢的原因。

.開始之前
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。
* 必須有新的、已確認的或過時的動態效能事件。


「事件詳情」頁面顯示使用者定義和系統定義的工作負載列表，並依元件使用率最高或受事件影響最大程度進行排序。這些值是根據 Unified Manager 在偵測到並上次分析該事件時識別出的峰值。

.步驟
. 顯示事件詳細資料頁面以檢視有關事件的資訊。
. 在工作負載延遲和工作負載活動圖表中，選擇 *高負載工作負載*。
. 將游標停留在圖表上，即可檢視影響該元件的前幾名使用者定義惡意工作負載。
