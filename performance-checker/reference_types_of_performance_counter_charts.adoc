= 了解 Active IQ Unified Manager 中的各種效能計數器圖表類型
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
標準效能圖表會顯示所選儲存設備物件的計數器值。每個細分計數器圖表都會顯示總值，並將其分為讀取、寫入和其他類別。此外，某些細分計數器圖表在以縮放檢視顯示時，會顯示更多詳細資訊。

下表顯示可用的效能計數器圖表。

|===
| 可用圖表 | 圖表執行摘要 


 a| 
事件
 a| 
顯示與根目錄物件統計圖表相關的關鍵、錯誤、警告和資訊事件。除了效能事件外，也會顯示健全狀況事件，以便全面了解效能可能受到影響的原因。



 a| 
延遲 - 總計
 a| 
回應應用程式要求所需的毫秒數。請注意，平均延遲值是以 I/O 加權的。



 a| 
延遲 - 細目
 a| 
此圖表顯示的資訊與「總延遲」圖表相同，但效能資料分為讀取、寫入和其他延遲。此圖表選項僅適用於所選物件為 SVM、節點、彙總、Volume、LUN 或命名空間的情況。



 a| 
延遲 - 叢集元件
 a| 
顯示的資訊與「總延遲」相同，但效能資料會依叢集元件細分為延遲。此圖表選項僅在所選物件為 Volume 時適用。



 a| 
IOPS - 總計
 a| 
每秒處理的輸入 / 輸出作業次數。針對節點顯示時，選取 "`Total`" 會顯示流經此節點（可能位於本機或遠端節點）之資料的 IOPS，選取 "`Total (Local)`" 則會顯示僅位於目前節點之資料的 IOPS。



 a| 
IOPS - 細目
 a| 
此圖表顯示的資訊與「IOPS 總和」圖表相同，但效能資料分為讀取、寫入和其他 IOPS。此圖表選項僅適用於所選物件為 SVM、節點、彙總、Volume、LUN 或命名空間的情況。

在縮放檢視中顯示時，Volume 圖表會顯示 QoS 最小和最大處理量值（如果在 ONTAP 中設定）。

當針對節點顯示時，選擇 "`Breakdown`" 會顯示流經此節點之資料（可能位於本機或遠端節點）的 IOPS 細分，而選擇 "`Breakdown (Local)`" 則會顯示僅位於目前節點之資料的 IOPS 細分。



 a| 
IOPS - 協定
 a| 
顯示的資訊與 IOPS 總和相同，但效能資料會分別以圖表形式呈現，涵蓋 CIFS、NFS、FCP、NVMe 和 iSCSI 協定流量。此圖表選項僅在選取物件為 SVM 時適用。



 a| 
IOPS/TB - 總計
 a| 
根據工作負載所消耗的總空間（以 TB 為單位）所處理的每秒輸入 / 輸出作業次數。此計數器也稱為 I/O 密度，用於衡量特定儲存容量所能提供的效能。在縮放檢視中顯示時，Volume 圖表會顯示預期的 QoS 和峰值處理量值（如果在 ONTAP 中設定）。

此圖表選項僅適用於所選物件為 Volume 的情況。



 a| 
MB/s - 總計
 a| 
每秒傳輸至物件及從物件傳出的資料百萬位元組數。



 a| 
MB/s - 細目
 a| 
與 MB/s 圖表顯示的資訊相同，但處理量資料分為磁碟讀取、Flash Cache 讀取、寫入及其他。以縮放檢視顯示時，如果在 ONTAP 中有設定，Volume 圖表會顯示 QoS 最大處理量值。

此圖表選項僅適用於所選物件為 SVM、節點、彙總、Volume、LUN 或命名空間的情況。

[NOTE]
====
Flash Cache 資料僅針對節點顯示，而且只有在節點中安裝了 Flash Cache 模組時才會顯示。

====


 a| 
已用效能容量 - 總計
 a| 
節點或彙總所消耗的效能容量百分比。



 a| 
已使用的效能容量 - 細目
 a| 
已使用的效能容量資料分為使用者協定和系統背景程序。此外，也會顯示可用效能容量。



 a| 
可用 IOPS - 總計
 a| 
此物件目前可用（閒置）的每秒輸入 / 輸出作業次數。此數值是從 Unified Manager 計算出該物件可執行的總 IOPS 中，減去目前已使用的 IOPS 所得出的結果。此圖表選項僅適用於所選物件為節點或彙總的情況。



 a| 
使用率 - 總計
 a| 
使用中物件的可用資源百分比。使用率表示節點的節點使用率、彙總的磁碟使用率，以及連接埠的頻寬利用率。此圖表選項僅適用於選取的物件為節點、彙總或連接埠時。



 a| 
快取未命中率 - 總計
 a| 
在用戶端應用程式的讀取請求中，從磁碟而非快取返回資料的百分比。此圖表選項僅在所選物件為 Volume 時適用。

|===
