= 在 Active IQ Unified Manager 中分析系統定義的效能閾值事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
從系統定義的效能臨界值所產生的事件指出，特定儲存設備物件的效能計數器或一組效能計數器已跨越系統定義原則的臨界值。這表示該儲存設備物件（例如彙總或節點）發生效能問題。

您可以使用「事件詳情」頁面來分析效能事件，並在必要時採取修正行動，使效能恢復正常。

[NOTE]
====
Cloud Volumes ONTAP、ONTAP Edge 或 ONTAP Select 系統未啟用系統定義的臨界值原則。

====
