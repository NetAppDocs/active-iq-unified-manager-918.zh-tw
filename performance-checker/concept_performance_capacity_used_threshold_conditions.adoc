= 在 Active IQ Unified Manager 中設定已使用效能容量臨界值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以建立使用者定義的效能臨界值原則，以便在節點或彙總的效能容量使用值超過定義的效能容量使用臨界值設定時觸發事件。

此外，節點還可以設定「效能容量使用率接管」臨界值原則。此臨界值原則會加總 HA 配對中兩個節點的效能容量使用率統計資料，以判斷如果其中一個節點故障，另一個節點是否會缺乏足夠的容量。由於容錯移轉期間的工作負載是兩個合作夥伴節點工作負載的總和，因此可以將相同的效能容量使用率接管原則套用至兩個節點。

[NOTE]
====
這種已用效能容量的等效性在節點之間通常是成立的。但是，如果透過其容錯移轉合作夥伴發送到其中一個節點的跨節點流量明顯較多，則在一個合作夥伴節點與另一個合作夥伴節點上執行所有工作負載時，所使用的總效能容量可能會略有不同，具體取決於發生故障的節點。

====
在定義 LUN 和 Volume 的臨界值時，效能容量使用條件也可用作次要效能臨界值設定，以建立組合臨界值原則。效能容量使用條件套用於 Volume 或 LUN 所在的彙總或節點。例如，您可以使用下列條件建立組合臨界值原則：
