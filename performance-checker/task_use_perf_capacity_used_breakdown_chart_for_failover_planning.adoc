= 在 Active IQ Unified Manager 中使用「效能容量使用細分」圖表進行容錯移轉規劃
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
詳細的「效能容量使用情況 - 細分」圖表會顯示主要節點和合作夥伴節點所使用的效能容量。它也會顯示預估接管節點上的可用效能容量。這些資訊有助於您判斷合作夥伴節點發生故障時是否會出現效能問題。

除了顯示節點使用的總效能容量外，細目圖表還會將每個節點的值分為使用者通訊協定和背景程序。

* 使用者協定是指使用者應用程式與叢集之間進行的 I/O 操作。
* 背景程序是指與儲存效率、資料複寫和系統健全狀況相關的內部系統程序。


這種額外的細節層級使您能夠確定效能問題是由使用者應用程式活動還是背景系統程序（例如重複資料刪除、RAID 重建、磁碟清理和 SnapMirror 複本）引起的。

.步驟
. 前往將作為預計接管節點之節點的*效能/節點故障轉移規劃*頁面。
. 從 *時間範圍* 選擇器中，選擇要在計數器網格和計數器圖表中顯示歷史統計資料的時段。
+
系統會顯示主要節點、合作夥伴節點及預估接管節點的統計資料計數器圖表。

. 從 *選擇圖表* 清單中，選擇 *效能容量使用量*。
. 在 *效能容量使用率* 圖表中，選取 *細分* 並按一下 *縮放檢視*。
+
系統會顯示效能已用容量的詳細圖表。

+
image::../media/headroom_advanced_zoom_chart.gif[顯示效能已使用容量詳細圖表的使用者介面快照。]

. 將游標移到詳細圖表上，即可在彈出視窗中檢視效能容量使用資訊。
+
效能容量剩餘百分比是指預計接管節點上可用的效能容量。它表示故障轉移後接管節點上剩餘的效能容量。如果該百分比為 0%，則故障轉移會導致接管節點上的延遲增加到無法接受的層級。

. 考慮採取修正行動，以避免可用效能容量百分比過低。
+
如果您計畫啟動容錯移轉以進行節點維護，請選擇可用效能容量百分比不為 0 的時間使合作夥伴節點故障。
