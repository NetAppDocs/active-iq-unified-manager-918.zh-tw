= 回應 Active IQ Unified Manager 中違反效能臨界值原則的情況
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當計數器值超過其定義的效能臨界值，且達到持續時間所指定的時間長度時，即會違反該臨界值並報告事件。

該事件會導致啟動下列行動：

* 此事件會顯示在儀表板、效能叢集摘要頁面、事件頁面和特定物件的效能清單頁面中。
* （選用）可以將關於該事件的電子郵件警報傳送給一個或多個電子郵件收件者，並將 SNMP 設陷傳送給設陷接收器。
* （可選）可以執行指令碼來自動修改或更新儲存設備物件。


第一個行動一律會執行。您可以在「警示設定」頁面中設定是否執行選用的行動。您可以根據違反的是警告還是關鍵臨界值原則，來定義獨特的行動。

當儲存設備物件發生效能臨界值原則違規後，該原則將不再產生事件，直到計數器值低於臨界值為止；此時，此限制的持續時間將重設。只要臨界值持續被超過，事件的結束時間就會持續更新，以反映該事件仍在後續。

臨界值事件會擷取或凍結與嚴重性和原則定義相關的資訊，以便即使未來修改臨界值原則，也能將唯一的臨界值資訊與事件一起顯示。
