= 檢視 Active IQ Unified Manager 中物件登陸頁面的元件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
物件登陸頁面提供有關所有關鍵、警告與資訊事件的詳細資訊。它們提供所有叢集物件效能的詳細檢視，讓您能夠選擇並比較不同時間週期內的個別物件。

物件登陸頁面可讓您檢查所有物件的整體效能，並以並排格式比較物件效能資料。這在評估效能與疑難排解事件時非常有幫助。

[NOTE]
====
計數器總結面板和計數器圖表中顯示的資料是基於五分鐘的採樣間隔。頁面左側物件庫存網格中顯示的資料是基於一小時的採樣間隔。

====
下列映像顯示物件登陸頁面的範例，其中顯示 Explorer 資訊：

image::../media/perf_manager_page_1.gif[一張 UI 快照，展示了物件登陸頁面的範例，其中顯示了 Explorer 資訊。]

根據正在檢視的儲存設備物件，物件登陸頁面可以包含下列索引標籤，以提供有關該物件的效能資料：

* 總結
+
顯示三到四個計數器圖表，其中包含前 72 小時內每個物件的事件和效能，包括顯示該期間最高值和最低值的趨勢線。

* 探索者
+
顯示與目前物件相關的儲存設備物件網格，以便將目前物件的效能值與相關物件的效能值進行比較。此標籤包含多達 11 個計數器圖表和一個時間範圍選擇器，可讓您執行各種比較。

* 資訊
+
顯示有關儲存設備物件的非效能組態屬性的值，包括已安裝的 ONTAP 軟體版本、HA 合作夥伴名稱以及連接埠和 LIF 的數量。

* 表現優異者
+
對於叢集：根據您選擇的效能計數器，顯示效能最高或效能最低的儲存設備物件。

* 容錯移轉規劃
+
對於節點：顯示如果節點的 HA 合作夥伴發生故障，對節點效能影響的估計值。

* 詳細資料
+
對於 Volume：顯示所選 Volume 工作負載的所有 I/O 活動和作業的詳細效能統計資料。此標籤適用於 FlexVol Volume、FlexGroup Volume，以及 FlexGroups 的組成部分。
