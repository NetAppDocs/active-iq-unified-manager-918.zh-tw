= 在 Active IQ Unified Manager 中使用已使用效能容量值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
效能容量使用值可協助您識別目前過度使用或未充分利用的節點和彙總。這使您能夠重新分配工作負載，從而提高儲存資源的效率。

下圖顯示資源的延遲與使用率曲線，並以彩色圓點標示目前運作點可能所在的三個區域。

image::../media/headroom_chart_over_under.gif[一張顯示資源延遲與使用率曲線的使用者介面快照。]

* 效能容量使用百分比等於 100 時，即為最佳狀態。
+
目前資源正被有效率地使用。

* 效能容量使用百分比超過 100 表示節點或彙總過度使用，且工作負載的效能未達最佳狀態。
+
不應向該資源新增新的工作負載，並且可能需要重新分配現有工作負載。

* 效能容量使用率低於 100 表示節點或彙總未充分利用，且資源未被有效使用。
+
可以為該資源新增更多工作負載。



[NOTE]
====
與使用率不同，效能容量使用率可以超過 100%。雖然沒有最高百分比限制，但資源過度使用時，其使用率通常在 110% 到 140% 之間。更高的百分比則表示資源有嚴重問題。

====
