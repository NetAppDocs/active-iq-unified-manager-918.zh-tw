= 使用 Active IQ Unified Manager 介面管理儲存系統效能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
這些章節包含有關 Active IQ Unified Manager 所提供之兩種使用者介面的資訊，這兩種使用者介面用於疑難排解資料儲存設備容量、可用度和保護問題。這兩種使用者介面分別是 Unified Manager Web 使用者介面和維護主控台。

如果您要使用 Unified Manager 中的保護功能，也必須安裝和設定 OnCommand Workflow Automation （WFA）。



[[unified-manager-web-ui]]
== Unified Manager Web 使用者介面

Unified Manager Web UI 讓系統管理員能夠監控並疑難排解與資料儲存設備容量、可用度及保護相關的叢集問題。

這些章節描述了一些系統管理員可以遵循的常見工作流程，以對 Unified Manager Web UI 中顯示的儲存容量、資料可用度或保護問題進行疑難排解。



[[maintenance-console]]
== 維護主控台

Unified Manager 維護主控台可讓系統管理員監控、診斷和解決與 Unified Manager 伺服器本身相關的作業系統問題、版本升級問題、使用者存取問題和網路問題。如果 Unified Manager Web UI 無法使用，維護主控台是存取 Unified Manager 的唯一途徑。

您可以利用這些資訊存取維護主控台，並利用它來解決與 Unified Manager 伺服器運作相關的問題。
