= 選擇要在 Active IQ Unified Manager 中顯示的效能圖表
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「選擇圖表」下拉清單可讓您選擇要在「計數器圖表」窗格中顯示的效能計數器圖表類型。這可讓您根據效能要求檢視特定資料和計數器。

.步驟
. 在 *計數器圖表* 窗格中，按一下 *選擇圖表* 下拉清單。
. 新增或移除圖表：
+
|===
| 若要…… | 這樣做…… 


 a| 
新增或移除單一圖表
 a| 
按一下要顯示或隱藏的圖表旁的核取方塊



 a| 
新增所有圖表
 a| 
按一下 *全選*



 a| 
移除所有圖表
 a| 
按一下 *Unselect All*

|===
+
您選擇的圖表會顯示在「計數器圖表」窗格中。請注意，新增圖表時，新圖表會依照「選擇圖表」下拉清單中圖表的順序插入「計數器圖表」窗格中。選擇其他圖表可能需要捲動頁面。
