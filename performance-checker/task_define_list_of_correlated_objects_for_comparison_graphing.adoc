= 在 Active IQ Unified Manager 中定義用於比較圖表的相關物件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在「計數器圖表」窗格中定義用於資料和效能比較的相關物件清單。例如，如果您的儲存設備虛擬機器（SVM）遇到效能問題，您可以比較 SVM 中的所有 Volume，以確定哪個 Volume 可能導致該問題。

您可以將關聯物件網格中的任何物件新增至「比較」和「計數圖」窗格中。這樣，您就可以檢視和比較多個物件以及根目錄物件的資料。您可以為關聯物件網格新增和移除物件；但是，「比較」窗格中的根目錄物件無法移除。

[NOTE]
====
在「比較」窗格中新增過多物件可能會對效能產生負面影響。為保持效能，您應該選擇有限數量的圖表進行資料比較。

====
.步驟
. 在物件網格中，找到您要新增的物件，然後按一下 *新增* 按鈕。
+
*Add* 按鈕變成灰色，物件會加入到「比較」窗格中的其他物件清單中。物件的資料會加入到「計數器圖表」窗格中的圖表中。物件的眼睛圖示（image:../media/eye_icon.gif[""]）的顏色與圖表中物件資料趨勢線的顏色相符。

. *選用：* 隱藏或顯示所選物件的資料：
+
|===
| 若要執行此操作…… | 採取以下行動…… 


 a| 
隱藏選取的物件
 a| 
在「比較」窗格中，按一下所選物件的眼睛圖示（image:../media/eye_icon.gif[""]）。物件的資料會隱藏，且該物件的眼睛圖示會變為灰色。



 a| 
顯示隱藏物件
 a| 
按一下「比較」窗格中選定物件的灰色眼睛圖示。

眼睛圖示恢復到原來的顏色，物件資料重新加入計數器圖表窗格的圖表中。

|===
. *選用：*從 *比較* 窗格中移除選取的物件：
+
|===
| 若要執行此操作…… | 採取以下行動…… 


 a| 
移除選取的物件
 a| 
將滑鼠停留在「比較」窗格中所選物件的名稱上，即可顯示「移除物件」按鈕 (*X*)，然後按一下該按鈕。該物件將從「比較」窗格中移除，其資料也將從計數器圖表中清除。



 a| 
移除所有選取的物件
 a| 
按一下「比較」窗格頂部的「移除所有物件」按鈕（*X*）。所有選取的物件及其資料都會被移除，只留下根目錄物件。

|===
