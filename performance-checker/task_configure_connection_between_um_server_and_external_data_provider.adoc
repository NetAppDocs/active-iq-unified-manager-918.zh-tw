= 設定 Active IQ Unified Manager 與外部資料供應商之間的連線
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 可以將叢集效能資料傳送到外部伺服器。您可以指定要傳送的統計資料類型以及資料傳送間隔。

.開始之前
* 您必須擁有授權的使用者 ID 才能登入 Unified Manager 伺服器的維護主控台。
* 您必須掌握以下關於外部資料供應商的資訊：
+
** 伺服器名稱或 IP 位址（IPv4 或 IPv6）
** 伺服器預設連接埠（如果未使用預設連接埠 2003）


* 您必須設定遠端伺服器和第三方軟體，以便它可以從 Unified Manager 伺服器接收統計資料。
* 您必須知道要傳送哪一組統計資料：
+
** PERFORMANCE_INDICATOR：效能監控統計資料
** RESOURCE_UTILIZATION：資源使用率和效能監控統計資料
** DRILL_DOWN：所有統計資料


* 您必須知道您想要傳輸統計資料的時間間隔：5、10 或 15 分鐘
+
預設情況下，Unified Manager 每 5 分鐘收集統計資料。如果將傳輸間隔設定為 10（或 15）分鐘，則每次傳輸發送的資料量將是使用預設 5 分鐘間隔時的兩倍（或三倍）。

+
[NOTE]
====
如果將 Unified Manager 效能收集間隔變更為 10 或 15 分鐘，則必須變更傳輸間隔，使其等於或大於 Unified Manager 收集間隔。

====


您可以設定一個 Unified Manager 伺服器和一個外部資料供應商伺服器之間的連線。

.步驟
. 以維護使用者身分登入 Unified Manager 伺服器的維護控制台。
+
顯示 Unified Manager 維護主控台提示。

. 在維護主控台中，輸入 *外部資料供應商* 功能表選項的編號。
+
顯示「外部伺服器連線」選單。

. 輸入 *新增/修改伺服器連線* 選單選項的編號。
+
顯示目前伺服器連線資訊。

. 出現提示時，請鍵入 `*y*`以繼續。
. 出現提示時，輸入目的地伺服器的 IP 位址或名稱以及伺服器連接埠資訊（如果與預設連接埠 2003 不同）。
. 出現提示時，請鍵入 `*y*`以確認您輸入的資訊是否正確。
. 按任意鍵返回外部伺服器連線選單。
. 輸入 *修改伺服器組態* 選單選項的編號。
+
顯示目前伺服器組態資訊。

. 出現提示時，請鍵入 `*y*`以繼續。
. 出現提示時，請輸入要傳送的統計資料類型、傳送統計資料的時間間隔，以及是否要立即啟用統計資料傳輸：
+
|===
| 為了…… | 輸入…… 


 a| 
統計資料群組 ID
 a| 
`*0*` - PERFORMANCE_INDICATOR （預設）

`*1*` - RESOURCE_UTILIZATION

`*2*` - DRILL_DOWN



 a| 
供應商標籤
 a| 
用於儲存外部伺服器上統計資料之資料夾的描述性名稱。"`netapp-performance`" 是預設名稱，但您可以輸入其他值。

透過使用點分式表示法，您可以定義分層資料夾結構。例如，輸入  `*stats.performance.netapp*` 後，統計資料將位於 *stats* > *效能* > *netapp* 中。



 a| 
傳輸間隔
 a| 
`*5*`（預設）、 `*10*` 或  `*15*` 分鐘



 a| 
啟用/停用
 a| 
`*0*` - 停用

`*1*` - 啟用（預設）

|===
. 出現提示時，請鍵入 `*y*`以確認您輸入的資訊是否正確。
. 按任意鍵返回外部伺服器連線選單。
. 輸入  `*x*` 退出維護主控台。


連線設定完成後，所選效能資料將按您指定的時間間隔傳送至目的地伺服器。計量需要幾分鐘才會開始顯示在外部工具中。您可能需要重新整理瀏覽器才能在計量階層中看到新計量。
