= 在 Active IQ Unified Manager 中檢視效能容量計數器圖表
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在「效能資源管理器」頁面檢視節點和彙總的效能容量使用量圖表。這可讓您檢視特定時間範圍內所選節點和彙總的詳細效能容量資料。

標準計數器圖表顯示所選節點或彙總的已使用效能容量值。細分計數器圖表顯示根目錄物件的總效能容量值，並根據使用者傳輸協定與背景系統程序的使用情況分隔。此外，也會顯示可用的效能容量。

[NOTE]
====
由於某些與系統和資料管理員相關的背景活動會被識別為使用者工作負載並歸類為使用者協定，因此當這些程序執行時，使用者協定的百分比可能會顯得異常高。這些程序通常在午夜前後執行，此時叢集使用率較低。如果您發現午夜前後使用者協定活動出現峰值，請檢查叢集備份作業或其他背景活動是否已設定為在該時間執行。

====
.步驟
. 從節點或彙總 *Landing* 頁面中選擇 *Explorer* 標籤。
. 在 *計數器圖表* 窗格中，按一下 *選擇圖表*，然後選擇 *效能容量使用量* 圖表。
. 向下捲動直到可以檢視圖表。
+
標準圖表的色彩顯示物件處於最佳範圍（黃色）、物件使用率偏低（綠色）以及物件過度使用（紅色）的時機。細分圖表僅顯示根目錄物件的詳細效能容量詳細資料。

+
image::../media/headroom_counter_charts.gif[一張 UI 快照，顯示僅針對根目錄物件的詳細效能容量分解圖。]

. 若要以全尺寸格式檢視任一圖表，請點選*縮放檢視*。
+
這樣，您就可以在分隔的視窗中開啟多個計數器圖表，以便在同一時間段內比較已使用效能容量值與 IOPS 或 MBps 值。
