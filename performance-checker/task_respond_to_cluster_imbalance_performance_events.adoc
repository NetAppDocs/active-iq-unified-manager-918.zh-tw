= 回應 Active IQ Unified Manager 中的叢集不平衡效能事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當叢集中某個節點的運作負載遠高於其他節點，因此可能影響工作負載延遲時， Unified Manager 會產生叢集不平衡警告事件。這些系統定義的事件提供了修正潛力效能問題的商機，以免許多工作負載受到延遲的影響。

.開始之前
您必須擁有操作員、應用程式管理員或儲存管理員角色。

Unified Manager 透過比較叢集中所有節點的效能容量使用值，來產生叢集不平衡臨界值原則違規的警告事件，以查看任何節點之間是否存在 30% 的負載差異。

這些步驟可以幫助您識別以下資源，以便您可以將高效能工作負載遷移到使用率較低的節點：

* 同一叢集中使用率較低的節點
* 新節點上使用率最低的彙總
* 目前節點上效能最高的 Volume


.步驟
. 顯示 *事件* 詳細資料頁面以檢視事件的資訊。
. 請檢閱 *描述* ，其中說明導致事件的臨界值違規。
+
例如，訊息 "`Dallas-1-8 叢集上的節點之間的效能容量使用計數器顯示負載差異為 62%，並已根據 30% 的系統臨界值觸發警告事件`" 表示其中一個節點的效能容量被過度使用，影響了節點效能。

. 檢閱 *建議動作* 中的文字，將高效能 Volume 從效能容量使用值高的節點移至效能容量使用值最低的節點。
. 找出已用效能容量值最高和最低的節點：
+
.. 在 *事件資訊* 區段中，按一下來源叢集的名稱。
.. 在「*叢集 / 效能摘要*」頁面中，按一下「*受管理物件*」區域中的「*節點*」。
.. 在 *節點* 清單頁面中，依 *已使用效能容量* 欄對節點進行排序。
.. 找出效能容量使用值最高和最低的節點，並寫下這些名稱。


. 找出在效能容量使用值最高的節點上，使用最多 IOPS 的 Volume：
+
.. 按一下已用效能容量值最高的節點。
.. 在 *節點 / 效能資源管理器* 頁面中，從 *檢視和比較* 功能表中選擇 *此節點上的彙總*。
.. 點選已使用效能容量值最高的彙總。
.. 在 *彙總 / 效能總管* 頁面中，從 *檢視與比較* 功能表中選取 *此彙總上的 Volume*。
.. 將 Volume 依 *IOPS* 欄排序，並寫下使用最多 IOPS 的 Volume 名稱，以及該 Volume 所在彙總的名稱。


. 找出效能容量使用值最低的節點上，使用率最低的彙總：
+
.. 點選 *儲存設備* > *彙總* 以顯示 *彙總* 庫存頁面。
.. 選擇 *效能：所有彙總* 檢視。
.. 按一下 *篩選器* 按鈕，新增一個篩選器，其中「`節點`」等於您在步驟 4 中記下、具有最低效能容量使用值的節點名稱。
.. 寫下已用效能容量值最低的彙總名稱。


. 將 Volume 從過載節點移至您在新節點上確定的使用率較低的彙總。
+
您可以使用 ONTAP System Manager、OnCommand Workflow Automation、ONTAP 命令或這些工具的組合來執行移動作業。



幾天後，檢查是否從此叢集收到相同的叢集不平衡事件。
