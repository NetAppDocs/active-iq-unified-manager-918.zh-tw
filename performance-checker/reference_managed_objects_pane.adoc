= 查看 Active IQ Unified Manager 中的「託管物件」窗格
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「效能總結」標籤中的「代管物件」窗格提供了叢集儲存設備物件類型和數量的總覽。您可以透過此窗格追蹤每個叢集中物件的狀態。

代管物件數量是截至上次收集週期的時間點資料。每 15 分鐘會發現新物件。

按一下任何物件類型的連結編號，即可顯示該物件類型的物件效能清單頁面。此物件清單頁面已篩選，僅顯示此叢集中的物件。

代管物件為：

* *節點*
+
叢集中的一個實體系統。

* *彙總*
+
一組多個備援獨立磁碟陣列（RAID）群組，可作為單一單位代管，以進行保護與配置。

* *連接埠*
+
節點上的實體連接點，用於連接網路上的其他設備。

* *儲存虛擬機器*
+
透過唯一的網路位址提供網路存取的虛擬機器。SVM 可能從獨立的命名空間提供資料，並且可與叢集的其餘部分分開管理。

* *磁碟區*
+
透過一或多種支援的存取協定保存可存取使用者資料的邏輯實體。計數包括 FlexVol® Volume 和 FlexGroup Volume；不包括 FlexGroup 成員組成。

* *LUN*
+
Fibre Channel （FC） 邏輯單元或 iSCSI 邏輯單元的識別碼。邏輯單元通常對應於一個儲存設備 Volume，並在電腦作業系統中表示為一個裝置。

* *網路介面*
+
代表節點網路存取點的邏輯網路介面。計數包含所有介面類型。
