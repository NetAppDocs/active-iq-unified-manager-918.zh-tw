= 使用 Active IQ Unified Manager 中的工作負載分析器來疑難排解工作負載
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
工作負載分析器提供了一種在單一頁面上檢視單一工作負載的重要健全狀況和效能指標的方法，以協助您進行疑難排解。透過檢視工作負載的所有目前和過去事件，您可以更了解工作負載目前可能發生效能或容量問題的原因。

使用此工具還可以幫助您判斷儲存設備是否為應用程式任何效能問題的原因，或者該問題是否由連網或其他相關問題所引起。

您可以透過使用者介面中的多個位置啟動此功能：

* 從左側導覽選單的「工作負載分析」選項中
* 從「事件詳細資料」頁面，按一下 *分析工作負載* 按鈕
* 在任何工作負載清單頁面（Volume、LUN、工作負載、NFS 共享或 SMB/CIFS 共用區）中，按一下「更多」圖示 image:../media/more_icon.gif[""]，然後按一下 *分析工作負載*
* 在「虛擬機器」頁面上，按一下任何資料儲存物件的 *分析工作負載* 按鈕


從左側導覽功能表啟動工具時，您可以輸入要分析的任何工作負載的名稱，並選擇要疑難排解的時間範圍。從任何工作負載或虛擬機器清單頁面啟動工具時，工作負載名稱將自動填入，並且工作負載的資料將以預設的 2 小時時間範圍顯示。從事件詳細資訊頁面啟動工具時，工作負載名稱將自動填入，並顯示 10 天的資料。
