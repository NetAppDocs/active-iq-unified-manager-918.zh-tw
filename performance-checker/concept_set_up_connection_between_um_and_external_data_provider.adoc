= 在 Active IQ Unified Manager 和外部資料供應商之間建立連線
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 伺服器與外部資料供應商之間的連接，可讓您將叢集效能資料傳送至外部伺服器，以便儲存設備管理員可以使用第三方軟體繪製效能計量圖表。

透過維護控制台中標記為 "`External Data Provider`" 的選單選項，可以建立 Unified Manager 伺服器與外部資料供應商之間的連線。
