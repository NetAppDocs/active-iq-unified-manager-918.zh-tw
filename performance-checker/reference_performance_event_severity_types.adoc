= 在 Active IQ Unified Manager 中依嚴重程度對效能事件進行優先排序
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
每個效能事件都與一個嚴重性類別相關聯，以幫助您確定需要立即修正行動的事件的優先順序。

* *關鍵*
+
發生了效能事件，如果不立即採取修正行動，可能會導致服務中斷。

+
關鍵事件僅在達到使用者定義的臨界值時才會發送。

* *警告*
+
叢集物件的效能計數器超出正常範圍，應進行監控以確保其不會達到關鍵嚴重性。此嚴重性的事件不會導致服務中斷，可能無需立即採取修正行動。

+
警告事件由使用者定義、系統定義或動態臨界值發出。

* *資訊*
+
當發現新物件或執行使用者行動時，就會觸發此事件。例如，當刪除任何儲存設備物件或進行任何組態變更時，都會產生嚴重性類別為「資訊」的事件。

+
當 ONTAP 偵測到組態變更時，資訊事件會直接從 ONTAP 傳送。
