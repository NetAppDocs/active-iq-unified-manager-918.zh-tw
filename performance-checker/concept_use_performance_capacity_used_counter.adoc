= 在 Active IQ Unified Manager 中使用效能容量使用計數器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通常，組織希望將效能容量使用百分比維持在 100 以下，以便有效利用資源，同時保留一些額外的效能容量來支援尖峰時段的需求。您可以使用臨界值原則來自訂何時針對較高的效能容量使用值傳送警報。

您可以根據效能要求設定具體目標。例如，金融服務公司可能會保留更多效能容量，以確保及時執行交易。這些公司可能希望將已用效能容量臨界值設定在 70-80% 的範圍內。利潤較低的製造公司如果願意承擔效能風險以妥善管理 IT 成本，可能會選擇保留較少的效能容量。這些公司可能會將已用效能容量臨界值設定在 85-95% 的範圍內。

當效能容量使用率超過使用者定義的臨界值原則中設定的百分比時， Unified Manager 會傳送警報郵件並將事件新增至事件清單頁面。這可讓您在潛力問題影響效能之前進行管理。這些事件也可以作為指標，指出您需要在節點和彙總內進行工作負載的移動與變更。
