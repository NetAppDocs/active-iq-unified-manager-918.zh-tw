= 在 Active IQ Unified Manager 中檢查 MetroCluster 組態健全狀況
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager 審查透過 IP 或 FC 之 MetroCluster 組態中的叢集健全狀況。健全狀況狀態和事件可協助您判斷是否存在可能影響工作負載效能的硬體或軟體問題。

如果您將 Unified Manager 設定為傳送電子郵件警報，則可以查看電子郵件，以了解本機或遠端叢集上可能導致效能事件的任何健全狀況問題。在 Unified Manager GUI 中，您可以選擇 *Event Management* 以查看目前的事件清單，然後使用篩選器僅顯示 MetroCluster 組態事件。

如需詳細資訊，請參閱link:../health-checker/task_check_health_of_clusters_in_metrocluster_configuration.html["檢查 MetroCluster 組態中叢集的健全狀況"]
