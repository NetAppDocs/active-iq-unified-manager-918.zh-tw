= 了解 Active IQ Unified Manager 中的效能容量使用計數器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
已用效能容量計數器可協助您識別節點或彙總的效能是否已達到臨界點，以致於工作負載增加時效能可能會降級。它也能顯示節點或彙總目前在特定時段內是否遭到過度使用。已用效能容量與使用率類似，但前者能針對特定工作負載在實體資源中的可用效能能力，提供更深入的見解。

最佳已使用效能容量是指節點或彙總達到最佳使用率和延遲（回應時間），並被有效利用的點。下圖顯示彙總的延遲與使用率曲線範例。

image::../media/headroom_chart.gif[一張 UI 快照，顯示彙總的延遲與使用率曲線範例。]

在此範例中，_運作點_指出彙總目前以 50% 的使用率運作，延遲為 1.0 ms/op。根據從彙總擷取的統計資料，Unified Manager 判斷此彙總還有額外的效能容量可用。在此範例中，_最佳點_被識別為彙總處於 80% 使用率且延遲為 2.0 ms/op 的點。因此，您可以將更多 Volume 和 LUN 新增至此彙總，以便更有效率地使用您的系統。

已使用的效能容量計數器預計會大於 "`使用率`" 計數器，因為效能容量會將對延遲的影響納入考量。例如，如果某個節點或彙總已使用 70%，則效能容量值可能在 80% 到 100% 之間，具體取決於延遲值。

然而，在某些情況下，儀表板頁面上的使用率計數器可能會更高。這是正常現象，因為儀表板會在每個收集週期更新目前的計數器值；它不像 Unified Manager 使用者介面中的其他頁面那樣顯示一段時間內的平均值。效能容量使用計數器最適合用作一段時間內平均效能的指標，而使用率計數器最適合用於判斷資源的瞬間使用量。
