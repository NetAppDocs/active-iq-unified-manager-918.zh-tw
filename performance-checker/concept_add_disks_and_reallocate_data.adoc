= 了解在 Active IQ Unified Manager 中新增磁碟如何影響資料重新分配
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以將磁碟新增至彙總，以增加該彙總的儲存容量與效能。新增磁碟後，只有在將資料重新分配到您新增的磁碟上之後，您才會看到讀取效能的提升。

當 Unified Manager 收到由動態臨界值或系統定義的效能臨界值觸發的彙總事件時，您可以使用這些指示：

* 當您收到動態臨界值事件時，在事件詳細資訊頁面上，代表發生爭用之彙總的叢集元件圖示會以紅色醒目提示。
+
圖示下方括號內是彙總的名稱，用來識別您可以新增磁碟的彙總。

* 當您收到系統定義的臨界值事件時，在「事件詳細資料」頁面上，事件執行摘要文字會列出發生問題的彙總名稱。
+
您可以在此彙總上新增磁碟機並重新分配資料。



新增到彙總的磁碟必須已存在於叢集中。如果叢集沒有可用磁碟，您可能需要聯絡系統管理員或購買更多磁碟。您可以使用 ONTAP System Manager 或 ONTAP 命令將磁碟新增至彙總。

[NOTE]
====
僅在使用 HDD 和 Flash Pool 彙總時才需要重新分配資料。請勿在 SSD 或 FabricPool 彙總上重新分配資料。
