= 了解 Active IQ Unified Manager 中的叢集元件和爭用
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當叢集元件發生爭用時，您可以找出叢集效能問題。使用該元件的工作負載效能會下降，且其對用戶端要求的回應時間（延遲）會增加，這會在 Unified Manager 中觸發事件。

處於爭用狀態的元件無法以最佳層級運作。其效能已經下降，而其他叢集元件與工作負載（稱為「受害者」）的延遲可能會增加。若要使元件脫離爭用狀態，您必須減少其工作負載或提高其處理更多工作的能力，以便效能恢復到正常水準。由於 Unified Manager 會以五分鐘為間隔來收集並分析工作負載效能，因此只有在叢集元件持續過度使用時，它才會偵測到。在五分鐘間隔內僅持續一小段時間的短暫過度使用尖峰，則無法偵測到。

例如，儲存設備彙總可能面臨資源爭用，因為其上的一個或多個工作負載正在爭相完成其 I/O 要求。彙總上的其他工作負載可能會受到影響，導致其效能下降。為了減少彙總上的活動量，您可以採取不同的措施，例如將一個或多個工作負載移至較不繁忙的彙總或節點，以降低目前彙總的整體工作負載需求。對於 QoS 原則群組，您可以調整處理量限制，或將工作負載移至不同的原則群組，使工作負載不再受到限制。

Unified Manager 會監控下列叢集元件，並在它們發生爭用時發出警報：

* *網路*
+
表示叢集外部連網協定對 I/O 請求的等待時間。等待時間是指叢集在回應 I/O 請求之前，等待 "`transfer ready`" 交易完成所花費的時間。如果網路元件處於爭用狀態，則表示協定階層的高等待時間正在影響一或多個工作負載的延遲。

* *網路處理*
+
代表叢集中負責協定階層與叢集之間 I/O 處理的軟體元件。自從偵測到該事件以來，負責網路處理的節點可能已變更。如果網路處理元件處於爭用狀態，則表示網路處理節點的高使用率正在影響一個或多個工作負載的延遲。

+
在雙主動式組態中使用全 SAN 陣列叢集時，兩個節點都會顯示網路處理延遲值，以便您驗證節點是否平均分擔負載。

* *QoS 限制最大值*
+
表示指派給工作負載的儲存設備服務品質 (QoS) 原則群組的最大處理量（峰值）設定。如果原則群組元件處於爭用狀態，表示原則群組中的所有工作負載都會受到設定的處理量限制，這會影響其中一個或多個工作負載的延遲。

* *QoS 最低限制*
+
表示由於指派給其他工作負載的 QoS 處理量最低（預期）設定而導致的工作負載延遲。如果某些工作負載上設定的 QoS 最低值佔用了大部分頻寬來保證承諾的處理量，則其他工作負載將會受到節流限制，並出現更高的延遲。

* *叢集互連*
+
表示叢集節點實體連接所用的纜線與介面卡。如果叢集互連元件發生爭用，表示叢集互連的 I/O 要求等待時間過長，進而影響一個或多個工作負載的延遲。

* *資料處理*
+
表示叢集中負責叢集與包含工作負載的儲存設備彙總之間 I/O 處理的軟體元件。自從偵測到該事件以來，負責資料處理的節點可能已變更。如果資料處理元件處於爭用狀態，則表示資料處理節點的高使用率正在影響一或多個工作負載的延遲。

* *Volume 啟動*
+
代表追蹤所有作用中 Volume 使用情況的程序。在有超過 1000 個作用中 Volume 的大型環境中，此程序會追蹤有多少關鍵 Volume 需要同時透過節點存取資源。當同時作用中的 Volume 數量超過建議的最大臨界值時，某些非關鍵 Volume 將會發生此處所指出的延遲。

* *MetroCluster 資源*
+
代表 MetroCluster 資源，包括 NVRAM 和交換器間連結（ISL），用於在 MetroCluster 組態中的叢集之間鏡射資料。如果 MetroCluster 元件處於爭用狀態，則表示來自本機叢集上工作負載的寫入處理量過高，或是連結健全狀況問題影響了本機叢集上一個或多個工作負載的延遲。如果叢集未處於 MetroCluster 組態中，則不會顯示此圖示。

* *彙總或 SSD 彙總操作*
+
表示工作負載運作所在的儲存設備彙總。如果彙總元件處於爭用狀態，則表示彙總上的高使用率正在影響一個或多個工作負載的延遲。彙總可以由全部 HDD 組成，也可以由 HDD 和 SSD 混合組成（Flash Pool 彙總），或由 HDD 和雲端分層混合組成（FabricPool 彙總）。"`SSD 彙總`" 由全部 SSD 組成（All Flash 彙總），或由 SSD 和雲端分層混合組成（FabricPool 彙總）。

* *雲端延遲*
+
代表叢集中負責叢集與儲存使用者資料的雲端層之間 I/O 處理的軟體元件。如果雲端延遲元件發生爭用，即表示從託管於雲端層的 Volume 進行大量讀取，正在影響一個或多個工作負載的延遲。

* *同步 SnapMirror*
+
表示叢集中負責在 SnapMirror Synchronous 關係中，將使用者資料從主要 Volume 複製到次要 Volume 的軟體元件。如果同步 SnapMirror 元件發生爭用，即表示來自 SnapMirror Synchronous 作業的活動正在影響一或多個工作負載的延遲。
