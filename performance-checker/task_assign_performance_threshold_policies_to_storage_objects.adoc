= 在 Active IQ Unified Manager 中為儲存設備物件指派效能臨界值原則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以將使用者定義的效能臨界值原則指派給儲存設備物件，以便 Unified Manager 在效能計數器的值超過原則設定時報告事件。

.開始之前
您必須擁有應用程式管理員角色。

您要套用至物件的效能臨界值原則必須存在。

一次只能對一個物件或一組物件套用一個效能原則。

每個儲存設備物件最多可以指派三個臨界值原則。將原則指派給多個物件時，如果其中任何一個物件已指派了最大數量的原則， Unified Manager 將執行下列動作：

* 將此原則應用於所有尚未達到其最大值的選取物件
* 忽略已達到最大原則數的物件
* 顯示一則訊息，提示該原則尚未指派給所有物件


.步驟
. 在任意儲存設備物件的「效能清單」頁面中，選擇要為其指派臨界值原則的物件：
+
|===
| 若要將臨界值指派給…… | 按一下…… 


 a| 
單一物件
 a| 
該物件左側的核取方塊。



 a| 
多個物件
 a| 
每個物件左側的核取方塊。



 a| 
頁面上的所有物件
 a| 
image:../media/select_dropdown_65_png.gif["選擇下拉圖示"] 下拉方塊，然後選擇 *選擇此頁面上的所有物件*。



 a| 
所有相同類型的物件
 a| 
image:../media/select_dropdown_65_png.gif["選擇下拉圖示"] 下拉式方塊，並選擇 *選擇所有物件*。

|===
+
您可以使用排序和篩選功能來精簡庫存頁面上的物件清單，以便更輕鬆地將臨界值原則套用至許多物件。

. 進行選取，然後按一下 *指派效能臨界值原則*。
+
此時會顯示「指派效能臨界值原則」頁面，其中列出該特定類型儲存設備物件現有的臨界值原則。

. 按一下每個原則以顯示效能臨界值設定的詳細資料，以驗證您是否已選取正確的臨界值原則。
. 選取適當的臨界值原則後，按一下 *Assign Policy*。
+
頁面頂端的成功訊息確認臨界值原則已指派給物件，並提供前往警示頁面的連結，以便您為此物件和原則設定警示設定。



如果您希望透過電子郵件或 SNMP 陷阱傳送警報，以通知您已產生特定的效能事件，則必須在「警報設定」頁面中設定警報設定。
