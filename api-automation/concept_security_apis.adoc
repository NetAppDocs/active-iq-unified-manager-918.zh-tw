= 使用 API 在 Active IQ Unified Manager 中管理使用者
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 `security`類別中的 API 來控制使用者對 Active IQ Unified Manager 中所選叢集物件的存取。您可以新增本機使用者或資料庫使用者。您也可以新增屬於驗證伺服器的遠端使用者或群組。根據您指派給使用者的角色權限，他們可以管理儲存物件或檢視 Unified Manager 中的資料。

[NOTE]
====
您必須擁有應用程式管理員角色才能執行這些操作。您也可以使用 Unified Manager Web UI 設定這些設定。

====
此 `security`類別下的 API 使用 users 參數（即使用者名稱）而不是 key 參數作為使用者實體的唯一識別碼。

[cols="3*"]
|===
| HTTP 動詞 | 路徑 | 說明 


 a| 
`GET`

`POST`
 a| 
`/security/users`

`/security/users`
 a| 
您可以使用這些方法取得使用者的詳細資訊，或將新使用者新增至 Unified Manager。

您可以根據使用者類型為其新增特定角色。新增使用者時，您必須為本機使用者、維護使用者和資料庫使用者提供密碼。



 a| 
`GET`

`PATCH`

`DELETE`
 a| 
`/security/users/\{name}`
 a| 
GET 方法可讓您擷取使用者的所有詳細資料，例如名稱、電子郵件地址、角色、授權類型。PATCH 方法可讓您更新詳細資料。DELETE 方法可讓您移除使用者。

|===
