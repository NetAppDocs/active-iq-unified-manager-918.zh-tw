= 使用 Active IQ Unified Manager 中的 API 檢視儲存設備工作負載
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
此處列出的 API 可讓您檢視資料中心中所有 ONTAP 叢集的儲存設備工作負載總計清單。這些 API 還提供 Active IQ Unified Manager 環境中已配置的儲存設備工作負載數量及其容量和效能（IOPS）統計資料的總結檢視。



[[view-storage-workloads]]
== 檢視儲存設備工作負載

您可以使用下列方法檢視資料中心內所有叢集的所有儲存設備工作負載。如需根據特定欄位篩選回應的相關資訊，請參閱 Unified Manager 執行個體中提供的 API 參考文件。

[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備供應商
 a| 
取得
 a| 
`/storage-provider/workloads`

|===


[[view-storage-workloads-summary]]
== 檢視儲存設備工作負載總結

您可以使用以下方法評估每個效能服務等級代管的已使用容量、可用容量、已使用 IOPS、可用 IOPS 以及儲存設備工作負載數量。顯示的儲存設備工作負載可以針對任何 LUN、NFS 檔案共享或 CIFS 共用區。此 API 提供儲存設備工作負載總覽、Unified Manager 資源配置的儲存設備工作負載總覽、資料中心總覽，以及資料中心內總空間、已使用空間、可用空間和 IOPS 的總覽（按分配的效能服務等級劃分）。回應此 API 收到的資訊將用於填入 Unified Manager UI 中的儀表板。

[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備供應商
 a| 
取得
 a| 
`/storage-provider/workloads-summary`

|===
