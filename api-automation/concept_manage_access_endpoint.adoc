= 使用 Active IQ Unified Manager 中的 API 管理存取端點
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您需要建立存取端點或邏輯介面（LIF），這是配置儲存虛擬機器（SVM）、LUN 和檔案共享所必需的。您可以在 Active IQ Unified Manager 環境中檢視、建立、修改和刪除 SVM、LUN 或檔案共享的存取端點。



[[view-access-endpoints]]
== 檢視存取端點

您可以使用下列方法檢視 Unified Manager 環境中的存取端點清單。若要查詢特定 SVM、LUN 或檔案共享的存取端點清單，您需要輸入該 SVM、LUN 或檔案共享的唯一識別碼。您也可以輸入唯一的存取端點金鑰來擷取特定存取端點的詳細資訊。

[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備供應商
 a| 
取得
 a| 
`/storage-provider/access-endpoints`

`/storage-provider/access-endpoints/\{key}`

|===


[[add-access-endpoints]]
== 新增存取端點

您可以建立自訂存取端點並為其指派所需的屬性。您必須輸入要建立之存取端點的詳細資料作為輸入參數。您可以使用此 API、System Manager 或 ONTAP CLI 在每個節點上建立存取端點。IPv4 和 IPv6 位址均支援用於建立存取端點。

[NOTE]
====
為了成功配置 LUN 和檔案共享，您必須為 SVM 設定每個節點最少數量的存取端點。您應該為 SVM 設定每個節點至少兩個存取端點，其中一個支援 CIFS 和/或 NFS 協定，另一個支援 iSCSI 或 FCP 協定。

====
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備供應商
 a| 
POST
 a| 
`/storage-provider/access-endpoints`

|===

您可以使用下列方法刪除特定存取端點。您需要提供存取端點金鑰作為輸入參數，以刪除特定存取端點。

[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備供應商
 a| 
刪除
 a| 
`/storage-provider/access-endpoints/\{key}`

|===

您可以使用下列方法修改存取端點並更新其屬性。若要修改特定的存取端點，您需要提供存取端點鍵。您還需要輸入要更新的屬性及其值。

[cols="3*"]

| 類別 | HTTP 動詞 | 路徑

|===
