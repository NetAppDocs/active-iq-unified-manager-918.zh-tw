= 使用 Active IQ Unified Manager 中的 API 修改儲存設備工作負載
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
修改儲存設備工作負載包括更新缺少參數的 LUN 或檔案共享，或變更現有參數。

本工作流程以更新 LUN 和檔案共享的效能服務等級為例進行說明。

[NOTE]
====
此工作流程假設 LUN 或檔案共享已資源配置效能服務等級。

====


[[modify-file-shares]]
== 修改檔案共享

修改檔案共享時，您可以更新以下參數：

* 容量或大小。
* 線上或離線設定。
* 儲存效率原則。
* 效能服務等級。
* 存取控制清單（ACL）設定。
* 匯出原則設定。您也可以刪除匯出原則參數，並回復檔案共享上的預設（空）匯出原則規則。


[NOTE]
====
在單一 API 執行期間，您只能更新一個參數。

====
本流程介紹如何為檔案共享新增效能服務等級。您可以使用相同的流程更新任何其他檔案共享屬性。

. 取得要更新的檔案共享的 CIFS 共用區金鑰或 NFS 檔案共享金鑰。此 API 會查詢資料中心上的所有檔案共享。如果您已經知道檔案共享金鑰，請跳過此步驟。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備供應商
 a| 
取得
 a| 
`/storage-provider/file-shares`

|===
. 使用您取得的檔案共享金鑰執行下列 API，即可檢視檔案共享的詳細資訊。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備供應商
 a| 
取得
 a| 
`/storage-provider/file-shares/\{key}`

|===
+
在輸出結果中查看檔案共享的詳細資訊。

+
[listing]
----
"assigned_performance_service_level": {
        "key": null,
        "name": "Unassigned",
        "peak_iops": null,
        "expected_iops": null,
        "_links": {}
      },
----
. 取得要指派給此檔案共享的效能服務等級的金鑰。目前尚未為其指派任何原則。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
效能服務等級
 a| 
取得
 a| 
`/storage-provider/performance-service-levels`

|===
+
[NOTE]
====
您可以將  `system_defined` 輸入參數設定為  `true`，以擷取系統定義的效能服務等級詳細資訊。從輸出中，取得您要套用至檔案共享的效能服務等級金鑰。

====
. 將效能服務等級套用至檔案共享。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備提供者
 a| 
PATCH
 a| 
`/storage-provider/file-shares/\{key}`

|===
+
在輸入中，您必須僅指定要更新的參數以及檔案共享金鑰。在本例中，它是效能服務等級的金鑰。

+
*cURL 範例*

+
[listing]
----
curl -X POST "https://<hostname>/api/storage-provider/file-shares"`-H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>" -d
"{
\"performance_service_level\": { \"key\": \"1251e51b-069f-11ea-980d-fa163e82bbf2\" },
}"
----
+
JSON 輸出顯示一個 Job 物件，您可以使用該物件來驗證是否已成功建立主節點和合作夥伴節點上的存取端點。

. 使用輸出中顯示的作業物件鍵，驗證效能服務等級是否已新增至檔案共享。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
管理伺服器
 a| 
取得
 a| 
`/management-server/jobs/\{key}`

|===
+
如果您透過 Job 物件的 ID 進行查詢，您會看到檔案共享是否已成功更新。如果發生故障，請對故障進行疑難排解，然後再次執行 API。成功建立後，查詢檔案共享以查看修改後的物件：

+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備供應商
 a| 
取得
 a| 
`/storage-provider/file-shares/\{key}`

|===
+
在輸出結果中查看檔案共享的詳細資訊。

+
[listing]
----
"assigned_performance_service_level": {
        "key": "1251e51b-069f-11ea-980d-fa163e82bbf2",
        "name": "Value",
        "peak_iops": 75,
        "expected_iops": 75,
        "_links": {
            "self": {
                "href": "/api/storage-provider/performance-service-levels/1251e51b-069f-11ea-980d-fa163e82bbf2"
            }
        }
----




[[update-luns]]
== 更新 LUN

更新 LUN 時，您可以修改以下參數：

* 容量或大小
* 線上或離線設定
* 儲存效率原則
* 效能服務等級
* LUN 對應


[NOTE]
====
在單一 API 執行期間，您只能更新一個參數。

====
此程序介紹如何為 LUN 新增效能服務等級。您可以使用相同的程序更新任何其他 LUN 屬性。

. 取得要更新的 LUN 的 LUN 金鑰。此 API 會傳回資料中心中所有 LUN 的詳細資訊。如果您已經知道 LUN 金鑰，請略過此步驟。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備提供者
 a| 
取得
 a| 
`/storage-provider/luns`

|===
. 使用您獲得的 LUN 金鑰執行以下 API，即可查看 LUN 的詳細資訊。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備提供者
 a| 
取得
 a| 
`/storage-provider/luns/\{key}`

|===
+
查看輸出中的 LUN 詳細資訊。可以看到，此 LUN 沒有指派效能服務等級。

+
*JSON 輸出範例*

+
[listing]
----

  "assigned_performance_service_level": {
        "key": null,
        "name": "Unassigned",
        "peak_iops": null,
        "expected_iops": null,
        "_links": {}
      },
----
. 取得要指派給 LUN 的效能服務等級的金鑰。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
效能服務等級
 a| 
取得
 a| 
`/storage-provider/performance-service-levels`

|===
+
[NOTE]
====
您可以透過將 `system_defined`輸入參數設為 `true`，來擷取系統定義的效能服務等級詳細資訊。從輸出中，取得要套用於 LUN 的效能服務等級的鍵。

====
. 將效能服務等級套用至 LUN。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備提供者
 a| 
PATCH
 a| 
`/storage-provider/lun/\{key}`

|===
+
在輸入中，您必須只指定要更新的參數以及 LUN 金鑰。在本例中，它是效能服務等級的金鑰。

+
*cURL 範例*

+
[listing]
----
curl -X PATCH "https://<hostname>/api/storage-provider/luns/7d5a59b3-953a-11e8-8857-00a098dcc959" -H "accept: application/json" -H "Content-Type: application/json" H "Authorization: Basic <Base64EncodedCredentials>" -d
"{ \"performance_service_level\": { \"key\": \"1251e51b-069f-11ea-980d-fa163e82bbf2\" }"
----
+
JSON 輸出會顯示 Job 物件鍵，您可以使用該鍵來驗證您更新的 LUN。

. 使用您獲得的 LUN 金鑰執行以下 API，即可查看 LUN 的詳細資訊。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
儲存設備提供者
 a| 
取得
 a| 
`/storage-provider/luns/\{key}`

|===
+
查看輸出結果中的 LUN 詳細資訊。您可以看到效能服務等級已指派給此 LUN。

+
*JSON 輸出範例*

+
[listing]
----

     "assigned_performance_service_level": {
        "key": "1251e51b-069f-11ea-980d-fa163e82bbf2",
        "name": "Value",
        "peak_iops": 75,
        "expected_iops": 75,
        "_links": {
            "self": {
                "href": "/api/storage-provider/performance-service-levels/1251e51b-069f-11ea-980d-fa163e82bbf2"
            }
----
