:allow-uri-read: 
:icons: font

+
** `_IP address/hostname_` 是 API 伺服器的 IP 位址或完整網域名稱 （FQDN）。
** 連接埠 443
+
443 是預設的 HTTPS 連接埠。如有需要，您可以自訂 HTTPS 連接埠。



+
若要從 Web 瀏覽器發出 HTTP 請求，您必須使用 REST API 瀏覽器外掛程式。您也可以使用 cURL 和 Perl 等指令碼平台存取 REST API。





[[authentication]]
== 驗證

Unified Manager 支援 API 的基本 HTTP 驗證方案。對於安全的資訊流（請求和回應），REST API 僅可透過 HTTPS 存取。API 伺服器會向所有用戶端提供自簽的 SSL 憑證以進行伺服器驗證。此憑證可以替換為自訂憑證（或 CA 憑證）。

您必須設定使用者對 API 伺服器的存取才能呼叫 REST API。使用者可以是本機使用者（使用者設定檔儲存在本機資料庫中），也可以是 LDAP 使用者（如果您已將 API 伺服器設定為透過 LDAP 進行驗證）。您可以透過登入 Unified Manager 管理主控台使用者介面來管理使用者存取。
