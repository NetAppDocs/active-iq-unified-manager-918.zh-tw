= 使用 Active IQ Unified Manager API 驗證 ONTAP 叢集上的 SVM
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在資源配置檔案共享或 LUN 之前，您必須驗證叢集上是否已建立儲存虛擬機器（SVM）。

[NOTE]
====
此工作流程假設已將 ONTAP 叢集新增至 Unified Manager，並且已取得叢集金鑰。叢集應具備在其上進行 LUN 資源配置與檔案共享所需的授權。

====
. 確認叢集中是否已建立 SVM。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
資料中心
 a| 
取得
 a| 
`/datacenter/svm/svms`
`/datacenter/svm/svms/\{key}`

|===
+
*cURL 範例*

+
[listing]
----
curl -X GET "https://<hostname>/api/datacenter/svm/svms" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. 如果未傳回 SVM 金鑰，則建立 SVM。建立 SVM 時，您需要用於資源配置 SVM 的叢集金鑰。您還需要指定 SVM 名稱。請依照下列步驟操作。
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
資料中心
 a| 
取得
 a| 
`/datacenter/cluster/clusters`
`/datacenter/cluster/clusters/\{key}`

|===
+
取得叢集金鑰。

+
*cURL 範例*

+
[listing]
----
curl -X GET "https://<hostname>/api/datacenter/cluster/clusters" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. 從輸出結果中取得叢集金鑰，然後將其用作建立 SVM 的輸入。
+
[NOTE]
====
建立 SVM 時，請確保其支援在其中資源配置 LUN 與檔案共享所需的所有通訊協定，例如 CIFS、NFS、FCP 和 iSCSI。如果 SVM 不支援所需的服務，資源配置工作流程可能會失敗。建議在 SVM 上也啟用各個工作負載類型的服務。

====
+
[cols="3*"]
|===
| 類別 | HTTP 動詞 | 路徑 


 a| 
資料中心
 a| 
POST
 a| 
`/datacenter/svm/svms`

|===
+
