= 在 Active IQ Unified Manager 中編輯使用者和群組配額電子郵件地址
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以根據與叢集、儲存設備虛擬機器（SVM）、Volume、qtree、使用者或使用者群組關聯的使用者配額來修改電子郵件地址。當您想要置換「產生使用者和群組配額電子郵件地址的規則」對話方塊中指定的規則所產生的電子郵件地址時，可以修改電子郵件地址。

.開始之前
* 您必須擁有操作員、應用程式管理員或儲存管理員角色。
* 您必須已審閱過link:reference_rules_to_generate_user_and_group_quota.html["制定規則的指導原則"]。


如果您編輯了電子郵件地址，則用於產生使用者和群組配額電子郵件地址的規則將不再適用於該配額。若要將通知傳送至由指定規則產生的電子郵件地址，您必須刪除該電子郵件地址並儲存變更。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備* > *SVMs*。
. 在「運作狀況：所有儲存虛擬機器」檢視中，選擇一個 SVM，然後按一下「使用者和群組配額」標籤。
. 點選標籤列下方的 *編輯電子郵件地址*。
. 在 *編輯電子郵件地址* 對話方塊中，執行適當的行動：
+
|===
| 如果...... | 然後 ...... 


 a| 
您希望將通知傳送到由指定規則產生的電子郵件地址
 a| 
.. 刪除 *電子郵件地址* 欄位中的電子郵件地址。
.. 按一下 *Save* 。
.. 按 F5 重新整理瀏覽器以重新載入「編輯電子郵件地址」對話方塊。根據指定規則產生的電子郵件地址將顯示在 *電子郵件地址* 欄位中。




 a| 
您希望將通知傳送到指定的電子郵件地址
 a| 
.. 修改 *電子郵件地址* 欄位中的電子郵件地址。
.. 點選 *儲存*。用於產生使用者和群組配額電子郵件地址的規則不再適用於此配額。


|===
