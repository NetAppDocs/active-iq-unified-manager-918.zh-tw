= 在 Active IQ Unified Manager 中配置和管理工作負載
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 的作用中管理特色提供效能服務等級、儲存效率原則和儲存設備供應商 API，用於在資料中心中進行資源配置、監控和管理儲存設備工作負載。

[NOTE]
====
Unified Manager 預設提供此功能。如果您不打算使用此功能，可以從 *儲存管理* > *功能設定* 中將其停用。

====
啟用後，您可以在您的 Unified Manager 執行個體代管的 ONTAP 叢集上資源配置工作負載。您也可以為工作負載指派原則，例如效能服務等級和儲存效率原則，並根據這些原則管理您的儲存環境。

此功能可實現以下功能：

* 自動探索新增叢集上的儲存設備工作負載，從而簡化儲存設備工作負載的評估和部署
* 資源配置支援 NFS 和 CIFS 協定的 NAS 工作負載
* 資源配置支援 iSCSI 和 FCP 協定的 SAN 工作負載
* 同一檔案共享同時支援 NFS 和 CIFS 協定
* 效能服務等級與儲存設備效率策略的管理
* 為儲存設備工作負載分配效能服務等級和儲存效率策略


UI 左側窗格上的 *資源配置*、*儲存設備* > *工作負載* 和 *原則* 選項可讓您修改各種組態。

您可以使用這些選項來執行下列功能：

* 在 *儲存設備* > *工作負載* 頁面上檢視儲存設備工作負載
* 從「資源配置工作負載」頁面建立儲存設備工作負載
* 從原則建立與管理效能服務層級
* 從原則建立和管理儲存設備效率原則
* 從「工作負載」頁面為儲存設備工作負載指派策略
