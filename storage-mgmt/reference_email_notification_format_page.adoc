= 了解 Active IQ Unified Manager 中的電子郵件通知格式頁面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
電子郵件通知格式頁面會顯示當發生配額相關問題（超出軟限制或達到硬限制）時，傳送給使用者或使用者群組的電子郵件規則。

只有在產生下列使用者或使用者群組配額事件時，才會傳送電子郵件通知：超出使用者或群組配額磁碟空間軟限制、超出使用者或群組配額檔案計數軟限制、達到使用者或群組配額磁碟空間硬限制，或達到使用者或群組配額檔案計數硬限制。

* *從*
+
顯示傳送電子郵件的電子郵件地址，您可以修改此地址。預設情況下，這是「通知」頁面中指定的電子郵件地址。

* *主旨*
+
顯示通知郵件的主旨。

* *電子郵件詳情*
+
顯示通知電子郵件的文字。您可以根據需求修改文字。例如，您可以提供與配額屬性相關的資訊，並減少關鍵字的數量。但是，您不應修改關鍵字。

+
有效關鍵字如下：

+
** $EVENT_NAME
+
指定引發電子郵件通知的事件名稱。

** $QUOTA_TARGET
+
指定配額適用的 qtree 或 Volume。

** $QUOTA_USED_PERCENT
+
指定使用者或使用者群組使用的磁碟硬限制、磁碟軟限制、檔案硬限制或檔案軟限制的百分比。

** $QUOTA_LIMIT
+
指定使用者或使用者群組達到的磁碟硬限制或檔案硬限制，並產生以下事件之一：

+
*** 使用者或群組配額磁碟空間已達硬限制
*** 使用者或群組配額磁碟空間軟限制已達到
*** 使用者或群組配額檔案數量已達硬限制
*** 使用者或群組配額檔案數軟限制已達到


** $QUOTA_USED
+
指定使用者或使用者群組使用的磁碟空間或建立的檔案數。

** $QUOTA_USER
+
指定使用者或使用者群組名稱。







[[command-buttons]]
== 命令按鈕

命令按鈕可讓您預覽、儲存或取消對電子郵件通知格式所做的變更：

* *預覽*
+
顯示通知郵件的預覽。

* *還原為出廠預設值*
+
允許您將通知格式還原為出廠預設值。

* *儲存*
+
儲存對通知格式所做的變更。
