= 了解 Active IQ Unified Manager 中的「修復問題」和「全部修復」按鈕選項
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「管理行動」頁面提供 *修復此問題* 或 *全部修復* 按鈕，用於修復 Unified Manager 透過事件收到通知的問題。

我們建議您視需要點擊按鈕來解決問題。但是，如果您不確定是否要按照 Unified Manager 的建議解決問題，您可以執行下列行動：

|===
| 您想要做什麼？ | *行動* 


 a| 
請 Unified Manager 修復所有已識別物件上的問題。
 a| 
按一下 *全部修復* 按鈕。



 a| 
目前不要修復任何已識別物件的問題，並隱藏此管理行動，直到再次引發該事件。
 a| 
點擊向下箭頭，然後點擊 *全部取消*。



 a| 
僅修復部分已識別物件的問題。
 a| 
點選管理行動的名稱以擴充清單，並顯示所有個別的 *Fix It* 行動。然後依照步驟修復或撤銷個別的管理行動。

|===
|===
| 您想要做什麼？ | 行動 


 a| 
請 Unified Manager 修復此問題。
 a| 
按一下 *修復* 按鈕。



 a| 
目前暫不修復此問題，並隱藏此管理行動，直到再次出現該事件。
 a| 
按一下向下箭頭，然後按一下 *關閉*。



 a| 
顯示此事件的詳細資料，以便您更了解問題。
 a| 
* 按一下 *Fix It* 按鈕，並在產生的對話方塊中審查將套用的修復。
* 按一下向下箭頭，然後按一下 *檢視事件詳細資料* 以顯示事件詳細資料頁面。


然後，如果您想修復此問題，請從這些結果頁面中的任一個按一下 *Fix It*。



 a| 
顯示此儲存設備物件的詳細資料，以便您更清楚了解問題。
 a| 
按一下儲存設備物件的名稱，即可在「效能資源管理器」或「運作狀況詳細資料」頁面中顯示詳細資料。

|===
在某些情況下，修復程序會在接下來的 15 分鐘組態輪詢中生效。但在其他情況下，組態變更的驗證和事件的失效可能需要數小時之久。

若要查看已完成或正在進行的管理行動清單，請按一下篩選圖示並選擇 *已完成* 或 *正在進行*。

Fix All 作業會以循序方式執行，因此當您檢視 *進行中* 面板時，某些物件的狀態將顯示為 *進行中*，而其他物件的狀態將顯示為 *已排程*；這表示它們仍在等待實作。
