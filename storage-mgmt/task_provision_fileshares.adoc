= 在 Active IQ Unified Manager 中配置檔案共享 Volume
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以從「資源配置工作負載」頁面，在現有的叢集和儲存虛擬機器（儲存 VM）上，建立支援 CIFS/SMB 和 NFS 協定的檔案共享 Volume。

.開始之前
* 儲存 VM 必須有空間以供資源配置檔案共享 Volume。
* 您的儲存虛擬機器上應該啟用 SMB 和/或 NFS 服務。
* 若要選擇和指派工作負載的效能服務等級（PSL）和儲存效率原則（SEP），必須在開始建立工作負載之前建立這些原則。


.步驟
. 在 *資源配置工作負載* 頁面上，新增您要建立的工作負載名稱，然後從可用清單中選取叢集。
. 根據您選擇的叢集，*儲存虛擬機器* 欄位會篩選出該叢集可用的儲存虛擬機器。請從清單中選擇所需的儲存虛擬機器。
+
根據儲存虛擬機器上支援的 SMB 和 NFS 服務，在主機資訊部分啟用 NAS 選項。

. 在「儲存和最佳化」部分，指派儲存容量和 PSL，並可選擇為工作負載指派 SEP。
+
SEP 的規格會指派給 LUN，而 PSL 的定義會在建立工作負載時套用至工作負載。

. 如果您想要強制執行指派給工作負載的 PSL ，請選取 *強制效能限制* 核取方塊。
+
將 PSL 指派給工作負載，可確保建立該工作負載的彙總能夠支援對應原則中定義的效能和容量目標。例如，如果將工作負載指派給「極致效能」PSL，則要資源配置該工作負載的彙總應具備支援「極致效能」原則的效能和容量目標的功能，例如 SSD 儲存設備。

+
[NOTE]
====
除非選取此核取方塊，否則 PSL 不會套用於工作負載，且儀表板的工作負載狀態將顯示為未指派。

====
. 選擇 *NAS* 選項。
+
如果看不到已啟用的 *NAS* 選項，請確認您選擇的儲存虛擬機器是否支援 SMB 或 NFS，或兩者皆支援。

+
[NOTE]
====
如果您的儲存虛擬機器同時啟用了 SMB 和 NFS 服務，您可以選取 *透過 NFS 共享* 和 *透過 SMB 共享* 核取方塊，建立一個同時支援 NFS 和 SMB 協定的檔案共享。如果您只想建立 SMB 共享或 CIFS 共用區，則只需選取對應的核取方塊即可。

====
. 對於 NFS 檔案共享 Volume，請指定要存取該檔案共享 Volume 的主機或網路的 IP 位址。您可以輸入以逗號分隔的值來指定多部主機。
+
新增主機 IP 位址後，系統會執行內部檢查，以比對主機詳細資料與儲存虛擬機器，並為該主機建立匯出原則，或者如果已有現有原則，則重複使用該原則。如果為相同主機建立了多個 NFS 共享，則會為所有檔案共享重複使用具有相符規則的相同主機可用匯出原則。當您使用 API 資源配置 NFS 共享時，可以透過提供特定的原則金鑰來指定個別原則的規則或重複使用原則。

. 對於 SMB 共享，請指定哪些使用者或使用者群組可以存取該 SMB 共享，並指派所需的權限。在建立檔案共享期間，系統會為每個使用者群組產生一個新的存取控制清單 (ACL)。
. 按一下 *Save* 。
+
此工作負載已新增至儲存設備工作負載清單中。
