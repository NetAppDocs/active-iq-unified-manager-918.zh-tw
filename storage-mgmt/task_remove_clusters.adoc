= 從 Active IQ Unified Manager 中移除叢集
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用「叢集設定」頁面從 Unified Manager 中移除叢集。例如，如果叢集探索失敗，或者當您想要退役儲存系統時，您可以移除叢集。

.開始之前
您必須擁有應用程式管理員角色或儲存設備管理員角色。

此工作會將選取的叢集從 Unified Manager 中移除。叢集移除後，將不再受到監控。向已移除叢集註冊的 Unified Manager 執行個體，也會從該叢集中取消註冊。

刪除叢集也會從 Unified Manager 中刪除其所有儲存設備物件、歷史資料、儲存設備服務以及所有相關事件。這些變更將在下一個資料收集週期後反映在清單頁面和詳細資料頁面上。

[NOTE]
====
必須先從 Unified Manager 中移除叢集，才能將其停用。如果嘗試移除叢集時叢集已離線或無法連線，Unified Manager 將無法與叢集通訊以移除應用程式記錄和已設定的事件管理系統（EMS）訂閱。這將導致移除程序失敗或在完成前無回應。

====
.步驟
. 在左側導覽窗格中，按一下 *儲存管理* > *叢集設定*。
. 在叢集設定頁面上，選取您要移除的叢集，然後按一下 *移除*。
. 在 *移除資料來源* 訊息對話方塊中，按一下 *移除* 以確認移除要求。
