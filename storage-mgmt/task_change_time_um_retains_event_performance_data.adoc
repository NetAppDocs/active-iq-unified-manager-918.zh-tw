= 更改 Active IQ Unified Manager 保留事件和效能資料的時間長度
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
預設情況下，Unified Manager 會將所有受監控叢集的事件資料和效能資料儲存 6 個月。此後，系統會自動刪除舊資料，以便為新資料騰出空間。此預設時間範圍適用於大多數組態，但對於包含大量叢集和節點的超大型組態，可能需要縮短保留期間，以確保 Unified Manager 最佳化運作。

.開始之前
您必須擁有應用程式管理員角色。

您可以在「資料保留」頁面中變更這兩種類型資料的保留期間。這些設定會影響此 Unified Manager 執行個體正在監控的所有叢集的資料保留。

[NOTE]
====
Unified Manager 每 5 分鐘收集效能統計資料。每天，這 5 分鐘的統計資料會彙總成每小時的效能統計資料。它會保留 30 天的 5 分鐘歷史效能資料和 6 個月的每小時彙總效能資料（預設）。

====
只有當空間不足或備份及其他操作耗時過長時，才應縮短保留期間。縮短保留期間會產生以下影響：

* 午夜過後，舊的效能資料將從 Unified Manager 資料庫中刪除。
* 舊的事件資料會立即從 Unified Manager 資料庫中刪除。
* 保留期間之前的事件將不再可在使用者介面中檢視。
* 在保留期間之前，使用者介面中顯示每小時效能統計資料的位置將為空白。
* 如果事件保留期間超過效能資料保留期間，則會在效能滑桿下方顯示一則訊息，警告較舊的效能事件可能在其關聯的圖表中沒有支援資料。


.步驟
. 在左側導覽窗格中，按一下 *原則* > *資料保留*。
. 在 *資料保留* 頁面中，選擇「事件保留」或「效能資料保留」區域中的滑桿工具，將其移至資料應保留的月數，然後按一下 *儲存*。
