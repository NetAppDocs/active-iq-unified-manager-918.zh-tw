= 在 Active IQ Unified Manager 中使用「配額」對話方塊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在「健全狀況：所有 Storage VM」檢視的「使用者和群組配額」標籤中使用適當的選項，來設定發生配額相關問題時發送的電子郵件通知的格式，並設定規則以根據使用者配額指定電子郵件地址。
