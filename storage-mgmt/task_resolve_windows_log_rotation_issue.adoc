= 解決 Active IQ Unified Manager 中的 NetApp 可管理性 SDK 日誌輪替問題
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 Windows 作業系統上將基於 ONTAPI API 的叢集新增至 Unified Manager 後， `nmsdk.log` 檔案大小會增加並超過 10 MB 的大小限制。

*原因*

如果未發生日誌輪替，可能會發生此問題。

*修正行動*

. 停止 Unified Manager。
. 在 Windows 上安裝 Unified Manager 時，請安裝 Logrotate 版本 0.0.0.18。如需詳細資訊，請參閱 link:https://www.netapp.com/pdf.html?item=/media/78941-tr-4945.pdf["NetApp Manageability SDK 技術報告安全強化指南"^]。
. 啟動 Unified Manager。
