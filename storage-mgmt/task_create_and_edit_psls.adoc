= 在 Active IQ Unified Manager 中建立和編輯效能服務級別
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當系統定義的效能服務層級與您的工作負載要求不符時，您可以建立針對您的工作負載最佳化的自訂效能服務層級。

.開始之前
* 您必須擁有應用程式管理員角色。
* 效能服務層級名稱必須是唯一的，且不能使用下列保留關鍵字：
+
`Prime`、 `Extreme`、 `Performance`、 `Value`、 `Unassigned`、 `Learning`、 `Idle`、 `Default` 及 `None`。



您可以透過在「效能服務層級」頁面中定義存取儲存設備的應用程式所需的服務層級目標，來建立和編輯自訂效能服務層級。

[NOTE]
====
如果效能服務層級目前已指派給工作負載，則無法對其進行修改。

====
.步驟
. 在左側導覽窗格的 *設定* 下，選擇 *策略* > *效能服務層級*。
. 在 *效能服務層級* 頁面中，根據您是要建立新的效能服務層級還是要編輯現有的效能服務層級，按一下適當的按鈕。
+
|===
| 若要…… | 請依照以下步驟操作...... 


 a| 
建立新的效能服務層級
 a| 
點擊 *Add* 。



 a| 
編輯現有的效能服務層級
 a| 
選擇現有的效能服務層級，然後按一下 *編輯*。

|===
+
顯示用於新增或編輯效能服務層級的頁面。

. 透過指定效能目標來自訂效能服務層級，然後按一下 *提交* 以儲存效能服務層級。


您可以從「工作負載」頁面或在配置新工作負載時，將新的或變更的效能服務層級套用至工作負載（LUN、NFS 檔案共用、CIFS 共用）。
