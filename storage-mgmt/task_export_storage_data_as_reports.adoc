= 在 Active IQ Unified Manager 中將儲存設備資料匯出為報告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以將儲存設備資料匯出為多種輸出格式，然後使用匯出的資料產生報告。例如，如果有 10 個尚未解決的關鍵事件，您可以從「事件管理」清單頁面匯出資料以建立報告，然後將報告傳送給管理員，由他們解決這些問題。

您可以從 *儲存設備* 和 *網路* 清單頁面將資料匯出至  `.csv` 檔案、 `.xlsx` 檔案或  `.pdf` 文件，並使用匯出的資料建立報告。產品中還有其他位置只能產生  `.csv` 或  `.pdf` 檔案。

.步驟
. 執行下列其中一項動作：
+
|===
| 如果您想匯出…… | 這樣做…… 


 a| 
儲存物件清單詳細資料
 a| 
從左側導覽功能表中按一下 *儲存設備* 或 *網路*，然後選擇儲存設備物件。選擇系統提供的其中一個檢視，或您建立的任何自訂檢視。



 a| 
QoS 策略群組詳細資料
 a| 
從左側導覽功能表中按一下 *儲存設備* > *QoS 原則群組*。



 a| 
儲存容量與保護歷史記錄詳細資料
 a| 
按一下 *儲存設備* > *彙總* 或 *儲存設備* > *Volume*，然後選取單一彙總或 Volume。



 a| 
事件詳細資料
 a| 
從左側導覽選單中點選 *事件管理*。



 a| 
儲存物件效能排名前 10 的詳細資料
 a| 
按一下 *儲存設備* > *叢集* > *效能：所有叢集*，然後選擇一個叢集，並選擇 *效能最佳* 標籤。接下來，選擇一個儲存設備物件和效能計數器。

|===
. 點選 *報告* 按鈕（或在某些使用者介面頁面中的 *匯出* 按鈕）。
. 按一下 *下載 CSV*、*下載 PDF* 或 *下載 Excel* 以確認匯出要求。
+
從「表現最佳」索引標籤中，您可以選擇下載您正在檢視的單一叢集或資料中心內所有叢集的統計資料報告。

+
檔案已下載。

. 請使用相應的應用程式開啟檔案。
