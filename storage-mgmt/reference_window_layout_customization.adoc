= 在 Active IQ Unified Manager 中自訂視窗佈局
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 可讓您自訂儲存設備和網路物件頁面上資訊的版面配置。透過自訂視窗，您可以控制可供檢視的資料以及資料的顯示方式。

* *排序*
+
您可以按一下欄位標題來變更欄位項目的排序順序。當您按一下欄位標題時，該欄位會出現排序箭頭（image:../media/sort_asc_um60.gif["欄排序圖示 – 遞增"] 和 image:../media/sort_desc_um60.gif["欄排序圖示 - 遞減"]）。

* *過濾*
+
您可以點選篩選器圖示（image:../media/filtering_icon.gif[""]）來套用篩選器，自訂儲存設備和網路物件頁面上的資訊顯示，以便僅顯示符合指定條件的項目。您可以在「篩選器」窗格中套用篩選器。

+
「篩選器」窗格可讓您根據所選選項篩選大多數欄位。例如，在「運作狀況：所有 Volume」檢視中，您可以透過在「狀態」下選擇適當的篩選選項，使用「篩選器」窗格顯示所有處於離線的 Volume。

+
任何清單中與容量相關的欄始終以適當的單位顯示容量資料，並四捨五入到小數點後兩位。篩選容量欄時也適用此規則。例如，如果您在「健全狀況：所有彙總」檢視的「總資料容量」欄中使用篩選器篩選大於 20.45 GB 的資料，則實際容量 20.454 GB 將顯示為 20.45 GB。同樣，如果您篩選小於 20.45 GB 的資料，則實際容量 20.449 GB 將顯示為 20.45 GB。

+
如果在「運作狀況：所有彙總」檢視的「可用資料 %」欄中使用篩選器篩選大於 20.45% 的資料，則實際容量 20.454% 將顯示為 20.45%。同樣地，如果篩選小於 20.45% 的資料，則實際容量 20.449% 將顯示為 20.45%。

* *隱藏或顯示欄*
+
您可以點擊欄顯示圖示（*顯示/隱藏*）來選擇要顯示的欄。選擇好適當的欄後，您可以使用滑鼠拖曳來重新排列它們的順序。

* *搜尋中*
+
您可以使用搜尋框搜尋特定物件屬性，以協助縮小庫存頁面中的項目清單。例如，您可以輸入 "cloud" 以縮小 Volume 庫存頁面中的 Volume 清單，查看所有包含 "cloud" 一詞的 Volume。

* *匯出資料*
+
您可以按一下 *Reports* 按鈕（或 *Export* 按鈕）將資料匯出至逗號分隔值 `(.csv)`檔案、 `(.pdf)`文件或 Microsoft Excel `(.xlsx)`檔案，並使用匯出的資料來建立報表。
