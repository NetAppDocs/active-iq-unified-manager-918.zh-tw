= 在 Active IQ Unified Manager 中檢視並新增 vCenter 伺服器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要檢視與疑難排解虛擬機器（VM）的效能，必須在您的 Active IQ Unified Manager 執行個體上新增相關的 vCenter 伺服器。

.開始之前
在新增或檢視 vCenter 伺服器之前，請確保下列事項：

* 您感知 vCenter 伺服器名稱。
* 您知道 vCenter Server 的 IP 位址，並且擁有所需的憑證。憑證必須屬於 vCenter Server 系統管理員，或是對 vCenter Server 具有唯讀存取的 root 使用者。
* 您要新增的 vCenter 伺服器執行 vSphere 6.5 或更新版本。
+

NOTE: Unified Manager 對 VMware ESXi 和 vCenter Server 的支援提供英文和日文版本。

* vCenter Server 中的資料收集設定已設為統計資料層級 `_Level 3_`，確保對所有受監控的物件進行所需層級的計量收集。間隔持續時間應為 `_5 minutes_`，保存週期應為 `_1 day_`。
+
如需詳細資訊，請參閱 VMware 文件中 _vSphere 監控和效能指南_ 的 "`資料收集層級`" 一節。

* 為了成功計算延遲值，vCenter Server 中的延遲值是以毫秒為單位設定，而不是以微秒為單位。
* 將資料儲存體新增至 vCenter Server 時，您可以使用主機的 IP 位址或完整網域（FQDN）。如果您新增的是 FQDN，請確保 Unified Manager 伺服器可以解析該網域名稱。例如，對於 Linux 安裝，請確保已將網域名稱新增至 `/etc/resolv.conf`檔案中。
* vCenter 伺服器目前時間與 vCenter 伺服器所在時區同步。
* vCenter 伺服器可連線以成功進行探索。
* 將 vCenter Server 新增至 Unified Manager 時，您擁有對 VMware SDK 的讀取存取權。這是組態輪詢所必需的。


對於每部新增並探索到的 vCenter 伺服器，Unified Manager 會收集組態資料，例如 vCenter 伺服器和 ESXi 伺服器詳細資訊、ONTAP 對應、資料存放區詳細資訊，以及託管的虛擬機器數量。它還會收集元件的效能計量。

.步驟
. 前往 *VMWARE* > *vCenter*，並檢查您的 vCenter 伺服器是否在清單中。
+
[NOTE]
====
如果您的 vCenter 伺服器無法使用，則必須新增 vCenter 伺服器。

====
+
.. 點擊 *Add* 。
.. 新增 vCenter Server 的正確 IP 位址，並確保裝置可連線。
.. 新增對 vCenter Server 具有唯讀存取的系統管理員或 root 使用者的使用者名稱和密碼。
.. 如果您使用的是預設 443 以外的連接埠，請新增自訂連接埠號碼。
.. 按一下 *Save* 。
+
成功探索後，將顯示伺服器憑證供您接受。

+
接受憑證後，vCenter 伺服器會新增至可用的 vCenter 伺服器清單中。新增裝置不會導致相關聯虛擬機器的資料收集，且收集會在排定的時間間隔進行。



. 如果您的 vCenter 伺服器在 *vCenters* 頁面上可用，請將滑鼠懸停在 *狀態* 欄位上檢查其狀態，以顯示您的 vCenter 伺服器是否按預期運作，或者是否有警告或錯誤。
+
[NOTE]
====
新增 vCenter 伺服器可讓您檢視下列狀態。不過，在新增 vCenter 伺服器之後，對應虛擬機器的效能與延遲資料可能需要長達一小時的時間才能準確反映。

====
+
** 綠色：「正常」，表示 vCenter Server 已被探索，且已成功收集效能計量
** 黃色：「警告」（例如，當 vCenter Server 的統計資料層級未設定為 3 或以上，以取得每個物件的統計資料時）
** 橘色：「錯誤」（表示任何內部錯誤，例如異常、組態資料收集故障，或 vCenter Server 無法連線）。您可以按一下欄顯示圖示（*顯示/隱藏*）來檢視 vCenter Server 狀態的狀態訊息，並對問題進行疑難排解。


. 如果 vCenter 伺服器無法連線或憑證已變更，請選取 *vCenter* > *編輯* 來編輯 vCenter 伺服器詳細資料。
. 在 *編輯 VMware vCenter 伺服器* 頁面上進行必要的變更。
. 按一下 *Save* 。


*vCenter 伺服器資料收集開始*

vCenter Server 即時收集 20 秒的效能資料樣本，並將其彙總為 5 分鐘的樣本。Unified Manager 的效能資料收集排程是根據 vCenter Server 的預設設定。Unified Manager 處理從 vCenter Server 取得的 5 分鐘樣本，並計算虛擬磁碟、VM 和主機每小時的 IOPS 和延遲平均值。對於資料存放區，Unified Manager 根據從 ONTAP 取得的樣本計算每小時的 IOPS 和延遲平均值。這些值會在每個整點提供。效能計量不會在新增 vCenter Server 後立即可用，而是只有在下一個小時開始時才可用。效能資料輪詢會在完成一個組態資料收集週期後開始。

為了輪詢 vCenter Server 組態資料， Unified Manager 遵循與收集叢集組態資料相同的排程。如需有關 vCenter Server 組態與效能資料收集排程的資訊，請參閱「叢集組態與效能資料收集活動」。
