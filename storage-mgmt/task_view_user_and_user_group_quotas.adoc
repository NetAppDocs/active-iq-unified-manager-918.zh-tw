= 在 Active IQ Unified Manager 中檢視使用者和使用者群組配額
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Storage VM / 健全狀況詳細資料頁面會顯示在 SVM 上設定的使用者和使用者群組配額的相關資訊。您可以檢視使用者或使用者群組的名稱、在磁碟和檔案上設定的限制、已使用的磁碟和檔案空間，以及用於通知的電子郵件地址。

.開始之前
您必須擁有操作員、應用程式管理員或儲存管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *儲存設備* > *儲存虛擬機器*。
. 在 *健全狀況：所有 Storage VM* 檢視中，選取一個 Storage VM，然後按一下 *使用者與群組配額* 標籤。
