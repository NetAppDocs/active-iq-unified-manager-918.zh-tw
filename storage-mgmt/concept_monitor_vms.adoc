= 了解 Active IQ Unified Manager 如何監控虛擬機器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果虛擬機器（VM）應用程式出現任何延遲問題，您可能需要監控虛擬機器以分析和疑難排解原因。當虛擬機器的 vCenter 伺服器和託管虛擬機器儲存設備的 ONTAP 叢集新增至 Unified Manager 後，虛擬機器即可使用。

您可以在 *VMWARE* > > *Virtual Machines* 頁面上查看虛擬機器的詳細資料。系統會顯示可用度、狀態、已使用和已分配容量、網路延遲，以及虛擬機器、資料存放區和主機的 IOPS 和延遲等資訊。對於支援多個資料存放區的虛擬機器，網格會顯示延遲最差之資料存放區的計量，並以星號（*）圖示指出其他資料存放區。如果您按一下該圖示，就會顯示其他資料存放區的計量。其中有些欄無法用於排序和篩選。

[NOTE]
====
若要檢視虛擬機器及其詳細資料，必須完成 ONTAP 叢集的探索（輪詢或計量收集）。如果叢集從 Unified Manager 中移除，則在下一次探索週期之後，該虛擬機器將不再可用。

====
從此頁面，您也可以檢視虛擬機器的詳細拓撲，顯示與虛擬機器相關的元件，例如連接至該虛擬機器的主機、虛擬磁碟和資料存放區。拓撲檢視會依照下列順序，在特定層中顯示底層元件：*虛擬磁碟* > *虛擬機器* > *主機* > *網路* > *資料存放區* > *VMDK*。

您可以從拓撲的角度來判斷 I/O 路徑和元件層級的延遲，並找出儲存設備是否為效能問題的起因。拓撲的總結檢視會顯示 I/O 路徑，並反白顯示發生 IOPS 與延遲問題的元件，以便您決定疑難排解步驟。您也可以查看拓撲的展開檢視，其中會分別顯示每個元件及其延遲。您可以選取一個元件，以判斷各層中反白顯示的 I/O 路徑。



[[view-summary-topology]]
== 檢視總結拓撲

透過檢視總結拓撲中的虛擬機器來確定效能問題：

. 前往 *VMWARE* > *虛擬機器*。
. 在搜尋方塊中輸入虛擬機器名稱來搜尋您的虛擬機器。您也可以按一下 *篩選* 按鈕，根據特定條件篩選搜尋結果。不過，如果您找不到虛擬機器，請確定已新增並探索到對應的 vCenter Server。
+
[NOTE]
====
vCenter Server 允許在 vSphere 實體的名稱（例如虛擬機器、叢集、資料存放區、資料夾或檔案）中使用特殊字元（例如 %、&、*、$、#、@、!、\、/、:、*、?、"`、<, >、|、;、'）。VMware vCenter Server 和 ESX/ESXi Server 不會逸出顯示名稱中使用的特殊字元。但是，當名稱在 Unified Manager 中處理時，它的顯示方式會有所不同。例如，在 vCenter Server 中命名為  `%$VC_AIQUM_clone_191124%` 的虛擬機器，在 Unified Manager 中會顯示為  `%25$VC_AIQUM_clone_191124%25`。當您查詢名稱中包含特殊字元的虛擬機器時，必須留意此問題。

====
. 檢查虛擬機器狀態。虛擬機器狀態是從 vCenter 伺服器取得。有下列狀態可用。如需這些狀態的詳細資訊，請參閱 VMware 文件。
+
** 正常
** 警告
** 警示
** 未監控
** 未知


. 按一下 VM 旁的向下箭頭，即可查看跨運算、網路和儲存設備層之元件拓撲的總結檢視。發生延遲問題的節點會反白顯示。總結檢視會顯示元件中最嚴重的延遲。例如，如果 VM 有多個虛擬磁碟，則此檢視會顯示所有虛擬磁碟中延遲最嚴重的虛擬磁碟。
. 若要分析資料儲存在一段時間內的延遲和處理量，請按一下資料儲存物件圖示上方的 *Workload Analyzer* 按鈕。您將進入 Workload Analysis 頁面，您可以在該處選擇時間範圍並檢視資料儲存的效能圖表。如需 workload analyzer 的詳細資訊，請參閱 _使用 workload analyzer 對工作負載進行疑難排解_。

== 檢視擴充拓撲

您可以透過檢視虛擬機器的展開拓撲，分別深入查看每個元件。

.步驟
. 在總結拓撲檢視中，按一下 *展開拓撲*。您可以分別查看每個組件的詳細拓撲以及每個物件的延遲數值。如果某個類別中有多個節點（例如資料儲存或 VMDK 中的多個節點），則延遲最嚴重的節點將以紅色突出顯示。
. 若要查看特定物件的 IO 路徑，請按一下該物件以查看 IO 路徑和對應的對應關係。例如，若要查看虛擬磁碟的對應關係，請按一下該虛擬磁碟以檢視其與對應 VMDK 反白顯示的對應關係。如果這些元件出現效能延遲，您可以從 ONTAP 收集更多資料並疑難排解問題。
+
[NOTE]
====
不會針對 VMDK 報告計量。在拓撲中，僅顯示 VMDK 名稱，而不顯示計量。

====
