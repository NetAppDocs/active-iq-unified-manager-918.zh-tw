= 檢視 Active IQ Unified Manager 中待修復的管理操作狀態
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在「管理行動」頁面中檢視您選擇要修正的所有管理行動狀態。在 Unified Manager 將 ONTAP 命令傳送至叢集之後，大多數的行動很快就會顯示為 *Completed*。不過，某些行動（例如移動 Volume）可能需要較長的時間。

管理行動頁面上有三個篩選器可用：

* *已完成* 顯示已成功完成的管理行動和已失敗的行動。*失敗* 的行動會提供故障原因，以便您手動解決問題。
* *進行中* 顯示正在實施的管理行動和計畫實施的管理行動。
* *建議* 顯示目前所有受監控叢集作用中的所有管理行動。


.步驟
. 按一下左側導覽窗格上的 *管理行動*。或者，按一下 *儀表板* 上 *管理行動* 面板頂部的 image:../media/more_icon.gif["更多圖示"]，然後選取您要查看的檢視。
+
顯示「管理行動」頁面。

. 您可以按一下 *描述* 欄位中管理行動旁邊的插入符號圖示，查看有關問題的詳細資訊以及用於修復問題的命令。
. 若要檢視任何 *失敗* 的行動，請在 *已完成* 檢視中依 *狀態* 欄排序。您也可以使用 *篩選* 工具來達到相同的目的。
. 如果您想檢視有關失敗管理行動的更多資訊，或者如果您決定修復建議的管理行動，可以在點擊管理行動旁邊的箭頭圖示後，從展開的區域中點擊 *檢視事件詳細資料*。該頁面上提供 *修復* 按鈕。
