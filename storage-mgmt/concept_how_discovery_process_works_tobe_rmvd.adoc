= 了解 Active IQ Unified Manager 中的叢集探索過程如何運作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
將叢集新增至 Unified Manager 後，伺服器會探索叢集物件並將其新增至其資料庫。了解探索程序的工作原理有助於您管理組織的叢集及其物件。

預設監控間隔為 15 分鐘：如果您已將叢集新增至 Unified Manager 伺服器，則需要 15 分鐘才能在 Unified Manager UI 中顯示叢集詳細資料。
