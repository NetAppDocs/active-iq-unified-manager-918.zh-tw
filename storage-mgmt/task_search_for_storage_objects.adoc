= 在 Active IQ Unified Manager 中搜尋儲存設備物件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要快速存取特定物件，您可以使用功能表列頂部的 *搜尋所有儲存設備物件* 欄位。這種跨所有物件的全域搜尋方法可讓您依類型快速尋找特定物件。搜尋結果會依儲存設備物件類型排序，您可以使用下拉式功能表進一步依物件篩選。

.開始之前
* 您必須擁有下列其中一個角色才能執行此工作：操作員、應用程式系統管理員或儲存設備系統管理員。
* 有效的搜尋詞必須至少包含三個字元。


使用下拉式選單值「全部」時，全域搜尋結果將顯示所有物件類別中找到的結果總數，每個物件類別最多顯示 25 個搜尋結果。您可以從下拉式選單中選擇特定物件類型，以在特定物件類型內縮小搜尋範圍。在這種情況下，傳回的清單不限於前 25 個物件。

您可以搜尋的物件類型包括：

* 叢集
* 節點
* 儲存 VM
* Aggregate
* 磁碟區
* Qtree
* SMB 共用
* NFS 共用
* 使用者或群組配額
* LUN
* NVMe 命名空間
* 啟動器群組
* 啟動器
* 一致性群組


輸入工作負載名稱，即可傳回對應 Volume 或 LUN 類別下的工作負載清單。

您可以點選搜尋結果中的任何物件，導覽至該物件的健全狀況詳細資料頁面。如果某個物件沒有直接的健全狀況頁面，則會顯示父物件的健全狀況頁面。例如，搜尋特定 LUN 時，會顯示該 LUN 所在的 SVM 詳細資料頁面。

[NOTE]
====
連接埠和 LIF 無法在全域搜尋欄中搜尋。

====
.步驟
. 從選單中選擇物件類型，以將搜尋結果縮小到僅包含單一物件類型。
. 在 *搜尋所有儲存設備物件* 欄位中，輸入物件名稱至少三個字元。
+
在此範例中，下拉方塊已選擇「Volume」物件類型。在 *搜尋所有儲存設備物件* 欄位中輸入 "vol1" 將顯示名稱包含這些字元的所有 Volume 清單。
