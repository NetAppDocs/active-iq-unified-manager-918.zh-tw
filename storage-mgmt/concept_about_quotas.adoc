= 了解 Active IQ Unified Manager 中的配額
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
配額提供了一種限制或追蹤使用者、群組或 qtree 使用的磁碟空間和檔案數量的方法。您可以使用  `/etc/quotas` 檔案指定配額。配額應用於特定的 Volume 或 qtree。
