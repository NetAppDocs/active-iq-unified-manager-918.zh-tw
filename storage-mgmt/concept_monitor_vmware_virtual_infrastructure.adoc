= 了解 Active IQ Unified Manager 如何監控 VMware 虛擬化基礎架構
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 可提供對虛擬化基礎架構中虛擬機器（VM）的可見度，並支援監控和疑難排解虛擬化環境中的儲存設備和效能問題。您可以使用此功能來確定儲存環境中的任何延遲問題，或當您的 vCenter Server 上有報告的效能事件時。

在 ONTAP 上部署的典型虛擬化基礎架構包含分佈在運算、網路與儲存設備層的各種元件。虛擬機器應用程式的任何效能延遲，都可能是由於各個元件在相應層級遇到的延遲共同造成的。此功能對於需要分析虛擬化環境中的效能問題，並了解問題發生在哪個元件的儲存設備與 vCenter Server 管理員和 IT 一般人員非常有用。

您現在可以從 VMware 區段的 vCenter 功能表存取 vCenter 伺服器。列出的每個虛擬機器的預覽檢視在拓撲檢視中都有 *VCENTER SERVER* 連結，可在新的瀏覽器中產品發表 vCenter 伺服器。您也可以使用 *展開拓撲* 按鈕來產品發表 vCenter 伺服器，然後按一下 *在 vCenter 中檢視* 按鈕，以檢視 vCenter 伺服器中的資料存放區。

Unified Manager 以拓撲檢視呈現虛擬化環境的底層子系統，以便確定運算節點、網路或儲存設備是否有延遲問題。該檢視還會突顯導致效能延遲的特定物件，以便採取補救措施並解決根本問題。

部署在 ONTAP 儲存設備上的虛擬化基礎架構包含下列物件：

* vCenter Server：用於管理虛擬化環境中 VMware 虛擬機器、ESXi 主機及所有相關元件的集中式控制平台。如需有關 vCenter Server 的詳細資訊，請參閱 VMware 文件。
* 主機：執行 VMware 的虛擬化軟體 ESXi 並託管虛擬機器的實體或虛擬系統。
* 資料存放區：資料存放區是連接至 ESXi 主機的虛擬儲存設備物件。資料存放區是 ONTAP 的可管理的儲存設備實體，例如 LUN 或 Volume，用作虛擬機器檔案（例如記錄檔、指令碼、組態檔和虛擬磁碟）的儲存庫。它們透過 SAN 或 IP 網路連線連接至環境中的主機。對應至 vCenter Server 的 ONTAP 外部資料存放區不受支援，也不會顯示在 Unified Manager 上。
* VM：VMware 虛擬機器。
* 虛擬磁碟：屬於虛擬機器的資料儲存上的虛擬磁碟，其副檔名為 VMDK。來自虛擬磁碟的資料會儲存在對應的 VMDK 上。
* VMDK：資料存放區上的虛擬機器磁碟，為虛擬磁碟提供儲存空間。每個虛擬磁碟都有一個對應的 VMDK。


這些物件呈現在虛擬機器拓撲檢視中。

== 不支援哪些內容

* 位於 ONTAP 之外且對應至 vCenter Server 執行個體的資料存放區，在 Unified Manager 上不受支援。在這些資料存放區上具有虛擬磁碟的任何虛擬機器也不受支援。
* 不支援跨越多個 LUN 的資料存放區。
* 不支援使用網路位址轉換 （NAT） 對應資料 LIF （存取端點） 的資料存放區。
* 在多 LIF 組態中，不支援將 Volume 或 LUN 匯出為具有相同 IP 位址之不同叢集上的資料存放區，因為 Unified Manager 無法識別哪個資料存放區屬於哪個叢集。
+
例如：假設叢集 A 有資料存放區 A。資料存放區 A 透過資料 LIF 匯出，且具有相同的 IP 位址 x.x.x.x，而 VM A 建立在此資料存放區上。同樣地，叢集 B 有資料存放區 B。資料存放區 B 透過資料 LIF 匯出，且具有相同的 IP 位址 x.x.x.x，而 VM B 建立在資料存放區 B 上。UM 既無法將 VM A 拓撲的資料存放區 A 對應至對應的 ONTAP Volume/LUN，也無法對應 VM B。

* 僅支援 NAS 和 SAN Volume（適用於 VMFS 的 iSCSI 和 FCP）作為資料存放區，不支援虛擬 Volume（vVols）。
* 僅支援 iSCSI 虛擬磁碟。不支援 NVMe 和 SATA 類型的虛擬磁碟。
* 這些檢視不允許您產生用於分析各個元件效能的報表。
* 對於僅在 Unified Manager 上的虛擬化基礎架構支援的儲存設備虛擬機器（儲存設備 VM）災難恢復（DR）設定，必須在 vCenter Server 中手動變更組態，以在切換和切回情境中指向作用中的 LUN。如果沒有手冊干預，其資料存放區將無法存取。
