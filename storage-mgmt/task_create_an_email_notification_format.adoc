= 在 Active IQ Unified Manager 中建立使用者和使用者群組配額的電子郵件通知格式
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以為發生配額相關問題（超出軟限制或達到硬限制）時，傳送給使用者或使用者群組的電子郵件建立通知格式。

.開始之前
您必須擁有應用程式系統管理員或儲存系統管理員角色。

.步驟
. 在左側導覽窗格中，按一下 *一般* > *配額電子郵件格式*。
. 在 *寄件者*、*主旨* 和 *電子郵件詳細資料* 欄位中輸入或修改詳細資料。
. 按一下 *預覽* 來預覽電子郵件通知。
. 按一下 *結案* 以結案預覽視窗。
. 如有需要，修改電子郵件通知的內容。
. 按一下 *Save* 。
