= 了解 Active IQ Unified Manager 中的工作負載儀表板
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
工作負載代表儲存設備物件（例如 Volume 或 LUN）的輸入/輸出 (I/O) 作業。儲存設備的資源配置方式取決於預期的工作負載需求。Active IQ Unified Manager 僅在儲存設備物件有流量進出時才會追蹤工作負載統計資料。例如，使用者開始使用資料庫或電子郵件應用程式後，即可獲得工作負載 IOPS 和延遲值。

「工作負載」頁面顯示由 Unified Manager 代管的 ONTAP 叢集的儲存設備工作負載總結。它提供符合效能服務等級的儲存設備工作負載以及不符合等級的儲存設備工作負載的累積概覽資訊。此外，您也可以透過此頁面評估資料中心內各叢集的總容量、可用容量、已使用容量和效能（IOPS）。

[NOTE]
====
建議您評估不符合規範、不可用或未由任何效能服務等級代管的儲存設備工作負載的數量，並採取必要的行動以確保其符合規範、容量使用量和 IOPS。

====
「工作負載」頁面包含以下兩個部分：

* 工作負載總覽：提供由 Unified Manager 代管的 ONTAP 叢集上的儲存設備工作負載數量的總覽。
* 資料中心總覽：提供資料中心儲存設備工作負載的容量和 IOPS 總覽。相關資料以資料中心層級和個別顯示。




[[workloads-overview-section]]
== 工作負載總覽部分

工作負載總覽部分提供儲存設備工作負載的匯總概覽資訊。儲存設備工作負載的狀態會根據已指派和未指派的效能服務等級顯示。

* *已指派*：對於已指派效能服務層級的儲存設備工作負載，將報告下列狀態：
+
** *合格*：儲存設備工作負載的效能取決於指派給它們的效能服務等級。如果儲存設備工作負載在關聯效能服務等級中定義的臨界值延遲範圍內，則它們會被標記為 "`合格`"。合格的工作負載以藍色標記。
** *不符合標準*：在效能監控期間，如果儲存設備工作負載延遲超過相關效能服務層級中定義的延遲臨界值，儲存設備工作負載將被標記為 "`non-conforming`"。不符合標準的工作負載將以橘色標示。
** *無法使用*：如果儲存設備工作負載處於離線狀態，或是無法連線至對應的叢集，則會將其標記為 "`unavailable`"。無法使用的工作負載會以紅色標示。


* *未指派*：未指派效能服務等級的儲存工作負載將顯示為 "`unassigned`"。該數字透過資訊圖示顯示。


工作負載總數是已指派和未指派工作負載的總和。

您可以按一下此區段顯示的工作負載總數，然後在「工作負載」頁面上檢視它們。

「按效能服務層級劃分的一致性」小節顯示可用儲存設備工作負載的總數：

* 符合每種類型的效能服務層級
* 對於指派的效能服務等級與建議的效能服務等級不符的情況

== 資料中心總覽部分

資料中心總覽部分以圖形方式展示了資料中心內所有叢集的可用容量、已使用容量和 IOPS。您可以利用這些資料來管理儲存設備工作負載的容量和 IOPS。該部分還顯示了所有叢集中儲存設備工作負載的以下資訊：

* 您資料中心內所有叢集的總容量、可用容量和已使用容量
* 您的資料中心內所有叢集的總 IOPS、可用 IOPS 和已使用 IOPS
* 基於各效能服務層級的可用容量和已使用容量
* 基於各效能服務層級的可用和已使用 IOPS
* 未分配效能服務等級的工作負載所使用的總空間和 IOPS


*資料中心容量和效能如何根據效能服務等級計算*

已使用容量和 IOPS 是根據叢集中所有儲存設備工作負載的總已使用容量和效能來擷取的。

可用 IOPS 是根據節點上的預期延遲和建議的效能服務層級計算得出的。它包括所有預期延遲小於或等於其自身預期延遲的效能服務層級的可用 IOPS。

可用容量是根據預期延遲和彙總上建議的效能服務等級計算得出的。它包含所有預期延遲小於或等於其自身預期延遲的效能服務等級的可用容量。
