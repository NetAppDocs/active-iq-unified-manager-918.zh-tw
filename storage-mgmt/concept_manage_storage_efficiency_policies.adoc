= 在 Active IQ Unified Manager 中管理儲存設備效率原則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
儲存效率原則（SEP）可讓您定義工作負載的儲存效率特性。您可以在最初建立工作負載時將 SEP 指派給工作負載，或在之後透過編輯工作負載來指派。

儲存效率包括使用資源隨需配置、重複資料刪除和資料壓縮等技術來提高儲存使用率並降低儲存設備成本。在建立 SEP 時，您可以單獨或組合使用這些節省空間的技術，以實現最高的儲存效率。當您將原則與儲存設備工作負載建立關聯時，指定的原則設定會指派給它們。Unified Manager 可讓您指派系統定義和使用者定義的 SEP，以最佳化資料中心的儲存資源。

Unified Manager 提供兩種系統定義的 SEP：高和低。這些 SEP 適用於資料中心的大多數儲存設備工作負載，然而，如果系統定義的 SEP 無法滿足您的需求，您可以建立自己的原則。

您無法修改系統定義的 SEP，或目前已指派給工作負載的 SEP。您無法刪除已指派給工作負載的 SEP，或是唯一可用的 SEP。

「儲存效率原則」頁面列出可用的 SEP，並允許您新增、編輯和刪除自訂的 SEP。此頁面顯示下列資訊：

|===
| 欄位 | 說明 


 a| 
Name
 a| 
SEP 的名稱。



 a| 
類型
 a| 
原則為系統定義或使用者定義。



 a| 
空間保留
 a| 
Volume 是否採用資源隨需配置或完整配置。



 a| 
重複資料刪除
 a| 
工作負載是否啟用了重複資料刪除功能：

* 內嵌：重複資料刪除是在寫入工作負載時進行
* 背景：工作負載中會發生重複資料刪除
* 停用：工作負載已停用重複資料刪除功能




 a| 
壓縮
 a| 
工作負載是否啟用了資料壓縮：

* 即時：資料壓縮在寫入工作負載時進行
* 背景：資料壓縮發生在工作負載中
* 停用：工作負載的資料壓縮已停用




 a| 
工作負載
 a| 
已分配 SEP 的儲存設備工作負載數量

|===

== 建立自訂儲存效率原則的準則

如果現有的 SEP 不符合您儲存設備工作負載的原則要求，您可以建立自訂的 SEP。不過，建議您嘗試將系統定義的 SEP 用於您的儲存設備工作負載，並且僅在必要時才建立自訂的 SEP。

您可以在「所有工作負載」頁面和「Volume / 健全狀況詳細資料」頁面中檢視指派給工作負載的 SEP。您可以在儀表板的「容量」面板和「容量：所有叢集」檢視中，檢視根據這些儲存效率的叢集層級資料減量比率（不含 Snapshot 快照技術複本）。
