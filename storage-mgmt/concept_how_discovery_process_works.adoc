= 了解 Active IQ Unified Manager 中的叢集探索過程如何運作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
將叢集新增至 Unified Manager 後，伺服器會探索叢集物件並將其新增至其資料庫。了解探索程序的運作方式，有助於您管理組織的叢集及其物件。

用於收集叢集組態資訊的監控間隔為 15 分鐘。例如，新增叢集後，需要 15 分鐘才能在 Unified Manager UI 中顯示叢集物件。對叢集進行變更時，此時間範圍同樣適用。例如，如果您在叢集中的 SVM 中新增兩個新磁碟區，則會在下一個輪詢間隔後（最長可能需要 15 分鐘）在 UI 中看到這些新物件。

下列映像說明了探索過程：

image::../media/discovery_process_oc_6_0.gif[探索過程的運作方式]

在發現新叢集的所有物件後，Unified Manager 會開始收集過去 15 天的歷史效能資料。這些統計資料是透過資料連續性收集功能收集的。此功能可在叢集新增後立即提供超過兩週的效能資訊。資料連續性收集週期完成後，預設情況下，系統會每五分鐘收集即時叢集效能資料。

[NOTE]
====
由於收集 15 天的效能資料會佔用大量 CPU 資源，建議您錯開新增叢集的時間，以免資料連續性收集輪詢同時在太多叢集上運作。
