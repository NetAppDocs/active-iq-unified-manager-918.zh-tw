= 從 Active IQ Unified Manager 移除 vCenter 伺服器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以從 Active IQ Unified Manager 執行個體中移除 vCenter 伺服器。例如，如果 vCenter 伺服器探索失敗或不再需要時，您可以移除 vCenter 伺服器。

移除 vCenter 伺服器也會刪除託管在該 vCenter 上的所有虛擬機器（VM）及其組態資料。移除 vCenter 伺服器後，將不再監控該伺服器及其關聯的物件與歷史資料。這些變更將反映在 vCenter 和虛擬機器清單頁面上。

.開始之前
移除 vCenter 伺服器之前，請確保以下事項：

* 您具有 Application Administrator 角色或 Storage Administrator 角色。
* 您應該感知 vCenter 伺服器名稱及其對應的 IP 位址。


.步驟
. 在左側導覽窗格中，按一下 *VMWARE>vCenter*。
. 在 vCenters 頁面上，選取您要移除的 vCenter 伺服器，然後按一下 *移除*。
. 在 *移除 vCenter* 訊息對話方塊中，按一下 *確定* 以確認移除要求。
