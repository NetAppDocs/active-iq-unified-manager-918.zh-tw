= 在 VMware vSphere 上開始使用 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以下載包含根憑證、 `README` 檔案和  `OVA` 檔案的  `.tar` 檔案，並將 Unified Manager 部署為虛擬應用裝置。



[[system-requirements]]
== 系統需求

* 作業系統：VMware ESXi 8.0
* 記憶體：12 GB
* CPU：總計 9572 MHz
* 可用磁碟空間：5 GB（資源隨需配置），152 GB（完整配置）


如需詳細的系統需求，請參閱 link:../install-vapp/concept_requirements_for_installing_unified_manager.html["安裝 Unified Manager 的需求"] 和 link:http://mysupport.netapp.com/matrix["互通性矩陣"]。



[[install-active-iq-unified-manager]]
== 安裝 Active IQ Unified Manager



[[download-the-installer]]
=== 下載安裝程式

. 下載  `.tar` 檔案，其中包含根目錄憑證、 `README` 檔案和  `OVA` 檔案。
. 將檔案儲存到 vSphere 用戶端可存取的本機目錄或網路目錄。
. 在下載 `.tar`檔案的目錄中，輸入 `tar -xvzf ActiveIQUnifiedManager-<version>.tar.gz`命令。+ 所需的 `OVA`檔案、根目錄憑證和 `README`檔案會解壓縮至目標目錄。




[[verify-integrity]]
=== 驗證完整性

您可以依照 `README`檔案中提供的步驟，驗證 `OVA`檔案的完整性。



[[install-unified-manager]]
=== 安裝 Unified Manager

. 在 vSphere 用戶端中，按一下 *檔案 > 部署 OVF 範本*。
. 找到 OVA 檔案，然後使用精靈將虛擬應用裝置部署到 ESXi 伺服器上。
. 在「審查詳細資料」頁面的「發布者」區段中，訊息  `Entrust Code Signing - OVCS2 (Trusted certificate)` 確認了下載的  `OVA` 檔案的完整性。對於訊息  `Entrust Code Signing - OVCS2 (Invalid certificate)`，請將 VMware vCenter 伺服器升級至 7.0U3E 或更高版本。
. 在「自訂範本」頁面的「屬性」標籤中，根據您要執行的安裝類型，按需填寫欄位：
+
** 對於靜態組態，請在所有欄位中輸入所需資訊。不需要新增 *次要 DNS* 欄位的資訊。
** 對於使用 IPv4 的 DHCP，請勿在任何欄位中新增任何資訊。
** 對於使用 IPv6 的 DHCP，請勾選「啟用自動 IPv6 位址分配」方塊。請勿在任何其他欄位中新增任何資訊。


. 啟動虛擬機器。
. 按一下 Console 索引標籤、即可檢視初始開機程序。
. 設定時區。
. 輸入 Unified Manager 維護使用者名稱和密碼。


安裝完成後，將顯示連接到 Unified Manager Web UI 的資訊。
