= 升級 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您只能將 Active IQ Unified Manager 從 9.14 或 9.16 版本升級至 9.18 版本。

升級過程中，Unified Manager 將無法使用。您應該在升級 Unified Manager 之前完成任何執行中的作業。

如果 Unified Manager 與 OnCommand Workflow Automation 執行個體配對，且這兩個產品都有新版本的軟體可用，您必須中斷這兩個產品的連線，然後在執行升級後設定新的 Workflow Automation 連線。如果您僅對其中一項產品執行升級，則應在升級後登入 Workflow Automation，並驗證它是否仍在從 Unified Manager 取得資料。

[NOTE]
====
如果您的系統是從 Unified Manager 9.7 升級而來，由於 Debian 版本中的檔案系統發生了變化，您無法直接從 9.14 升級到 9.18。請依照以下建議的升級路徑進行：9.14 -> 9.16P2 -> 9.18。

====
.步驟
. 請依照 link:task_download_unified_manager_iso_image_vapp.html["下載 Unified Manager ISO 映像"] 中的步驟操作。
. 此外，請依照 link:task_upgrade_unified_manager_virtual_appliance_vapp.html["升級 Unified Manager"] 中所述的步驟操作。
