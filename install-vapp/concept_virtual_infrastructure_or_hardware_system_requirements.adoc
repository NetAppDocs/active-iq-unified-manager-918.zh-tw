= 了解 Active IQ Unified Manager 的虛擬化基礎架構和硬體需求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在虛擬化基礎架構或實體系統上安裝 Unified Manager 應滿足記憶體容量、CPU 和磁碟空間的最低要求。

下表顯示建議的記憶體容量、CPU 和磁碟空間資源值。這些值已經過驗證，可確保 Unified Manager 達到可接受的效能水準。

[cols="2*"]
|===
| 硬體組態 | 建議設定 


 a| 
RAM
 a| 
12 GB



 a| 
處理器
 a| 
4 個 CPU



 a| 
CPU 週期容量
 a| 
總計 9572 MHz（最低要求 9572 MHz）



 a| 
可用磁碟空間
 a| 
* 5 GB（資源隨需配置）
* 152 GB（完整配置）


|===
Unified Manager 可以安裝在記憶體容量較小的系統上，但建議使用 12 GB RAM，以確保有足夠的記憶體容量來實現最佳效能，並使系統能夠在組態擴充時容納額外的叢集和儲存設備物件。您不應在部署 Unified Manager 的虛擬機器上設定任何記憶體容量限制，也不應啟用任何會妨礙軟體使用系統上所分配記憶體容量的功能（例如，記憶體氣球）。

此外，單一 Unified Manager 執行個體可監控的節點數量有所限制，超過限制後您需要安裝第二個 Unified Manager 執行個體。有關節點限制、CPU 和記憶體建議，請參閱link:https://www.netapp.com/pdf.html?item=/media/13504-tr4621.pdf["Unified Manager 最佳實務做法指南"^]。

記憶體頁交換會對系統和管理應用程式的效能產生負面影響。爭奪因主機整體使用率而無法使用的 CPU 資源，可能會導致效能降級。



[[requirement-for-dedicated-use]]
== 專用用途要求

安裝 Unified Manager 的實體或虛擬系統應僅用於 Unified Manager，不應與其他應用程式共享的。其他應用程式可能會使用系統資源，並可能大幅降低 Unified Manager 的效能。



[[space-requirements-for-backups]]
== 備份的空間要求

如果您計劃使用 Unified Manager 備份與恢復功能，請分配額外容量，以便「`data`」目錄或磁碟具有 150 GB 的空間。備份可寫入本機目的地或遠端目的地。最佳實務做法是識別外部於 Unified Manager 主機系統的遠端位置，且該位置至少具有 150 GB 的空間。



[[requirements-for-host-connectivity]]
== 主機連線功能需求

安裝 Unified Manager 的實體系統或虛擬系統應設定為能夠從主機本身成功 `ping` 主機名稱。在 IPv6 組態的情況下，您應驗證對主機名稱的 `ping6` 是否成功，以確保 Unified Manager 安裝成功。

您可以使用主機名稱（或主機 IP 位址）存取產品 Web UI。如果您在部署期間為網路設定了靜態 IP 位址，則您已為網路主機指定名稱。如果您使用 DHCP 設定網路，則應從 DNS 取得主機名稱。

如果您打算允許使用者使用短名稱而不是使用完整網域名稱（FQDN）或 IP 位址來存取 Unified Manager，則您的網路組態必須將此短名稱解析為有效的 FQDN。
