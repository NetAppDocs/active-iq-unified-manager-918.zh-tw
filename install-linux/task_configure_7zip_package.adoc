= 在 Active IQ Unified Manager 中設定 7-zip 軟體包
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要在 Red Hat Enterprise Linux 系統上成功安裝 Unified Manager，您的系統必須設定為能夠存取 7-zip 軟體套件。如果網路存取可用，且防火牆未封鎖 7-zip URL，則 7-zip 會在安裝或升級過程中自動下載到您的系統。NetApp 建議使用自動下載方式。

請確定防火牆未封鎖下列 URL，以允許 Unified Manager 自動下載 7-zip 軟體套件：
`https://7-zip.org/a/7z2301-linux-x64.tar.xz`

或者，您可以預先安裝 7-zip。



[[pre-install-the-7-zip-package]]
== 預先安裝 7-zip 套件

您可以手動下載或使用隨附的指令碼來預先安裝 7-zip。請選擇以下兩種方法之一：



[[download-using-a-bundled-script]]
=== 使用隨附的指令碼下載

.步驟
. 執行 Unified Manager zip 檔案中包含的  `install7zip.sh` 指令碼。




[[download-manually]]
=== 手動下載

請務必僅從官方網站下載 7-zip 套件。

.步驟
. 從官方站台下載 7-zip 軟體包（版本 23.01）：
+
`https://7-zip.org/a/7z2301-linux-x64.tar.xz`

. 將檔案複製到您的 RHEL 虛擬機器：
+
[source, CLI]
----
7z2301-linux-x64.tar.xz
----
. 解壓縮歸檔：
+
[source, CLI]
----
sudo tar -xf 7z2301-linux-x64.tar.xz
----
. 將 `7zz`檔案移至 `/usr/bin/`目錄：
+
[source, CLI]
----
sudo cp 7zz /usr/bin/
----
. 設定執行檔權限：
+
[source, CLI]
----
sudo chmod 755 /usr/bin/7zz
----




[[verify-the-installation]]
== 驗證安裝

請確認 7-zip 軟體包已成功安裝在您的系統上：

[source, CLI]
----
7zz -version
----
