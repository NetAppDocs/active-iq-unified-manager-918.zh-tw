= 了解 Active IQ Unified Manager 中的 Linux 軟體和安裝需求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
安裝 Unified Manager 的 Linux 系統需要特定版本的作業系統和支援軟體。對於 Linux 安裝，Unified Manager 只能安裝在 Red Hat Enterprise Linux 作業系統上。它無法安裝在任何其他作業系統上。



[[operating-system-software]]
== 作業系統軟體

Linux 系統必須安裝以下版本的作業系統和配套軟體：

* 基於 x86_64 架構的 Red Hat Enterprise Linux 8.x 與 9.6 版本


請參閱互通性對照表，以取得支援的 Red Hat Enterprise Linux 版本的完整最新清單。

https://mysupport.netapp.com/matrix["NetApp 相容性矩陣"^]

伺服器應專用於運行 Unified Manager。不得在伺服器上安裝任何其他應用程式。在某些環境中，由於公司原則，Linux 系統上會安裝漏洞掃描器（例如 Qualys）。為避免安裝故障，您應在安裝 Unified Manager 之前停用該漏洞掃描器。


NOTE: 漏洞掃描器（例如 Qualys）在掃描虛擬機器（VM）時可能會導致 CPU 使用率過高，無論是在內部（Unified Manager 和漏洞掃描器安裝在同一台虛擬機器上）還是外部（Unified Manager 和漏洞掃描器安裝在兩台不同的伺服器上，漏洞掃描器掃描安裝了 Unified Manager 的虛擬機器）。此問題通常會導致虛擬機器無回應，並影響 Unified Manager 服務。因此，NetApp 建議停用安裝了 Unified Manager 的虛擬機器中的漏洞掃描器。如果無法停用掃描器，請在非營業時間掃描虛擬機器，並在掃描完成後重新啟動服務。



[[third-party-software]]
== 第三方軟體

Unified Manager 部署在 WildFly Web 伺服器上。WildFly 27.0.1.Final 已與 Unified Manager 捆綁並配置。

以下第三方軟體套件是必要的，但未包含在 Unified Manager 中。如果您已依照下列小節所述設定儲存庫，這些套件會在安裝期間由 `yum`安裝程式自動安裝。

* MySQL Community Edition 8.4.10 版（來自 MySQL 儲存庫）
* OpenJDK 版本 17.0.14+6（來自 Red Hat Extra Enterprise Linux Server 儲存庫）
* Python 3.13.3（來自 Red Hat Extra Enterprise Linux Server 儲存庫）
* 7zip 版本 7z2301-linux-x64。如需詳細資訊，請檢視 link:task_configure_7zip_package.html["設定 7-zip 軟體套件"]。


[NOTE]
====
在升級任何第三方軟體之前，必須先關閉正在執行的 Unified Manager 執行個體。第三方軟體安裝完成後，即可重新啟動 Unified Manager。

====


[[user-authorization-requirements]]
== 使用者授權要求

在 Linux 系統上安裝 Unified Manager，可由 root 使用者或非 root 使用者使用  `sudo` 命令來執行。

此外，預設的 Unified Manager 安裝會在  `/etc/sudoers.d/` 目錄的 sudoers 檔案 (`ocum_sudoers` 和  `ocie_sudoers`）中包含 umadmin 使用者（預設維護使用者）和 jboss 使用者。如果因為安全性原則或安全性監控工具而從您的環境中移除此內容，則必須將其重新加入。您需要保留 sudoers 組態，因為某些 Unified Manager 作業需要這些 sudo 權限。



[[installation-requirements]]
== 安裝需求

以下列出在系統上安裝 Red Hat Enterprise Linux 及相關儲存庫的最佳實務。如果系統安裝或設定方式不同，或部署在異地（雲端），則可能需要額外的步驟，且 Unified Manager 在此類部署中可能無法正常運作。

* 您必須按照 Red Hat 最佳實務安裝 Red Hat Enterprise Linux，並且您應該選擇以下預設選項，這需要選擇「`Server with GUI`」基本環境。
* 在 Red Hat Enterprise Linux 上安裝 Unified Manager 時，系統必須能夠存取適當的儲存庫，以便安裝方案可以存取並安裝所有必要的軟體相依性。
* 若要讓 `yum` 安裝程式在 Red Hat Enterprise Linux 儲存庫中找到相依軟體，您必須在 Red Hat Enterprise Linux 安裝期間或之後，使用有效的 Red Hat 訂閱來註冊系統。
+
如需 Red Hat Subscription Manager 的相關資訊，請參閱 Red Hat 文件。

* 您必須啟用企業版 Linux 額外軟體包（EPEL）儲存庫，才能成功在您的系統上安裝所需的第三方公用程式。
+
如果您的系統上未設定 EPEL 儲存庫，則必須手動下載並設定儲存庫。

+
請參閱 link:task_manually_configure_epel_repository.html["手動設定 EPEL 儲存庫"]。

* 如果未安裝正確版本的 MySQL，則必須啟用 MySQL 儲存庫才能成功在系統上安裝 MySQL 軟體。
+
如果您的系統上未設定 MySQL 儲存庫，則必須手動下載並設定儲存庫。

+
請參閱 link:task_manually_configure_mysql_repository.html["手動設定 MySQL 儲存庫"]。

* 您的 Unified Manager 主機上只能安裝一個 Java 版本；否則，系統可能無法確定要使用哪個版本。請參閱 https://kb.netapp.com/data-mgmt/AIQUM/AIQUM_Kbs/After_updating_Java_on_the_Active_IQ_Unified_Manager_host_services_will_not_start["在 Active IQ Unified Manager 主機上更新 Java 後，服務將無法啟動"]。


如果您的系統沒有網際網路存取，且儲存庫未從連網系統鏡射到未連網系統，您應遵循安裝指示來判斷系統的外部軟體相依性。然後，您可以將所需的軟體下載到連網系統，並將  `.rpm` 檔案的複本複製到您計畫安裝 Unified Manager 的系統。若要下載成品與套件，您必須使用  `yum install` 命令。您必須確保兩個系統執行相同的作業系統版本，且訂閱授權適用於適當的 Red Hat Enterprise Linux。

[NOTE]
====
您不得從此處列出的儲存庫以外的其他儲存庫安裝所需的第三方軟體。從 Red Hat 儲存庫安裝的軟體專為 Red Hat Enterprise Linux 設計，並符合 Red Hat 最佳實務（目錄佈局、權限等）。來自其他地點的軟體可能不符合這些準則，這可能會導致 Unified Manager 安裝失敗，或導致未來升級出現問題。

====


[[port-443-requirement]]
== 連接埠 443 要求

通用版 Red Hat Enterprise Linux 映像可能會區塊外部存取 443 連接埠。由於此限制，安裝 Unified Manager 後您可能無法連線至管理員 Web UI。執行下列命令可允許通用版 Red Hat Enterprise Linux 上的所有外部使用者和應用程式存取 443 連接埠。

`# firewall-cmd --zone=public --add-port=443/tcp --permanent; firewall-cmd --reload`

您必須安裝具有「Server with GUI」基礎環境的 Red Hat Enterprise Linux。它提供 Unified Manager 安裝說明中使用的命令。其他基礎環境可能需要您安裝額外的命令來驗證或完成安裝。如果您的系統上無法使用  `firewall-cmd`，您必須執行下列命令來安裝它：

`# sudo yum install firewalld`

在執行命令之前，請聯絡您的 IT 部門，以了解您的安全性策略是否要求採用不同的操作流程。

[NOTE]
====
在 Red Hat 系統上應停用 THP （透明大頁）。啟用後，在某些情況下，當某些程序使用過多記憶體容量並被終止時，可能會導致 Unified Manager 關閉。
