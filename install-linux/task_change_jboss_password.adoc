= 在 Active IQ Unified Manager 中更改 JBoss 密碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以重設安裝期間設定的特定執行個體 JBoss 密碼。如果您的站台需要此安全性功能來置換 Unified Manager 的安裝設定，您可以選擇性地重設密碼。此作業也會變更 JBoss 用於存取 MySQL 的密碼。

* 您必須擁有安裝 Unified Manager 的 Red Hat Enterprise Linux 系統的 root 使用者存取權。
* 您必須能夠存取目錄 `/opt/netapp/essentials/bin`中由 NetApp 提供的 `password.sh`指令碼。


.步驟
. 以 root 使用者身分登入系統。
. 請依所示順序輸入以下命令，停止 Unified Manager 服務：
+
`systemctl stop ocieau`

+
`systemctl stop ocie`

+
請勿停止相關的 MySQL 軟體。

. 請輸入以下命令開始密碼更改程序：
+
`/opt/netapp/essentials/bin/password.sh resetJBossPassword`

. 出現提示時，輸入新的 JBoss 密碼，然後再次輸入以進行確認。
+
請注意，密碼長度應為 8 到 16 個字元，並且必須至少包含一個數字、一個大寫字母和一個小寫字母，以及以下特殊字元中的至少一個：

+
`+!@%^*-_+=[]:<>.?/~+`

. 指令碼執行完畢後，請依所示順序輸入下列命令啟動 Unified Manager 服務：
+
`systemctl start ocie`

+
`systemctl start ocieau`

. 所有服務啟動完畢後，即可登入 Unified Manager 使用者介面。
