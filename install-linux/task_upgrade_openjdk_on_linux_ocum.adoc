= 升級 Linux 上的 OpenJDK 以支援 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以將安裝 Unified Manager 的 Linux 伺服器上的 OpenJDK 升級至較新版本，以取得安全性漏洞的修復程式。

.開始之前
您必須擁有安裝了 Unified Manager 的 Linux 系統的 root 權限。

您可以在版本系列內更新 OpenJDK 版本。例如，您可以從 OpenJDK 11.0.14 升級到 OpenJDK 11.0.17，但不能直接從 OpenJDK 11 更新到 OpenJDK 12。

.步驟
. 以 root 使用者身分登入 Unified Manager 主機。
. 下載適當版本的 OpenJDK（64-bit）至目標系統。
. 停止 Unified Manager 服務：
+
`systemctl stop ocieau`

+
`systemctl stop ocie`

. 在系統上安裝最新版本的 OpenJDK。
. 啟動 Unified Manager 服務：
+
`systemctl start ocie`

+
`systemctl start ocieau`
