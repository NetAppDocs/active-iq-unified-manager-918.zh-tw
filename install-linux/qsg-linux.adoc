= 在 Linux 上開始使用 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以下載安裝套件，並將 Unified Manager 安裝在實體或虛擬的 Red Hat Enterprise Linux 平台上。



[[system-requirements]]
== 系統需求

* 作業系統：Red Hat Enterprise Linux 8.x 和 9.4 版本，基於 x86_64 架構，使用作業系統安裝程式的「軟體選擇」選項中的「具有圖形使用者介面的伺服器」基本環境進行安裝
* RAM：12 GB，CPU：總計 9572 MHz
* 可用磁碟空間： `/opt/netapp/data` 目錄需要 100 GB 的磁碟空間，根目錄分割區需要 50 GB。對於單獨掛載的 `/opt` 和 `/var/log` 目錄，請確保 `/opt` 有 15 GB、 `/var/log` 有 16 GB，且 `/tmp` 有 10 GB 的可用空間。


如需詳細的系統需求以及在安全的站台中安裝產品的相關資訊，請參閱 link:../install-linux/concept_requirements_for_install_unified_manager.html["安裝 Unified Manager 的需求"] 和 link:http://mysupport.netapp.com/matrix["互通性矩陣"]。



[[install-active-iq-unified-manager]]
== 安裝 Active IQ Unified Manager



[[download-the-installer]]
=== 下載安裝程式

. 下載 `ActiveIQUnifiedManager-<version>.zip`安裝套件以及程式碼簽章憑證(`.pem`）和數位簽署(`.sig`）。
. 在您下載安裝檔案的目錄中，執行：
+
`# unzip ActiveIQUnifiedManager-<version>.zip`





[[verify-integrity]]
=== 驗證完整性

執行下列命令以驗證安裝程式套件的完整性：

* 執行 `openssl x509 -pubkey -noout -in AIQUM-RHEL-CLIENT-INTER-ROOT.pem > <public_key_file_name>`以建立包含程式碼簽署憑證公鑰的檔案。
* 執行  `openssl dgst -sha256 -verify <public_key_file_name> -signature <signature_file_name> ActiveIQUnifiedManager-<version>.zip` 以驗證安裝程式套件上的簽署。




[[verify-repository-configuration]]
=== 驗證儲存庫組態

設定 Red Hat Enterprise Linux 儲存庫的程序會因站台而異。您可以使用安裝套件中包含的  `pre_install_check.sh` 指令碼來驗證作業系統的組態。如果您的系統已連線至網際網路，您將自動收到設定 Red Hat Enterprise Linux 儲存庫的指示。

`# sudo ./pre_install_check.sh`



[[install-unified-manager]]
=== 安裝 Unified Manager

Unified Manager 使用  `yum` 公用程式來安裝軟體和任何相依軟體。由於 Red Hat Enterprise Linux 的映像有所不同，因此安裝的套件取決於映像中存在的軟體。 `yum` 公用程式會決定要安裝的相依軟體套件。如果您需要有關相依軟體套件的更多資訊，請參閱 link:../install-linux/reference_red_hat_software_and_installation_requirements.html["Linux 軟體和安裝需求"]。

若要安裝 Unified Manager，請以 root 使用者身分或使用 `sudo`，從解壓縮安裝檔案的目錄執行下列命令：

`# yum install netapp-um<version>.x86_64.rpm`

或

`% sudo yum install netapp-um<version>.x86_64.rpm`

安裝完成後，將顯示連線至 Unified Manager Web UI 的資訊。如果您無法連線至 Web UI，請參閱軟體隨附的 `README`檔案，以取得有關連接埠 443 限制的詳細資訊。
